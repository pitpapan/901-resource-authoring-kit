# RE 常规低中阶特性速查（901 资源估价材料）

**身份**：本页汇总 RE v1.03 的特性数量、判例及注明身份的撰写检查要求，**不是 901 已采用的统一购价、已获能力或平衡批准**。出处的条名指向具体条目；单项接入时核对动作、能耗、范围、触发、防护、资格与叠加。原文索引：[数值类特性](../content/RE/04_traits/可以确认的特性/数值类特性.md)（N）、[乱七八糟的记录](../content/RE/04_traits/可以确认的特性/乱七八糟的记录.md)（Z）、[负面特性相关算法](../content/RE/04_traits/可以确认的特性/负面特性相关算法.md)（F）、[RE 撰写规则](../content/RE/01_rules/03_其他规则/撰写规则.md)（W）。

## 先核预算与限制

| ID | RE 原文基准；901 使用边界 |
| --- | --- |
| TB-01 模板总额 | W 第32—36行“能力组模板”：各级 **4 个普通同级特性＋额外的同级技能树开启特性**；不要把树入口从普通4特性中再扣一次。可与样板 S-06 武士 D级“力量双特性＋两招＋树”对照。无池能力组D级为 **6D普通效果＋D树入口**；C级为 **4C普通效果＋C树入口**。未用容量可保留但须明列，不写成已花完，也不以空预算代替强度校准；XP 模板价与实际投入估价分开，不按余量比例自动折价。没有技能树则原模板不予收录。W“技艺／能量模板”：各级基础 **3 个同级特性**；位于已交付树入口的兑换下，**每项技艺各＋1，共4个同级特性**；支付双倍分数＋1、适用施法规则＋1各另有前提。血统／改造同级4、瞳术同级3，另有各自条件，不能借给能力组。 |
| TB-02 能量池补偿 | W 对血统、瞳术、改造、能力组均写 **D 级**可开启能量池；没有能量池得 2 个特性。只在该模板的 D 级按条件核算，不能每一级重复领，也不能给未列出的技艺／物品套用。 |
| TB-03 级别换算 | [RE 能力段](../content/RE/01_rules/01_建卡与属性/能力段.md)旧支线可 3D↔1C；这是**预算单位**换算，不代表 1C 的数值必为 1D 的三倍。N“数值税”例：攻击常规加值 1D＝3，1C＝6；重复投入 7D 仅＝15 而非 21。进阶是追加新特性还是替换旧特性必须单写；数值税本身不决定旧级收益丢失或叠加。属性另有按属性数量变化的免税段；绝不能照搬九属性全属性表到 901 六属性。 |
| TB-04 叠加及负面 | N 开头：非同项资源同类加值默认不叠加；若设可叠加，除闪避防御外数值通常减半。F 开头：负面特性收益受**该资源当前等级、负面影响程度和该负面影响上限**共同约束，D 级限制不能堆出 S 级总额。F 的“卖锁”、伤害易伤等是特定负面条件，不是默认加特性或 XP 规则。901 的 DR／能量抗力另按[常用规则卡 CR-06](common_rules.md)取最高。 |
| TB-05 类比与实际收益 | [类比核算](calibration.md)：明价、整套原型类比与未定标分开；原型的前置购买、条件、动作、能耗、目标、持续和叠加须一起比较。捆绑效果无独立单价时不得任意拆分；跨人授予、增目标、移除能耗等不能默认各值1特性。没有明价不等于不能估价：可由多个一致近例支持候选并解释差异，见S-10。容量凑满不等于估价通过。另核本体＋技艺的实际收益：被同类高值覆盖的加值不能宣称额外提升。 |
| TB-06 能力组与属性 | W 能力组模板无禁止属性条款；[武士](../content/RE/02_resources/能力组/近战类型/武器类型/武士.md)第9—13行直接用双D特性购买力量＋2。[属性值的增减](../content/RE/01_rules/01_建卡与属性/属性值的增减.md)第8—22行允许能力给予永久属性加值，并区分基础属性与能力加值。可据此用普通特性配置属性，但901六属性映射、加值类型／叠加、派生值及6／11等节点收益须写清；旧式15XP只是候选，不能由RE预算自洽推出901已采用，也不能由普通升级价直接反推资源价。本库稿件另遵守TB-07的用户设计上限。 |
| TB-07 设计边界与属性投入 | **用户指定的本库撰写约束，非RE新禁令：能力组每一级最多使用2个同级特性强化属性**，D阶≤2D、C阶≤2C，按实际投入预算计，不按属性点数、项数或表格行数计，不要求用满。各阶新增投入分别计数，继承旧阶收益不重复计入。依[指南](guide.md)先定训练内容、岗位和实际收益，再找近例估价；常规攻防、先攻、技能、耐受和装备训练可构成本体，不强制每阶特殊招牌或新动作，也不设任意攻防上限。通用训练覆盖代表岗位，护卫等专门职责可选。修订时保留用户指定骨架，区分规则错误、估价缺口与审美偏好，不整套改换主题；仅对复杂交互做短场景检查。 |
| TB-08 固有性质与额外保护 | 依[类比核算](calibration.md)先固定版本与结算阶段，把数值收益、类别固有交互、额外抵抗整体减防分别记账。某减防机制的目标清单不含该类别，原本就不能削去它；这一性质不另收费，不代表防御数值免费或免疫所有减防。只有超出既有交互的保护才单独找明价／完整近例；无价时标缺口，不能用剩余容量倒推价格。RE 将偏斜并入力场的版本变更不自动进入 901；伤害阶段的吸收／DR 保护不能直接套价到防御 DP。 |
| TB-09 按机制寻找样板 | **检索方法，非新增特性价表：**特性表没有直接条目的任何机制，都可依[样板检索流程](calibration.md#按机制寻找样板)作类比，不限于成长加值。按触发、对象、结算阶段和近义措辞跨类别检索，先看少量机制接近的同阶、低阶完整阶段，高阶仅按需交叉比较；核全部前提、动作、能耗、持续与捆绑收益。无需逐字同构或独立组件明价，须解释差异和候选估价；不任拆整包或倒填预算。证据不足时定点补查，仍不能约束的部分标具体缺口；同批复用已有记录，不反复通读。 |

## 可检索的具体特性

“预算”保留原书写法；同一行的限制是生效范围或取得预算的条件，不能省去。N、Z、F 均指上方所链的原文页。

| ID／条目与精确出处 | RE 预算及必要条件 | 901 适配注意 |
| --- | --- | --- |
| T-01 单项属性；N“数值类特性／某项属性” | 1D＝1 点。N“属性的免税阶段”另列单／双／多属性跨级曲线。 | 六属性职责已改变，先定作用于哪一项；旧九属性曲线不能直接当六属性模板。 |
| T-02 指定技能检定；N“某项技能检定” | 1D＝＋3 DP；默认同类加值不跨资源叠加。 | 指明主技能领域及适用子项；加值不授予训练资格或子技能等级。 |
| T-03 攻击检定；N“攻击检定” | 1D＝＋3 DP；跨级和重复投入受数值税。 | 仅改攻击 DP，不自行提高武器伤害、上限或实际伤害。 |
| T-04 防御；N“防御” | 1D＝＋3 防御；叠加例外见 N 开头。 | 指明基础／闪避／格挡等防御类型，避免在攻击与伤害阶段重扣。 |
| T-05 单项豁免；N“单项豁免” | 1D＝＋6；“三豁免”则 1D＝＋3。 | 先明确反射／强韧／意志及旧属性映射；不通用于所有抵抗。 |
| T-06 先攻；N“先攻” | 1D＝＋4。 | 901 新卡基础先攻为敏捷＋风度；已有卡面异式优先。 |
| T-07 小众检定；N“小众DP检定” | 限不用于攻击的某技能某小众专业、限定低收益用途，**至多** 1D＝＋6 等效。 | 必须写清场景和动作资格；不能把“至多”当无条件 ＋6。 |
| T-08 单能量抗力；N“单能量抗力” | 1D＝4 点；仅对应单一能量。 | 指明伤型；同类抗力无明示叠加时取最高，其他防护类别另算。 |
| T-09 实际伤害后附加；N“攻击造成实际伤害时附加…” | 1D＝1 点常规同类伤害／异常点；若可豁免，可变为 1D＝2 点。 | 触发点是实际伤害，写明额外段、豁免和是否再经防护。 |
| T-10 无视防护数值；N“无视至多2点…” | 1D＝无视至多 2 点减免、吸收、抵消、转化或硬度。 | 要指明所针对的防护和伤型。此项不是【破甲】关键字的单价；RE破甲不穿DR，剩余可破硬度，见CR-09；旧PHB装备兼容口径不能反套到明确采用RE关键字的新资源。 |
| T-11 技能等级提升；N“每个D/C/B/A特性…” | D/C/B/A＝＋1/＋1/＋2/＋4 技能等级；提升后上限分别 5/7/11/15。 | 901 需逐项确定落在主或子、是否受主 5 上限、自动成功及前提；不是直接送 XP。 |
| T-12 移动方式速度；N“某种移动方式…” | 2D＝该移动方式速度提升 1 倍；另“速度提升20米”＝1D。 | 指明移动方式、基础速度和动作价格；不额外赋予该移动方式。 |
| T-13 水下行动；Z“功能类／1D” | 1D＝水下呼吸、等同移动速度的游泳速度、免受水下环境负面影响。 | 仅水下环境；相关攻击、动作、特殊状态仍看具体来源。 |
| T-14 跳跃助跑；Z“功能类／1D” | 1D＝跳跃总视为已最大助跑。 | 不替代运动检定与位移资格。 |
| T-15 感知盲视；Z“整理记录” | 模糊感知范围等同盲视＝1B；敏感感知范围等同盲视＝1C。旁列盲感 1C 后有问号，**不可定标**。 | 901 正常视觉敏感距离不生成盲视；须核定位、障碍与感官来源。 |
| T-16 飞行；Z“整理记录” | 等同移动速度、机动性普通＝2D；良好 1C；完美 4D。 | 高机动等级原文缺进一步动作说明，接入时逐项定转向／停留。 |
| T-17 反射半速移动；Z“整理记录” | 反射动作以飞行速度／速度半速移动＝3C；2AP 反射版另列 3C 且 1 轮冷却／每轮一次。 | 反射锁照 CR-04；2AP 只定动作价格，效果仍须选具体版本。 |
| T-18 以技能代格挡；Z“防御面／1D” | 1D＝某技能替代原技能进行白刃／肉搏格挡。 | 只替换指定技能项，按 901 主＋匹配子求有效值；不免除格挡资格。 |
| T-19 以属性代检定；Z“属性替换类／1D” | 1D＝某属性替换某个**单项**检定所用属性；另 1D 可替换某一个衍生属性的计算属性。 | 旧属性→六属性须按职责决定；不扩成“全部检定／衍生值”替换。 |
| T-20 心灵负面点数减少；Z“整理记录” | 1D＝受影响心灵的负面点数时先减 4 点；1C 版本另给意志＋3。 | 按实际异常来源和伤害流程接入，不能当普适 DR。 |
| T-21 伤势自然恢复降级；N“将伤势视为降低一级…” | 1D＝**自然恢复时**伤势视低一级；原文例：2 天恢复 1A、15 分钟恢复 1L、一次短休移除所有 B。 | 仅自然恢复，不改即时 B/L/A 入槽或即时伤害降级。 |
| T-22 无法持用通常物品；F“失去某种行为能力…” | 1D **负面**特性；针对性变形可使其重新能持用。 | 先判断资源确有限制与对应等级；901 无默认 XP 收益，不能以描述性限制自动换预算。 |
| T-23 缩短单次攻击动作；N“以5/4/3/2/1AP进行一次攻击” | 5／4／3／2／1AP单次攻击分别为2D／2C／2B／2A／2S；不同于6AP内增加一次攻击的5D且一轮冷却。 | 4AP攻击＝2C，在901转为移动动作攻击；不是移动后再附送攻击，也不是2AP攻击只需2C。攻击所需距离、耗材和资格仍须满足，其他AP价格待适配；动作映射不自动赠送位移或解除反射锁。 |
| T-24 动作消耗带来的预算补偿；N第78—84行 | 2AP／自由动作通常不增加甚至酌情扣除；4AP增加1个次级特性；6AP增加1个同级特性；8AP增加1个同级＋1个次级特性；10／12AP另有倍率或加特性方案，须读原表。 | 对本项确实支付的启动动作核一次补偿，不给每个组件各领一次，也不把其他行动的消耗无条件视为本资源的新代价。RE白刃格挡为4AP（原文称标准动作），901映射为移动动作；C级若按此表计补偿为＋1D，不是＋1C。用户另定容量则明确标为本项采用值，不伪称原表；仍不得为多领容量擅自改动作。 |
| T-25 属性／技能等值加值；N第45—48行 | 属性关联杠杆默认属性32；技能等级杠杆D／C参照6、B参照8、A以上参照9；技能附加成功杠杆D—B参照2、A以上参照3。复数取低等情形另有收益率调整。 | 这些是估价参照，不是角色上限。RE传奇属性点数与901属性固定自动成功均在6／11／16……增长，属性32对应6点；不要无依据挑1—3点压低报价。还应比较完整成长资源，例如[智剑平八方](../content/RE/02_resources/能量/剑气.md)的D+500同时给传奇智力等值白刃检定与持武器闪避防御；不能只用高阶样板，也不能把整包任拆成明价。 |

另见 [RE 撰写规则原文](../content/RE/01_rules/03_其他规则/撰写规则.md) 的模板差异，及 [资源判例](../content/RE/04_traits/可以确认的特性/资源判例.md) 对实际能力的特性核算。判例中的 AP、能耗、冷却、单次或范围作用均是该案条件，不能单抽倍率作通则。
