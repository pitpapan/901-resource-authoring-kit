# 901 常用规则卡（资源撰写用）

本页只摘录已采用的通则和原书估价基准；单项能力仍须核对原文、取得记录与 901 接入决定。**901 已采用**见 [核心规则 v0.1](../rules/901-core-rules-v0.1.md)，未定事项见 [按需决策](../rules/901-open-decisions.md)。下列 ID 供草案定位，不是新规则编号。

| ID／问题 | 简要判据 | 身份与出处 |
| --- | --- | --- |
| CR-01 权威先后 | 901 已确认村规及修订 → 已接受融合架构 → 未替代 PHB v0.3 → 经选择适配的 RE v1.03 → 未采用建议。旧角色当期已确认卡面及明确异式优先于缺失字段的基础式。D/C/B/A/S 是原书资源级别，不能推出两版同战力或 901 取得资格。 | **901 已采用**：[核心规则 §1、§3](../rules/901-core-rules-v0.1.md)。 |
| CR-02 六属性、技能和资格 | 力量（含旧耐力／体质职责）、敏捷、智力、感知、意志（含旧决心／沉着）、风度（含旧操控）。九属性旧式按功能转译，不能机械相加。旧普通技能→主技能，旧专业／原生子项→子技能；有效值 `E＝主＋一个最贴切匹配子`，无匹配子项时只用主。主上限 5；子无固定上限。旧“专业：X”资格须对应子技能≥1；旧数字技能前提用相应 `E`。 | **901 已采用**：[核心规则 §1、§3](../rules/901-core-rules-v0.1.md)；原书 [PHB 技能](../content/PHB/01_rules/技能详述.md)、[RE 技能概述](../content/RE/01_rules/01_建卡与属性/技能概述.md)。 |
| CR-03 检定和普通操作 | 先判断行动、知识、目标与能力资格，再组骰池。PHB D10 每颗 8–10 算 1 成功，10 加骰；DP≤0 投机运骰，只有 10 产生成功。901 属性／技能自动成功在**合法检定**中即使掷骰 0 成功仍计入，不能创造操作资格；若单项引入 RE“附加成功”，保留其有效掷骰成功数>0门槛。普通主动对抗事先定主动方，其成功数达到被动方即成功；RE 同值重投未整体采用。 | **901 已采用＋PHB 继承**：[核心规则 §2](../rules/901-core-rules-v0.1.md)、[PHB 基本规则](../content/PHB/01_rules/基本规则.md)。训练资格仍以具体条目为准。 |
| CR-04 动作与反应锁 | 每回合至多标准×1、移动×1、迅捷×1；标准→移动、移动→迅捷，不能逆换。普通攻击＝标准；五尺快步＝移动。反射可中断，但用后直到下一次行动结束，不得再用反射或迅捷；响应占反射，在他人两动作间作一个标准，并跳过自己下一次行动。RE 固定价格 2／4／6／8AP → 迅捷／移动／标准／标准＋迅捷；冲锋按移动＋标准。 | **901 已采用＋PHB 继承**：[核心规则 §4](../rules/901-core-rules-v0.1.md)、[PHB 行动](../content/PHB/01_rules/非战斗行动与战斗行动.md)、[RE 场景与动作](../content/RE/01_rules/02_战斗与动作/场景与动作.md)。不运行 AP 池；其他 AP 价格、减费、恢复、额外次数**待单项适配**。 |
| CR-05 攻击、伤害与破甲 | 普通攻击沿 PHB 武器式，旧技能项换 `E`。如近战白刃：DP＝力量＋`E(白刃)`＋武器伤害－目标防御；上限＝武器伤害＋`E(白刃)`＋力量。通常每个最终成功造成 1 点伤型伤害，受上限限制。结算分 A 攻击与上限、B 免疫／减免／有来源的硬度吸收 DR 等、C 临时生命及 PHB B/L/A 入槽；区分命中、造成伤害、实际伤害。防御在 DP 仅扣一次。仅写“破甲 X”的旧 PHB 装备按装甲语义逐层消耗；RE 破甲／破魔／高速按具体类别单项适配。 | **901 已采用**：[核心规则 §5](../rules/901-core-rules-v0.1.md)、[PHB 行动](../content/PHB/01_rules/非战斗行动与战斗行动.md)、[PHB 装备](../content/PHB/01_rules/装备与装备位.md)、[RE 伤害流程](../content/RE/01_rules/02_战斗与动作/伤害处理流程.md)。混合／多段及定值效果**待单项适配**。 |
| CR-06 同类加值与防护 | 同次伤害多个适用的同类物理 DR／能量抗力，未明写叠加时取最高；写明“增加／额外／叠加”才依来源累加。此规则不能外推到吸收、硬度、抵消。RE 数值特性默认“非同项资源的同类加值不叠加”；可叠加加值除闪避防御外通常数值减半，此句只作 **RE 原文基准**，接入时须标明加值类型和来源。 | DR 部分 **901 已采用**：[核心规则 §5](../rules/901-core-rules-v0.1.md)；数值加值部分 **RE 原文基准／待单项适配**：[RE 数值类特性](../content/RE/04_traits/可以确认的特性/数值类特性.md)。 |
| CR-07 XP 与旧报价 | 属性普通升 1＝6XP，升到 6／11／16…＝12XP 并得自动成功及大能；主技能普通＝3XP、升到 5＝9XP 并得自动成功；子技能普通＝3XP、升到 5／10／15…＝9XP 并每满 5 得自动成功。普通专长逐级支付该级×3XP。节点 XP 由主持明确宣布，可为 0；训练天数不自动产 XP。自学能力逐项确认可学范围、XP 价格、训练条件后才可支付。 | **901 已采用**：[核心规则 §3](../rules/901-core-rules-v0.1.md)。[RE 撰写规则](../content/RE/01_rules/03_其他规则/撰写规则.md)的支线＋分数及旧自学换算只是**单项核价候选**，不是全体 901 通用报价；负面特性没有默认 XP 收益或赎买价。 |
| CR-08 取得与特性预算 | 血统、改造等需剧情来源；XP 足够本身不授予取得资格。RE 模板的“同级特性数”只用于估计单项资源容量，须算技能树开启、能量池、额外条件与限制；最终效果、叠加和价格由接入决定。 | 资格 **901 已采用**：[核心规则 §3](../rules/901-core-rules-v0.1.md)；预算为 **RE 原文基准／估价候选**：[RE 撰写规则](../content/RE/01_rules/03_其他规则/撰写规则.md)。 |

**待定只在使用时处理**：AP 特例、具体能量池、非普通伤害段、负面特性收益、补正、旧属性／专业前提、每项自学能力的条件与报价，见 [按需决策](../rules/901-open-decisions.md)。

**旧 RE 自学价格候选（CR-07）**：[RE 自学规则](../content/RE/01_rules/03_其他规则/自学规则.md)原式 `ceil(D支线个数×5＋分数/100)`；D＋500＝10XP，C＋1000＝25XP，能力组 D＋1000＝15XP／C＋2000＝35XP。各等级报价是该级**增量而非累计总价**。这些数字仅供单项接入时比较、核价，不能跳过可学范围与剧情／训练条件，也不启用原书“训练天数产 XP”。

**命名**：资源门类统一称“能力组”；“称号／训练”只作旧称检索词。普通技能领域及主／子技能，与资源门类“技艺”分别记录，避免同名词混用。
