# 帝国军伍能力组与配套技艺

2026-10-17，完整汇总稿。按用户确认版本整理，保留既定效果、前提、预算与 XP 报价。适用帝国重玩世界的普通正规士兵、老兵和精锐成员，设计目标上限为用户指定的 T3。采用 RE 的能力组与技艺分类，按 901 已确认的六属性、主／子技能、PHB 动作及伤害规则结算；未定标的技艺预算仍须作者裁定。

这套军中课程让士兵可靠地使用兵器、承担行军与警戒、在同伴身边作战，并在进一步训练后承担突击、掩护和协同任务。它由一个两阶能力组和九项可选技艺组成；“受训战兵”“精锐战兵”是课程阶段的名称，不授予军衔、军职或指挥权。

## 共通结算

- **有效技能 E**＝主技能＋本次最贴切的一个子技能。能力组不给技能赠级，不另开“军伍熟练度”数值层。已掌握的普通协同、急救、搬运救援、潜行、骑乘等仍可照常尝试；本套资源提供的是明确的额外收益。
- **受训兵器**：角色满足装备使用条件，对应主技能至少 1、匹配兵器子技能至少 1 的手持武器。近战沿白刃，弓沿弓箭，弩沿 PHB 的枪械主技能配“弩”子技能。弩子技能加值只用于弩；主技能在其所属领域照常适用，其他武器的训练和装备前提仍按原规则。投掷沿相应武器与运动规则。
- 本套相同类型的判定／防御加值在同次结算取最高；能力组明确写出的 D、C 两阶累计攻防是同一来源的累计值，先合成一个数值，再与外部同类加值比较。数值检定加值不提高技能等级，不产生门槛自动成功，也不提高伤害上限。
- **破甲**：贯甲打击明确采用 RE 的【破甲 X】：依次削减掩蔽、力场、器械、格挡中的盾牌防御、盔甲防御、天生防御；破尽可破防御后，余量每点再破 1 点硬度。破尽相应盾／甲／天生防御时，相关防护关键字依 RE 原文在本次伤害流程失效。不穿透 DR、吸收或能量抗力，也不提高伤害上限。本套技艺与武器自带的同类破甲取高，不额外相加；旧 PHB 装备单写的破甲仍按其自身条文处理。
- 一次攻击只能使用一项改写该攻击动作的主动技艺；被动效果与合条件的辅助效果仍照常适用。招式加值取最高。多次攻击技艺不能相互套用来倍增次数。
- 标“冷却 1 轮”的技艺，在本次行动使用后，下一次自己的行动仍不能使用，至再下一次行动才恢复。各技艺分别计冷却；被动技艺无冷却。
- 反射动作占用 PHB 的反射／迅捷限制：使用后至下一次自己行动结束前，不再使用反射或迅捷。移动均走实际可通行路径，仍受障碍、负重和脱离威胁范围规则影响。
- 除正文另有说明，各项不消耗意志点或特殊能量，也不产生能量。斗气、魔法及魔导器的学习与取得依其自身来源处理。

## 帝国军伍能力组

### D 阶 受训战兵

**类型与价格：**能力组，D 阶，15 XP。普通训练与经验形成的能力；效果无需超自然能量维持。

**学习条件：**完成相应兵器操练、队列协同、行军营地、警戒与军令训练；至少一种受训兵器的 E≥3，运动和求生主技能各≥1，意志≥2。可以通过帝国军队教导或具备这套课程的教官传授。没有固定“练若干天便自动获得”的规定，训练本身不产生 XP。

这些数值是本资源候选的学习前提，不将其写成全国征兵、服役或晋升标准。

**效果：**

| 特性 | 实际收益 |
| --- | --- |
| | 使用受训兵器攻击时获得 **+3DP 专长加值**。 |
| 临阵防护 | 保持意识且能察觉攻击时，防御获得 **+3 洞察加值**；适用防御被该攻击忽略时，这项加值也不保留。 |
| 警醒先手 | 先攻获得 **+4 专长加值**。不会因此自动察觉伏兵或免疫突袭。 |
| 行军耐受 | 抵抗疲惫、缺水、饥饿和窒息所作的身体耐受检定获得 **+6DP 专长加值**；依该效果实际要求使用力量或强韧骰池。不会免除饮食、休息和呼吸需求。 |
| 野外起居 | 仅在辨方向、寻找食水、选择及搭设普通营地的求生检定中获得 **+3DP 专长加值**。三项仍是原稿的同一野外维持训练范围；追踪敌军、战斗和魔法辨识不在此范围。通常可做的野外操作不以购买本组为前提。 |
| 整装负载 | 计算负重时力量视为高 **2**；判断能携带物品的体积与力量条件时，体积和力量各视为高 **2**。不增加实际属性、HP、攻击或对抗力量。 |

**技能树：**开启下文六项 D 级帝国军伍技艺的学习资格；仍须满足各项自身条件。

**预算与分配：**能力组基础 4D＋D 阶不开能量池补偿 2D＝制式操练、临阵防护、警醒先手、行军耐受、野外起居、整装负载各 1D，共 6D；另开 D 级技能树。新增属性强化投入 **0D／上限 2D**；整装负载只调整特定负重／携物判定，不是属性强化。普通军训不会由此令所有士兵掌握斗气。

### C 阶 精锐战兵

**类型与价格：**同一能力组的进阶，另付 35 XP。保留 D 阶全部效果。

**学习条件：**已取得 D 阶；一种受训兵器 E≥7，运动、求生和调查 E 各≥3，意志≥3；已掌握至少两项 D 级帝国军伍技艺，并经过持续作战、复杂任务演练或相当的针对性教导。其训练重点是压力下的稳定执行与小规模协同，不以被任命为小队成员代替学习。

| 特性 | 实际收益 |
| --- | --- |
| 精练兵技 | 制式操练的攻击专长加值再增加 **6DP**，同源合计 **+9DP**。 |
| 战场步法 | 临阵防护的洞察防御再增加 **6**，同源合计 **+9**，适用条件不变。 |
| 战斗韧性 | 强韧、反射和普通意志抵抗检定获得 **+6DP 专长加值**。不适用于消费意志点、意志池上限或其他意志相关行为；与行军耐受同次适用时取高。 |
| 战场观察 | 调查技能的合法检定获得 **+6DP 专长加值**，包括侦查、聆听和搜索。仍须有感官条件与可观察的线索，不提供透视、盲视或自动识破。 |

**技能树：**保留 D 级树，开启三项 C 级帝国军伍技艺。

**预算与分配：**精练兵技、战场步法、战斗韧性、战场观察各 1C，共 4C，另开 C 级技能树。新增属性强化投入 **0C／上限 2C**；继承 D 阶不重复投入。不开能量池的额外补偿仅计 D 阶一次。

## D 级配套技艺

以下每项均为 **10 XP**，前提包括帝国军伍 D 阶。它们是不同岗位可选的技艺，不是所有士兵必学清单。

### 贯甲打击

**用途：**用扎实的发力和落点对付装甲目标，而非增加攻击次数。

**额外前提：**相应白刃兵器 E≥3。

**动作与效果：**标准动作，以一把受训近战兵器进行一次正常攻击，本次获得 **+6DP 招式加值**及 **RE【破甲 4】**。伤型、伤害上限和触及范围仍按兵器与 PHB 公式；破甲按上文共通结算。冷却 1 轮。

**预算 4D：**攻击 +6DP 占 2D；破甲 4 参照 RE 刀术／剑击二级的同阶完整阶段，暂占 2D（有界类比）。本项放宽了原型的刀／剑武器范围，却要求单次标准攻击、1 轮冷却、D 能力组与兵器 E≥3；原型还有一级前置购买。因此 2D 并非独立明价，武器范围差异仍待桌面校准。未索取标准动作的额外预算。

### 持盾坚守

**用途：**在箭雨、碎片和迎面冲击下稳住防线。

**额外前提：**力量≥3，运动 E≥2，持有且能够使用盾牌。

**动作与效果：**移动动作进入守势，持续到下一次自己行动开始。对盾牌能实际参与防护的攻击，盾牌防御获得 **+6 增强加值**；对能借盾牌遮挡或导开的范围效果，反射检定获得 **+12DP 专长加值**。遇到完全忽略盾牌的攻击、从体内生效的能力或盾牌无法介入的方向时，相应收益不适用。失去盾牌或失去意识即结束。可正常使用剩余标准动作，不额外获得格挡或全防御动作。

**预算 4D：**防御 +6 为 2D，单项豁免 +12 为 2D。与 C 阶战斗韧性的反射加值取高。

### 稳手射击

**用途：**远距压力下保持射击精度。

**额外前提：**弓箭或枪械 E≥3，并具有对应弓／弩子技能至少 1 级；使用已完成装填的受训弓或弩。

**动作与效果：**标准动作进行一次正常射击，获得 **+6DP 招式加值**，本次距离减值至多减少 **6DP**，最低减至 0。射程上限、可见性和掩蔽照常；减少距离减值不把射程外目标变成合法目标。冷却 1 轮。取箭、上弦、装填仍使用原本所需动作。

**预算 4D：**攻击 +6DP 为 2D；只抵消距离减值的 6DP 按等额攻击加值保守占 2D。

### 骑乘突贯

**用途：**骑兵掠过目标后继续前进，避免每次出击都停在对手面前。

**额外前提：**白刃 E≥3，运动 E≥2，具备所乘坐骑的实际战斗骑乘训练；骑乘有能力执行本动作的坐骑，持适合骑乘使用的受训近战兵器。魔法坐骑和特殊载具另依自身规则。

**动作与效果：**消耗骑手本回合的移动与标准动作，以坐骑完成一次合法冲锋，并进行一次近战攻击，攻击获得 **+6DP 招式加值**。若本次移动尚有余量，攻击后可以继续沿可通行路径移动；攻击前后合计距离不超过坐骑这次正常移动额度，不额外取得坐骑行动或第二次冲锋。进入攻击位置前仍遵守 PHB 冲锋的直线及路径要求，脱离威胁范围照常处理。冷却 1 轮。

**预算 4D：**冲锋攻击 +6DP 占 2D；攻击前后分配同一次坐骑移动暂占 2D（RE 长枪骑士二级有界类比）。原型先取得一级、限定枪矛戟；本项扩大至合骑乘的受训近战兵器，但另需本组 D 阶、实际战斗骑乘训练且不赠坐骑第二次行动。移动部分并无独立明价，仍须核此武器范围的影响。

### 战地潜行

**用途：**巡察、接近阵地和沿掩蔽转移时保持行进效率。

**额外前提：**躲藏 E≥2，“潜行”子技能≥1。

**效果：**潜行与隐蔽的躲藏检定获得 **+6DP 专长加值**。正常全速移动不再承受仅因全速潜行产生的减值；奔跑的减值和成功数损失仍保留。仍需要合法隐蔽条件；没有掩蔽而直接暴露在对方面前时不会获得隐形。被动生效，无额外动作。

**预算 4D：**躲藏 +6DP 占 2D；消除正常全速潜行减值暂占 2D（有界但未定准）。RE 悄无声息三级的完整 3D 阶段同时免除正常移动的隐藏／潜行减值并可误导声音，且须先购一、二级；本项只保留潜行速度用途，放宽前置为本组 D 阶与躲藏 E≥2。原型没有单列移动部分售价，不能把此 2D 写成明价。

### 战地急救

**用途：**在短暂的掩护窗口内完成稳定伤势的处置。

**额外前提：**医学 E≥2，“急救”子技能≥1；能够接触伤者并使用合用的急救工具。

**效果：**医学检定获得 **+6DP 专长加值**；仍须有合法的治疗对象、工具与操作机会。以阻止 A 伤逐轮恶化为目的的 PHB 急救可改用一个标准动作，投 `敏捷＋E(医学／急救)＋适用修正`，至少 1 成功即稳定该次伤势恶化。

同一标准动作还可对该目标作一次 `智力＋E(医学／长线治疗)＋适用修正` 的长线治疗判定：若达到 PHB 长线治疗的 5／10 成功门槛，分别可把 1 点 L 转 B／1 点 A 转 L；两档均达到时可各转 1 点。只需基本合用的急救器材；**同一目标每天至多接受一次此伤级转化，且占用其当天的长线治疗机会**，不能用重复发动绕过该限制；新伤仍可另做稳定，但不再附送当天伤级转化。不额外支付意志点增加转化。稳定本身不恢复生命槽，不使昏迷者自动清醒；后续新伤或其他效果仍可重新触发恶化。这项技艺不产生医疗点数，不能治疗全 A 死亡。自己仍有意识、能接触伤处且满足操作条件时也可使用；已因 A 伤恶化而昏迷者不能自行急救。

**预算：**医学检定 +6DP 占 2D；快速稳定连同一次伤级转化、基本器材、当天治疗限制按 RE 初心者「紧急治疗」完整组件作有界适配，暂占 1D，合计估算 **3D／技艺模板容量 4D**，剩余 1D 不附加效果。原型 D 阶七个普通特性中明确将基本训练列为五特性，余下紧急治疗与装死各一特性；本项不取其耗意志额外转化。PHB 基础急救为他人花一轮；自救只在角色仍能行动时有效。完整紧急治疗可支持独立的战场救护用途，但其移植价格未单独明定；**10 XP** 仍按 D 级树内技艺模板暂报，待逐项核价，不以 3D／4D 的比例自行折价。

## C 级配套技艺

以下每项均为 **25 XP**，前提包括帝国军伍 C 阶。

### 破阵连击

**用途：**抓住短暂空隙，以连续两次攻击突破防线。

**额外前提：**相应白刃兵器 E≥7。

**动作与效果：**标准动作，以受训近战兵器依次作 **两次普通攻击**，本次两击均有同一个 **+12DP 招式加值**。可攻击同一目标或两个当时处于触及范围内的合法目标；第二个目标在第一击结算后选择。

两击分别掷骰、应用防御、伤害上限和防护。第一击后若使用者已不能攻击，第二击取消。两击之间不赠送移动，不把一次攻击的成功数复制给另一次；贯甲打击、其他连击等改写攻击动作的技艺不能套入。冷却 1 轮。

**预算：**标准动作额外一击占 5D；本次两击共用攻击 +12DP 占 **2C＝6D**（同级数值重复投入两次，尚未到第三次税点），而非逐击各售 +6；合计估算 **11D／技艺模板容量 4C＝12D**，剩余 1D 不附加效果。额外一击含 1 轮冷却的 RE 明价，攻击加值按数值特性核算；第二目标选择属于原两击用途，不另虚构单价。两次攻击与共同加值构成独立的连击技艺；**25 XP** 仍按 C 级树内技艺模板暂报，待逐项核价，不以 11D／12D 的比例自行折价。

### 交叉掩护

**用途：**盾手抢入同伴身前，亲自承受一记来袭攻击。

**额外前提：**运动 E≥3，能够使用盾牌；同伴在自己 **2 米内**，本人能察觉来袭的单体攻击，并有合法位置和路径介入。

**触发与动作：**该攻击已宣告、尚未掷骰时，以一个反射动作移动至多 **2 米**，占据能实际介入攻击路径的空位。不得超过自己正常移动速度，也不能穿过实体障碍或敌人。

**效果：**在同伴愿意接受掩护、且本人仍是该攻击合法目标的情况下，将该次单体攻击的目标改为自己；攻击者改用掩护者的防御重新确定本次攻击骰池。本次攻击中盾牌防御获得 **+12 增强加值**，与持盾坚守的盾牌加值取高。实际伤害及附带效果由掩护者承担。

此举不改变攻击类型、来源或射程，不复制攻击，不转移已经结算的伤害。范围攻击、已经命中的攻击、无法用身体介入的精神侵入等不能如此截下。途中触发的拦截先结算；若因此失去行动能力或未能到位，原攻击仍指向原目标。冷却 1 轮，并受正常反射／迅捷限制。

**预算 4C：**反射≤2米介入、合法单体攻击转向自己并由自己承伤，**整体暂占 2C**；单次盾牌防御 +12 占 2C。RE 反射“运动技能×2 米”有 1C 移动基准；组合技「交替」完整 D 技艺提供反射半速接替，却要求双方购买磨合、到达同伴原位置且其挪 1 米；守护骑士 C 阶把介入与取代目标捆在要塞风格 4C 中。本项一人购买即可发动但限定≤2米、合法路径与本人承伤，故 2C 是整套有界候选，不存在已证实的“转目标独立 1C”价。

### 集中打击

**用途：**将战场观察变成同伴马上可以利用的射击或突击窗口。

**额外前提：**调查 E≥3；能够清楚观察目标，并以同伴能理解的语言或预先学过的军用信号传达。

**动作与效果：**标准动作，标出一个自己能够合法定位的目标，指定 **20 米内至多三名友方参与者，可包括自己**。参与者必须愿意配合、收到信号，并能独立定位该目标。

在自己下一次行动结束前，每名参与者针对该目标的第一次合法兵器攻击获得 **+6DP 士气加值**；各人在攻击时自行决定是否行动、何时行动及使用何种合法攻击。没有在时限内攻击则收益消失。使用者本回合已经花费标准动作，通常可在下一次自己的行动中作首击；一次多次攻击只增强其中第一次，不给额外动作、攻击次数或感知共享。

多名使用者的集中打击对同一攻击不叠加；与其他攻击士气加值取高。不能接收信号或目标失去合法定位时无法应用。冷却 1 轮。此为同伴间的战术配合，不要求获得军官任命，也不能强迫他人行动。

**预算 4C：**整套三人首击 +6DP 的 4C 为有界候选，**不拆出每人或传递的独立价**。RE 剑舞者「永夜之诗」完整双 C 特性：标准动作耗 3 意志、持舞剑咏唱，风度×30米内能听到的友方攻、防、抗心灵 +3，可耗动作维持至一个场景；本文无能耗且首击 +6 较强，却限 20 米、至多三人、单一目标和一次攻击，持续只到下次行动结束。RE CO 指挥官「战场嗅觉」完整 D+500 技艺：能听到指挥官的友方在战斗判定与防御获能力组等级的加值，但须 CO 前提与通讯。两个原型都不能拆出跨人单价；本项以较高 4C 容量暂定整套协同效应，跨人／第三人的强弱仍待桌面校准。

## 两个结算示例

**普通兵的贯甲打击。**力量 3，白刃主 2＋长矛子 1，兵器伤害 2L。目标基础防御 2、单层盔甲防御 4，没有其他防护。D 阶制式操练 +3DP，贯甲打击 +6DP；RE 破甲 4 先削尽这 4 点甲防，故本次 DP 为 `3＋3＋2＋3＋6－2＝15`。近战伤害上限仍是 `2＋3＋3＝8L`。若掷得 5 成功，则上限前为 5L；若目标另有物理 DR2，最终为 3L。若可破防御只用了 3 点破甲，余 1 点才可破 1 点硬度；它仍不穿 DR。

**精锐盾手保护弩手。**盾手与弩手相距 1 米，来袭者宣告一记盾牌可以防护的单体攻击。盾手在掷骰前用交叉掩护，到达能介入的空位并成为合法替代目标。该次攻击重新按盾手的防御计算；若盾手此前持盾坚守生效，盾牌的 +6 与此次 +12 增强加值取 +12，能力组的同源 +9 洞察另按适用条件计算。盾手承受结算后的伤害，弩手不承受这一记单体攻击。盾手此后至自己下一次行动结束不能使用迅捷或另一次反射。

### 修订与目标上限检查

前次修订涉及野外起居 +6→+3、贯甲破甲定义、删除负伤撤援、破阵连击两击共享 +12、集中打击持续至使用者下次行动结束，以及各项预算证据和缺口说明。本轮仅从战地急救删除技能赠级及其高技能禁学条件，保留标准动作快速稳定和有 RE 原型支持的同次伤级转化；从破阵连击删除附带拔取。两项分别有 1D 未用容量，仍暂沿 10／25 XP 技艺模板候选价，待逐项核价，不补填新效果；其余七项技艺和两阶本体不在本轮改动范围。

T3 是原稿的综合战力目标，不是 RE 数值等级或本库加值天花板。D 常规兵器、防护、警戒、行军、营地收益覆盖盾、长兵、双手近战、弓弩等岗位；C 仍是进阶可靠性，专门的接替承伤与多人战术在可选技艺中。按正文动作检查，贯甲、骑乘与连击不能同次套用，反射介入受 901 反射锁，集中打击不赠行动或攻击次数。此为规则／预算自查，未宣称人物实战测试已证明 T3。仍需作者单项校准的主要缺口是破甲武器范围、潜行三级部分拆价、交叉掩护接替整体估值和集中打击跨人／第三人整体估值；它们在正文均以候选而非明价呈现。

删除说明：先前为补齐预算而给搬运同伴提供额外步行加速，会使背人比空身更快，偏离普通军伍救援训练的用途。本项整体删除，不将其4D转移给其他技艺；普通搬运与救援依基础规则进行。可选技艺数量无须固定为十项。
