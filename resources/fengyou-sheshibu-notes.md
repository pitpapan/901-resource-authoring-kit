# 风游涉世步 D级收录与核算依据

对应[资源正文](fengyou-sheshibu.md)。2026-10-19按已确定的《观澜法》D级身法版本收录：踏风履险、借势迁延、旋规折隙，保留＋40米身法速度加值、受击五尺快步与化劲配合。正文与定稿一致，核算与价格说明单独保存。

2026-10-23随《观澜法》冻结版同步更新：学习与使用的供能条件改为符合演化无碍的通用能量池，排除怒气、化劲等特殊能量；保留不穿重甲、至少一个合格池当前有1点能量的限制。三项特性的动作、数值、化劲规则及预算与价格保持不变。

**沿用D＋1000模板，容量5D，当前实投估价5D，余量0D；本批换算15XP，适用一理贯通后14XP。**基础组与五尺改造为有界类比，新增速度有明价；收录不表示人物已经学会或支付XP。

## 完整基础组

[九曜极速D级](../content/RE/02_resources/技艺/身法/九曜极速.md)第8—17行，独立D＋500、3D容量。完整组合含速度＋20米、无需助跑、液面与困难地形通行、蛛行及行动末落脚限制、非战斗狭窄支撑平衡、1点化劲槽、受击后2AP反射移动10米并转化1点伤害、自由散劲。原型前提为不穿重甲且内力或魔法力池不空。

本身法沿用整组用途和限制，按本次用户确认的[演化无碍](guanlan-fa.md#演化无碍)供能适配，要求至少一个合格的已有通用能量池不空。原型本已允许内力或魔法力，扩为本树定义的非特殊能量是本次适配，不改变能耗或取得新的能量池。依[901核心规则](../rules/901-core-rules-v0.1.md)适配动作、自由动作时机和反射锁，保留实际移动后化伤与合法路径要求。普通能量池上限增加不影响化劲槽。

[运动](../content/RE/01_rules/01_建卡与属性/运动.md)区分助跑与极限助跑；本身法只免除未助跑的不利，不额外赠送极限助跑DP。特殊地形通行至自己行动结束，仍须正常落脚，不取得飞行或危险地形伤害免疫。

## 五尺改造增量

[战斗专长·侧滑步一级](../content/RE/01_rules/01_建卡与属性/战斗专长.md)第643—648行，按专长模板为1D；前提为敏捷2、运动1且基本防御可全部运用。完整效果是受攻时反射移动1米：通常不视作脱离原攻击范围；近战可因插入第三者而产生落空、改换目标或掩蔽结果，远程则提供＋3闪避。

| 比较项 | 九曜／侧滑原型 | 本身法 |
| --- | --- | --- |
| 反射动作 | 两个原型均已有反射移动 | 保留一个反射动作及901反射锁 |
| 化伤额度 | 九曜每10米化1点 | 完成全部五尺步长化1点，单次仍最多1点 |
| 位移与路径 | 九曜移动10米；侧滑移动1米 | 只用固定五尺步长，要求合法路径及落脚点 |
| 使用资格 | 九曜要求不穿重甲且能量池不空；侧滑另要求基本防御完整 | 保留身法使用条件，不要求基本防御完整 |
| 原攻击保护 | 侧滑可取得闪避、掩蔽或特殊落空／改目标 | 命中已经确定，不追溯改变该次防御或使攻击落空 |
| 后续交互 | RE近例不直接处理901威胁范围 | 五尺快步安全脱离，只免除该步离开威胁范围引发的普通攻击 |

原九曜3D已经包含反射位移和1点化伤。本次用侧滑步的完整1D短步防护组合比较改造增量：取得短路径卸伤、安全脱离及不要求基本防御完整的便利，同时失去10米远移，也不取得侧滑步针对原攻击的防御收益。综合差异采用增量1D，改造后的基础组共4D。

该1D是本资源的有界类比，不是安全脱离的通用明价，也不把缩短路径直接当作纯削弱。五尺步的特定反射许可只属于本身法；自己行动中的普通五尺快步仍需移动动作。使用反射后，至下一次自己的行动结束前不能使用反射或迅捷，不形成逐次攻击连续化伤。

## ＋40米速度

[数值类特性](../content/RE/04_traits/可以确认的特性/数值类特性.md)第24行给出速度提升20米为1D。本身法在原基础组＋20米之上追加1D，使同一份身法加值提高至＋40米。速度项目相当于两份D级定值投入，未到同一数值每第三份投入的数值税节点。

这项提升不需要额外动作或持续能耗，仍要求不穿重甲且至少一个符合演化无碍条件的通用能量池当前有1点能量。与其他同类速度加值取最高，包括《腾转挪移》，不把两份身法速度直接相加；其他明确可叠加的来源依自身条文。速度不改变五尺步长、槽上限或单次化劲量。

## 学习价格与共用化劲槽

按[自学规则](../content/RE/01_rules/03_其他规则/自学规则.md)的旧价换算，D＋1000为5＋1000÷100＝15XP；再按[观澜法·一理贯通](guanlan-fa.md#一理贯通)减1XP，实际学习费用为14XP。这是本批既有价格口径，不额外增加新收费公式。通用XP与悟法XP不能混付，首次完整学成依积健为雄取得一次积累。

本门与[澄心玄鉴](chengxin-xuanjian.md)分别学习，互不作为学习前提。两门各提供1点相容化劲槽，合学上限为2；共槽增加已包含在各自原型的已有槽上限＋1条款内，不额外授予普通内力。

- **空槽受击：**减免后剩3L时，心法可以无动作纳入2劲，实际记入1L；槽已满后，身法受击短步只改变位置，不能再化去1L。
- **半槽受击：**已有1劲、上限2时，心法不能补纳；仍有反射且能完成合法五尺快步时，身法可以再化1点适用伤害补满。
- **借劲出手：**心法借劲出锋需要自己的迅捷动作，每轮最多消耗2劲；处于身法引发的反射锁时不能借劲，但自己的行动中仍可自由散尽。不会在自己行动外反复自由清槽。

同一点伤害不能重复转化，两门容量不能互相调剂。《澄心玄鉴》的预算与未定价格另见其[核算依据](chengxin-xuanjian-notes.md)，不因身法容量足够而自动解决。本次只同步已确认的供能前提，不变更心法效果或901规则，也不把预算核对视为实战平衡验证。
