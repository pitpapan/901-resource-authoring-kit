# 启剑式·风·狂岚：预算与样板依据

对应[纯净条文](kuanglan.md)。暂定 C 级、25 XP；免疫交互仍待定。

## 预算与 XP 依据

RE 独立 C 级技艺模板价为 **C+1000**，容量 **3C**；当前没有本技艺已支付技能树入口的证据，不能领取树内第 4 个 C 特性。按 RE 自学公式，`3 个 D 支线单位×5＋1000÷100＝25 XP`，故暂报 **25 XP**。群袭的 +3DP 攻击加值有 **1D** 明价；20 米逐目标白刃、排除友军、两种减防及互斥模式依下列完整近例作整体有界类比，没有各项独立单价，也不宣称恰好花满 3C。标准动作与 1 点能量已含在比较的整套招式条件中，不重复计作新增容量。
