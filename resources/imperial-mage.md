# 帝国法师

## 共同规则

**技能树：**D 阶开启帝国魔法施法职能 D 与本职魔法技艺／专有法术树 D；C 阶将同一入口提高至 C。该入口允许逐项学习相应等级的法术，不自动学会未列出的法术。非被动本职技艺受姿势、语言及专注的施法限制。

**能量池：**没有同源魔力池者，D 阶取得普通精神魔力池，上限为 `⌊(智力＋感知)÷4⌋`。长休 8 小时回复至上限；冥想每小时回复智力与感知固定自动成功数之和。已有同源池者沿用其池，不重复开池或叠加起始上限。C 阶的上限＋10只加在实际用于本职施法的一个池上一次。

**法术与专精：**D 阶选择一个主专精，直接学会一个合法的本职同系 D 级通用法术。C 阶保留入门、获得该领域主修进阶，并可选择另一个领域为副专精，取得其 D 阶入门。主副专精不禁止学习其他合法领域的通用法术。法术所属方向依其条目；同一数值写明“改为／总计”时替代旧值，不将两级相加。同种加值不因法术同时属于多个方向而重复取得。帝国法师不开放死灵专精。

**NPC 福利·法系辨识：**NPC 对已取得的每项主、副法系专精，在自身魔力感官察觉该系魔法时，无须辨识检定、额外动作或消耗，即可理解至多 A 级的该系魔法及其效果；异界魔法除外。此项适用于治愈、炼金、防护／结界、塑能／元素、变化、咒法／召唤、预言／探知、幻术及惑控／心灵。辨识不授予施展、复制、解除能力，也不扩大感官范围。该福利无需另付 XP 或特性。

**护甲与阵地：**穿中型铠甲施展有姿势成分的法术时掷 D10，结果为 1 则施法失败；重型铠甲结果为 1—3 则失败。已耗魔力不返还。只有明确允许阵地化的已知法术，才能依所需长时间判定制成阵地。

## D 级·学徒

**等级：**D。

**价格：**15 XP。

**能量池：**取得或沿用上述魔力池。

**技能树：**帝国魔法施法职能 D 与本职魔法技艺／专有法术树 D。

### 法术训练（三特性）

从所选主专精领域中选择一项合法、尚未学会的 D 级本职同系通用法术，直接学会，不另付该法术的学习 XP。技能树入口仅给予学习资格；除这项明确授予的法术外，其他法术仍须分别取得合法知识、学习途径与资格并支付学习 XP。

### 主专精入门（一特性）

从下列九系中选择一系为主专精，立即取得该系“入门”所列的全部效果。

## C 级·成职法师

**等级：**C。

**价格：**35 XP。

**能量池：**沿用实际用于本职施法的一个魔力池。

**技能树：**共同入口提高至 C。

### 魔力增储

上述实际用于本职施法的同一个魔力池上限＋10，只增加一次；不另开魔力池，也不将不同魔力池的上限相加。

### 普通魔力感官

在模糊视觉范围感到魔力使用及暴露魔力源的波动等级与方位：法术按能力等级，物品按物品等级－1，生物按其最高魔力能力等级－1；无支线为 0，D/C/B/A/S 分别为 1/2/3/4/5，0 级波动不可感知。感官等级等于实际魔力池等级，至多 B 级。已有同源感官者只取实际适用的一项，不叠加。

### 主修进阶

保留 D 阶主专精入门，取得同一领域下文“主修”所列的全部效果。

### 副修入门

可从不同于主专精的领域选择一系为副专精，仅取得该系“入门”所列的全部效果，不取得第二项主修进阶。不选副专精也不把它改为另一项主修。C 级入口允许学习合法 C 级法术，不自动赠送 C 级法术。

## 九系专精

### 治愈

#### D 级入门·医官训练

对伤病者作医学治疗判定时＋3DP。

#### C 级主修·治愈专精

施展治愈系魔法而需要施法判定时＋4DP。本人施展已知治愈法术且该术明列威力时，本次威力＋1，仍受威力上限约束；定值治疗依提高后的威力结算，不额外增加施法判定。

### 炼金

#### D 级入门·炼金入门

炼金术相关判定＋1DP；鉴定炼金物品时再＋2DP，该次总计＋3DP。

#### C 级主修·炼金制备

炼金术相关判定的基础加值改为总计＋4DP；鉴定炼金物品仍另加＋2DP，该次总计＋6DP。

本人施展已知炼金法术并亲自完成明列时长的成品制备或炼制流程时，将该流程所需时间减半：《炼制祝圣水》1 小时变为 30 分钟，《魔水融合》1 天变为 12 小时。

此项只缩短以分钟、小时或天计的制备程序，不缩短施放或使用成品的战斗动作，不改变材料、魔力、制作判定、成品数量与效果、逐瓶 XP。与其他缩时效果不相乘，取较短的实际所需时间。

另从合法且尚未学会的本职同系 D 级炼金通用法术中直接学会一项，不另付该术的学习 XP；可选《炼制祝圣水》或《魔水融合》。若两者都已知，授术名额留待另一项合法 D 级炼金通用法术，不兑换 XP 或重复学习。

### 防护／结界

#### D 级入门·护身训练

自己受到本人施展且仍生效的防护法术保护时，若该术提供盔甲或力场防御，使自己从其中一道法术实际选用的该类防御＋3；多道法术不重复取得。法术若改选抵消破甲而非防御，本项对该次攻击不生效。

#### C 级主修·防护增效

本人施展的防护／结界法术明列威力时，该次威力＋1。

### 塑能／元素

#### D 级入门·战斗施法

以本人已知的塑能／元素法术作攻击所需的施法判定时＋3DP，不提高伤害上限。

#### C 级主修·元素增效

本人施展的塑能／元素法术明列威力时，该次威力＋1；伤害依法术条目结算。

### 变化

#### D 级入门·机动训练

自己施展且仍生效的变化法术直接帮助移动、攀爬或跳跃时，相关运动判定＋3DP修行加值；与《飞檐走壁》的跳跃增强加值分属不同类别。

#### C 级主修·变化步法

自己施展且仍生效的变化法术直接帮助本人步行时，步行速度翻倍，包括《飞檐走壁》允许的沿墙与液面步行。不授予新移动方式或动作；其他步行增速与本项不叠加，取较高速度。

### 咒法／召唤

#### D 级入门·召请储备

实际用于本职施法的魔力池上限＋5；仍是同一个魔力池。

#### C 级主修·召请增效

本人施展的咒法／召唤法术明列威力时，该次威力＋1；目标、行动及持续依该术条目。

### 预言／探知

#### D 级入门·探知修行

自己受到本人施展且仍生效的预言／探知法术辅助时，相关侦查或魔法鉴别判定＋3DP修行加值；《侦测潜行》的增强加值按另一类别结算。

#### C 级主修·探知课程

上述修行加值改为总计＋6DP，仅用于受本人探知法术辅助的相应判定。另从合法且本人尚未学会的本职同系 D 级预言通用法术中选择两项不同法术，直接学会而不另付这两术的学习 XP；可选《侦测潜行》《识破隐形》《解析弱点》。已知法术不得重复选择；未用名额留待其他合法 D 级预言通用法术，不兑换 XP。

### 幻术

#### D 级入门·幻术施法

本人施展已知幻术而必须作施法判定时＋3DP。

#### C 级主修·瞬发咏唱

每日一次，施展本能力组教材中已知、原需 6AP／标准动作的幻术时，可在反射时机施放，本次支付降低后的 4AP／一个移动动作。

自己行动中当场支付；行动外发动前，若下一次自己的移动动作已被其他效果预占、失去或确定无法支付，就不能发动。否则立即预占该移动动作，不得再用于其他支付或预支；若事后下一行动无法执行，施法和每日次数不退款，预占动作视为失去。受 901 反应锁约束，发动后至下一次行动结束前不能再用反射或迅捷。本次不增加基础魔力消耗，免语言、姿势及施法时专注检定；原术后续维持专注照常。价值不超过旧制 10 分的材料可免，超过者照付；法器仍须拥有，无须手持。本次至少冷却 1 轮，若原本更长则取更长冷却。此项不加快后续幻象操控。

### 惑控／心灵

#### D 级入门·心灵安定

受到心灵影响给予的负面点数时，先减去 4 点，再承受剩余点数；这不算全伤害吸收或意志加值。

#### C 级主修·心灵增效

本人施展的惑控／心灵法术明列威力时，该次威力＋1；目标资格与抵抗规则照旧。
