# 澄心玄鉴

**等级：**D级  
**类别：**心法、观理识势  
**所属：**《观澜法》技能树  
**学习前提：**《观澜法》D级，白刃或肉搏的有效技能值至少为3，具有观澜之气内力池。有效技能值为主技能与一项匹配子技能之和。

御临风将剑势的开合、术法的流转与器物的承力一并留在心中，反复比较其变化与规律。心如止水时，眼前万象便如镜上波纹，各有可循之理、可用之隙；面对难以尽避的攻势，则顺其力而引之，使来劲暂存周身，转用于自己的出手。

本心法不属于法术，不受施法姿势、语言与专注限制。

### 知人识势

将一路所见融入自身学识，以见闻开眼界，以思辨明事理。

**学识主技能提升1级，最高提升至5级。**没有学识时取得1级；已有学识时增加1级。若本次提升使主技能首次达到5级，依通常规则获得该主技能的1个自动成功。已经达到5级时不再提升，也不转为子技能或其他收益。同一份赠级只取得一次。

### 观隙取势

临阵观其变化，静物察其承力。御临风从已经显露的形态、动作与力量变化中找出可用于攻守的规律。

在自己的行动中，以**自由动作**选择一个能够直接观察其形态、受力反馈或运行迹象的目标，进行一次**智力＋学识主技能＋一项匹配的学识子技能＋适用修正**判定。没有匹配子技能时只用智力与学识主技能，适用的自动成功照常计入；本次观察不消耗能量。

目标可以是一个生物、一件物品或一处独立障碍，也可以是一项已经被发现、正在运作的独立术法效果。须位于自己能够有效观察其细节的感知范围内，并具有效果线。静止物体不要求作出动作，持续结界不要求再次施放。

**难度为3。**成功时，从当前可观察的迹象中识得一项可用于交锋的规律，并可将该对象设为当前观察目标。本场景对当前目标进行的**攻击判定获得＋2DP洞察加值**，防御其攻击时，**整体防御获得＋2洞察加值**。

| 对象 | 观察与取势举例 |
| --- | --- |
| 武者 | 从已经显露的动作辨认发力重心、起手习惯和攻守衔接。 |
| 魔法师 | 从可观察的施术动作、移动和已显露的能量变化，判断出手节奏及防护受力。 |
| 结界、护盾或阵法 | 从显露的边界、纹路、流转或受击反馈，判断适合攻击的位置与时机。 |
| 墙壁、器械或其他死物 | 从外露的形状、连接与承力迹象，判断适合施力或破坏的位置。 |

上述观察是本心法将所见用于攻守的专用判定，不要求另修武学知识；它不替代普通神秘或科学的专业鉴定，不自动获知未知法术的完整作用、隐蔽阵眼、内部机关、精确防护数值或其他尚未显露的信息，也不提供额外感官、定位或透视。

同一场景对同一组迹象只能判定一次，不能反复切换目标重试；目标显露新能力、结构改变或出现新的实质反馈时，才可再次观察。成功取得的取势结果持续至本场景结束；若相关结构或运行方式被实质替换，旧结果不能用于被替换的部分。

自己的行动中，可以以自由动作切换至本场景已经取势成功且仍能观察的目标，同一时刻只保有一个当前观察目标。切换、主动放弃或无法继续观察时，不再对原目标取得攻防加值；恢复观察并重新选定仍有效的目标时，无须再次判定。

生物当前装备与直接构成其防护的附着效果可作为其表现的一部分。独立承受攻击或独立结算作用的结界、召唤物及机关，分别作为目标。法术确实采用攻击与防御结算时，适用本项对应加值；只要求豁免的效果不因此获得防御或豁免收益。对不会攻击的物体，仍可使用攻击加值。

重复观察不叠加数值，与其他来源的同类洞察加值取最高。不增加伤害上限、攻击次数或自动成功。

### 导气归元

将难以尽避的来劲导入周身，暂存而后散出，或借其余势送入下一次出手。

获得上限为**1点**的特殊［化劲］槽。若已经通过《风游涉世步》取得该槽，则共同上限增加1点；其他来源须明确相容才能合并。

化劲槽不自然回复，不受普通能量池上限强化影响，每个场景结束时清空。槽内的［劲］不能作为普通内力支付。

当槽内**没有任何劲**时，在所有通常伤害减免结算之后、伤害尚未计入生命之前，可以将本次即将承受的非精神、非毒素的冲击B或严重L伤害，按**1∶1**转为劲，使这些伤害不再由生命承受。

转化量自行选择，最多为本次适用伤害与当前空槽容量中的较低者。纳劲无需动作或能量，可以在他人的行动中发生，不触发反射锁。

槽内已有劲时，不能用本项继续纳劲，即使尚未达到上限。不能转化恶性A或已经计入生命的旧伤；同一点伤害不重复转化。

掌握以下两种散劲方法：

**散还天地**

在自己的行动中，以自由动作清空全部劲。来劲化为涟漪、白气或地面的细裂散去，不造成攻击或环境伤害。

**借劲出锋**

在自己的行动中，以一个迅捷动作消耗任意数量的劲，将等量无名DP加入本次自己的行动内、下一次合法的肉搏或白刃攻击判定。

D级每轮以此法消耗的劲合计最多为2点。攻击仍须正常支付动作；未在本次自己的行动内使用，加值即失效，劲不返还。重复发动不储存或叠加加值。

借劲只提供攻击DP，不增加攻击次数、武器伤害或伤害上限。自由散尽不占上述每轮2点额度。受到反射锁限制时不能借劲出锋，但仍可在自己的行动中自由散劲。

### 破隙入微

既察其理，便循其隙。人身有受力的薄弱处，器物有承接的关节，术法亦有力量难以周全之处。

对本场景经观隙取势成功取势的目标，进行合法的肉搏或白刃攻击时，在结算该次攻击的伤害防护阶段，可合计忽略至多**2点**适用的DR、伤害吸收、抵消、转化或硬度。

此效果适用于生物、物体，以及本来就允许被该次攻击伤害的结界或其他独立术法效果。攻击墙壁时可以忽略其适用硬度；攻击可被斩击破坏的结界时，可以忽略其适用的伤害减免或吸收。普通攻击本来无法影响的无形术法，不会因此变成可攻击对象。

2点额度由所选来源共同使用，不是每种防护各忽略2点；不能使任何来源低于零。不降低整体防御、力场防御或能量抗力，不忽略免疫，不提高伤害上限，也不提供破魔、解除法术或直接关闭结界的能力。

无需额外动作或能量。重复观察不叠加额度；切换观隙取势的当前观察目标，不影响对其他已取势目标使用本项。场景结束或对应取势结果失效时，相应破隙收益结束。

### 心法与身法合用

《澄心玄鉴》与《风游涉世步》可分别学习，互相不作为学习前提。两者兼修时，共用化劲槽的上限为**2点**；普通内力上限的增加不会扩大化劲槽。

空槽时，可用导气归元无动作纳入至多2点适用伤害；槽内已有1劲时，导气归元不能补纳，但有可用反射动作与合法短步路径时，可以用旋规折隙完成短步，依借势迁延再纳入1点。同一点伤害不重复转化，槽满后不再继续化去伤害。

两门技艺分别学成时，各按积健为雄的规则计一次完整学习。
