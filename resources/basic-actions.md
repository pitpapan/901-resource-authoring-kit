# 901 普通动作执行规则

### 全力防御

**动作：**标准动作；普通人物均可选择，不需要购买、学习或消耗能量。

直到下一次实际做出其他标准动作前，防御与对抗范围攻击的判定获得相当于当前基本防御的闪避加值。能看见使用枪械攻击的敌人时，该枪械攻击不享有高速优势。不能闪避时不取得上述闪避收益；措手不及仍按规则失去闪避。

本动作不因回合结束或下次行动开始自动结束；失败且未支付动作的请求不终止。整轮与冲锋包含标准动作部分，成功支付时终止。将标准额度换作移动或迅捷动作仍按实际动作种类判断。

可另用移动动作格挡；格挡到下次自身行动开始时结束，全力防御可继续保持。RE 法术“防护”所称“全防御”按此普通动作对应，不另赠动作。
