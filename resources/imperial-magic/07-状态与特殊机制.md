# 帝国通用魔法·状态与特殊机制

本页解释法术条目常用的状态、感官与防护词。法术写有更窄的对象、豁免或作用范围时，按该术结算；未写的关键字不因描述相似而自动获得。

## 状态点数

受到状态时，先作该术允许的抵抗，再记实际状态点数。通常抵抗骰池为`关键抵抗属性中较低者＋E(求生)`；单一关键属性只计一次。表中每点轻度减值，均指实际剩余的每 1 点状态使列出的检定、DP、防御合计或基础速度减少 1 点；重度通常仍保留轻度减值，除非该行另写。点数**超过**关键属性较高值即进入重度；超过该值两倍时，才检查该状态及来源是否允许毁灭性后果。相同状态的不同来源通常并列记录、取较高者生效，不合并点数；疲乏例外合计。状态来源仍存在时，只减少点数不等于消除来源。15 分钟完整短休可对一项状态重新抵抗，8 小时长休可移除一项状态等于较低关键属性的点数；疾病、毒素与法术明列的持续、恢复方式优先。

下表所说的“防御合计减值”作用于**基础防御＋闪避防御＋格挡防御的总和**，每点状态只减合计 1 点，并非在三个类别各减一次。

| 状态 | 关键抵抗属性 | 每点轻度影响 | 重度影响 |
| --- | --- | --- | --- |
| 恶心／反胃 | 力量、意志 | 攻击、施法、使用特殊能力及招式各受 1 点减值。 | 每轮只剩一个移动动作；若仍能以该动作攻击、施法或用能力／招式，减值照旧。 |
| 麻痹／定身 | 力量、意志 | 运动、攻击、基础速度及防御合计各受 1 点减值。 | 速度为 0；失去基础防御，不能闪避、格挡或作需要身体动作的行为，包括攻击及有姿势成分的施法。 |
| 晕眩／昏迷 | 力量、意志 | 攻击、运动、感知判定及基础速度各受 1 点减值。 | 昏迷，失去意识与行动能力，不能作任何动作，处于无助状态。 |
| 耳鸣／耳聋 | 力量、感知 | 聆听判定受 1 点减值。 | 不能聆听或运用听觉能力；先攻权只保留一半，因复数攻击而受的防御减值加倍。 |
| 目眩／目盲 | 力量、感知 | 视觉侦察、阅读取信息及攻击各受 1 点减值；延长动作的精细操作受一半目眩减值。 | 失去视觉，不能作需视觉的行为或精细操作；敌人对自己为全隐蔽，基础速度减半。目盲时不再叠受目眩减值；盲感、盲视按各自范围缓解。 |
| 精神束缚／定身 | 意志 | 运动、攻击、基础速度、需要动作的施法及防御合计各受 1 点减值。 | 同“麻痹／定身”的定身后果。 |
| 纠缠／定身 | 力量、敏捷 | 基础速度先减半，运动、攻击、减半后的基础速度及防御合计再各受 1 点减值。 | 同“麻痹／定身”的定身后果。 |
| 冻结／冰封 | 力量、敏捷 | 同麻痹的逐点运动、攻击、基础速度及防御合计减值。 | 同定身；进入冰封后再获得的冻结点数改为等量 L 寒冷伤害，不得抵抗这次转化。 |
| 疲乏／力竭 | 力量 | 力量、敏捷相关判定及基础速度各受 1 点减值；不能冲锋或全力攻击。不同来源合计。 | 基础速度先减半再受逐点减值；每轮失去移动动作。 |
| 魅惑／迷情 | 意志、风度 | 对沉迷对象的社交、说服、胁迫、掩饰作抵抗，以及以意志抵抗其特异或魔幻能力时，各受 1 点减值。 | 愿服从该对象，明显送死或完全违反自身道德观的命令除外；遇到这种命令可再对抗魅惑。 |
| 肢体妨害／残障 | 力量、敏捷 | 以受影响肢体为主的力量、敏捷、手艺判定各受 1 点减值；依靠该肢体移动时，基础速度受一半点数减值，若受妨害的移动肢体超过两条或达到一半则受全额点数减值。 | 该肢体无法使用；如依靠它移动，基础速度先减半再计上述点数减值。 |

**剧痛：**每点使社交、手艺、感知、意志对抗、上述防御合计，以及以心智属性为关键属性的施法或类似能力检定各受 1 点减值。点数超过`意志＋风度`或`力量＋意志`时昏迷，不能主动行动；毁灭性门槛为`2×max(意志＋风度, 力量＋意志)`，超出的点数作为等量属性伤害，在力量、意志之间分配。

**情绪异常：**关键抵抗属性为意志，每点都是 1 点士气减值。战栗使攻击恐惧对象、对其社交、使用心智属性特殊能力，以及对其他敌人的上述防御合计受减值；重度惊惧者还须以最有效的移动方式逃离恐惧对象，直到不能感觉其存在。沮丧使攻击、技能与延长动作判定受减值；重度厌世者除非接到确切、不可反抗的命令，否则不作主动动作，且不能闪避、格挡。亢奋使防御、先攻、社交与延长动作判定受减值；重度时不能静坐、冥想或作周期超过一分钟的延长动作，也不能从这类活动获得额外充能／回复。901 已采用 Q20：仇恨采用亢奋机械原型并保留来源名称，不强制攻击；关键属性意志，沿用短休重抗及长休去点，无逐轮衰减、场景清零或新增永久后果。

**燃烧：**每次结束自己的行动时，受到等于当前燃烧点数的 L 火焰伤害，直至火焰熄灭或燃料耗尽。用一个标准动作作反射判定，每个成功数消去 1 点；倒地打滚得＋2DP，跳入水中或用灭火器可立即扑灭能以这些方式扑灭的火。多来源取较高燃烧点数；通常的自然火焰每轮减 1 点，特殊燃烧或魔法火焰依其来源的持续及可扑灭条件。

**流血：**每次结束自己的行动时，受到等于当前流血点数的 L 物理伤害，持续至治愈；没有重度或毁灭性后果。每轮开始时可用 2AP（本集迅捷动作）作一次力量判定，每个成功数去掉 1 点流血；也可用标准动作对自己或触及目标作敏捷＋E(医学／急救)判定，成功数每点去掉 1 点流血。该 2AP 与原书同时称“标准动作”，本集只按其 AP 数映为迅捷，不额外给一次标准动作。

**冻结与燃烧：**适温下冻结每轮自然减少 1 点。新受的燃烧点数与现有冻结点数、或新受冻结点数与现有燃烧点数，彼此按点数一比一抵消，最低到 0；若一方声明不可减少，则仅另一方减少。受火焰伤害的冻结目标也按燃烧点数的反制方式处理，除非同一能力同时造成两种效果。

**欲眠（RE 独有）：**影响心灵；每点对身体属性与感知相关判定以及防御造成 1 点减值。关键抵抗属性为意志，重度时睡眠，没有额外毁灭性后果。受到伤害会减少等同伤害的欲眠点数；他人花标准动作叫醒一般睡眠，不因此直接消去仍存在的欲眠点数。

**失速（RE 独有）：**关键抵抗属性为力量、敏捷；每点使移动速度减少 20 米，最低 0。重度速度为 0，无法移动；飞行者开始坠落，在落地前处于浮空状态。没有额外毁灭性后果。

**惊惧斩的 4AP 动作剥夺：**失去本次行动尚未使用的移动动作；若本次已无可失去的移动动作，则失去下一次自己的移动动作。只剥夺这一动作，不使整次行动或下一整回合消失。

## 感知、定位与视线

**模糊定位**是大致知道位置：可攻击该位置，但相关判定失去一半成功数，通常不能以该生物为需要取目标的非攻击效果对象。**精确定位**知道确切位置，攻击不受这项模糊减值；若非攻击效果要求取目标，仍须有适用视线。选择区域或位置与选取生物目标是两种不同资格。正常视觉敏感距离若尚未确定，901 新建基线为`10×感知＋20×A(感知)`米；它不自动产生盲感、听觉敏感范围或穿墙视线。

**盲感**至多取得模糊定位；**盲视**至多取得精确定位，并可提供适用视线。它们通常不能绕过障碍物；只有另有透视等明确来源时才穿障。盲感、盲视的实际范围依受术者已有的相应模糊／敏感感知范围，不由施法者智力凭空新增范围。侦测等级对反侦测等级按各术交互，不能把“察觉波动”直接当成知道完整法术、精确定位或识破所有隐形。

## 防护、攻击关键字与物体

**法术抗力 X**在基于威力的效果对目标生效前，把该效果对目标的有效威力减少 X，最低为 0；先定施法威力与上限，再算抗力，不在伤害阶段重复扣。若效果明说可主动压制自身法术抗力，可无动作压制。不同来源的 RE 法术抗力依其明文叠加。它与能量抗力、DR、全伤害吸收、伤害抵消是不同防护；某术写以两倍能量支付来抵消伤害时，仅该术依其消耗比率结算，**法术抗力本身不自动带来通用抵消**。

**硬度**须有物体或能力来源。对物理伤害，每点未被击破的硬度减少 1 点伤害；精神、毒素不受硬度影响，能量伤害依其具体伤型规则。**伤害抵消**则按提供它的能力明列动作、能耗与额度，从最严重的伤害开始抵消；未限定伤型时可用于物理、能量、坠落、坠落物、精神及力场伤害。伤害阶段的抵消不倒扣先前攻击 DP。

| 关键字 | 对一次攻击的实际作用 |
| --- | --- |
| 高速 X | 每点依序减少基础防御、闪避、非盾牌格挡、洞察或修行防御 1 点；范围伤害则使反射豁免 DP 受相应减值。不扣盾牌格挡。 |
| 破甲 X | 每点依序减少掩蔽、力场、器械、盾牌格挡、盔甲、天生防御 1 点；破尽可破防御后的剩余值再破硬度。 |
| 破魔 X | 每点依序减少幸运、士气、增强、神圣／亵渎、招式、表现、内在或无名防御加值 1 点，不附送其他效果。 |
| 能量武器 | 远程能量武器令目标受 D 级措手不及影响，且至多把武器伤害的一半转为 A 伤；未另写时为纯能量伤害。范围伤害仅保留相应伤害转化，不因此把全区域目标都视为受远程武器措手不及。 |
| 防能量武器 | 阻止能量武器把伤害转化为 A；不等于免疫该攻击的原有伤害。 |
| 防弹 | 实弹枪械攻击的伤型降低一级，最低 B。若防弹来源不在盔甲上，破甲将目标的天生防御全部破除时，此防弹失效；“防弹（载具）”另有自己的载具护甲与武器伤害附加成功规则，不与普通防弹混用。 |
| 格挡 | 用该武器格挡时，另获得等于武器基本体积的盾牌防御；同时只能从一件有格挡特性的武器取得此收益。若盾牌防御来自该武器体积，还须按持用者适用体积调整修正其基础值。 |
| 魔法 | 魔法攻击按适用伤害减免的穿透条件结算；魔法武器能伤害虚体，伤害减半，仍不能仅凭“魔法”伤害灵体。法术及通用能量直接制造的攻击通常有魔法特性；用法术遥控一件普通武器攻击，不使该武器自动取得魔法特性。 |
| 幽冥 | 可直接影响并伤害灵体、虚体，造成 A 伤；目标作强韧豁免，每个成功数使 1 点 A 降为 L。有此特性的物品也能被灵体、虚体使用。仅能正常攻击灵体的其他能力不自动取得“幽冥”或 A 伤。 |
| 神圣／光明 | 对黑暗生物造成的神圣伤害，增加目标黑暗层级×5点；目标须确有黑暗生物层级。 |
| 亵渎／黑暗 | 对光明生物造成的亵渎伤害，增加目标光明层级×5点；目标须确有光明生物层级。 |

**贯穿：**成功对一个目标造成伤害后，立即可对同一直线的下一合法目标再作一次攻击判定，新判定的攻击 DP 须减去上次攻击造成伤害数的 DP；逐次继续，直至没有合法目标或某次未造成剩余伤害。穿过全掩蔽物攻击其后目标时，克服掩蔽物硬度和剩余生命值的代价从攻击 DP 扣除，而非从伤害扣除。一次贯穿效果至多影响同一目标一次。若“贯穿”给的是范围伤害，范围内直线路径上累计硬度不超过`伤害值×2`的物体会被摧毁（通常不含装备与携带物，载具例外）；每摧毁一件物体，越过它的路径上的范围伤害减少其实际生效硬度。载具在此按生物而非可直接摧毁的物体处理。

法术写“传奇智力”或其他传奇属性点数时，只取人物已有且适用的该属性传奇来源；901 属性或技能固定自动成功不因数值相同就变成传奇属性点数，也不凭空提高本术所需的传奇值。

只有条目明确给予这些 RE 关键字时才适用上表；旧 PHB 装备仅写“破甲 X”而无 RE 语义来源时，仍按其装甲语义逐层处理，不自动取得 RE 的扩大类别。

**物体硬度与生命：**已具有 RE 等级与旧分值、且未另写硬度的物品，可依该物品的旧等级折为 D＋分值／1000 并向上取整，或取明确材质硬度中较高者；默认生命为`5×(硬度＋体积调整)`，体积调整在该默认式中最低按 0，生命最低 1。物体只有一条生命，B/L/A 伤型对它均扣同样的物体生命；无心智物体免疫影响心灵、疾病、毒素及多数状态。直接以 901 XP 定价的新物品若无对应旧等级／分值或材质数据，须在物品条目给硬度与生命，不拿 XP 擅换旧分。普通持用物体通常不被范围伤害顺带击中，载具及专门效果另按自身条文。

**医疗点数：**治疗点数与医疗点数是同一资源，不能储存的点数立即用完；没有自由分配文字时，先治疗最重伤势。每点能修复多少 B、L、A 伤势或状态点数由具体法术写明，例如《水之抚慰》每 1 点修复一个 B 或 L 槽、每 4 点修复一个 A 槽，并准许分配；这不是其他法术的统一换算。全部生命槽已为 A 时角色死亡，普通医疗点数不自动复活。

遗体防腐若作为结界法术存在，依其结界条目使用；帝国禁止死灵专精不使所有涉及遗体的结界效果一概禁用。
