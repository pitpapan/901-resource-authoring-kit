# 帝国通用魔法·施法通则

本页用于帝国法师学习和施展已列出的 D、C 级通用法术。各法术的动作、成分、目标、能耗、持续与特殊结算以其条目为准；本页提供未另写时的共同结算。帝国法师可以学习合法的其他系法术；其专精加值只在对应条件成立时生效。死灵法术列于禁用附录，不属于帝国法师可选课程。

## 属性、技能与资格

901 使用力量、敏捷、智力、感知、意志、风度六属性。旧规则的耐力／体质职责由力量承担，旧决心／沉着职责由意志承担，旧操控职责由风度承担；旧力量、敏捷、智力、感知、风度依其原有功能使用。旧公式含有两个现已合并的属性时，按该检定的实际功能改写，不将同一新属性重复相加。

施法关键属性默认是**智力**。有明确天生魔力或其他已取得能力替换关键属性时，该来源指定的属性同时替换本术的施法判定、射程、范围和其他效果中的“智力”，不改变未被替换的属性、学习资格或魔力池来源。角色已有的异式魔力池按其自身条目运行；普通帝国法师魔力池的上限与恢复见[能力组](../imperial-mage.md)。

通常施法判定的骰池为`关键施法属性＋E(神秘·本术专业)＋适用加值`。有效技能`E＝主技能＋最贴切的一个匹配子技能`；没有该子技能时只用主技能。主技能至多 5，子技能按实际等级，不因条目写有专业就赠技能等级。法术并列要求两个专业时，学习与施展均须具备两项资格；写“或／或者”的专业则满足其中一项即可。同次检定仍只加最贴切的**一个**子技能，不把两个专业的等级相加。条目另写制作、攻击或其他判定时，使用条目指定的骰池。

先核法术是否已学、施法职能等级、专业、知识与目标资格，再投 D10；每颗 8—10 得 1 成功，10 可继续加投。合法检定中的 901 属性／技能自动成功直接计入，即使投骰为零成功；明确称 RE“附加成功”的效果仍依其有效掷骰成功数门槛。普通对抗由主动方达到被动方成功数即成功；法术另写豁免抵消或逐目标对抗时按该术处理。

**常用豁免骰池：**反射＝`敏捷＋E(运动)`；强韧＝`力量＋E(求生)`；普通意志检定及未另改写的意志豁免基础 DP＝`意志＋风度`。专门替换骰池、加值和自动成功照其来源加入一次。豁免是被动抵抗，不自行消耗施法者或目标的战斗动作。

## 等级、威力、能量与学习

| 法术版本 | 法术等级 | 基础威力 P | 通常威力上限 | 默认施放耗魔 | 独立学习 XP |
| --- | ---: | ---: | ---: | ---: | ---: |
| D | 1 | 3 | 4 | 1 | 10 |
| C | 2 | 6 | 8 | 3 | 25 |

`P` 是本次法术的有效威力；提升威力只影响条目明确随 P 变化的数字，不自动提高法术等级、侦测等级或未写 P 的效果。个别法术的自身基础威力、能耗、价格或威力上限若明列不同，以该条为准。法术能耗由实际可用的魔力池支付；明确允许替代能源的能力按其条目处理，不令所有法术任意换池。

学习**原生 C 级法术**只需达到 C 级施法职能并满足该术资格，按该术的 C 级价格学习；原生 C 术没有 D 版先修。把**已学 D 级法术升阶为 C 版**时，才要求已学该术 D 版：保留 D 版并学习 C 版，另付 25 XP，两版分别可用；舍弃 D 版而以 C 版替换，付差额 15 XP，之后不能再用 D 版。帝国法师能力组明列的授术特性只赠 **D 版**，不另付该次 D 版学习 XP，不连带赠 C 升阶。条目原生价格、另列进化或特别前提不同者，照该条单独结算。持有 XP 本身不代替知识、专业和取得资格。

## 动作与时机

自己行动内至多使用一个标准、一个移动、一个迅捷动作；标准可换移动，移动可换迅捷，不能反换。自由动作通常仅在自己行动内使用。下表右侧是本组转换法术的**施放动作**，没有可储存或逐点消费的 AP 池。

| 原条目施放价 | 本组支付的 901 动作 |
| --- | --- |
| 1—2 AP | 迅捷动作 |
| 3—4 AP | 移动动作 |
| 5—6 AP | 标准动作 |
| 7—8 AP | 同次行动的标准＋迅捷动作 |
| 9—10 AP | 同次行动的标准＋移动动作 |
| 11—12 AP | 整轮动作，占本次行动的标准、移动、迅捷；合法自由动作照常 |
| 14 AP 的传送术 | 本次整轮施法，并在下一次自己的行动支付迅捷动作后完成；期间持续专注 |

14 AP 传送在第二次行动的迅捷动作付清前不生效；若不能支付或专注中断，本次施法失败，已付动作与消耗不退。其他超过 12 AP 的法术在自身条目写明跨轮支付与完成时点。法术直接写反射、自由、持续仪式或多轮动作时，保持其行为与时机，不用数字表覆盖。一次施放需要的两类动作须在同一行动支付；不足则不能开始。10 AP 是标准＋移动，12 AP 是整轮，不借 AP 恢复跨回合拼付。

法术若增减其施放 AP，先按该术文字计算最终数值，再以表中覆盖该数值的最小动作档支付；减费不能凭差额换取另一次动作。降至 0 AP、AP 回收、临时 AP、额外 AP 或预支 AP 的条目，须在该法术中明确可用时机、占用哪次动作与次数；没有单项说明时，不产生可储存 AP 或额外施法。原文反射动作可在允许的时点中断，但使用后至下一次自己的行动结束前不能再用反射或迅捷；反射不会免除法术另外明列的动作或能耗。需要占用下一次行动的法术，不能重复预支同一动作。

## 成分、专注与目标

除条目免除外，法术受**语言、姿势、专注**三项限制。姿势要求能够正常动作且至少空出一只手；无法行动、被定身或受其他明确妨碍时不能完成。语言须清晰咏唱；与施法者有合法效果线、且施法者落在其模糊感知范围内的生物，会因此获得施法者的模糊定位。法器须实际拥有并能传递该术魔力；材料与仪式成分照法术条目准备。材料标注的旧“分”只是该物的材料资格／品级，不是 901 奖励点或学习 XP，不直接按数字扣 XP；材料如何取得依场景和具体条目。仪式要求持续投入的行动和专注，不把长时施法压缩成单个战斗动作。

施法或维持专注时受伤，以该次伤害点数为专注难度；已有不良状态以当前全部未忽略状态点数之和为难度，新添状态点数时立即重检。专注检定结果是一次意志豁免与一次强韧豁免的结果之和，**不计**这两次判定中来自属性、技能的自动／附加成功；其他明确适用的加值照常。失败失去本次施法已投入的动作、能量与材料。持续时间本身不等于每轮必须支付维持动作；只有条目写有维持动作才逐次支付，且施放减费不自动降低维持动作。

指定单体通常须精确定位，指定区域须确定中心或边界；默认需要视线与效果线。接触自愿目标无需攻击；接触非自愿目标须命中：近战接触用`力量＋E(神秘·本术专业)`，若接触射程被改变为非近战，则用`敏捷＋E(神秘·本术专业)`，对目标适用防御结算。未命中仍消耗施放动作和能量。法术的友军排除、隐形识别、穿障与范围边界只能依其明文，不能从名称推得。

## 效果结算

以施法判定作**法术攻击**时，攻击 DP＝`关键施法属性＋E(神秘·本术专业)＋条目明确计入的武器伤害或攻击 DP 修正－目标适用防御`；目标防御只扣一次。部分法术并不把 P 加入骰池，P 是武器伤害、额外加值还是效果强度以该术文字为准，不能重复加入。条目若只给定值回复、固定伤害或持续加值，不为使用专精加值而补造一次攻击判定；只以豁免抵消的定值范围术不扣目标被动防御。各目标分别豁免的范围法术依条目逐个结算，不把一次施法自动当成多次攻击。需以判定造成伤害、且未另写伤害上限的法术，伤害上限为`4P＋E(神秘·本术专业)`。

伤害依次结算攻击有效性、成功数和上限；免疫、确有来源的硬度／吸收／DR／能量抗力等；再结算临时生命、降级与 B／L／A 伤势槽。目标防御只在攻击 DP 中扣一次，伤害阶段不重复扣。同次伤害多个同类 DR 或抗力没有明确叠加时取最高。法术若按医疗点数修复伤势，转换比率以该术条目为准；状态点数的减少不自动变成后续免疫。重复施展同源增益通常只取最高适用值并刷新持续，已经消耗的临时生命不会因此在同一次施法中自行回充。持续范围是否随施法者移动、离区是否失效、受护对象可否重选，均按该术的明确效果处理。
