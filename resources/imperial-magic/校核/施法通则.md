# 施法通则校核

本页仅记录 [玩家通则](../00-施法通则.md) 所采用的来源与本批转换边界，不改变库内规则。

| 项目 | 来源与本批处理 |
| --- | --- |
| 六属性、技能、成功与豁免 | [901 核心 §1—3](../../../rules/901-core-rules-v0.1.md)：旧耐力／体质→力量、决心／沉着→意志、操控→风度；`E＝主＋最贴切一个子`。反射＝敏捷＋E(运动)、强韧＝力量＋E(求生)，普通意志基础 DP＝意志＋风度。旧双属性公式按功能去重，非机械替字。属性／技能自动成功与 RE 附加成功门槛分列。 |
| 职能、施法属性及专业 | [RE《施法规则》24—35、148—166行](../../../content/RE/01_rules/02_战斗与动作/施法规则.md)规定法术施法判定、双专业资格、天生魔力／特殊来源替换属性、非自愿接触攻击，以及合并职能与本职树时的共同限制。901 子技能不叠加；已确认人物异式池优先。 |
| 法术威力、耗能及升阶 | [RE《施法规则》85—112行](../../../content/RE/01_rules/02_战斗与动作/施法规则.md)给 D/C 基础威力 3/6、耗能 1/3、通常上限 `⌊基础×4/3⌋`、学会后升阶、保留低版或替换。D+500 自学 10XP、C+1000 升阶25XP／差额15XP见[自学规则](../../../content/RE/01_rules/03_其他规则/自学规则.md)；逐项异价仍按法术条目。能力组赠 D 只赠该版本。 |
| 已确认动作 | [901 核心 §4](../../../rules/901-core-rules-v0.1.md)确认标准／移动／迅捷次数、替换关系、反应锁及 2/4/6/8AP 对应动作。其余 AP 数值与回收／预支不属于已确认的全局换算。 |
| 本批其他施放价 | 为完整 D/C 法术逐项接入，`1/3/5/7/9/11AP` 在施放终价上向上落至迅捷／移动／标准／标准＋迅捷／标准＋移动／整轮；10AP＝标准＋移动；12AP＝整轮。14AP 传送为整轮＋下一行动迅捷完成，期间专注。减费先算终价再落档；0AP、动作赠予、恢复或预支须在法术条目定义时机与次数，不能恢复 RE AP 池。以上是本批明列操作约定，非快照或 PHB 现有通则。 |
| 成分、专注、接触 | [RE《施法规则》10—19、154—167行](../../../content/RE/01_rules/02_战斗与动作/施法规则.md)给姿势／语言／专注、法器／材料／仪式及非自愿接触。专注合并意志和强韧结果，排除属性技能附加成功；本稿与[已有配套法术](../../imperial-mage.md)一致，也排除 901 同功能自动成功。原材料旧分数只作材料资格，不转为 901 XP 或奖励点扣款。 |
| 攻击、伤害、治疗及状态 | [RE《施法规则》177—187行](../../../content/RE/01_rules/02_战斗与动作/施法规则.md)给需掷骰造成伤害的默认上限 `4P＋施法主技能`，901 双层技能把主技能项映射为有效施法技能。防御只扣一次、三阶段伤害、B/L/A 槽与状态沿[901 核心 §5—6](../../../rules/901-core-rules-v0.1.md)。定值法术不凭空产生施法攻击，治疗点数仍按各法术给的转换率。 |
| 感知、视线及目标 | [901 核心 §6](../../../rules/901-core-rules-v0.1.md)已给正常视觉新建值但不产生其他感官。PHB [战斗行动](../../../content/PHB/01_rules/非战斗行动与战斗行动.md)及 RE [侦测与定位](../../../content/RE/01_rules/02_战斗与动作/侦测与定位.md)提供定位、模糊／敏感感知、视线与效果线的源术语；法术排友、穿障、盲感、盲视须另看其自身条目。 |

**核对提示。**范围法术的目标是否可排除友军、一次施法是否逐目标攻击、减防是否叠加、多段伤害各过什么防护，不能由通则替每道法术补写。含 0AP、AP 恢复／预支、长时仪式、可选施法方式或特殊能耗的条目，须在各条明确具体行动后再交付玩家使用。

## 状态与特殊机制页依据

- 普通状态逐点减值、重度继续保留轻度效果、阈值、去重与恢复：[PHB《生存状态》](../../../content/PHB/01_rules/生存状态.md)第 136—153 行及[901 核心 §6](../../../rules/901-core-rules-v0.1.md)第 99—105 行；具体恶心至肢体妨害、情绪三类、冻结与燃烧的轻／重度后果见 PHB 第 207—302 行。冻结与燃烧的一比一反制细节见[RE《燃烧点数》](../../../content/RE/01_rules/02_战斗与动作/燃烧点数.md)第 22—24 行。流血的行动末 L 伤、无重度及自止／急救动作见[RE《流血点数》](../../../content/RE/01_rules/02_战斗与动作/流血点数.md)第 10—20 行；原文“2躯体AP的标准动作”与本集动作表名词不合，本集明确按 2AP 映为迅捷动作。RE 独有的[欲眠](../../../content/RE/01_rules/02_战斗与动作/欲眠点数.md)、[睡眠](../../../content/RE/01_rules/02_战斗与动作/睡眠.md)与[失速](../../../content/RE/01_rules/02_战斗与动作/失速点数.md)保留本身用途，阈值改用 901 §6。PHB 未将“仇恨”单列为通用异常，术语页不代具体法术编造重度后果。
- 模糊／精确定位、盲感／盲视与障碍物：[RE《侦测与定位》](../../../content/RE/01_rules/02_战斗与动作/侦测与定位.md)第 8—31 行；正常视觉新建值：[901 核心 §6](../../../rules/901-core-rules-v0.1.md)第 105 行。
- 法术抗力、能量武器与高速／破甲／破魔：[RE《物品关键字》](../../../content/RE/01_rules/04_附录/物品关键字.md)第 18—31、75、82—83、93 行；硬度／伤害抵消：[RE《防御类型》](../../../content/RE/01_rules/02_战斗与动作/防御类型.md)第 95—114 行。未见法术抗力自身附带通用“两倍抵消”的规则，不能将两种防护合并；若具体法术写两倍耗能抵消，须在该术另核。
- 其他已用关键字的完整结算：[RE《物品关键字》](../../../content/RE/01_rules/04_附录/物品关键字.md)第 62—66 行为防弹及载具区别，第 85—87 行为贯穿，第 95—102 行为魔法、幽冥、神圣／光明及亵渎／黑暗，第 112—115 行为格挡。能够伤害灵体并非取得“幽冥”的 A 伤或降级豁免。能力写传奇属性点数时按人物已确认来源读取；[901 核心 §1—3](../../../rules/901-core-rules-v0.1.md)第 28、38—42、50 行把固定自动成功与传奇智力点数分别记载，不能互代。
- 物体生命、硬度与体积调整：[RE《物品和装备位》](../../../content/RE/01_rules/04_附录/物品和装备位.md)第 114—121 行及[规则术语解释](../../../content/RE/01_rules/04_附录/规则术语解释.md)第 205—208 行；医疗点即时使用及优先伤势：[RE《生命值》](../../../content/RE/01_rules/02_战斗与动作/生命值.md)第 180 行。
