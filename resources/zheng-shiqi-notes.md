# 正十七：预算与样板依据

对应[纯净条文](zheng-shiqi.md)。按本项 4C 容量核算，C 级、25 XP 仍为候选；11D 类比分配尚未核定通过，具体缺口见合算判断。

## 预算、XP 与近例

**容量口径。**[RE 撰写规则](../content/RE/01_rules/03_其他规则/撰写规则.md)第 39—45 行给独立 C 技艺基础 **3C**；[RE 数值类特性](../content/RE/04_traits/可以确认的特性/数值类特性.md)第 78—83 行规定 4AP 得**次级特性**、6AP 才得同级特性；[RE 防御类动作](../content/RE/01_rules/02_战斗与动作/防御类动作.md)第 29—35 行白刃格挡用 4AP。[901／PHB 格挡](../content/PHB/01_rules/非战斗行动与战斗行动.md)第 202—205 行在本稿映射为移动等效动作。因此按 RE 原表直算是 **3C＋1D＝10D**，不能从“移动动作”直接推出 4C。本轮遵用户对正十七的明确口径，以 **4C＝12D** 作主核算；两种容量不叠加，动作和效果正文不变。

**合算判断。**按技能／传奇点联动完整近例的候选分配是 **`1D＋4D＋3D＋3D＝11D`**：在用户本项 **4C＝12D** 容量内余 1D，按 RE 原动作补偿 **3C＋1D＝10D** 则超 1D。②若暂按默认读数 `W6＋A6＝12` 的普通固定防御粗尺取 **6D** 而非 4D，合计变为 **13D**，超用户容量 1D；此对照不能机械替代成长机制类比，但两者差额也不能由“杠杆不同”或未说明的免税规则抹去。③目前仍只找到“免全力／冲锋所致减防”的 1C 特性和一剑藏空整包的近似交互，**是四笔中最弱的价格类比**；它与本项“只保护一份偏斜免受各种整体防御减值”没有同范围明价。④以受力格挡、学识替代的条件化 C 特性对照 B 阶常驻传奇属性吸收，仍是候选而非拆出的单价。因此 **C+1000／25 XP 有可说明的 11D 候选路线，但尚不能称已通过预算核定**；若②按固定值尺或③估价上调，12D 即可能不足。保持效果不变，不拿容量差额倒填或倒削组件。

**版本与 XP。**本稿保留 PHB 偏斜类别；RE 后版曾把偏斜并入力场（[V105](../content/RE/00_meta/关于本书/2.5R_V105.md)第 31 行、[V1055](../content/RE/00_meta/关于本书/2.5R_V1055.md)第 15 行），但不据该版本合并再按破甲收费。[自学规则](../content/RE/01_rules/03_其他规则/自学规则.md)第 12—14 行据 C+1000 换算 **`3×5＋1000÷100＝25 XP`**；[901 核心规则](../rules/901-core-rules-v0.1.md)第 48 行仍将旧公式作为估价参考、单项采用，故 25 XP 是本项候选而非全局自动定价。4C 是本项采用的可用容量，不自动改变 C+1000 的原价或按实际 11D 比例折价。四笔收益仍同时受正文的学识替代与合法受力格挡条件约束，效果正文未改。
