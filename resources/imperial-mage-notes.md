# 帝国法师预算与依据

对应[能力组正文](imperial-mage.md)及[完整通用法术](imperial-magic/README.md)。本页保留各项明价、类比估价和余量，不因正式收库而将类比变成 RE 明价或全局价表。NPC 法系辨识依本资源的用户指定福利处理，不计预算；本批适配仅用于对应资源。

## 预算与 XP 依据

**模板与报价。**RE 能力组普通容量为 D 阶 4D、C 阶 4C，各另有一次同级树入口；D 阶有能量池，不领取无池的额外 2D。候选价格沿能力组模板 D＋1000、C＋2000；旧自学式换算为 D `1×5＋1000/100＝15XP`、C `3×5＋2000/100＝35XP`，两阶分别支付共 50XP。它们是本稿的逐项候选，不是 901 通用价表，也不包括另购法术；是否取得仍受知识、来源与剧情资格约束。

**D 阶投入。**一项 D 级通用法术是明确授予的本体成果，直接参照 RE《法师》D 阶以三特性「魔法奥义」授一项 D 通用法术，暂记 **3D**。治愈、变化、预言、塑能、幻术的限定＋3DP直接参照数值表 **1D**；炼金入门的＋1／鉴定再＋2在任何一次适用检定最多＋3DP，按同一 1D 候选类比；防护的条件性本人防御＋3按普通防御＋3的 1D 标尺作候选，召唤魔力上限＋5有《幻术师》D 一特性完整近例；心灵入门的负面点数先减 4 是特性表明价 **1D**。各行 D 入门只择一，不九项累加。这样每位学徒实际**候选估计4D／容量4D**；D 模板只开普通魔力池，感官不在此列，合并树入口也不从四个本体特性里重复扣除。艾利异式体质不在这笔账中。

**C 阶共同投入。**魔力上限＋10单独参照 [RE《法师》C 阶奥术](../content/RE/02_resources/能力组/施法类型/法师.md)第 19—26 行，记 **1C 候选**。它与所选专业法术威力＋1同时出现时，还可整体参照 [RE《灭龙魔导士》C 阶「龙之魔力」](../content/RE/02_resources/能力组/施法类型/灭龙魔导士.md)第 26—30 行：完整**双 C 特性**给魔力上限再＋10、所选专业法术威力＋1，故防护、塑能、召唤、心灵四系的组合按 **2C 候选**；治愈的同组数值亦以此作整体样板。召唤 D＋5 与 C 再＋10 的累计也有该原型。《白魔法师》C 的单 C 威力＋1仅限本能力组所列法术，不能当作所有同专业已知法术的同条件单价。**普通魔力感官另记 1D 候选**：RE《魔力体质》将魔力双特性与「基本用法」感官单列，赠送能量池不附赠基本用法。已有原来源感官者继续使用原感官，不叠加出第二份收益。

**C 阶各主修。**治愈在魔力＋10以外保留原卡施法＋4DP，并新得治愈法术威力＋1：魔力与威力按上述完整 **2C 候选**，施法＋4按 [数值表](../content/RE/04_traits/可以确认的特性/数值类特性.md)第 12 行技能＋3及 [RE《法师》D 阶](../content/RE/02_resources/能力组/施法类型/法师.md)第 15—18 行限系施法＋6作 **1C 候选**，不假称＋4有独立明价。变化不再提高威力，而在自身变化法术辅助下步行速度翻倍，按数值表第 23 行一种速度翻倍 **2D 候选**；幻术的每日一次、仅本组已知术瞬发，按 [RE《白魔法师》C 阶](../content/RE/02_resources/能力组/施法类型/幻术师和白魔法师.md)第 20—24 行一项 C 特性作 **1C 整体候选**。其标准动作 6AP→4AP 的反射时机、下次行动支付及反应锁为本项 901 适配，不把 4AP 当免费动作，也不赠 B 级操控。炼金的同系制备时间减半直接作用于本批两道既有配方，对照 [RE《魔法工程师》技能树《万巧天工》](../content/RE/02_resources/能力组/施法类型/魔法工程师.md)第 39—42 行的制作加速方向，因原型同时减造物 XP，不能拆其完整价格；本稿限于已知炼金法术的明列制备时长，以 **1C 有界类比候选**计，不取得原型的 XP 减免。炼金另授一项 D 通用炼金法术，预言授两项不同 D 通用预言法术；每项授术均沿 [RE《法师》D 阶「魔法奥义」](../content/RE/02_resources/能力组/施法类型/法师.md)第 9—14 行的明确 **3D** 结构。预言三道可选课程中《识破隐形》和《解析弱点》分别见 [RE D 级《预言》](../content/RE/02_resources/技艺/技巧/施法类型/通用魔法/D级通用魔法/预言.md)第 17—30、91—108 行，均为 D＋500；授术发生在 C 本体，不能再收被赠法术的 10XP。不同副修只取得一个 D 入门，按上项 **1D 候选**。所有专精的 NPC 自动辨识均在预算之外，依本次用户调整授予，不作特性估价。

**替换数值的增量。**炼金 D 已为一般炼金＋1、鉴定再＋2（鉴定总＋3）支付 **1D 候选**；C 只新增一般炼金＋3，使一般总＋4、鉴定总＋6。新增是一次技能加值＋3，按数值表第 12 行记 **1D 候选**，不再把 C 的终值＋6当成从零新购的 1C。预言 D 已支付有条件侦查／鉴别＋3的 **1D**；C 再增＋3至总＋6，同表记新增 **1D 候选**。两者均为同数值累计两笔 D 级投入，尚未达到表第 35 行同级三笔的重复税节点；此为本稿跨阶增量记账，不宣称 1C 等于数值三倍，也不据《武士》两行属性总值反推替换售价。炼金新增的＋3实际适用于[配套《魔水融合》](imperial-magic/08-炼金配方.md#魔水融合)的制作检定；祝圣水仍无制作检定，不硬造掷骰。

各行的副修若未选择，再少投 1D，不因此获得第二项主修。余量只是容量，不是已购买收益；NPC 自动辨识由用户指定为免费福利，不在表内。D **15 XP**、C **35 XP**仍是两阶能力组的模板候选价，不按余量比例减价，也不将法术自己升阶的效果计入 C 能力组：法术 D→C 另购 25 XP 或替换差额 15 XP；D 本体明确赠一项 D 法术，炼金 C 主修再赠一项不同 D 炼金法术，预言 C 主修再赠两项不同 D 预言法术，均不重复付各自的学习 XP。

**适用边界。**NPC 自动辨识按本次用户决定执行，不列为待核预算。其余原创专精沿用本稿样板与候选报价；没有施法／对抗判定或没有「威力」栏的法术，不得为了让专精生效而凭空增加一个检定或参数。
