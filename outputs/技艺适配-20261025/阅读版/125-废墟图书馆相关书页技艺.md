# 废墟图书馆相关书页技艺

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>

<a id="L7"></a>
## 动作太慢 〔候选5XP〕

以一个标准动作，消耗1点精力，冷却2轮，指定一个目标，你在1轮内针对目标的下次攻击获得6点闪避加值，并在受到该攻击后移动最多2米对其发起一次近战攻击（移动后目标依旧不在触及范围内则无法进行，此外若对方该次动作还剩余攻击次数，本次攻击可以用于对攻），若对方此次未能造成伤害，你对其发起的下次攻击获得2个附加成功。


<a id="L10"></a>
## 发号施令 D级〔候选10XP〕

以一个标准动作，消耗1点精力，冷却2轮，你发起一次获得6点招式加值的近战攻击。同时你在获得格挡防御时格挡加值额外获得6加值，敏感范围内的友军获得1点DR/-与全能量抗力，持续一轮。


<a id="L12"></a>
## 回旋斩击 D级〔候选10XP〕

前提：白刃2级，敏捷4，力量4

以一个标准＋移动动作，消耗2点精力，冷却2轮，你以重剑分类的白刃武器发起三次攻击造成挥砍伤害的近战攻击，第一次获得3点招式加值，第二次承受3点招式减值但最终的伤害上限减半，第三次承受6点招式减值的同时最终成功数与伤害上限减半。

若你额外消耗两倍的意志力或精力，你可以以一个反射动作施放本技艺。


<a id="L16"></a>
## 天将拂晓 D级〔候选15XP〕

前提：白刃5级，力量6

以一个标准＋移动动作，消耗3点意志或精力,冷却6轮，你进行一次半速移动以及格挡后以重剑发起一次全力白刃近战挥砍攻击，你受到的下一次攻击时格挡防御提升6点（若用于对攻则在面对对方对攻的攻击生效，即使对方对攻的攻击可能会因为拼点失败而失效），你以本技艺发起的RE全力攻击获得18点招式加值。若你的攻击能造成火焰伤害或燃烧点数，则本次攻击在造成实际伤害时额外对目标造成2点火焰伤害或燃烧点数，该燃烧点数可叠加不可豁免。

若额外支付双倍意志或精力，你可以以一个反射动作使用本技艺。


<a id="L20"></a>
## 致命穿透 D级〔候选15XP〕

前提：白刃5级，力量6

以一个标准＋移动动作，消耗3点意志或精力,冷却6轮，你以能造成穿刺伤害具有长柄武器特性的武器进行一次RE冲锋攻击，本次RE冲锋攻击获得18点招式加值，并且造成额外4点同类伤害。


<a id="L23"></a>
## 锋芒毕现 D级〔候选15XP〕

前提：白刃3级，力量6

以一个标准动作，消耗2点精力，冷却1轮，你以能造成挥砍伤害的武器进行两次承受3点增强减值的近战白刃攻击，同时你发起的造成挥砍伤害的近战攻击武器伤害提升2点，持续时间一轮。


<a id="L26"></a>
## 黑云翻墨 D级〔候选15XP〕

前提：白刃4级

以一个标准＋迅捷动作，消耗3点精力或意志，冷却4轮，你以能造成挥砍伤害的武器进行两次获得6点招式加值的近战全力白刃攻击，你每有一个仅有主动施放方式且不具有其他效果，具有冷却时间但任意用法都不处于冷却时间的D级以上技艺便在第一次攻击中额外获得其等级点招式加值，至多再获得12点招式加值。


<a id="L29"></a>
## 一刀毙命 D级〔候选10XP〕

前提：白刃4级。

一刀毙命：以至少移动动作代价进行的近战白刃攻击，若该动作只攻击一次，可额外付1精力或意志点，获得12点修行攻击DP。


<a id="L32"></a>
## 神龙抬首 DD级〔候选20XP〕

前提：敏捷6，肉搏5

以一个反射动作，消耗1点精力或意志力，冷却1轮，你以腿部天生武器进行一次近战攻击，本次攻击获得6点招式加值，具有击飞特性，若本次攻击命中，可以缩减本页面内炎龙贯拳、铁山靠、飞燕疾风一轮冷却时间。本次攻击若用于对攻，则你可以在投掷攻击检定之前向对攻目标移动运动*3米的距离。

飞燕疾风（5XP）：你获得另一种用法—飞燕疾风

以一个标准动作，消耗3点精力或意志力，冷却3轮，你以腿部天生武器进行一次近战攻击，本次攻击获得12点招式加值，具有击飞特性，若本次攻击命中，可以缩减本页面内炎龙贯拳、铁山靠、飞燕疾风一轮冷却时间。施放后在持续时间内你可以以一个反射动作消耗1点精力以天生武器应对攻击发起对攻，直到你的对攻失败，持续1轮。


<a id="L38"></a>
## 生死界限 C级〔候选25XP〕

前提：白刃4级、敏捷4、意志4、感知4。

以一个反射动作，支付4点意志力，冷却4轮，你发起一次RE冲锋近战白刃攻击，在计算攻击DP之前，你可以投1D4作为自然骰，若结果为4，本次攻击中你RE冲锋获取的加值不受属性限制，并且获得45点招式加值、4点武器伤害提升和4点额外伤害上限，若成功命中目标，你可以向前继续移动至多等同你RE冲锋的剩余距离而无需进行闯越等判定，随后将武器收起入鞘。以本技艺发起对攻时强制对方应对进入对攻流程而无法拒绝（这并不阻止对方放弃本次攻击从而使这次攻击行为结束），你可以以此技艺向远程攻击发起对攻。

## 铁山靠 C级〔候选25XP〕

前提：肉搏6，力量6，敏捷6

以一个标准＋移动动作，消耗3点意志,冷却6轮，你进行一次半速移动后进行第一次肉搏近战攻击，该攻击获得6点招式加值，在攻击完成后能够立刻进行一次冲撞，若本次冲撞对抗你取得成功则对方的格挡状态结束需要重新格挡（若为总是视为格挡则视作其失效一轮）。这之后你能够再进行一次半速移动后进行全力肉搏近战攻击，该次攻击获得18点招式加值并具有眩晕特性，在攻击完成后能够再进行一次冲撞，且若两次冲撞都为同一目标则将上一次攻击冲撞的成功数作为DP计入。若你的攻击能造成火焰伤害或燃烧点数，则第二次攻击在造成实际伤害时额外对目标造成1+本场景满足基因锁开启状况的次数点火焰伤害或燃烧点数（至多6点），该燃烧点数可叠加不可豁免。以本技艺发起的冲撞中，方向由你选择，并且获得对应攻击的招式加值（第一次为6，第二次为18）。

若额外支付一倍意志或精力，你可以以一个反射动作使用本技艺。


<a id="L46"></a>
## 炎龙贯拳 C级〔候选25XP〕

前提：肉搏6，力量6，意志6

以一个标准＋移动动作，消耗4点意志,冷却6轮，你进行一次格挡后以手部的天生武器进行一次RE冲锋RE全力攻击，你受到的下一次攻击时格挡防御提升12点（若用于对攻则在面对对方对攻的攻击生效，即使对方对攻的攻击可能会因为拼点失败而失效），你以本技艺发起的攻击获得24点招式加值，且具有击飞、眩晕特性。若你的攻击能造成火焰伤害或燃烧点数，则本次攻击在造成实际伤害时额外对目标造成6点火焰伤害或燃烧点数，该燃烧点数可叠加不可豁免。

若额外支付一倍意志或精力，你可以标准＋移动动作以反射动作使用本技艺。

## C级〔候选35XP〕

铁山破势

白刃5，力量8，敏捷6

以一个反射动作，消耗4点意志或精力，冷却6轮，你进行一次半速移动后发起一次全力近战白刃攻击，本次攻击获得24点招式加值，若本次攻击成功命中，则对方的格挡与全防御状态立即结束（若为总是视为等无需启动的格挡与全防御状态则其一轮内无法生效）。

若本次攻击造成物理伤害，你可以选择以下内容中的一种类型。

—本次攻击造成挥砍伤害，并在造成实际伤害后使对方降低12点防御，优先从基础、闪避、格挡、洞察防御开始降低，持续1轮。

—本次攻击造成突刺伤害，并造成等同于实际成功数的流血点数，强韧豁免。

—本次攻击造成钝击伤害，并造成等同于实际成功数晕眩点数，强韧豁免。


<a id="L58"></a>
## 百折不挠 B级〔候选85XP〕

每场景一次，当你受到不高于S级来源的致死伤害或效果时，你免疫这次伤害或效果。

该效果触发后，你获得DR4/-，全能量抗力4，以及全伤害吸收4，持续一个场景。
