# 能量加持

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>

<a id="L6"></a>
## 能量加持（攻击） D级〔候选10XP〕/C级〔候选25XP〕/B级〔候选65XP〕/A级〔候选175XP〕

你在以手持武器或天生武器攻击或应用其效果时，可以消耗1/3/5/7点任意通用能量，本次攻击中武器伤害提升2/4/8/16点，获得6/12/24/48点增强加值，获得魔法，正常攻击灵体特性，并能在火焰，寒冷，电击或不改变中选择一个，你本次攻击的伤害变为该伤害类型。

本技艺各级间可以差价升级。各级效果互相取代。但较高级时可以使用较低级的用法。


<a id="L10"></a>
## 能量加持（防御） D级〔候选10XP〕/C级〔候选25XP〕/B级〔候选65XP〕/A级〔候选175XP〕

你在受到包括攻击在内的效果影响时，可以消耗1/3/5/7点任意通用能量，应对本次效果的防御或豁免上获得6/12/24/48点增强加值，若该效果造成了伤害，你获得3/6/12/24点临时生命应对该伤害。

本技艺各级间可以差价升级。各级效果互相取代。但较高级时可以使用较低级的用法。
