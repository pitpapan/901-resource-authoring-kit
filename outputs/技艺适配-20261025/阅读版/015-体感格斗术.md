# 体感格斗术

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
身法


<a id="L9"></a>
## 在涉及“体感肉搏术等级”时，D级视为1，AA级视为5. · D级〔候选15XP〕

运动闪避：你获得了新的防御方式：运动闪避。

当你以移动动作进行移动时，若你结束时至少偏离你初始位置1米，你进入一种类似格挡的状态，但以运动技能代替通常格挡技能计算格挡加值基本值，这在各种意义上视为你已经进入了格挡状态，但获得的不是格挡加值而是闪避加值，通常你不能再次进行格挡，除非有效果允许你多次格挡，或本能力达到较高等级让你不再视为进行了格挡。

每轮一次，可以反射动作应对一次攻击，针对该次攻击的防御额外获得5点闪避加值。


<a id="L15"></a>
## C级〔候选35XP〕

运动闪避可与一次普通格挡并用，各技能基本值只计一次。上一阶5点主动闪避改为7点；可以改取洞察加值，两者不叠加。仍用同一个反射并受反射锁。

气机查知：只要你穿戴轻甲或不穿甲，并且至少裸露出部分皮肤，你在防御和反射上获得2点洞察加值，在消耗意志力时该加值加倍，同时当考虑多次攻击对你造成的防御减值时，忽略前X次攻击，X为你的体感肉搏术等级的两倍。


<a id="L19"></a>
## B级〔候选85XP〕

动如脱兔：受攻击、需要反射豁免或受到伤害时，可用一个反射沿合法路径移动：前两种最多全速，伤害已确定后最多半速。移出范围在未命中前只使本次防御加倍；伤害确定后不追溯取消伤害。移动完成清空他人对你的瞄准；每轮最多一次并受反射锁。

气机查知：你在防御和反射上获得的加值变为6点洞察加值，同时在你模糊视觉内若有生物向你发起远程攻击或进行瞄准，你自动获得对该生物的模糊定位，这视为一个B级特异本质探知效果。

运动闪避：现在你不再必要以移动动作进行移动来获得效果，任何方式的移动都可以。


<a id="L24"></a>
## A级〔候选215XP〕

气机查知：你在防御和反射上获得的加值变为14点，对远程攻击或瞄准变为精确定位，并视为A级探知效果，你不会因为近战攻击而措手不及，这同样视为一个S级效果。

应力：你在对抗战技（包括擒抱，摔绊，冲撞，闯越，虚招）的判定中获得等同气机查知和运动闪避带来的加值之和的加值。受到部位攻击时，你的防御和部位攻击减值也提升同样的数值。
