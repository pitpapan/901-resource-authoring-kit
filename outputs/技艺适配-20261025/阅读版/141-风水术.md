# 风水术

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
风水术也被视为道术，其专业总是风水术。

特别的，风水术的使用不会消耗道力，而是消耗时间，尽管在能力表述中仍以道力陈述，但不会真正消耗道力，每1点道力转为花费8小时时间对环境进行调理，期间你每轮需要花费一个移动动作来进行调节，但依旧可以进行其他行动，但不能离开风水术的生效区域。使用开光镇物也可以不花费该时间，见后述。

风水术总是可以进一步消耗道力（并转化为额外时间）来扩大生效区域，每增加一倍基础道力消耗，风水术影响的区域也扩大一倍。

若风水术起点设置于地脉节点上（见寻龙特性），风水术中所有列于”效果：“的数值将以1.5倍计算。

要学习风水术，角色必须具有风水术基本特性，或拥有道力。


<a id="L14"></a>
## 风水术基本 D级〔候选10XP〕

你开启了道力能量池。

你获得以下能力：

寻龙：你总是知晓地脉能量的运动流向和聚集节点，该效果可生效于了解龙气的节点或是魔力的地脉等，无论能量类型。如果任务世界中存在的话。

望气：你能察知所看见的角色在当前任务世界世界中的气运，知道其为戏份极重的角色（如主角），有相当戏份的角色（重要配角），有一定戏份的角色（如配角），几乎没有戏份的角色（如龙套）或完全没有戏份的角色（如路人），由主持判定。这是个D级探知效果。

堪舆：你能直接看到风水术技能产生的效果，从而了解一片区域是否已经处于一种或多种风水术的作用之下，并能了解其作用。

开光：以一个标准动作消耗任意数量点道力，你能将能量注入任意手持物品中，该物品将成为镇物。镇物在制作后的24小时内若未加使用，其自动失去作为镇物的效果。

你在使用风水术时，可以以一个自由动作将手持的镇物设置于你当前所处的位置，这能令风水术的施展时间减少镇物中蕴含道力，每减少1点能减少8小时调理环境时间，至多将风水术的施法时间降低至自由动作，镇物中的剩余道力会延长风水术的生效时间，相当于道力点数*镇物创造时创造者的道力等级天。但在这种情况下，若镇物被摧毁或移动，风水术效果将立即结束，镇物会被视为具有道力的物体来被一些能观察到能量的效果观察到。镇物一经由这种方式使用，在风水术结束时效果也同样结束。


<a id="L23"></a>
## 基本风水术

参数：专业：风水术；威力：3；价格：D级〔候选10XP〕；动作：自由动作；能耗：1点道力；成分：语言，姿势；射程：自身；区域：以法术起点为中心，半径等同法术威力*智力*5米球形区域；持续：施法者道力上限天

效果：本道术包含了多种功能较弱的风水术布置方法，它可以用如下方式生效：

-招福/招灾：在法术区域内休息了至少8小时的生物在机运判定中获得1点加值或减值。该效果是一个D级基于命运法则的效果

-延寿/减寿：在法术区域内角色寿命会半速自然减少/角色寿命会双倍自然减少。该效果是一个D级基于时间法则。法术被升阶至C级时，延寿用法不会自然减少寿命。

-多子/绝育：在法术区域内角色的自然受孕率只要存在可能，概率提升法术威力倍/在法术区域内角色受孕率为0。效果是一个D级基于命运法则的效果

## 灵秀之地

参数：专业：风水术；威力：3；价格：D级〔候选10XP〕；动作：自由动作；能耗：1点道力；成分：语言，姿势；射程：自身；区域：以法术起点为中心，半径等同法术威力*智力*5米球形区域；持续：施法者道力上限天

灵秀之地：区域内各生物的所有通用能量池均可按道力基本用法修行增长容量，所需时间加倍：20、30、40天……各池分别记录进度，每天须实际在区域内完成长休入定，不把普通等候视为训练，不产XP；离区保留已完成容量与进度，离区时间不计入本术进度。重复区域不让同一天计算多次。

## 养尸地

参数：专业：风水术；威力：3；价格：D级〔候选10XP〕；动作：自由动作；能耗：1点道力；成分：语言，姿势；射程：自身；区域：以法术起点为中心，半径等同法术威力*智力*5米球形区域；持续：施法者道力上限天

养尸地：区域内具有不死生物特性的生物，强韧豁免获得6点修行DP；离区失效。活物不得受益。

设置于地脉时，上述加值变为9点，替代6点；不按训练天数发XP。

原限定XP的血统购买／升级效果不再提供；本术不赋予任何血统或绕过取得条件。

## 福地

参数：专业：风水术；威力：3；价格：D级〔候选10XP〕；动作：自由动作；能耗：1点道力；成分：语言，姿势；射程：自身；区域：以法术起点为中心，半径等同法术威力*智力*5米球形区域；持续：施法者道力上限天

效果：你在法术区域内进行的所有判定和防御上获得法术威力/3的幸运加值，并在机运和基因锁解锁判定上获得法术威力/3点加值。
