# 残暴驭手

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
残暴驭手是为骑手所准备的称号，他必须真正有一匹坐骑才能使用这个技艺，类似人马这样坐骑和骑手视为一体的能力是无法使用这个技艺的。一些为坐骑施加剧痛点数的效果可能使得坐骑反目。


<a id="L9"></a>
## D级〔候选10XP〕

横冲直撞：当你在骑乘状态下，坐骑的天生武器视为适合闯越和冲撞的武器而计入闯越和冲撞判定，此外若你具有骑术专长3级同名效果，你在闯越这些目标成功时，目标也将倒地。

鞭策坐骑：你可以驱策坐骑来提升其速度，以一个自由动作使坐骑受到1点可叠加不可避免的剧痛点数，坐骑移动速度提升40米，效果持续一个场景，若你对其不处于骑乘状态，则会在脱离骑乘状态的一轮后结束。

重装骑手：你擅长使用大型沉重的装备，你使用的所有武器力量需求降低1点，你使用的所有盔甲的盔甲减值降低1点。


<a id="L14"></a>
## C级〔候选25XP〕

猛冲：现在横冲直撞（包括特性和骑术专长3级）中受到影响的目标在受到闯越或冲撞效果结算后，若你或坐骑支付迅捷动作，对方还会受到坐骑发起的天生武器RE冲锋RE全力攻击，RE冲锋距离视同其实际在影响该目标前移动的距离，将这次攻击的伤害作为闯越或冲撞判定中的加值。同一生物在同一次移动中只会受到一次该攻击。

激发凶性：你可以以痛楚驱使坐骑提升战斗力，以一个自由动作使坐骑受到3点可叠加不可避免的剧痛点数，坐骑在生理与豁免检定中获得4点士气加值，持续一个场景，若你对其不处于骑乘状态，则会在脱离骑乘状态的一轮后结束。

一鼓作气：你在一场战斗中对一个生物发起的第一次攻击获得12点士气加值，若你的坐骑在同一轮中对同一生物发起攻击，其第一次攻击也获得同样的加值。


<a id="L19"></a>
## B级〔候选65XP〕

残暴驭手：当你和你的坐骑进行RE冲锋，RE全力攻击时，调整值上限不受基础防御影响，并且双方的力量叠加计算有效力量，但一方至多给另一方提供16点，这个有效力量也可以用于坐骑进行擒抱，冲撞，摔绊等，在处理这些效果时如果需要体积调整参与，双方的体积调整也叠加计算，但不再额外引起属性变动。

激发狂怒：你能够激发坐骑的狂性，你以一个自由动作启动这个效果，坐骑行动开始前受到5点可叠加不可避免的剧痛点数，在本轮中其来自C级的士气加值提高12点，并且暂时无视剧痛点数带来的影响，剧痛点数仍然正常累积，进入严重后果时这个忽略效果就会失效

诱发恐惧：当残暴驭手和他的坐骑以横冲直撞特性成功闯越一个生物并使其倒地时，每轮一次，可以立刻进行一次咆哮判定，这次判定中以你和坐骑合计的力量取代原本的风度进行，并将对该生物造成的伤害数作为士气加值加入判定中，所有能在模糊视觉范围内看到这个倒地生物的生物都需要对抗这个咆哮效果（而不需要将你的判定结果除以人数），并且这个效果带来的恐惧点数不会自动清空。


<a id="L24"></a>
## A级〔候选175XP〕

致命横行：现在你在骑乘移动中，若遇到障碍物，你可以立刻对其发动一次攻击，若攻击至少造成等同你的坐骑体积的伤害，该障碍物上会出现等同坐骑体积大小的缺口，使其不阻碍你移动的通过，同一障碍物在同一次移动中只会受到一次该攻击。

若你对载具使用此能力成功，可以直接打开缺口，造成闯入载具内部作战的效果。

此外，你以横冲直撞能力让坐骑对生物进行闯越时，无论闯越是否成功，你都可以支付迅捷动作立即对其进行一次近战攻击，这次攻击也视同你进行了RE冲锋和RE全力攻击，如同坐骑一般。

重装骑手：你懂得如何在战斗中保护你的坐骑，除了你的基础防御值之外，所有防御值都会对坐骑生效（包括但不限于盔甲，格挡，力场等，与坐骑自身取高计算），并且你拥有的不高于A级来源的减少伤害的能力（包括伤害减免，能量抗力，伤害吸收，抵消，降级等）也同样会对坐骑生效。

决死怒火：当你的坐骑在激发狂怒下受到足以致死的伤害时，它暂时不会因为伤害死亡，但你必须每轮有使用激发狂怒效果赋予其剧痛点数，并且赋予的剧痛点数每轮都会增加一倍（最初是5点，之后是10，20,40……）当其因剧痛累积至引起严重后果时才会死亡，若其在这种状态下受到伤害，将转而获得不可避免可叠加的剧痛点数。
