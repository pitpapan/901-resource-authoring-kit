# 盘蛇七冲阵

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
前提：拥有斗气

你必须持用分类为枪，矛，戟的武器才能使用这项技艺。


<a id="L10"></a>
## 蛇阵 D级〔候选10XP〕

盘蛇：以一个移动动作，你可以启动这个架势，持续直到你发生移动，无论主动或被动。

在盘蛇架势下，你视为进行了白刃格挡。

你失去全部的基础防御和闪避防御，在格挡加值上获得同等数量的加值。

你在对抗冲撞，摔绊和擒抱时，将武器伤害计入对抗判定中作为DP加值。

伺机待发：在盘蛇架势下，冷却时间1轮，在并非自己的回合中可以以一个反射动作进行一次相应武器近战攻击。


<a id="L18"></a>
## 千芒 D级〔候选10XP〕

当你处于盘蛇姿态下，对方不会因为连射获得加值。

此外，你的格挡加值提升4点。

此外，以一个反射动作，消耗1点斗气，冷却3轮，此时所有你可以对所有范围内的目标进行一次以相应武器进行的近战攻击，这次攻击不造成伤害，但是这些目标需要以反射豁免对抗你造成的伤害，每失败1点就会被击退1米，若无法后退或生物选择不后退，则正常造成攻击伤害。在表现上，你的身外枪影如万蛇夹杂着狂风翻腾，若不尽快退出，必遭灭顶之灾。

若你掌握了风劲，你可以加入风劲技巧，这时本反射动作可以触发风劲的主动效果（对攻击者的单体攻击进行攻击对抗而产生相关处理，随后再正常计算本效果的主动）。


<a id="L24"></a>
## 百夜 D级〔候选10XP〕

当你处于盘蛇姿态下，以一个标准动作，消耗1点斗气，冷却1轮，你可以以相应武器进行一次近战攻击，这次攻击射程增加等同武器体积米。

这次攻击中，高速优势提升8点，若你的高速优势破尽目标防御后还有剩余，转换为等量DP加值。

若对方以RE冲锋进入这个招式的射程，你可以一个反射动作使用这个技艺，同时视目标处于D级措手不及。


<a id="L29"></a>
## 风劲 D级〔候选10XP〕

当你处于盘蛇姿态下，你的格挡加值提升4点

若对方使用的是单发单体攻击，你可以以一个反射动作消耗1点斗气，冷却时间1轮，与对方进行一次攻击对抗，若你胜出，该攻击失去等同你攻击上附加成功再加上你的胜出数的成功数。

若你本轮使用过“三鬼”，且对方以单发的单体攻击对你进行攻击时，你可以改为消耗一个反射动作和1点斗气，进入盘蛇架势并使用“风劲”。

你在以“千芒”触发这个效果时，这个能力对非单发的单体攻击也能启用。


<a id="L35"></a>
## 三鬼 D级〔候选10XP〕

当你处于盘蛇姿态下，以一个标准动作消耗1点斗气，冷却1轮，你进行一次跳跃判定，若这个跳跃判定的结果足以越过你们之间的距离，则你发动招式成功

视为你如蛇般弹射而起，冲向对方，之后你的枪在空中划过三道弧线，进行一次攻击检定，对方被视为已经被攻击了2次一般计算防御。

同时这次攻击你获得RE冲锋和RE全力攻击的好处。你会移动到你选择的能攻击到对方的位置，并因此结束盘蛇效果。

若你在1轮内使用过“风劲”，你的攻击带有幽冥特性，视为枪影斗气收敛在你枪上，之后三枪划出。

若你在1轮内中使用过“千芒”，对方被视为攻击了10次而不是2次般计算防御。此时，你不是在空中画出三道弧线，而是带着无数扭曲鬼影从天而降。


<a id="L42"></a>
## 元蛟 C级〔候选35XP〕

你在发动是三鬼后，可以以一个反射动作回到原位并且重新进入盘蛇架势，仿佛你从来没动过。

元蛟：每轮一次，可免除本树一个反射招式原本另需在自己行动支付的迅捷代价；本招仍使用反射，且不解除反射锁，不增加反射次数。

当你被动移动而结束了盘蛇架势时，你可以以一个反射动作发动三鬼。

若你本轮发动过百夜，你发动三鬼后自动在新的位置重新进入盘蛇架势而无需动作。


<a id="L47"></a>
## 七探七变七幻截 B级〔候选65XP〕

前提：盘蛇七冲阵的其他6个技巧。

七探：无需盘蛇架势即可用相应武器火力压制。每轮一次，若对至少一目标造成实际伤害，本轮下一个本树反射招式的能量消耗减少1，最低0；不增加动作次数。

七变：盘蛇架势下，以标准动作及3斗气，冷却1轮，沿合法路径移动最多速度，对沿路触及的每个所选目标各攻击一次；各获RE冲锋及RE全力攻击效果。若至少一目标受伤，本轮下一个本树反射招式可免付1点斗气，不增加反射次数。

七幻截：受伤后可用一个反射重摆盘蛇架势；每轮一次，若本树反射攻击造成实际伤害，本轮下一次盘蛇架势的启动可用自由动作替代移动动作。不能通过本项反复创造反射或攻击。

七探七变七幻截：若你在一轮中使用了至少过“三鬼”“百夜”“千芒”“风劲”各一次，你可以立刻消耗5点斗气，进行一次移动，至多等同你速度的两倍，你可以在移动路径上对任意数量可以发起攻击的目标进行攻击，这些攻击获得RE冲锋和RE全力攻击的好处并可以进行连射或火力压制。并且你在移动终点重新进入“盘蛇”姿态。
