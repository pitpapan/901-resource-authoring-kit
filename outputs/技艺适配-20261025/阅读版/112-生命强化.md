# 生命强化

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
初级生命强化D级〔候选10XP〕

生命强化：人物生命值上限永久+10。

加速恢复：角色可以用两天时间连续进行长休息来恢复1点恶性伤害，在15分钟的短休息中恢复1点严重伤害，而一次15分钟的短休息可以移除所有冲击伤害。


<a id="L11"></a>
## 次级生命强化C级〔候选25XP〕

前提：初级生命强化

生命强化：人物生命值上限永久再+20

高速再生：人物获得1点快速医疗。


<a id="L16"></a>
## 中级生命强化B级〔候选65XP〕

前提：次级生命强化

生命强化：人物生命值上限永久再+40

高速再生：人物获得的快速医疗变为3点。


<a id="L21"></a>
## 高级生命强化A级〔候选175XP〕

前提：中级生命强化

生命强化：人物生命值上限永久再+80

高速再生：人物获得的快速医疗变为6点。
