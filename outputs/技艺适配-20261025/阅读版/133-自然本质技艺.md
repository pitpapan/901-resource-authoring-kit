# 自然本质技艺

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
特殊恢复据点中并非只能修行那些超自然的本领，普通的技艺之中亦有过人之处。

本页每项标250的技艺候选3XP，可作为一级专长学习；标500的一发破的候选6XP，可作为二级专长学习。均无需秘籍，但须实际完成对应基础训练与满足所列前提。


<a id="L9"></a>
## 传武八极-六大开 〔候选3XP〕

六大开是指“顶、抱、担、提、挎、缠”六种基本方法，每次购买可以获得其中一种。

六大开各自选学：顶〔命中后可付迅捷追加冲撞，方向不能向上，冲撞DP加实际伤害〕；抱〔一次肉搏攻击前，在攻击／防御之间转移最多E(肉搏)点DP，持续至下一次自己行动开始或下一次肉搏攻击〕；担、提、挎、缠见下。

担：肉搏近战攻击破甲＋2、高速＋2。

挎：肉搏攻击及擒抱／摔绊／冲撞主动和抵抗检定均＋3增强DP。

提：肉搏近战造成至少1点实际伤害且目标脚踏实地时，其下一次抵抗摔绊或冲撞的DP减少该实际伤害，最多持续至下一次自己行动开始。缠：肉搏格挡时来袭近战攻击DP−3；自己在下一次行动结束前对该攻击者的下一次攻击忽略3点闪避防御。


<a id="L15"></a>
## 传武八极-活步 〔候选3XP〕

活步是一种双脚贴地，无需作势的步法，能在无声无息间靠近对手。

你可以用迅捷动作进行移动，至多2米，你若以此法进行移动，本回合做出的下一次攻击视对手处于D级措手不及效果之下。


<a id="L18"></a>
## 听劲 〔候选3XP〕

你在贴身短打中磨练了对力的敏锐感知

你在肉搏格挡时若受到近战攻击，你在防御上获得6点修行加值


<a id="L21"></a>
## 寸劲 〔候选3XP〕

寸劲是将呼吸，步法，体势合一，于零距离爆发全力的技巧。

你可以以一个迅捷动作调整架势，你本轮中下一次近战肉搏攻击将视为RE全力攻击。


<a id="L24"></a>
## 禅宗射手 〔候选3XP〕

你以冥想和禅定来改善射击的准确性

你可以以感知取代敏捷来进行远程攻击判定


<a id="L27"></a>
## 一发破的 〔候选6XP〕

前提：禅宗射手

你在使用感知取代敏捷来进行远程攻击时，冷却时间1轮，你可以以远程武器发起RE全力攻击，这次RE全力攻击中，以感知取代力量计算上限。


<a id="L30"></a>
## 传武太极-接 〔候选3XP〕

你懂得如何拦截对手的发力动作，破坏对方的攻击架势

你在肉搏格挡时若受到近战攻击，攻击者的攻击判定受到6点减值。


<a id="L33"></a>
## 传武太极-化 〔候选3XP〕

你懂得如何以最小的动作带偏对手的劲力。

你在进行格挡时，在防御上获得3点招式加值


<a id="L36"></a>
## 传武太极-发 〔候选3XP〕

你懂得如何运用对方的力量来进行回击

若你在进行格挡时受到近战攻击，记录这次近战攻击的dp数，你在下一轮行动结束前，对该攻击者发起的下一次攻击中获得等同前述记录dp数的招式加值，至多9点。
