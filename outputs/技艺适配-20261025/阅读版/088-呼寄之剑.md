# 呼寄之剑

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
在购买任意一个呼寄之剑的技巧后，你即被视作强化了呼寄之剑。你的双手会被植入一对两个寄生兽，它们平时不会对你的行动产生任何妨碍，只在施展“呼寄之剑”时才会起效。因此，你不可使用自学能力的方式来购买这系列强化的第一个技巧。

这一对寄生兽具有一个共用的魔力池，其数值等于5点。寄生兽的魔力池只能用来施展“呼寄之剑”，你并不视为强化了魔力池，亦不可将这些魔力移作他用，但侦测魔力的技巧可能凭借寄生兽的魔力池定位你。寄生兽的魔力只能通过时间恢复，每24小时会回复等同于寄生兽魔力池三倍的魔力，平均分散到最小回复时长。你可以为这个魔力池兑换能量池强化。

技巧明列不可避免自伤；仅计算该次列明伤害，治疗限制采用本册依赖的血量累计机制，同一自伤不重复扣两份。

本系列通常为标准、冷却1轮。须双手寄生兽实际接触，至少空出一手，不能戴手套；断任一手或影响双手的改造会使本系列不可用。离体寄生兽死亡，须实际存在的重新植入服务才能恢复，物资按服务条目，不把旧500点当当前学习价。

若无特殊说明，呼寄之剑造成的伤害全部为纯能量伤害。

本系列伤害上限为力量＋E(白刃·呼寄之剑)；原全招学满改用力量的收益因六属性合并已并入力量，不再重复加力量。


<a id="L14"></a>
## 鬼之无月华 · D级〔候选10XP〕

效果：消耗寄生兽的1点魔力，并且对自身造成1点不可避免的严重伤害，双手互握，在空中凝聚出四团月光，扑击而下。

你进行一次白刃攻击，这次攻击中以力量进行，武器伤害为5L，具有魔法，正常攻击灵体，能量武器特性，并且攻击中自动适用长点射

这次攻击的获得射程等同你的力量*10米，攻击倒地的敌人时，额外获得6点招式加值。

连续技：若你在“鬼之一线悬”状态下使用这个技巧，在攻击之前你可以先以力量+白刃代替通常的力量+肉搏对目标进行一次冲撞，但只能选择击倒目标。同时“鬼之一线悬”状态立刻结束。


<a id="L20"></a>
## 鬼之天狂奔 · D级〔候选10XP〕

效果：消耗寄生兽的1点魔力，并且对自身造成1点不可避免的严重伤害，双手互握，在空中凝聚出四面八方的细刃，攒射中央。

你进行一次白刃攻击，这次攻击中以力量进行，武器伤害为5L，具有魔法，正常攻击灵体，能量武器特性，并且可以进行连射或火力压制。

这次攻击的射程等同你的力量*10米，攻击飞行的敌人时，目标会承受失速点数等同其受到的实际伤害，反射豁免。

连续技：若你使用“鬼之天狂奔”对目标造成了伤害，你可以立刻进行一次“鬼之斩无赦”的凝聚如同支付了标准＋迅捷动作额度一般。在视觉上，“鬼之天狂奔”的细刃不会在攒射后消失，而是化作一道光轮在你身前翻滚。


<a id="L26"></a>
## 鬼之一线悬 · D级〔候选10XP〕

前提：任意一个其他的呼寄之剑技巧

效果：消耗寄生兽的1点魔力，并且对自身造成1点不可避免的严重伤害，双手互握。一条如风般旋转的光线在脚下升腾，将你托上天空。

你获得飞行能力，速度等同你的移动速度，机动性完美，效果持续一个场景。

你在白刃技能上每有两个附加成功，速度增加一倍。

连续技：在结束“鬼之斩无赦”或呼寄之剑的任何奥义后，你可以迅捷动作展此招式。


<a id="L33"></a>
## 鬼之斩无赦 · D级〔候选10XP〕

前提：任意一个其他的呼寄之剑技巧

效果：消耗寄生兽的1点魔力，并且对自身造成1点不可避免的严重伤害，双手互握。

这是呼寄之剑中威力最大的一式，但只有对固定的目标才能造成巨大的杀伤力。第一段，以一个标准＋迅捷动作，你瞄准一个模糊视觉范围内的地点，在你面前缓缓凝聚成一道耀眼的光刃，在凝聚成这道光刃后，到你劈出这道光刃前你无法进行任何移动，亦无法进行格挡等任何需要你双手的动作，否则本招式自动终止。

随后，以一个标准动作，冷却6轮，你能够将光刃射出，直线劈向你瞄准的地点。这条直线上所有目标受到12点范围严重伤害，反射豁免，你可以进行一次力量+白刃判定，作为这些目标反射豁免中的减值。

鬼之斩无赦可继续蓄力：每额外一轮付标准与寄生兽魔力1，范围伤害再加4。合计蓄力轮数不超过已学呼寄技巧数，期间不能移动或以双手做其他事；射出仍另付标准，冷却6轮。

连续技：若你的攻击范围内包含未炸裂的“鬼之千月光”，则“鬼之千月光”会炸裂，且将“鬼之斩无赦”的范围伤害的一半加在“鬼之千月光”的范围伤害中。


<a id="L41"></a>
## 鬼之千月光 · D级〔候选10XP〕

前提：任意一个其他的呼寄之剑技巧

效果：消耗寄生兽的1点魔力，并且对自身造成1点不可避免的严重伤害，双手互握。

在模糊视觉范围内，选择一个区域，无数光刃旋转着聚成一道直径3米、高10米、中空且不可移动的竖直光柱，你可以决定它是否封顶或封底。

光柱具有4点硬度和20点生命值，在创造光柱时，你决定其向内或者向外爆裂。

当光柱被摧毁时，会发生爆裂，重新变回无数光刃，向内的话光柱内所有目标受到8点范围严重伤害，反射豁免，向外的话光柱外20米半径内所有目标受到这一伤害，反射豁免。

连续技：若你在使用奥义：心月碎天后仍然保有意识，那么直到你下个回合开始之前，若你遭受攻击，你可以无需支付任何代价，以反射动作使用“鬼之千月光”，在对方攻击之前发生，但光柱需以你自己为中心，向外爆裂。


<a id="L49"></a>
## 奥义：幽月梦情 · D级〔候选10XP〕

前提：任意两个其他的呼寄之剑技巧

效果：消耗寄生兽的1点魔力，并且对自身造成1点不可避免的严重伤害，双手互握。

在模糊视觉范围内选择一个目标，你唤出五道流光，如同情人的手一般缓缓抚摸过对方的身体。

你可以移除目标身上8点任意心灵来源的状态点数。

连续技：在你使用“奥义：幽月梦情”后，同一个场景中下一个呼寄之剑消耗的魔力和对自身的伤害减少1点，可以到0。


<a id="L56"></a>
## 奥义：梦月绯天 · C级〔候选25XP〕

前提：任意两个其他的呼寄之剑技巧

效果：消耗寄生兽的3点魔力，并且对自身造成3点不可避免的严重伤害，双手互握。

以一个标准动作，冷却3轮，在模糊视觉范围内选择一个目标。在目标周围，无数能量向中央滚动聚集。

目标受到20点严重伤害，反射豁免，反射中每失败1点，被向上方击飞1米，被击飞的距离会减少等同目标体积调整的数字，只要至少被击飞1米，目标在坠落前处于浮空状态，并可能受到坠落伤害，并在落地后处于倒地状态。

你进行一次力量+白刃判定，目标在反射豁免中受到等同你判定成功数的减值。

连续技：若你在上个回合使用了“鬼之无月华”，目标在对抗“奥义：梦月绯天”的反射豁免中失去等同你“鬼之无月华”造成伤害的成功数。


<a id="L64"></a>
## 奥义：心月碎天 · C级〔候选25XP〕

前提：其他所有的呼寄之剑技巧

效果：消耗寄生兽的所有魔力（至少为1点），并且对自身造成等同于生命值上限的不可避免的严重伤害，双手互握前伸。

以一个标准＋移动动作，冷却10轮，你向目标发动一次RE冲锋全力白刃攻击，这次攻击中两者的调整值都不受基础防御限制，并且增强加值额外提升等同你消耗的魔力和自己的生命上限点。

这次攻击可以以力量进行判定，并取代力量计算伤害上限。

这次攻击使用的武器视为武器伤害16L，具有魔法，幽冥，能量武器特性，破甲12，破魔12，高速12的武器进行。

这次RE冲锋中，你的速度提升240米。
