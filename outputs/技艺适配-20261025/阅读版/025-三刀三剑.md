# 三刀三剑

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
本招式无需按顺序购买。


<a id="L9"></a>
## 一剑藏空 C级〔候选25XP〕

以一个标准动作，消耗3点内力，冷却2轮，你以分类为剑的武器发起一次近战攻击，这次攻击获得射程等同你的感知*10米，这次攻击具有超级贯穿特性，获得16点高速优势，若是变为8点高速提升更为有效，则变为8点高速提升。

攻击发起后，你的防御上获得两倍E(白刃)的力场加值，持续1轮。

你也可以以一个标准＋移动动作发动此能力，此时不仅产生一道直线攻击，以这道直线为中心，半径等同感知米的区域之内所有目标都会受这个攻击影响，此时防御上的力场加值再提升两倍，变为四倍E(白刃)。

你可以在发动此招的同时向攻击方向移动一段距离，至多等同你的速度，若你如此进行，视为你本招进行的攻击中适用了RE冲锋和RE全力攻击效果，但不会在防御上受到减值，RE冲锋距离等同你移动的距离。


<a id="L15"></a>
## 千刀不尽 C级〔候选25XP〕

以一个标准动作，消耗3点内力，冷却1轮，你以分为为刀的武器发起一次近战攻击，这次攻击获得射程等同你的感知*10米，并可以进行连射或火力压制。

如果你的下一轮也对同一目标发动了该攻击，即使你没有消耗内力使用本技艺，也可以获得上述效果，并且连射的dp再提升3点，火力压制时也在你的攻击判定中获得可叠加的3点加值。

只要你每轮都至少对同一目标进行了一次该攻击，这个效果可以无限叠加，若在一个回合中进行了多次该攻击，也可以叠加至多16次。

你也可以以一个标准＋移动动作发动此能力，此时可以对以你为中心，半径感知*5米范围内的所有选择的目标发起攻击，并具有连射或火力压制效果，同样，只要你每轮都以标准＋移动动作进行这种形式的攻击，不需要支付额外能量，且连射的dp和火力压制的加值如同对单体攻击一般可以被叠加至多16次，但是两种加值不会混用。

无论如何，叠加的数量在场景重置时清空。

你可以在每次发动这种未中断的可造成叠加的攻击同时，若是标准动作进行，可向攻击方向移动一段距离，至多等同你速度的一半，若你如此进行，视为你本招进行的攻击中适用了RE冲锋和RE全力攻击效果，并且调整值不受基础防御限制

若是标准＋移动动作进行，你可以同时进行白刃格挡，并在攻击中获得等同你白刃技能的环境加值。


<a id="L24"></a>
## 百剑无终 B级〔候选65XP〕

以一个标准动作，消耗5点内力，冷却3轮，你对以你为中心，半径感知*30米范围内所有目标发起两次独立的以分类为剑的武器进行的近战白刃攻击，这两次攻击独立计算，视为进行了连射而获得3DP加值，但不会因为攻击多个目标而受到减值，无视防御上的格挡，掩蔽加值并且造成的伤害都是力场伤害，若两次攻击都造成伤害，目标立刻受到等同两次伤害差值的力场伤害。

你可以将剑气收束，这样伤害范围变成长度感知*60米的锥体。

若以一个标准＋移动动作来使用这个能力，剑招残留的无形剑气会潜伏在攻击过的空间内，直到你下一轮行动之前，除你之外进入该范围的目标都会受到这两次攻击。


<a id="L29"></a>
## 十刀破极 B级〔候选65XP〕

以一个整轮动作，消耗15点内力，冷却10轮，你一刀挥出数道不断延伸而出的巨大刀气，这视为你以分类为刀的武器连续进行了十次火力压制，每次伤害独立结算，射程视同你的感知*50米，并且伤害变为力场伤害。

这些火力压制若影响到同一目标，每影响一次，下一次本能力中火力压制的伤害增加1点。


<a id="L33"></a>
## 万剑归元 A级〔候选175XP〕

以一个标准＋迅捷动作，消耗7点内力，冷却3轮，你在以自身为中心，半径感知*100米范围内唤起无数剑气，你进行一次以分类为剑的武器进行的白刃攻击判定，将目标防御视为0

范围内所有你选择的目标受到等同你判定成功数的力场伤害，至多120点，反射豁免。

同时你的判定成功数也成为你的临时生命值，并且这些临时生命值可以保护范围内你选择的目标，在其受到伤害时才做决定是否使用。

这个临时生命值和范围伤害持续一轮，期间若临时生命值下降，则范围伤害也会同步下降，从而减轻对之后进入范围的目标产生的影响。

若以一个整轮动作来施展“万剑归元”，可以在发动此招的同时向任意方向移动一段距离，至多等同你的速度，若你如此进行，视为你本招进行的攻击中适用了RE冲锋和RE全力攻击效果，但不会在防御上受到减值，并且获得的调整值不受基础防御影响，RE冲锋距离等同你移动的距离，此外在你移动过程中进入范围的目标也会受到这一伤害影响。


<a id="L40"></a>
## 一刀绝空 A级〔候选175XP〕

以一个标准动作，消耗7点内力，冷却10轮，你进行一次意志判定，之后以分类为刀的武器进行一次白刃攻击，斩出由刀意气劲凝聚而成的一道刀罡虚影，这次攻击的射程视为感知*500米

这次攻击是A级接触攻击，并造成A级措手不及效果，具有超级贯穿特性，造成力场伤害，并且无视等同你意志判定成功数的硬度，伤害吸收，抵消或降级。

此外，此招已经具备近似于“概念斩击”的效果，若你对一个生物或物体进行本次攻击伤害已经足以在不计算体积调整带来的生命时致死或毁坏，并且你的攻击射程足够，就可以干净利落的将目标一分为二，这不是即死效果，如同正常的伤害致死，这使你可以轻易的斩断珠峰或是将帝国大厦从中剖开。但可能没有尚不能斩开星球。（即使100感知，也仅50公里射程，远不足以斩开星球）

此外，此招可以用来攻击其他法阵，结界，空间道标等效果，被攻击的目标效果若在A级或更低自动被破坏，更强的效果不会受到影响。

每次一刀绝空可额外付一个迅捷，使该次攻击再获15点完美DP，伤害上限增加4。不能为同一次攻击重复支付。

若以本技艺来进行对攻,本次对攻具有以下效果：

你可以以本攻击向远程攻击发起对攻。

你可以向选择其他目标的攻击发起对攻，若进入对攻流程，则对方的攻击目标转移为你，但原本受攻击或发起攻击的目标必须在你的攻击射程范围内。

本次动作进行的对攻强制对方应对进入对攻流程而无法拒绝。（这并不阻止对方放弃本次攻击从而使这次攻击行为结束）

若本动作的本次对攻胜出，则对方本次动作的剩余攻击动作全部失效。

若对方的攻击行为是对多个目标发起各一次攻击，进入本次对攻流程后若对方失败本次行为无法再对其他目标进行攻击（见QA52部分）。

若对方的攻击行为是对多个目标发起各X次攻击，你在使其之后的攻击失效时同样使这些攻击行为失效。
