# 驯兽师

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>

<a id="L7"></a>
## D级〔候选15XP〕

驯兽师的技艺特性中，所有【你的伙伴】皆指代所有你以造人规则制造出的生物，若作为非冒险者N角色的特性获取，也可以视作其控制的其他生物能够应用。

战斗指挥：所有你的伙伴在战斗中获得等同L(智力)/2的攻击上的洞察加值

培育进化：每次主持宣布完整冒险结算，所有你的伙伴各获得1.5伙伴XP，分别记录小数并持续累计，不能转交你或其他伙伴。仅用于该伙伴已经满足资格的普通成长或单项已定价资源；不因休息、训练或普通节点再发。

治愈伙伴：以一个标准动作，消耗1点意志，你可以为一个你的伙伴提供4点医疗点数，每4点回复1点恶性伤害，2点回复1点严重伤害，1点回复1点冲击伤害。

战斗意志：当你和你的伙伴在同一战斗中登场时，都不会因为伤势而失去意识。

补正·驯兽师（3XP）：

补正〔3XP〕：培育进化的结算奖可改为该阶固定数÷6×L(智力)，取得补正时选择，和未补正数值择一，不重复发放。


<a id="L16"></a>
## C级〔候选35XP〕

战斗指挥：现在这个加值延伸到防御和所有判定上。

培育进化：每次完整冒险结算的伙伴XP改为4.5，替代1.5。

治愈伙伴：现在D级提供的医疗点数也可以1:1移除任意状态点数，若你支付3点意志，医疗点数可提升至8

战斗意志：只要你没有失去意识，你的伙伴每轮获得1点持续1轮的临时意志可供使用。


<a id="L22"></a>
## B级〔候选85XP〕

战斗指挥：现在战斗指挥的加值变为L(智力)+1点

培育进化：每次完整冒险结算的伙伴XP改为10.5，替代4.5。

治愈伙伴：现在你在复活你的伙伴时只需要支付1/3的价格，在复活伙伴时，你的伙伴可以视为冒险者来享受一些复活方式，例如太阳金经等。此外，若你为C级的能力支付的意志提升至5点，医疗点数可提升至16。

认主：所有你的伙伴会获得等同你技艺等级的免疫影响心灵效果。


<a id="L28"></a>
## A级〔候选215XP〕

战斗指挥：当你的伙伴需要消耗意志时，你可以代替其来消耗意志。

当其为任意判定或防御使用意志力的基础用法时，若你这么做获得的加值更高，你可以用你的加值取代对方的加值。

此外，你可以消耗你的意志力来使其再获得一次基础用法的效果，两次的效果叠加。

培育进化：你为你的伙伴开启了一个能力库，每个伙伴兑换或自学的不高于B级的强化都会加入库中，但不包括模板类和物品类强化，其他伙伴在自学这些强化时需要支付的XP消耗降低一半。

治愈伙伴：现在你复活一个伙伴的价格降低到1/9。此外，若你为B级的能力支付的意志提升至7点，医疗点数可提升至32。

死斗：你的伙伴受到伤害时可以以等量的意志力进行代替。
