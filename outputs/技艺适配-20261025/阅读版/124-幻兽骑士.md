# 幻兽骑士

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>

<a id="L8"></a>
## D级〔候选15XP〕

幻兽契约：你可以花费1小时时间与一个自愿生物签订幻兽契约，它将在了解作为你的从属

该生物必须是确实存在的生物，因此不能有持续时间，即使是永久也不行

你也不能与其他带有轮回手表的生物作为你的幻兽，幻兽必须具备智慧和语言，因此通常的生物是不行的

一般而言，该对象可以是你通过造人方式制作出的能被骑乘的生物，或者是剧情世界中的某些N角色

你在同时只能有一个契约幻兽，你若和第二个生物进行契约，第一个契约就会自动失效。

你和你的契约幻兽之间获得无视距离的心灵感应并能互相交流，且互相知道对方的生命值和状态点数。

共同成长：你可以将你获得的属性上的内在加值和修行加值共享给你的幻兽，在D级时，你至多只能共享D级兑换赋予的属性，幻兽若原本有对应加值类型，则取高计算。


<a id="L17"></a>
## C级〔候选35XP〕

幻兽契约：现在你可以将契约幻兽送入幻兽空间，或将其召唤出来，以一个标准动作，消耗1点意志，你可以将契约幻兽送入亚空间，你成为其空间道标，同样以一个标准动作，消耗1点意志，你可以将它召唤出来，必须与你相邻。

共同成长：现在你能共享C级兑换赋予的属性。


<a id="L21"></a>
## B级〔候选85XP〕

幻兽契约：当你骑乘契约幻兽时，你或你的坐骑在进行基于生理属性或生理技能的判定时，若坐骑更高其可以坐骑的相应属性或技能来代替；需要用到体积调整时，若也可以选择使用较高的一方。

共同成长：现在你能共享B级兑换赋予的属性。


<a id="L25"></a>
## A级〔候选215XP〕

幻兽契约：当你骑乘契约幻兽时，若受到伤害，可以将任意数量的伤害转移给坐骑，这个效果在伤害处理前进行，因此转移的伤害各自进行伤害处理（也就是进行减免，抗力，吸收，抵消，降级等）

共同成长：现在你能共享A级兑换赋予的属性。
