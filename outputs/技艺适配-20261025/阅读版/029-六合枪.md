# 六合枪

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>

<a id="L8"></a>
## 枪法入门：D级〔候选10XP〕

效果：枪法娴熟（双特性），骑战武艺

枪法娴熟：你在白刃技能上提升1级，上限5级，获得枪/矛/戟专业，在对应专业上获得的加值是3点而不是1点。

骑战武艺：六合枪在骑乘状态下使用时在攻击和防御上额外获得3点环境加值。


<a id="L12"></a>
## 虎牙断：D级〔候选10XP〕

前提：枪法入门

效果：你以枪法入门中枪法娴熟提及的专业的武器发起攻击时，可以无视6点任意来源的防御和2点任意来源的伤害减免、抵消或吸收。


<a id="L15"></a>
## 白蟒破山枪：D级〔候选10XP〕

前提：枪法入门

效果：你以枪法入门中枪法娴熟提及的专业的武器发起攻击时，可以将武器多送出至多等同武器体积的距离，亦即触及范围增加这个数字。此时你在攻击中破甲提升4点，并获得【贯穿】特性。


<a id="L18"></a>
## 昴龙闪：D级〔候选10XP〕

前提：枪法入门

效果：你以枪法入门中枪法娴熟提及的专业的武器发起攻击时，可以进行连射和火力压制。此时你在攻击中高速优势提升4点。


<a id="L21"></a>
## 霸王战意：C级〔候选25XP〕

前提：枪法入门

效果：在进行先攻检定后，你在攻击，防御和豁免判定中获得1点士气加值。

战斗每经过1轮，这个数字提升1点。

每当你对敌方目标造成伤害（一次行动造成多个伤害，或者对多个目标造成伤害，都视为1次），这个数字提升1点。

每当你受到敌方目标造成的伤害，这个数字提升1点。

这个效果可以叠加至12点，但场景结束时重置。


<a id="L28"></a>
## 金刚不坏：C级〔候选25XP〕

前提：枪法入门

效果：当你受到伤害时，可以立即消耗6点意志和精力发动此能力，对该伤害获得20点临时生命值。


<a id="L31"></a>
## 疾电：C级〔候选25XP〕

前提：枪法入门

效果：你以枪法入门中枪法娴熟提及的专业的武器发起攻击时，可以不造成伤害，而是对目标的基础防御，闪避防御，格挡加值造成减值，按该顺序依次下降，若一次造成的减值超过了三项之和，超出的部分会变成纠缠状态点数，可叠加，不可豁免。

造成的减值持续一轮。


<a id="L36"></a>
## 青龙汲水：C级〔候选25XP〕

效果：你以枪法入门中枪法娴熟提及的专业的武器发起攻击时，造成实际伤害时，可以放弃伤害而是造成等同实际伤害数的流血点数，强韧豁免。


<a id="L38"></a>
## 枪挑华岳：C级〔候选25XP〕

前提：枪法入门

效果：你以枪法入门中枪法娴熟提及的专业的武器发起攻击时，若目标的体积调整高于你，你获得同等数量的附加成功，伤害也提升同等数量的伤害上限。若对目标而言只有一条生命值（如物品，其没有冲击、严重、恶性生命之分），这些附加成功和上限加倍。


<a id="L41"></a>
## 赤焰穿心枪：B级〔候选65XP〕

前提：枪法入门

效果：你以枪法入门中枪法娴熟提及的专业的武器发起攻击时，可以消耗5点意志，本次攻击获得36点增强加值，若成功造成伤害，额外追加8点火焰严重伤害。


<a id="L44"></a>
## 磐龙决：B级〔候选65XP〕

前提：枪法入门

效果：你手持枪法入门中枪法娴熟提及的专业的武器时，获得以下好处

-攻击，防御和豁免中获得6点内在加值

-移动速度增加80米

-你总是处于格挡状态，并且可以用迅捷动作进行移动动作的移动。


<a id="L50"></a>
## 霸王崩山劲 A级〔候选175XP〕

前提：枪法入门

效果：以一个标准动作，消耗7点意志，冷却1轮，你以枪法入门中枪法娴熟提及的专业的武器连续发起三次近战攻击，每次攻击都视为获得RE全力攻击带来的好处。

若第一次攻击命中，第二次攻击获得DP加值等同第一次攻击造成的伤害数，若未命中，第一次攻击中的高速，破甲，破魔的一半叠加计入第二次攻击中的高速，破甲，破魔之中。

若第二次攻击命中，第三次攻击获得DP加值等同第二次攻击造成的伤害数，若未命中，第二次攻击中的高速，破甲，破魔的一半叠加计入第三次攻击中的高速，破甲，破魔之中。
