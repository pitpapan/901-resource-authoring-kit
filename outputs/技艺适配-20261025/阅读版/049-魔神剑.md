# 魔神剑

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
魔神剑式

任何造成挥砍伤害的近战人造武器都可以使用这个招式。


<a id="L10"></a>
## D级〔候选10XP〕魔神剑

你的白刃训练E提升1级（最多到5）

以一个标准动作，消耗1点任意能量或1点意志，冷却1轮，你可以用你的近战武器挥出一道剑气（若你使用能量）或风压（若你使用意志），射程为力量*20米内的一个目标，这如同你对他进行了一次近战攻击，你可以用风度代替力量或敏捷来进行这次攻击判定，这次攻击获得8点高速优势。


<a id="L13"></a>
## C级〔候选25XP〕刚魔神剑

你的白刃训练E提升1级（最多到6）

当你发动魔神剑时，消耗额外3点任意能量或3点意志，加速魔神剑的飞行速度从而在逸散前能攻击更多距离，并使其边缘变的更为锐利。以此方式增强之后的魔神剑获得获得8点破甲，破魔，高速提升4点，射程增加一倍。


<a id="L16"></a>
## B级〔候选65XP〕魔神剑·双牙

你的白刃训练E提升2级（最多到10）

当你发动魔神剑或刚魔神剑时，你可以花费一个额外的移动动作来再挥出一道魔神剑或刚魔神剑，从两侧以高速向目标包抄，这两次伤害独立结算，并且无视目标8点基础防御，闪避或格挡加值。


<a id="L19"></a>
## A级〔候选175XP〕魔神连牙斩

你的白刃训练E提升3级。

当你发动魔神剑时，你可以花费一个标准＋移动动作，先向与目标的直线挥出一道魔神剑，接着在同一直线上挥出一道去势更快的刚魔神剑，再接着挥出两道刚魔神剑构成的魔神剑·双牙以高速沿曲线向目标包抄而去，最终四次攻击同时击中那个目标，你需要分别支付4次招式的能量花费（10点），这4次攻击都独立计算。
