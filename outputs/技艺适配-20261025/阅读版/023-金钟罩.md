# 金钟罩

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
金钟罩（护身劲）

金钟罩各进化须依低阶至高阶购买；只强化金钟罩自身效果。

金钟罩使用内力或佛力推动。所有金钟罩中提及的额外获得类效果都仅针对金钟罩的能力有效。


<a id="L11"></a>
## 金钟入门：D级〔候选10XP〕

前提：有内力池或佛力池

你获得3点天生防御，DR1/-，全能量抗力1，你的天生武器视为具有伤害3L，破甲3。

以自由动作消耗1点能量，你额外获得6点天生防御，DR1/-，全能量抗力1，持续5轮。

罩门：当你受到一次攻击后，攻击者可以通过一个DC6的智力+学识（武学知识）判定寻找罩门，一旦找到罩门，不但攻击你会无视所有金钟罩的效果，而且会直接破劲而入摧毁你的金钟罩，让你在1分钟内失去金钟罩效果且无法再度启用。

笨重：当你以能量推动金钟罩时，移动速度减半。

进化（15XP）：你在反复的战斗中弥补了金钟罩的缺陷，金钟罩不再具有笨重特性，并且罩门的影响缩小，即使罩门受到攻击，金钟罩也不会再被摧毁而无法使用，但依然对该攻击失去效果。启用金钟罩时你如同脚下生根，在对抗让你移位或倒地的判定中获得5个附加成功数（若只有对方判定，则减少对方的成功数）。


<a id="L20"></a>
## 金钟气劲：C级〔候选25XP〕

你的金钟罩不再有罩门，额外获得3点天生防御，DR1/-，全能量抗力1，天生武器的伤害提升1点，破甲提升1点。

以自由动作消耗3点能量，你获得额外6点天生防御，DR3/-，全能量抗力3

这些效果均和D级叠加，也可以独立运转，效果持续5轮。

进化（20XP）：你的身体强韧无比，刀剑难及，你的肉身获得了【防弹】和【防能量武器】特性，并获得4点硬度。


<a id="L27"></a>
## 神功初成：B级〔候选65XP〕

金钟初成：你额外获得9点力场防御，4点全伤害吸收，天生武器伤害再提升2L，破魔提升4，获得魔法，正常攻击灵体，以及神圣，幽冥特性。

以一个自由动作消耗5点能量，你额外获得12点力场防御， 4点全伤害吸收，效果持续5轮。

进化（65XP）：你的金钟劲已经可以收放自如，来自金钟罩功法的所有防御，包括DC级的天生防御，都可以同时视为天生防御，盔甲防御或力场防御之一，视何者更为有利，来自金钟罩功法的所有防御加值全部叠加，此外你已经学会了以金钟劲反震对手，当你受到近战攻击时，你可以消耗5点能量以迅捷动作对其进行还击，如同你用金钟罩所给与的天生武器进行了肉搏近战攻击。


<a id="L33"></a>
## 金钟大成：A级〔候选175XP〕

金光强弱可自由控制，隐藏光效不降低防御。

金钟大成：你额外获得18点力场防御，DR3/-，全能量抗力3，全伤害吸收3，天生武器伤害再提升3L，破甲，破魔各提升8。

以一个自由动作消耗7点能量，你额外获得24点力场防御，DR5/-，全能量抗力5，全伤害吸收5，这些效果均和BCD级效果叠加，也可以独立运转，持续5轮。
