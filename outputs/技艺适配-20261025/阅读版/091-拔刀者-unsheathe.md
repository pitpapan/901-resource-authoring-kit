# 拔刀者-unsheathe

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
参数：价格：特殊

前提：限男性购买，但并不视作前提

此能力购买时，需要绑定一件价格不低于D级〔候选10XP〕的近战冷兵器购买，再加上本能力自身的D级〔候选10XP〕合计决定价格，购买时，你可以设定一个自身的女性形象。

购买能力后，你不会获得那件武器，而是获得一本体积1的黑色的手册作为代替，其中记录了武器的相关内容。

以一个移动动作，你可以将那本黑色的手册转换为绑定的武器，同时进行变身，你会成为你的女性版本。

同时，被解放的男性力量充斥于你全身，你在力量、敏捷上获得1点增强加值，并在以绑定武器进行攻击时获得3点增强加值。

变身效果与武器变化效果皆持续至多一个场景。

性别转换时，一般而言你的数据不会有所变化，但有性别前提的资源会无法使用，你可以在女性化形态下购买仅限女性使用的资源，但相应的转为男性形态后就无法使用。

特殊的，若你的绑定武器被破坏（被称为折刀），属性提升效果立刻结束，但你将无法变回男性形态，武器也不会转变为黑色的手册。

你可以在折刀状态下再次拔刀，此时刀刃将由你的存在构筑，被称为复仇之刃，第一次拔出复仇之刃时，你选择一把与之前武器价位相同或更高的近战冷兵器绑定（但不能是原本的）。

复仇拔刀时，动作变为标准＋移动动作，并需要消耗3点意志和精力，尽管不会再变身，但你的存在凝聚依然使你在力量、敏捷，感知上会获得2点增强加值取代原本的变身效果。

复仇拔刀的属性提升和刃转化同样持续至多一个场景。

若在复仇拔刀形态下若再次折刀，你将失去智力，意志，以及所有社交属性，变为无心智纯粹追求破坏的怪物，这视为一个持续时间永久的A级诅咒与命运法则效果。
