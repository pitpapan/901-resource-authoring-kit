# 龙虎连击式

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>

<a id="L8"></a>
## 任何造成挥砍伤害的近战人造武器都可以使用这个招式


<a id="L9"></a>
## D级〔候选10XP〕虎牙破斩

你的运动训练E提升1级（最多到5）

你以一个标准动作，冷却3轮，先对对手发动一次普通近战攻击，这次攻击不会造成任何伤害，而是力争破开对手的防御，这次攻击如常计算实际伤害，但不会真正造成实际伤害，而是对手需要进行力量判定，并将自身体积调整作为附加成功计入，难度等同这次攻击本应造成的实际伤害数，特别的，如果对手处于[浮空]状态，他无法进行这次力量判定。你将对方打起等同【目标失败数-目标体积】米的高度，若对方离地至少1米，视同处于【浮空】状态

接着你可以高高跃起，借着重力的加速挥下第二击，支付1点任意能量或意志，你可以跃起至多相当于你移动速度的距离或对方被击飞的距离，取低，在这次攻击中，你获得额外的破甲值，相当于每5米高度1点，上限为24点。造成伤害的同时目标会被击落等同你第二次攻击成功数-目标体积的距离，如坠落地面，先结算坠落伤害，之后因为无法移动的每米再增加1点坠落伤害，可以超过原本上限，若目标受到坠落伤害，则同时处于倒地状态。你不会因本技艺受到坠落伤害。

如果这个招式用来对付原本在空中飞行而非地面的敌人，你在第一击中视同对手处于浮空状态，第二次攻击中的破甲为双方的高度差/5。


<a id="L14"></a>
## C级〔候选25XP〕虎牙连斩

你的运动训练E提升1级（最多到7）

要发动虎牙连斩，你需要正在发动虎牙破斩并进行第二次攻击，第二次攻击结算后，坠落发生前，你可以以一个反射动作消耗3点任意能量或意志，以该目标再发动一次虎牙破斩。

虎牙破斩的冷却时间降低至1轮。
