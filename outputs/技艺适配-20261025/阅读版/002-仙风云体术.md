# 仙风云体术

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
前提：拥有最少一项东方背景的能量池。


<a id="L9"></a>
## D级〔候选10XP〕

以一个自由动作消耗1点能量启动，维持5轮

轻身：在这个阶段你感到行动变的轻快，与物理法则和体型无关，你的体重降低到原先的1/2。这让你移动速度增加20米，基础防御+3，反射豁免+3，免疫坠落伤害。


<a id="L12"></a>
## C级〔候选25XP〕

以一个自由动作消耗3点能量启动，维持5轮，同时获得D级效果无需额外消耗。

云体：在这个阶段你开始产生飘渺之感，仿佛可以随风而行，与物理法则和体型无关，这让你移动速度再增加40米，基础防御再+6，反射再+6，你现在免疫困难地形带来的移动妨碍，并且可以在液体表面上正常移动和站立。


<a id="L15"></a>
## B级〔候选65XP〕

以一个自由动作消耗5点能量启动，维持5轮，同时获得D和C级效果无需额外消耗。

踏风：在这个阶段你开始感觉自己和环境融为一体。你的体重继续下降一半，你可以在这个值和你标准的体重之间自由变化。这让你移动速度再增加80米，基础防御再+12，反射再+12，你现在可以踏风而行，如同在地面上行走一般在空中行走，并且移动力不受爬升角度的影响，同时这个能力不视为飞行能力。
