# 镰影伤天法

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
哀魔法则·镰影伤天法（招式·巨镰）

只有哀魔法则持有者能学本武技；以其他巨镰施展时，攻击DP额外减少该武器体积。各阶另须同阶哀魔法则。

需要以令哀魔法则认主的能量来推动。

每个等级的镰影伤天法必须有相应等级的哀魔法则支持


<a id="L10"></a>
## 学习补正α D级〔候选10XP〕

学习补正α：不再发放限定XP。以本页技艺进行的近战攻击判定获得3点修行DP；被同类较高修行加值覆盖时取高。


<a id="L12"></a>
## 学习补正β D级〔候选10XP〕

学习补正β：不再按训练周期产XP。研究、辨识或传授本页技艺的学识判定获得3点修行DP；不直接学会招式、不减学习价。

提高白刃技能的效果没有限定条件。


<a id="L15"></a>
## D级〔候选10XP〕

白刃训练E提升1级，但最多不高过5，并获得专业：巨镰

使用巨镰时，若你攻击的目标/攻击你的目标没有专业：巨镰，则攻击DP/防御+4，若有，则改为+2，这视为环境加值。

使用巨镰时，你的镰影伤天法的每个等级可以为你额外提供+1DP攻击和防御，这视为招式加值。


<a id="L19"></a>
## C级〔候选25XP〕

白刃训练E提升1级，最多不超过6

以一个移动动作消耗3点能量启动，效果持续5轮，你使用巨镰时，在攻击和防御上再额外+3DP招式加值。

若本轮内移动超过10米，你在攻击上的每个附加成功为攻击再提供+1DP，防御上的每个附加成功为防御提供+1加值。

以一个标准动作，消耗3点能量，你可以以独特的运劲方法，虚构出无数道镰影在镰刃之前，用以迷惑对手的招式，进行一次风度+白刃判定，每个成功数，可以令你在受到攻击时降低对手1点攻击DP，或在攻击时减少对方1点基础防御，闪避或格挡加值，你需要在启动时分配，该效果持续1轮。


<a id="L24"></a>
## B级〔候选65XP〕

E(白刃)再提高2级，最多不超过10

在C级效果下，以自由动作，消耗额外5点能量启动，持续时间增加5轮

使用巨镰时，只要成功造成伤害，对方两点完好、冲击或严重生命直接转成恶性，从最好的状态开始，这个效果不视为伤害。

使用巨镰时，只要成功造成伤害，下一次对同一目标发动攻击时就再获得两个附加成功，该效果可不断叠加。

若本轮内移动超过10米，则攻击和防御上再获得等同镰影伤天法等级的附加成功，和C级效果叠加。

若你在一个动作中移动的同时发动了攻击，你可以在攻击后继续移动，直到移动距离耗尽。

以一个标准动作，消耗5点能量启动，冷却3轮，你能以独特的运劲方法，高速挥舞巨镰形成范围的音波攻击。魔音穿脑，甚至能破坏人的五感和平衡系统。

进行一次攻击判定，每个成功数能对1米/成功数半径范围内的所有生物造成一点音波冲击伤害，至多64点伤害，强韧豁免。因此受到的伤害若高于体积和力量中较低者的两倍，需要进行强韧判定，目标是受到的伤害-较低者的两倍，每点差值受到1点晕眩点数。

该效果可以消耗能量来抵抗，受影响者可立刻消耗X任意非特殊能量，进行一次DP为消耗能量数的检定，每个成功可以阻挡2点伤害。


<a id="L34"></a>
## A级〔候选175XP〕

在B级效果下，以自由动作，消耗额外7点能量启动，持续时间增加5轮

使用巨镰时，只要成功造成伤害，对方4点完好、冲击或严重直接转成恶性。

使用巨镰时，只要成功造成伤害，你在防御上获得等于该次伤害值的格挡加值，持续1轮，对每个目标每次造成的伤害取最高生效，至多获得48点。

使用巨镰时，加骰提升到8

使用巨镰时，你以任何方式攻击时，在攻击前或后可以支付迅捷动作额外移动等同你移动动作所能移动的距离一半。

以一个标准动作，消耗7点能量和7点意志，冷却10轮，你的攻击穿越时间和空间的桎梏，直接伤害到对方存在的根本。这次攻击，在扣除对方所有防御手段之后，剩余的DP全部自动取10，但无法获得加骰。这视为一个时间，空间，命运三重效果，视为A级，必须同时免疫三者才能免疫此攻击。
