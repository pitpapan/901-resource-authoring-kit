# 组合技总纲

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
组合技

组合技是一种技艺。

组合技需要多个角色参与才能使用，因此组合技的强度通常会高于每个参与者需要支付的价格，需要参与的人数越多，这一情况也就越发显著。

组合技通常需要角色以特定的方式参与进来，每种组合技都有自己的生效限制。

由于和不同的角色进行组合技需要的磨合是不同的，特殊重塑服务无法直接提供“磨合”兑换，其只提供用于自学的秘籍兑换，之后每个参与者需要以自学方式支付XP用于和特定的其他参与者“磨合”，该XP的支付是高度限定的，例如一个由3人发起的组合技，你在磨合完毕时就必须确定另外两人，其中哪怕更换了一人，该组合技的磨合也不再成立而必须重新支付XP。

另外，即使你有能力在保留自身技艺的情况下分出多个个体，哪怕他们都是你，你们之间也需要为合体技进行磨合，以至于每个个体都需要为此支付XP，如果它们能进行自学以支付XP的话。

组合技在考虑等级时，以组合技自身的等级计算。

每个参与者的磨合价为该组合技本批候选XP价除以固定参与人数，向上取整。所有参与者须同时参与实际合作练习、具备招式资格，并分别支付自己的XP；不使用训练天数兑换XP。

固定伙伴共同完成一次实战或一个连续练习场景后即可结算磨合学习，未参与或中断者不完成；训练快慢及天数不产生额外XP。

不得只支付XP而跳过共同磨合经历；不能用皇帝特权等临时取得方式代替指定伙伴的磨合记录。
