# THE_LAND通用技艺

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
若无特殊说明，其本质皆为魔幻本质。


<a id="L8"></a>
## 奇妙握法D级〔候选10XP〕

前提：力量达到6点

在判断武器是否符合你的体调时，你可以将自己的体积调整向上或向下调整2点进行计算，在判断力量是否满足武器使用的力量要求时提升2点。


<a id="L11"></a>
## 集中回避D级〔候选10XP〕：

前提：敏捷达到6点

集中回避：每场景一次，用一个反射并付意志点1，应对本次攻击或需反射豁免的效果时获得11点闪避防御／反射DP加值。此后至下一次自己行动结束，每次面对同类效果仍享此加值，但不再附带移动或额外动作；反射锁照常。


<a id="L14"></a>
## 集中冥想D级〔候选10XP〕

前提：智力达到6点

每场景一次，以一个标准动作，消耗3点意志力，你恢复智力点精神魔力。每天你能以此恢复的魔力不得超过你的精神魔力上限点。


<a id="L17"></a>
## 魔力增幅D级〔候选10XP〕

前提：智力达到6点

以一个自由动作，消耗3点意志力、魔力、精力，你在接下来的3轮内，施法检定获得智力一半点增强加值。


<a id="L20"></a>
## 分析D级〔候选10XP〕

前提：智力达到6点

只要你能在模糊视觉范围内看到敌人，以一个迅捷动作，你可以以智力+学识（怪物）了解怪物知识

你的成功数每超出怪物的战斗力*2/3有1点，你就得到一条信息，例如一项属性的数字，一项受训的技能值，一项衍生属性，被动特性，或能量池等级大小等，你可以提出问题，这是一个C级探知效果。

你可以反复使用此能力了解尚未明确的怪物情报。并且，若你解明了怪物所有情报。你可以立即再进行一次分析判定，你对该怪物的攻击和防御上获得洞察加值，等同成功数的一半，该效果无法重试。


<a id="L25"></a>
## 魔力控制DD级〔候选20XP〕

前提：神秘达到5级

你施展的法术威力提升1点。


<a id="L28"></a>
## 变换施法D级〔候选10XP〕

前提：神秘达到5级

若你本轮决定不使用上轮使用过的法术，本轮使用的法术魔力消耗降低1点，施法检定上获得6点招式加值。


<a id="L31"></a>
## 有备无患D级〔候选10XP〕

前提：感知达到6点

每场景一次，当你消耗能量、意志力、精力的行动失败未产生效果并且未返还上述消耗时，你可以保留该行动所消耗的能量、意志力、精力。


<a id="L34"></a>
## 反手一击D级〔候选10XP〕

前提：白刃或肉搏达到5级

若对方对你进行的攻击未取得任何成功数，你可以支付迅捷动作与1点精力对其发起一次白刃或肉搏攻击。


<a id="L37"></a>
## 死中求活D级〔候选15XP〕

前提：意志达到6点

每场景一次，当你死亡时，将你的生命值变为只差1点冲击伤害就会死去的状态。

随后因为死亡导致清空的意志力会被转化为等额的治疗点数，每4点治疗点数恢复1点A伤，2点恢复1点L伤，1点恢复1点B伤。


<a id="L41"></a>
## 意志坚定 D级〔候选10XP〕

前提：意志达到6点

在进行意志豁免时，角色可以额外进行一次该豁免，但必须使用重骰的结果。


<a id="L44"></a>
## 明镜止水 D级〔候选10XP〕

前提：意志达到6点

每天一次，自己行动内自由使用，恢复意志属性一半的意志点或精神魔力，不重复计算合并前两项属性。


<a id="L47"></a>
## 绝境反击 D级〔候选10XP〕

前提：意志达到6点

每场景一次，你在进行攻击检定时，支付自身剩余的所有意志力，若支付超过1点，则你获得意志力基础用法的好处与消耗意志力点数的完美加值。


<a id="L50"></a>
## 苦行僧D级〔候选15XP〕

前提：力量6

若你不装备盾牌、未装备轻甲和重甲，你获得2点全伤害吸收。


<a id="L53"></a>
## 身强体壮D级〔候选10XP〕

前提：力量6

角色的生命上限额外增加5点，每点L(力量)额外增加1点，并在强韧豁免上获得6点内在加值。


<a id="L56"></a>
## 修养生息 D级〔候选10XP〕

前提：力量6

精力上限额外＋5＋L(力量)；每次完整长休另恢复意志属性数的意志点，不超过实际上限。


<a id="L59"></a>
## 处决 D级〔候选10XP〕

前提：E(白刃)达到5级

你只能对已经失去全部基础防御，闪避加值和格挡加值的目标进行该动作。（由于是对已经失去，因而仅在攻击时生效的高速、措手不及无法应用，但特殊的，你可以对受虚招而失去以上防御的目标）

以一个标准＋迅捷动作，消耗3点精力，冷却时间6轮，你对其进行一次全力近战白刃攻击，本次攻击中计算武器伤害带来的附加成功时无需掷骰而是取满，并且获得18点表现加值。
