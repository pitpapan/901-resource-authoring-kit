# 机甲术

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
若你的技能树中包含了人机改造组件，你视为已经满足了条件。

否则须力量6、敏捷6才能学习；合并前力量前提取同一力量门槛6。


<a id="L10"></a>
## 机甲学徒 D级〔候选10XP〕

“机”：机甲术不消耗能量，而是通过集中精神来达到对战斗情况的掌握，将“机”作为一种集中程度的计数器使用，每场景开始时，你的机视为0，以一个移动动作集中心神，你可以获得1点机，你能保有的机至多不超过你的敏捷和意志中较低者，每点机让你无视1点来自环境的减值，并在防御上获得1点闪避加值。

机敏护身：若你至少有一个机，你忽略5+机数点高速优势。

千机变：若你至少有一个机，你可以以自由动作取出身上物品，若你消耗一个机，收回物品也是一个自由动作。


<a id="L15"></a>
## 机甲从者 C级〔候选25XP〕

“机”：现在你也可以用迅捷动作来获得1点机。并且上限变为两者取高

精确机打：你忽略部位攻击减值，等同你拥有的机数量。

自由机斗：你在擒抱，摔绊，攻击特定部位，冲撞，虚招等战技判定中获得等同于你拥有的机数量，若你消耗一个机，一次判定中效果加倍。


<a id="L20"></a>
## 机甲武士 B级〔候选65XP〕

“机”：现在你也可以每轮一次，以自由动作来获得1点机。并且上限变为两者之和。

克敌机先：只要战斗开始时你不处于突袭轮，你就能获得4点机，以一个反射动作消耗3点机，你可以立刻开始你本回合的行动，这视为你预支了本回合的行动，并不会改变先攻结果。

机动逆搏：当你攻击体积调整高于你的对手时，你获得加值，当体积调整高于你的对手攻击你时，你获得防御上的加值，两者都等于你拥有的机数量，至多不超过双方体积调整之差的两倍。


<a id="L25"></a>
## 机甲大师 A级〔候选175XP〕

继承B级每轮自己的行动中免费取得1机；另可付迅捷取得1机、移动取得2机或标准取得3机，三种额外付费方式每轮合计选一次，仍受机上限。

高周波攻击：近战攻击命中时，可消耗5机，作感知＋意志检定。此次伤害中至多检定成功数点伤害提高一级；目标以强韧豁免每成功减少1点提高。体积阈值后续附带效果未启用，见U02。

反击之机：受到近战攻击时，可立即消耗4机，无动作地进行一次普通近战反击；每次均实扣4机，不使用反射。或使用在自己上一次行动预付的一个迅捷，取得本轮一次同样反击〔未在下一次自己行动前使用即失效〕。反击可先于来袭结算；双方都有先结算能力时，按能力等级、先攻先后，均相同则同时。双方这一层攻击各自结算后，若仍满足受击条件且仍有足额机，可以进入下一层反击；逐层记支出，机不足或放弃则停止。预付迅捷机会不能再次触发自身或再次预支；明确属于反射的其他能力仍受反射锁。

你可以以本反击进行对攻。
