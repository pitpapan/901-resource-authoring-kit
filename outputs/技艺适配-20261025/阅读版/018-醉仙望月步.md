# 醉仙望月步

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
特殊可选：启动该技能必须先喝酒才可以启动。

前提：拥有一个通用东方能量池。需求运动3级。

习得本身法后，你选择你所拥有的一个通用东方能量池，然后与其绑定，绑定后，本身法所消耗的所有能耗，皆为该能量池。


<a id="L11"></a>
## D级：

参数：价格：D级〔候选10XP〕

消耗：1点能量

参数：动作：自由动作

目标：自身

参数：射程：无；范围：无；持续：5轮

效果：启动后，你现在RE冲锋并不一定非要沿直线才可以发动，只要你在移动前可以看见目标即可。你从倒地站起来只需要一个自由动作，你在倒地状态下不会受到减值，但依然保留加值，并且可以正常移动。你摇摆不定的姿态让对你发起的攻击受到-3DP减值，并且你的每次移动都会使得他人对你进行的瞄准次数减少一次。


<a id="L20"></a>
## C级：

参数：价格：C级〔候选25XP〕

消耗：3点能量

参数：动作：自由动作

目标：自身

参数：射程：无；范围：无；持续：5轮

效果：启动后，除了D级的效果外，你现在学会了如何在攻防中前后迂回，左右摇摆来躲避攻击。你的攻击轨迹令人摸不着头脑，被你近战攻击的对象视为处于C级措手不及效果，在攻击你时受到的减值提升至-9DP，当你受到物理伤害时，你可以消耗X点能量抵消X点伤害，X上限是你的L(敏捷)+2。现在你进行RE冲锋或RE全力攻击不再减少你的防御值，但上限没有改变。


<a id="L29"></a>
## B级：

参数：价格：B级〔候选65XP〕

消耗：5点能量

参数：动作：自由动作

目标：自身

参数：射程：无；范围：无；持续：5轮

效果：启动后，除了D级和C级的效果外，你可以以一个自由动作或迅捷动作额度发动虚招和冲撞。攻击你时受到的减值提升至-21DP，你现在可以抵消所有类型的伤害，而不限于物理伤害，你造成的措手不及效果升级至B级。
