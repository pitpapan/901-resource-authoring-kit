# 凶星剑诀

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

## 凶星剑 计都：D级〔候选15XP〕

凶星计视为一把重剑，并获得如下特性

认主：凶星计都拥有认主特性

嗜血：凶星计都拥有8加骰。

不祥：凶星计都拥有魔法，幽冥，黑暗特性。

暴虐：星魂极凶，会鼓动宿主以近乎暴虐的方式进行杀戮，每次持有者在战斗中杀死目标后都必须以自己的意志对抗你在本场景内杀死的人数*3，若失败则失去1点意志且继续攻击场景中剩余敌人。你可以在自己的回合结束时消耗1点意志重新进行判定。

你现在能够学习凶星剑诀。


<a id="L16"></a>
## 星魂解放：C级〔候选35XP〕

前提：拥有凶星剑计都

以一个自由动作，消耗3点意志，你可以解放星魂，至多持续一个场景，你可以随时以一个标准＋移动动作将其封印回去。

星魂解放中，凶星剑计都的武器伤害提升至8L，获得8点破甲和破魔，并获得神兵特性，武器等级也对应提升到C。

凶气：极盛的凶杀之气甚至会影响附近人的心智，所有在模糊视觉范围内能看到持有者的生物受到等同持有者L(风度)3倍的恐惧点数，不分敌我，意志豁免。

凶星剑诀：

前提：需要拥有计都剑。拥有能量为内力，斗气，剑气或杀气。

## D级技能：

隔空剑——华光猎影：

以凶星剑计都发起攻击时，可以支付1点能量，你可以斩出一道高速旋转的刃形剑劲斩击敌人。

这视为这次以凶星剑计都发起的攻击获得射程，等同你的力量*60米，这次攻击中还会获得8点高速优势。

破城剑——希望泪泣：

以凶星剑计都发起攻击时，可以支付1点能量，这次攻击中的破甲值提升4点，并忽略至多4点任意来源的伤害减免，吸收，抵消或硬度。

束刺剑——星血穿虹：

以凶星剑计都发起攻击时，可以支付1点能量，这次攻击具有超级贯穿特性，且距离增加10米。

对幽体剑——伤剑破心：

以凶星剑计都发起攻击时，可以支付1点能量，冷却1轮，这次攻击中的破魔值提升4点，并在伤害计算时先击破至多16点临时生命。

恒音剑——万籁唯音：

以凶星剑计都发起攻击时，可以支付1点能量，以被攻击的目标为中心，至多你的力量*5米为半径进入沉默状态，任何声音都无法发出，范围内进行潜行判定自动成功，需要语言或声音成分的能力无法使用，持续1轮，这个范围是固定的，不会随着目标移动。


<a id="L46"></a>
## C级技能：

旋圆剑——暗黑轮回：

以凶星剑计都发起格挡时，获得格挡特性，并在格挡加值上获得6点加值。

你在攻击一个在1轮内你格挡时对你进行过攻击的目标时，你可以消耗3点能量，本次攻击中获得等同你格挡加值的增强加值，至多36点。

蔓草剑——藤痛哀号：

以凶星剑计都发起攻击并成功造成伤害时，可消耗3点能量，埋下一道难以驱除的剑劲，目标每次行动开始时受到等同你K(白刃)的严重伤害，这个伤害不受B级以下来源的伤害吸收，减免，抵消或降级。效果持续5轮。

多次击中时可以叠加这个剑劲，被击中的目标可以在剑劲生效时，消耗1点任意通用能量，永久减少1点这种持续性的严重伤害。

多重劲剑——无限领域：

以凶星剑计都发起攻击时，可以投两次取较高的数字。

若你对结果不满，可以再支付重投次数点能量连续重投，至多可重投等同你K(白刃)的次数。

对空间剑——末日碎裂：

以凶星剑计都发起攻击时，可以支付3点能量，这次攻击视为火力压制般计算伤害处理，但武器伤害不减半，并对目标点为中心，半径你的力量*5米产生同样的效果。

此外，区域内若存在空间道标，这次火力压制同样可以影响到该道标对应的目标。

## B级技能

星速剑——瞬极连牙：

星速剑：以计都完成一次只含一次攻击、施展动作不高于标准的技艺攻击后，可付5能量追加同一技艺攻击一次，不另付动作。该技艺的其他代价照付、冷却和资格必须满足；本项冷却1轮。

每次再追加同类攻击另付5能量；同一把计都本轮由星速剑产生的额外攻击数至多K(白刃)，不从这些附加攻击递归触发星速剑。

每次攻击视为独立攻击来计算伤害上限，但计算目标受到的防御减值时视为一次攻击。

每把凶星剑以本能力每轮最多可进行K(白刃)次攻击。

特殊：附加攻击无法触发附加攻击。

禁城剑——血色涅槃：

以凶星剑计都发起格挡时，可以支付5点能量，二十八道剑劲环绕于你的身周，每当你受到伤害时可以消耗任意数量的剑劲，每道剑劲视为1.5点临时生命值。

如果剑劲没有耗尽，效果持续一个场景。

囚牢剑——封禁惨祸：

以凶星剑计都发起攻击时，可以支付5点能量，二十八道剑劲封锁敌人的行动。

你可以指定这些剑劲封锁目标的何种行动，例如攻击，防御等，每道剑劲会造成1点力场减值。

当其进行判定时，你可以以一个反射动作转移封锁的类型，每次转移失去一道剑劲。

如果剑劲没有耗尽，效果持续一个场景。

暗伤剑——错空刃袭：

以凶星剑计都发起攻击时，可以支付5点能量，1轮冷却，这次攻击获得50米射程且无需效果线，并且攻击表现的目标和实际的目标可以不是同一目标。

实际被攻击的目标视为处于A级措手不及效果影响之下。


<a id="L85"></a>
## A级技能：

以凶星剑计都发起攻击时，可以支付7点能量，冷却3轮，本次攻击造成的所有伤害都是恶性伤害，强韧豁免，每点将1点恶性伤害降级。

极杀剑——绝灭杀戮：

以凶星剑计都发起攻击时，冷却时间6轮，你可以以此能力投入不超过上限数量的能量，每支付1点能量，本次攻击获得5点增强加值和1点附加成功，以及3点伤害上限，并在伤害结算前击破3点临时生命，你可以支付任意数量的能量，也可以支付不同类型的可以推动凶星剑诀的能量。

每因此投入1点能量，你就会对自身造成1点不可避免的冲击伤害。

你每次至多投入等同你投入的某个能量的关键属性之和点能量。

最强剑舞——凶 天地剑舞：

以一个整轮动作，消耗9点能量，冷却10轮，你以凶星剑计都发起9次攻击，这9次攻击在计算属性带来的附加成功时，视作你的六属性的L值之和，同时伤害上限也提升对应点。

每天你至多使用本招式三次。
