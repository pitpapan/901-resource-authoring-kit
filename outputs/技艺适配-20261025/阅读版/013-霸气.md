# 霸气

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
本质：特异本质

武装色霸气


<a id="L12"></a>
## D级：D级〔候选10XP〕

以一个标准动作，消耗1点意志或精力，你发动武装色霸气，效果持续一个场景。

效果持续期间，你在攻击，防御上获得6点力场加值，同时你的近战攻击与身体获得魔法特性，并能正常影响灵体。


<a id="L15"></a>
## C级：C级〔候选25XP〕

现在在启动武装色霸气时可以额外消耗3点意志或精力

你在攻击，防御上的力场加值提升6点，并获得2点全伤害吸收


<a id="L18"></a>
## B级：B级〔候选65XP〕

现在在启动武装色霸气时可以再额外消耗5点意志或精力

你在攻击，防御上的力场加值再提升12点，你的全伤害吸收再提升4点，此外你的近战攻击可以转为力场伤害。


<a id="L21"></a>
## A级：A级〔候选175XP〕

现在在启动武装色霸气时可以再额外消耗7点意志或精力

你在攻击，防御上的力场加值再提升24点，你的全伤害吸收再提升8点，你在受到物理伤害时，可以将等同L(力量)*2的伤害下调一级，至少是冲击伤害。

见闻色霸气


<a id="L27"></a>
## D级：D级〔候选10XP〕

以一个标准动作，消耗1点意志或精力，你发动见闻色霸气，效果持续一个场景。

效果持续期间，你在攻击，防御上获得6点洞察加值，你获得灵敏听觉。


<a id="L30"></a>
## C级：C级〔候选25XP〕

现在在启动见闻色霸气时可以额外消耗3点意志或精力

你在攻击，防御上的洞察加值提升6点，你获得盲感能力，等同你的敏感感知范围，此外，你能得知此范围中目标的伤势情况，当你对此范围中的生物进行准备动作时，无需宣言触发条件，也无需宣言准备的动作，可以在任何时点触发，并在触发时宣言动作。


<a id="L33"></a>
## B级：B级〔候选65XP〕

现在在启动见闻色霸气时可以额外消耗5点意志或精力

你在攻击，防御上的洞察加值再提升12点，你的盲感能力扩大到你的模糊感知范围，C级能力所述的范围也随之扩大，并在你的敏感感知范围内获得盲视能力，此外，你免疫B级的措手不及效果


<a id="L36"></a>
## A级：A级〔候选215XP〕

现在在启动见闻色霸气时可以额外消耗7点意志或精力

攻击、防御洞察加值再提升12；盲视扩大至模糊感知范围；可与范围内生物心灵感应交流，免疫多次受攻击减防。每轮一次，可将一个本来只占标准的已掌握动作改以反射施展，照付其他代价并受反射锁；自由动作只能在自己行动内使用，原本明确允许轮外者每轮一次。


<a id="L40"></a>
## 霸王色霸气

参数：价格：S级〔候选485XP〕

前提：A级见闻色霸气与A级武装色霸气，该前提不能以任何方式被无视

被动：现在你可以以一个整轮动作，消耗9点意志或精力开启霸王色霸气，效果持续一个场景。启动期间你获得如下效果

启动后，同时视为开启了全等级的见闻色霸气和武装色霸气。

所有在你风度*100米范围内的生物受到精神束缚点数等同你的意志值/2，该效果无法叠加，意志豁免，因此进入严重后果的生物会进入震慑而非定身状态。

同样具有霸王色霸气的生物免疫本效果。

在发动霸王色霸气的期间，武装色霸气和见闻色霸气中的攻防数值部分全部增加1.5倍（从D级到A级，也就是72点攻防力场加值和54点攻防洞察加值），见闻色的免疫措手不及等级提升至S级。
