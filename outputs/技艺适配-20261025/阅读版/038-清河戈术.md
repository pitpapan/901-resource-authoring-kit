# 清河戈术

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
前提：白刃5，力量6，敏捷6，意志6，专业：戈矛任意东方能量驱动，选择后不可更改

若以下战技于坐骑上使用时，使用坐骑的速度，并可以在最终伤害计算时得到一个额外的附加成功，如果你可以化身为半坐骑形态，比如，英召，半人马，马腹，或者其他类似形态，你也可以得到这个额外的附加成功


<a id="L11"></a>
## 雷霆万钧（B级〔候选65XP〕）

前提：骑乘状态

消耗：10能量，5意志

参数：冷却：6轮

你策动坐骑发起一次致命的RE冲锋，这视为你进行了一次骑乘RE冲锋，你至少需要移动等于你坐骑移动速度的距离，这次RE冲锋路径必须是直线，即使你有其他能力能绕过这一限制也一样。

你进行这次RE冲锋时，路线上可以被其他生物或物体阻挡，只要你能看见目标，就能对目标发动RE冲锋，这种情况下，你会对RE冲锋路径上遇到的第一个生物或物体进行骑乘RE冲锋攻击，本次RE冲锋获得的RE冲锋加值只受限于你和坐骑的力量之和并同步增加你的伤害上限，若攻击的是静态物体，只要你造成的伤害高于物体硬度、抵破甲、盔甲与力场防御之和，物体就会崩碎能容纳你坐骑大小通过的缺口，且不会阻滞你本次RE冲锋，若是载具等动态物体，视同生物处理。若生物死于本次RE冲锋，你的RE冲锋也不会被阻滞，若生物没有死于本次RE冲锋，你立刻对其发动一次闯越判定，使用你和坐骑的力量之和作为力量，并获得RE冲锋加值和你造成的伤害加值作为额外加值，若闯越成功，你的RE冲锋也不会被阻滞。如你的RE冲锋被阻滞（因为未能击破物品或闯越生物和载具），招式到此结束。

如果你的RE冲锋没有被阻滞，你可以继续RE冲锋路径上的下一个目标，RE冲锋加值以所有未被阻滞的RE冲锋路径计算。

你在本能力中造成的RE冲锋伤害上限加倍。

你在RE冲锋中每杀死一个生物，令你在本次RE冲锋攻击下一个生物时获得可累积的+12DP士气加值，可叠加10次。

你本次RE冲锋是如此迅速，以至于任何反射动作或针对你和你坐骑的触发效果，准备动作都无法正常触发，直到你RE冲锋结束,除非其免疫A级以上措手不及。


<a id="L22"></a>
## 指天划地（B级〔候选65XP〕）

消耗：5点能量

参数：冷却：3轮

你发动一次骑乘RE冲锋，并视为RE全力攻击，挥戈突进直击敌之下盘，这次RE冲锋中你可以以一个B级或更低需要最多标准动作进行攻击的能力来发起攻击（并附带RE冲锋和RE全力攻击效果），并且RE冲锋和RE全力攻击调整值只受你和坐骑力量之和限制，如果造成的伤害大于对手的体积，你将长戈自下而上猛挥，将敌人挑空，此时视为敌人处于浮空状态，可趁势对其发起致命的突击，再获得发动一次基础近战攻击的机会，用以重创敌手（发动招势依然需要消耗）


<a id="L27"></a>
## 星散阵崩（B级〔候选65XP〕）

消耗：5点能量

参数：冷却：10轮

你进行一次RE冲锋并同时发动RE全力攻击，直线路径上的所有敌人受到[力量+武器伤害]的范围伤害，至多64点，反射豁免，并且受到你攻击中取得的高速点减值，你因RE冲锋和RE全力攻击获得的dp数可减半增加在减值之上，所有路径上的目标会被斜线击退每点伤害1米，若未被击退，也视为你正常通过，在路径终点你可以对一个目标发动骑乘RE冲锋攻击，这次攻击如常获得RE冲锋和RE全力攻击的优势，每有一个目标在范围攻击中受到伤害，你在这次攻击中获得+6dp士气加值，至多获得12次。


<a id="L32"></a>
## 披肝沥胆（C级〔候选35XP〕）

消耗：3

以一个移动动作发动，你将你的L(意志)*2加到自身和生物坐骑的攻击和防御上，并且若双方自愿，你和生物坐骑能互相转移伤害，每当你或生物坐骑受到伤害，由你决定如何分配，被分配的伤害不可避免。持续一个场景。

你至多将等同生物坐骑生命值的伤害分配给生物坐骑。


<a id="L37"></a>
## 众志成城（C级〔候选35XP〕）

被动效果：每次战斗，只要队友在场，你可以使模糊视觉范围内的友军的攻击，防御和豁免判定上获得士气加值，每个队友1点（仅限冒险队伍成员）。

你自身获得同样的好处，再额外加上队友人数。

你每拥有一个本技艺以外的清河戈术，加值额外增加1点。

你每拥有一个B级清河戈术，还增加一个附加成功。


<a id="L43"></a>
## 血舞狂风（C级〔候选35XP〕）

消耗3点能量，冷却1轮，你进行一次RE全力攻击，这次RE全力攻击的调整值只受你和你坐骑的力量之和限制，你以坐骑和自身体积之和为半径，对范围内所有目标发动这次攻击，范围内每个被攻击的目标为你这次攻击提供可累积的+6dp士气加值。
