# 海虎爆破拳

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
海虎爆破拳（招式.拳法）

海虎白军浪自创的拳法。电磁强者力量专用的武术，也可消耗内力推动，本技巧视为电磁力技能

前提：电磁力或内力


<a id="L9"></a>
## 气灌双拳 · D级〔候选10XP〕

强化天武：只要你的内力或电磁力不空，天生武器伤害就提升2L

劲：你在进行肉搏攻击时，消耗1点能量，使这次攻击获得3点招式加值

增幅：你可以投入额外的能量数，每点再增加3点招式加值，单次攻击可以投入的能量上限等同L(力量)。


<a id="L15"></a>
## C级〔候选25XP〕

强化天武：只要你的内力或电磁力剩余不低于10点，天生武器伤害再提升4L，并且可以忽略2点伤害减免。

爆破劲：若你以D级中的劲发动攻击并造成伤害，目标体内就被送入一道不稳定的能量，在受到该伤害的回合结束时爆发从而结束持续时间，造成等同你投入的劲的能量点数的严重伤害，这个伤害不会被D级以下效果伤害减免，吸收。


<a id="L19"></a>
## B级〔候选65XP〕

天空爆破拳

强化天武：只要你的内力或电磁力剩余不低于20点，天生武器伤害再提升4L，并且可以忽略总共4点伤害减免。

爆破劲：你在D级的劲中现在可以投入额外的能量，至多等同L(力量)，只要你至少投入1点能量，你的天生武器获得威猛，晕眩，击飞特性，并且你在C级爆破劲效果中造成的伤害在治疗时难度视为恶性伤害。

内伤：当你的爆破劲产生伤害时，你可以选择等同爆破劲伤害数的任意一种并非影响心灵的不良状态点数施加给目标，这种状态点数不能对物体也生效（如燃烧，冻结，纠缠），也不能是通常影响心灵的状态点数（如影响心灵，精神束缚），可叠加，强韧豁免。


<a id="L25"></a>
## A级〔候选175XP〕

海虎爆破拳

海虎爆破拳：你以爆破劲产生的伤害现在是恶性伤害，并且只能通过自然回复或特殊重塑恢复，不会被C级以下效果伤害减免，吸收。

你不再能选择你造成的不良状态点数，而是随机两种不良点数获得，不同的肢体妨碍点数视为不同的状态点数。

你在劲中能投入的能量上限加倍。
