# 百难通劫法

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>

<a id="L8"></a>
## D级〔候选15XP〕

百难不死：你的伤势不会自动恶化。

劫中妙悟：遭遇真实危境且符合本册危境触发时，无需动作获得本场景意志、强韧、反射豁免各＋3DP洞察加值；每场景一次，不发XP，不另作基因锁判定。

虽然正常开启基因锁可以主动进行，但主动尝试解开基因锁无法触发本能力。


<a id="L13"></a>
## C级〔候选35XP〕

百难不死：每次完整冒险两次，你能在一次足以致死的效果中逃脱，当你死亡时，将你的生命值变为只差1点冲击伤害就会死去的状态。

劫中妙悟：上述豁免洞察加值提升至6，替代D级3，不发XP。


<a id="L17"></a>
## B级〔候选85XP〕

百难不死：该特性能使用的次数增加四次

劫中妙悟：上述豁免洞察加值提升至12，替代C级6，不发XP。


<a id="L21"></a>
## A级〔候选215XP〕

百难不死：该特性能使用的次数再增加八次。

劫中妙悟：上述豁免洞察加值提升至24，替代B级12，不发XP。
