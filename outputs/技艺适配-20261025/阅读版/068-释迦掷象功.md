# 释迦掷象功

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
不要求宗教信仰；外人可能将其识为天竺／佛门武学，但不据此强加信仰。


<a id="L10"></a>
## 狮子缚手·释迦稳固体式 D级〔候选10XP〕

效果：你在擒抱对抗中获得6点招式加值，你不会因为擒抱一个目标而对其他目标失去防御。

当擒抱中的你或目标受到尚未确定目标的攻击时，你可以以一个反射动作，消耗1点内力，再与目标进行一次擒抱对抗，若你成功，这个攻击击中的是目标而不会是你，除非对方承受减值选定你攻击。


<a id="L13"></a>
## 狮子缚手·大摔碑式 C级〔候选25XP〕

前提：狮子缚手·释迦稳固体式

效果：当你尝试压制擒抱中的敌人时，D级的招式加值提升12点

若你的压制判定成功，你不但压制对手，还能让对手处于倒地状态，并受到等同你擒抱对抗胜出数的物理伤害，若倒地处特别松软，可以是冲击伤害（如沙漠），甚至没有伤害（液体或空气）。否则通常是严重伤害。若倒地区域有明显其他造成伤害的效果，例如钉板，酸液等，也自动附加这一伤害。

你可以在压制状态下使用这个技艺。


<a id="L18"></a>
## 狮子缚手·如露如电 B级〔候选65XP〕

前提：狮子缚手·大摔碑式

效果：你在擒抱判定中获得的招式加值再提升24点。

当你处于擒抱状态下尝试进行压制时，可以只需要一个迅捷动作，但此时具有1轮冷却时间。


<a id="L22"></a>
## 狮子缚手·罗摩擒龙 A级〔候选175XP〕

前提：狮子缚手·如露如电

你在擒抱判定中获得的招式加值再提升48点。

与你进行擒抱对抗的目标无法从体积调整差值中获得额外的附加成功。

你可以在压制状态下做出任何行动，被你压制的目标只能做出摆脱压制的动作，其他所有动作，即使是自由动作进行说话也无法进行。


<a id="L28"></a>
## 掷象秘传·飞星传恨 D级〔候选10XP〕

效果：你可以将任何体积在5或更高的物体作为重投掷武器来进行投掷攻击，此时其射程基础单位变为你的力量*5米，你的力量依然需要能正常举起这些东西。

你也可以将被你擒抱的目标以一个标准动作如此投掷出去，不需要额外进行擒抱对抗。

以此发动的攻击武器伤害下限视为4L，通常依然视为临时武器计算伤害。

若在进行这种投掷攻击时获得等同L(力量)的高速优势。

你可以以一个移动动作用双手举起任何大小的物体并做好投掷准备，只要你的力量足够。

被你投掷出去的目标可以依你的意愿选择是否使其受到坠落伤害，若选择让其受到坠落伤害，则其受到的坠落伤害等同武器本身的伤害，而无关它被投出的距离。


<a id="L35"></a>
## 掷象秘传·金刚粉碎 C级〔候选25XP〕

前提：掷象秘传·飞星传恨

效果：现在这种攻击的武器伤害下限变为8L。射程基础单位变为你的力量值*10米，高速优势提升至你的L(力量)*4。

若你在投掷时消耗3点内力，你可以选择不作为单体攻击，而是造成范围物理严重伤害，伤害等同武器伤害，范围为以目标点为中心，半径为投掷物体积/3米，反射豁免，但你可以进行敏捷+运动判定，结果作为其反射豁免中的减值。

这个伤害被你投掷的物品或生物也会受到，视同其受到了坠落伤害（启用这一能力时，你无法让被投掷的目标免于坠落伤害）。


<a id="L40"></a>
## 掷象秘传·达摩拔山 B级〔候选65XP〕

前提：掷象秘传·金刚粉碎

效果：现在这种攻击的武器伤害下限变为16L。射程基础单位变为你的力量值*20米，你不会因为投掷临时武器而受到减值，包括没有专业带来的劣势。

此外当你进行擒抱判定成功进入擒抱状态时，可以立刻将被擒抱的目标或生物投掷出去而不再需要额外的攻击动作。

你可以以此能力从物体整体中拔下一个部分投掷出去，这需要该整体是固体，无生命，并且非敌对者持有，只要你取下的部分物体的最大硬度不超过你的力量值的一半，并且你的负重足够，就能取下伤害尽可能高的临时武器用于投掷，但应用的武器伤害最高不得超过你的力量点，举例而言，你可以拔出森林中的树木（硬度2），街边的路灯（硬度5左右）用于投掷。


<a id="L45"></a>
## 掷象秘传·须弥周流 A级〔候选175XP〕

前提：掷象秘传·达摩拔山

效果：现在这种攻击的武器伤害下限变为32L。射程基础单位变为你的力量值*40米。

你在进行这种投掷攻击时，可以消耗7点内力，藉由旋转，将你的投掷物螺旋投出，此时被投掷的对象在这次攻击中获得超级贯穿特性（这意味着你在空中甚至可以把一个目标投入数以千米深的地底，鉴于路上的东西都被超级贯穿击碎，但它也能沿着这条道路返回），并且这次攻击的武器伤害提升20点。
