# 截天七剑

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
各招之间没有前置关系，可以随意购买。

共有使用前提（而非获得前提），拥有任意S级东方通用能量，下称相应能量。


<a id="L10"></a>
## 第一式 斩道见我 S级〔候选485XP〕

以一个标准动作，消耗9点相应能量，冷却1轮，你以手持分类为剑的武器发起一次近战白刃攻击，这次攻击若命中，不造成通常伤害，目标失去等同你伤害上限的意志力，意志豁免减少。

若该次攻击使目标意志点余额降至0，目标昏迷；只能由实际存在的特殊复苏服务解除，需支付其既有复活代价的三分之一。此处不是降低意志属性。

学会本招能令你自动度过基因锁四阶的心魔。

本招式是一个影响心灵效果，但度过心魔的部分不是。


<a id="L16"></a>
## 第三式 道无岁月 S级〔候选485XP〕

以一个标准动作，消耗9点相应能量，冷却1轮，你以手持分类为剑的武器发起一次近战白刃攻击，这次攻击若命中，不造成通常伤害，若生物不具备无限的寿命，立即命尽而亡，因命尽而亡的生物在解决寿命问题之前无法被复活，通常只能在特殊重塑服务处在复活的同时兑换解决寿命问题的办法。若生物具备无限的寿命，每次命中目标将失去一个使其获得无限寿命的特性（如果可拆分）或兑换（如果不可拆分），直到失去全部此类特性后，可以正常的命尽而亡。若攻击的是物体，A级或更低的物体将立刻被摧毁。

本招式是一个基于时间法则的效果。


<a id="L20"></a>
## 第五式 道传寰宇 S级〔候选485XP〕

以一个标准动作，消耗9点相应能量，冷却1轮，你以手持分类为剑的武器发起一次近战白刃攻击，这次攻击具有无限大的射程，该攻击无需效果线，并可以攻击和你不处于同一位面的目标，也可以直接摧毁空间道标，和/或者攻击与空间道标指向的目标。这次攻击可以同时攻击射程内的所有目标，你可以选择任意数量目标不受此攻击。

本招式是一个基于空间法则的效果。


<a id="L24"></a>
## 第七式 道灭道生 S级〔候选485XP〕

道灭道生：标准动作、9点相应能量，冷却1轮，以手持剑近战攻击。命中不造成通常伤害：生物立刻消亡，按S级即死比较实际即死免疫；物品被摧毁，不因只有生物即死免疫而自动免除，明确保护物品免于同阶消亡／摧毁的防护仍照常。每场景一次，本招确实杀死非临时、非友方且有真实威胁的生物，或摧毁敌方正在运作的独立结界后，自己本场景下一次合法攻击取得48点洞察DP，用后消失；此奖励范围不限制攻击本身可选的合法物品，不发XP或按旧价折奖。
