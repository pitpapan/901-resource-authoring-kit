# 通感

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
能力：通感

通感可以以自由动作主动压制，需要的时候再以自由动作重新打开。


<a id="L10"></a>
## 二感互通 D级〔候选10XP〕

二感互通：你选择视听触嗅味中任意两者，这让你在使用相应感官的判定中获得+1DP加值（最常见的视听可能已经涵盖了绝大多数判定，如攻击，侦查，反射等，但可能强韧意志并算不上）。当选择的感官中的一个受到影响时，另一个也会受到影响，将视觉对应目眩，听觉对应耳鸣，触觉对应剧痛，嗅觉和味觉对应恶心，当角色确实受到任一对应状态点数时，同时承受连通的感官所对应的状态点数，无法豁免，选择嗅味联觉不会承受双倍点数，相应的使用范围较为狭隘。

强化第六感：强化的直觉让你免疫措手不及，幻术等同你通感能力等级，每级占用双特性，后续不再赘述，同时你在所有判定包括先攻和防御上获得+1洞察加值。


<a id="L14"></a>
## 三感互通 C级〔候选25XP〕

三感互通：你选择第三项感觉加入，负特性也被同步加强，相应判定中获得的加值变为+2。

强化第六感：相应的洞察加值变为+2


<a id="L18"></a>
## 四感互通 B级〔候选65XP〕

四感互通：你选择第四项感觉加入，负特性也被同步加强，相应判定中获得的加值变为+4。

强化第六感：相应的洞察加值变为+4


<a id="L22"></a>
## 五感互通 A级〔候选175XP〕

五感互通：你选择第五项感觉加入，负特性也被同步加强，相应判定中获得的加值变为+8，五感互通让你将该判定加值延伸至所有判定，包括先攻和防御上。

强化第六感：相应的洞察加值变为+8


<a id="L26"></a>
## 第七感 S级〔候选485XP〕

时空知觉：你将五感和第七感时空觉连通，你对时间和空间法则获得了直观的了解，你免疫时间和空间法则相关效果，该等级视为S级，你有绝对的时空感，总是知道以自身为基点的精确计时和位移，即使你经过传送，时停等等也不会改变。

强化第六感：你将原本A级的免疫措手不及效果和幻术效果提升至S级。
