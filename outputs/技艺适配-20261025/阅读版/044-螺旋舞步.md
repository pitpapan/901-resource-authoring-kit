# 螺旋舞步

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
螺旋舞步（招式 身法）

-要学习螺旋舞步，你必须达到智力6+，敏捷6+，科学5并有力学专业，白刃5并有巨镰专业。

-螺旋舞步的维持需要消耗高度集中性的能量，它可以用灵力，精神力，魔力或直接使用意志来推动。它可以作为一个灵力招式来学习，也可以作为一个精神力技能来开启精神力池。特殊的，在使用螺旋舞步时，魔力可以用于抵消灵感疲劳。

-你必须使用巨镰来启动螺旋舞步，如果你因某种原因巨镰离开手中，那么螺旋舞步立刻停止。


<a id="L13"></a>
## D级（+1000）

以一个移动动作，消耗1点能量，效果持续5轮。

当你处于螺旋舞步中时，你不再使用力量作为巨镰攻击时的关键属性，而是使用敏捷和智力中较高者。

将敏捷与智力中较低者的L值加入本次伤害上限。

你在使用巨镰进行的攻击以及格挡时的格挡加值上获得等同K(科学)的加值，在攻击上视为招式加值。

你在使用巨镰时，视为具有【格挡】特性。

补正·螺旋舞步（3XP）

在计算本页面中L(敏捷)/L(智力)造成的影响时，你可以将其视作6点与你自身的对应传奇属性取高。


<a id="L21"></a>
## C级（+2000）

处于螺旋舞步中时，你可以以自由动作额外消耗3点能量，增加5轮持续效果并获得如下额外好处。

D级巨镰攻击招式DP、格挡加值各再增加min(L(敏捷),L(智力))。

若你支付迅捷动作，在你的回合结束时，以你为中心造成半径为你自身体积+武器体积球形区域内，伤害等同你武器伤害/2，并拥有和武器特性一致的范围伤害，你可以选择哪些目标受此伤害，反射豁免。你将敏捷，L(智力)之和，以及科学，K(白刃)之和，作为其豁免中受到的减值。

除此之外，你现在进行白刃格挡是一个迅捷动作。


<a id="L26"></a>
## B级（+4000）

处于螺旋舞步中C级效果时，你可以以自由动作额外消耗5点能量，增加5轮持续效果并获得如下额外好处。

你用你使用巨镰攻击的关键属性取代力量计算伤害上限。

你在D级使用巨镰进行的攻击的招式加值以及格挡时的格挡加值上提升等同你的E(科学)。

你在C级回合结束时造成的伤害提升至武器伤害*2/3+L(智力)/L(敏捷)取高。

现在你进行白刃格挡是一个自由动作。


<a id="L32"></a>
## A级（+8000）

处于螺旋舞步中B级效果时，你可以以自由动作额外消耗7点能量，增加5轮持续效果并获得如下额外好处。

D级巨镰攻击招式DP、格挡加值各再增加4×min(L(敏捷),L(智力))。

你在B级回合结束时造成的伤害提升至武器伤害+L(智力)/L(敏捷)取高。，且该效果中提及的豁免减值变为扣除成功数。

若一个目标因你的螺旋舞步造成范围伤害而受到伤害，他在进行攻击，防御，对抗判定时失去等同伤害数的成功数或附加成功数（防御即为附加成功），持续一轮。
