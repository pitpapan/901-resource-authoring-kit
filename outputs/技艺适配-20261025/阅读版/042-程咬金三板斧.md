# 程咬金三板斧

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
程咬金三板斧(技艺)

前提：你必须使用分类为斧的武器来使用这项技艺


<a id="L11"></a>
## 切西瓜 〔候选5XP〕

以一个标准动作，冷却1轮，你以相应武器进行一次RE全力攻击，你的攻击获得3点表现加值。

此外，你的下一次攻击也会获得3点表现加值。


<a id="L15"></a>
## 小鬼剔牙 〔候选5XP〕

以一个标准动作，冷却1轮，你以相应武器进行一次RE全力攻击，这次攻击获得8点高速优势

若你在本回合或上回合中使用过切西瓜，那么下次攻击也获得3点表现加值。


<a id="L19"></a>
## 掏耳朵 〔候选5XP〕

以一个标准动作，你以相应武器进行一次RE全力攻击，这次攻击额外获得1点附加成功

若你这次攻击中有来自小鬼剔牙或切西瓜的表现加值，这个表现加值全部变为附加成功

若你在本回合或上回合中使用过小鬼剔牙，那么这次攻击也获得该能力的高速优势。

进化：


<a id="L26"></a>
## 天旋地转 C级〔候选25XP〕

前提：切西瓜

你在使用切西瓜时，会对目标造成等同武器伤害/2的范围伤害，特性与武器相同，反射豁免。

若你持用两把武器，可以生效两次。


<a id="L31"></a>
## 雷霆怒劈 C级〔候选25XP〕

前提：小鬼剔牙，拥有东方通用能量

在保留小鬼剔牙的同时，你可以选择消耗3点能量。

这次RE全力攻击不受基础防御限制，并且获得的增强加值加倍，你获得的增强加值每有6点，就附加1点额外的雷电严重伤害。


<a id="L36"></a>
## 狂风暴砍 C级〔候选25XP〕

前提：掏耳朵，天旋地转，拥有东方通用能量

你在使用掏耳朵时，消耗3点能量，可以同时触发天旋地转，因此触发的天旋地转在伤害之后结算，目标在反射判定中受到等同伤害值的减值。
