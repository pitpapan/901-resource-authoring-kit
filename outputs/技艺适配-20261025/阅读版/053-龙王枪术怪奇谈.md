# 龙王枪术怪奇谈

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
龙王枪术第一章『怪奇谈』

这套枪法消耗的能量为妖力、内力或灵力。


<a id="L10"></a>
## 使用龙王枪术必须持有枪，长矛分类的白刃武器

前提：妖力，内力或灵力


<a id="L12"></a>
## 月兔 D级〔候选10XP〕

以一个标准动作，消耗1点能量，冷却3轮，你以相应的武器对所有触及范围内的目标发起一次攻击，这次攻击不会造成伤害

但直到你下一轮行动结束为止，你攻击的每个敌人在基础防御，闪避防御和格挡加值中受到等同伤害值的减值，减少顺序同前。

进化技-狂：支付10点XP，你将幻惑的枪法作为打破对手平衡性的武器，施展时若额外支付2点能量，因月兔带来的减值也作为目标所有生理属性，技能相关判定中的减值。


<a id="L18"></a>
## 雾雨 C级〔候选25XP〕

以一个标准动作，消耗3点能量，冷却1轮，将千百次微弱打击的力道半凝半散，发放于外，收束为一道破空劲力，这劲力看上去像一束绯色的光芒。

你以相应的武器进行一次攻击，本次攻击变为B级接触攻击，并具备超级贯穿特性，射程提升至10米*感知值。

进化技-星尘狂欢：支付5点XP，劲力由千化一，复由一化千，如漫天星光落雨，你的枪劲凝化五彩流星洒下。你在雾雨的攻击中可以进行连射和火力压制。


<a id="L23"></a>
## 即望 B级〔候选65XP〕

以一个迅捷动作，消耗5点能量启动，你进入被称为“即望”的状态，效果持续一个场景

这一状态中，你以相应的武器进行攻击时，可以消耗3点能量，本次攻击造成的伤害中有等同你白刃技能的部分不受伤害吸收，减免，转化，降级影响，这视为一个A级命运法则效果，这也使得你的该次攻击视作附带A级命运法则效果来击破一部分效果。
