# 冥星纹身

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
每个人只能拥有一个冥星纹身，它们在启动后视为概念武装。


<a id="L10"></a>
## 千眼君王：D级〔候选10XP〕

尼罗格的第一阶层是思考者，无月之夜在千眼君王星座即将落下的时刻，纹刻于思考者之身的纹身可以使他们更加敏锐。以一个迅捷动作消耗1意志可以唤醒千眼君王，它的千只眼睛游走在你的体表。你获得全局视野，从而免疫D级措手不及，并在调查相关判定上获得+3DP。当你进行任何基于智力或感知的技能或属性判定时，也获得+3DP的加值可与调查判定加值叠加。持续1个场景。

进化（25XP）：你融合了千眼君王的强大力量和太古智慧，在智力和感知上获得+4增强加值，仅当你唤醒千眼君王时生效。


<a id="L14"></a>
## 九翼龙：D级〔候选10XP〕

尼罗格的第二阶层是战士，半月下于九翼龙星座达到中天之时刻下的纹身可以成为他们无形的爪牙。以一个迅捷动作消耗1意志可以唤醒九翼龙，它会游走在你的肢体上，这使你的天生武器伤害提升了3L，持续1个场景。

进化（25XP）：你在启动九翼龙时，迫发九翼龙的强力力量和速度，忽略9点来自格挡，盾牌或掩蔽的防御加值，9点来自天防或盔甲的防御加值，9点来自闪避或基础防御的防御值。


<a id="L18"></a>
## 十臂圣子D级〔候选10XP〕

尼罗格的第三阶层是劳作者。满月下当十臂圣子星座初升时刻下的纹身可以赋与他们快速工作的能力。你在进行延长判定时获得+6DP加值，以及1个附加成功。你可以在延长判定中消耗意志来获得意志力的基本用法。

进化（25XP）：延长判定中，你只需要消耗1点意志，就视为每次判定都消耗了意志以获得基本用法。
