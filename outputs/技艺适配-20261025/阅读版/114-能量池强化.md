# 能量池强化

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
这是一项通用技能，角色可以选择一项任意能量，但该能量不能带有特殊能量或者不视为能量的描述（因此电力可以，但血量，堕气，怒气等则不行）。

同池逐级取得D/C/B/A，容量累计＋10／30／70／150；高阶自然回复频率替换低阶，不把1小时、30分钟和15分钟额外叠加。原池自身独立自然恢复按实际来源保留；容量增长不直接填满新增容量。

特殊：本强化可以针对意志力池和精力池两个非能量池购买，对意志力池购买并不会增加你的意志值或意志检定。

特殊：本强化可以重复购买，每次针对不同的能量池。


<a id="L11"></a>
## 基础能量强化 D级〔候选10XP〕

能量强化：选择的能量池上限+10点。

能量回复：选择的能量池每小时会自然恢复1点


<a id="L15"></a>
## 次级能量强化 C级〔候选25XP〕

前提：基础能量强化

能量强化：选择的能量池上限再+20点。

能量回复：选择的能量池每30分钟会自然恢复1点。


<a id="L20"></a>
## 中级能量强化 B级〔候选65XP〕

前提：次级能量强化

能量强化：选择的能量池上限再+40点。

能量回复：选择的能量池每15分钟会自然恢复1点。


<a id="L25"></a>
## 高级能量强化 A级〔候选175XP〕

前提：中级能量强化

能量强化：选择的能量池上限再+80点。

能量回复：选择的能量池每15分钟会自然恢复2点。
