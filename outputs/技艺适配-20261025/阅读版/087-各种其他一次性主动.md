# 各种其他一次性主动

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
食脑秘术


<a id="L7"></a>
## 特异本质

价格 b+4000点

施展这个可怕仪式的代价，施法者将成为游离于光明与黑暗之间的阴影。他将同时承受光明与黑暗生物不利的一面，但不能得到相关的优势，这包括不能获得得以光明黑暗生物为前提条件的资源。

举行仪式需要花费一个场景的时间，这个过程中不能被人打扰，否则需要重新来过。被食用的大脑必须还保持着新鲜和完整，支离破碎或者腐烂的脑组织无法让仪式使用者获得力量，另外每天你只能进行一次这个仪式。

通过食脑秘术所继承的力量上限取决与你的感知和力量，每在这两个属性（仅计算不具有持续时间的属性）上多具备四个附加成功都能多容纳一份力量（下文称为容量）。可以被这个仪式继承的力量，包括死者生前具备的非生理系属性、技能、能力组、专长、通用法术、技艺。而能量、血统、改造、瞳术、魔导书等等无法通过这种形式得到继承。

你可以获得死者生前具备的一个能力组，这个能力组不能超过你的最高强化等级或者死者生前的等级,也不能达到S级。你无法通过这种方式获得一种以上的能力组，能力组的D级会占据1份容量，C级占据2份，B级6份，A级18份。

你可以习得一种死者生前具备的技艺，必须满足前提条件,也不能达到S级。如果此技艺来自于专属技能树，你必须先获其血统/改造/能力组。通过方式习得的技艺D级会占据1份容量，C级占据2份，B级6份，A级18份

你可以获得死者所具备的一个专长，通过这种方式获得专长，你必须满足相关条件。另外每个专长都将占据一份容量。

你可以选择在死者生前所具备的最高属性或者技能上得到提升，你将获得在其属性或技能上上附加成功数的亵渎加值。每个属性和技能都会占据一份容量，如此方式提升的技能不会给予你XP。

## 死神的约定 · D级〔候选15XP〕

购买此能力后，人物可以与他人进行特殊的契约

发动契约能力有如下限制：

第一：双方必须均为自愿，且不处于影响心灵的效果之下。

第二：订立契约时双方自动获悉对方的真实意思表示，不会产生歧义

第三：契约的条款对双方均有效，并且具有绝对的强制力

第四：契约只在当前世界生效。

契约会直接出现在双方的精神认知中，成功签订契约之后，人物会暂时失去一点意志力（每多与一个生物签订契约就会多失去一点），直到契约达成，破坏或结束之前不会恢复。契约双方都会知晓，违反契约的一方，将由契约死神予以无条件的追杀，直到契约结束或另一方也背弃契约。契约双方都会知道违约的后果。违约后果视为一个仅针对自愿契约者的S级基于命运法则的效果。只要违反主体未死亡，他将每小时失去等同自身力量的生命上限，失去的生命上限无法恢复，直到生命上限降低到0或更低，或回到特殊恢复据点。若生命上限因此降低到0或更低，角色会不可避免的死亡，也不会触发任何在死亡时/后触发的效果，并且灵魂将被死神带走，导致需要三倍的价格来让特殊重塑服务进行复活。回到特殊恢复据点或因此死亡时，失去生命上限的效果移除。

## 濒死立即行动 C级〔候选25XP〕

每场战斗最多只能使用一次，当你的生命槽最严重的伤害为恶性伤害，并且全部生命槽都已被伤害填满时，你可以选择在他行动结束后立刻进行行动轮，若你本轮已经行动过了，则此行动预支你下一轮的行动，若你的先攻值比对手低，则此行动预支你本轮的行动，此效果不改变原有先攻检定结果。


<a id="L32"></a>
## 短程瞬移 B级〔候选65XP〕

你可以进行传送式移动，只要你和目标位置之间有视线相连即可出现在目标位置上，锁定空间的效果可以禁止你以这种方式移动。

作为短程瞬移，只要你和目标位置之间的直线距离低于你的速度就不会失败，高于你的速度时，每多一倍速度叠加4%失败率，至多二十五倍速度时变为100%，瞬移失败时你会在原地停留，但移动动作仍被消耗。

你将L(意志)*4加入基础防御和反射豁免判定中。


<a id="L37"></a>
## 濒死能量恢复 D级〔候选15XP〕

每次完整冒险最多只能用一次，当你的生命槽最严重的伤害为恶性伤害，并且全部生命槽都已被伤害填满时，你可以选择一种你具备能量池的通用能量，恢复该能量最大值的1/4，这种恢复只能恢复一种能量，不能自行分配。


<a id="L40"></a>
## 明镜止水B级〔候选65XP〕

需要：感知5，意志5，意志5

进入明镜止水状态是一个迅捷动作，消耗5点意志，持续一个场景。

当处于明镜止水时，你和环境产生极度的和谐，你的行动仿佛受环境的引导。

-你无视环境带来的减值，但并不能无视伤害

-你免疫措手不及，效果等级视为B级

-你免疫影响心灵效果，等级视为B级

-你在所有判定上获得+4环境加值。

强化：投入额外的BB级〔候选110XP〕来强化这个能力，你将与环境深度同调，免疫措手不及的等级变为A，免疫心灵的等级也变为A，现在环境也不会对你造成伤害，你还获得了在他人造成的时间停止中如常行动的能力，这视为你在此时免疫A级时间法则效果影响。

强化：投入额外S级〔候选485XP〕来强化这个能力，免疫等级皆提升到S，你现在甚至与法则也完成了调和，你不受任何基于法则的效果影响，如时间，空间，命运等。
