# 鬼谷纵横剑

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
前提：任意东方通用能量

特殊：你必须手持使用分类为剑的武器来使用此技艺

鬼谷纵剑术：


<a id="L11"></a>
## 第一式：一剑夺命式 D级〔候选10XP〕

当你以相应武器发动攻击时，消耗1点能量，目标的格挡，闪避，基础防御共减少等同你E(白刃)+4点，减少顺序如前述。


<a id="L14"></a>
## 第二式：荡平四海式 D级〔候选10XP〕

当你以相应武器发动RE全力攻击时，消耗1点能量，冷却1轮，你的触及范围增加等同你的体积米，并且可以攻击范围内所有目标，这次攻击获得等同L(敏捷)的加值。


<a id="L17"></a>
## 第三式：池横不顾式 D级〔候选10XP〕

当你以相应武器进行格挡和全防御时，若受到单体攻击且攻击者处于你的触及范围之内，你可以消耗1点能量，以一个反射动作，冷却1轮，先对攻击者发动一次相应武器攻击，在对方攻击之前处理，你也可以以此发起对攻。


<a id="L20"></a>
## 第四式：左右逢源式 D级〔候选10XP〕

你可以以标准动作，消耗1点能量，冷却1轮，以相应武器进行一次虚招，这次虚招中以敏捷+白刃进行判定取代原本的虚招判定并且获得6点招式加值。

若目标受到虚招影响，你可以立刻以相应武器发动一次攻击。


<a id="L24"></a>
## 第五式：天地腾挪式 C级〔候选25XP〕

以一个标准动作，消耗3点能量，冷却1轮，你进行一次跳跃判定，以敏捷取代力量进行，随即进行一次相应全力武器攻击，这次攻击中获得判定成功数的增强加值。


<a id="L27"></a>
## 第六式：弹剑作歌式 D级〔候选15XP〕

你在进行相应武器格挡时，可以将肉搏技能也加入格挡加值基本值中。

当你处于格挡状态下时受到实体武器（远程则是实弹）攻击时，消耗1点能量与一个反射动作，这次攻击失去等同你肉搏技能的成功数。


<a id="L31"></a>
## 第七式：逆剑抱元式 C级〔候选25XP〕

若你受到单体攻击且攻击者处于你的触及范围之内，你可以以一个反射动作，冷却1轮，消耗3点能量，对攻击者发动一次相应武器攻击，这次在对方攻击之前处理，因而可进行对攻，并且对方的此次攻击中失去等同E(白刃)的成功数。


<a id="L34"></a>
## 第八式：百步飞剑式 B级〔候选65XP〕

以一个标准动作，消耗5点能量，冷却10轮，你向目标发动一次RE冲锋RE全力攻击，这次攻击中以敏捷取代力量决定调整值上限，并且不受基础防御限制。此外，这个RE冲锋中你还获得240米移动速度提升。

你在这个RE冲锋中还能在攻击前先发动一次虚招，视为你追上抛剑并持剑斩击，这次虚招以敏捷+白刃进行判定。

最后，你在此能力中投入意志力基本用法时，可以投入至多等于你的L(意志)意志力，每点额外的意志提升4dp完美加值（注：并不会反复提供基因锁加值）。

本次百步飞剑式可额外支付一个迅捷，在攻击上取得9点完美DP；该加力每次攻击只能支付一次。
