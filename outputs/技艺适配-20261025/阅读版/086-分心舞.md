# 分心舞

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
本质：特异本质

分类：技艺

主持有权以任何理由禁止该资源的获取。

参数：价格：D级〔候选10XP〕

效果：你以一个标准＋移动动作进行跳舞，此后每轮以标准＋移动动作维持，仅进行跳舞这个行为可能不会被部分角色认为是在展现敌意。当有角色将你纳入其敏感视觉范围观看你舞蹈10轮后，其需要通过一个意志检定，与你的风度+表达-舞蹈检定进行对抗，你的风度+表达-舞蹈检定至多获得16点成功数。

若对方失败，则其会产生跳舞的冲动，在一个场景之内每轮支付标准＋移动动作专注于进行该舞蹈无暇他顾，但敌意、伤害以及对其明显不利的情形或者会使对方立刻清醒从而失效，这是一个D级影响心灵效果。
