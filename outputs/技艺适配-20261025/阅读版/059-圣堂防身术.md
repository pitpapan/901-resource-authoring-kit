# 圣堂防身术

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
当学会圣堂防身术-0之后（只有学会了零式才能学习进一步的技巧），在战斗开始的第一回合，你可以以一个标准动作或消耗1意志力进入一种特殊的精神集中状态。投感知+意志，每个成功数允许你保持精神集中状态一轮时间，但最多不超过你的意志值。你必须处在精神集中状态下才能使用圣堂防身术的技巧，同时一场战斗中你无法多次进入精神集中状态。当你处于精神集中状态时，你的意志判定会获得+2洞察加值，若你在意志判定上至少拥有一个附加成功，那么此加值提升为+4。

变体：对于那些比较偏好使用武器战斗或想要扮演某些特殊人物的玩家来说，可以考虑将圣堂防身术与某些特殊的武器相结合，以白刃代替肉搏，来使这套肉搏术成为强攻型的白刃技巧。


<a id="L10"></a>
## 圣堂防身术-0 · D级〔候选15XP〕

前提：肉搏3、敏捷3、感知3

加成：基础防御+3

招式效果：启动“圣堂防身术-0”是一个移动动作，视为你发动了肉搏格挡，并获得相应的好处和坏处。此时，在受到等同你E(肉搏)的攻击次数前，你不会因多次被攻击而受到防御减值。启动此招式的同时，你可以选择在攻击DP上减少不超过你E(肉搏)的数值，直到你下一回合行动前，你在格挡加值上获得等额的提升。如果你在肉搏技能上有附加成功，那么你可以抵消对方攻击上等额的附加成功，最多不超过你在攻击DP上减少的数值。


<a id="L16"></a>
## 圣堂防身术-1 · D级〔候选15XP〕

前提：圣堂防身术-0、意志4、敏捷4

加成：肉搏格挡时，格挡加值获得3点加值

招式效果：你进行一次全力防御，但你并不获得额外的闪避加值，取而代之的是你进行一次敏捷+肉搏的判定。被攻击时，你在该判定中获得的每个成功数都可以抵消对方的一个攻击附加成功。如果对方的附加成功因此而被减少到0，则你在下一次对其进行的肉搏攻击中获得剩余的DP加值作为的洞察加值。你必须在你下一轮行动结束前作出此攻击，否则此加值失效。你可以对多个目标获得这个效果，只要你剩余的成功数足以将其附加成功减少到0。

连续技：如果在前一轮或本轮内使用过圣堂防身术 -0、13或 21，那么你在使用此招式时将额外获得DR3/神兵。


<a id="L23"></a>
## 圣堂防身术-5 · D级〔候选10XP〕

前提：圣堂防身术-0、肉搏 4、力量4、敏捷4

加成：擒抱和摔绊判定+6

招式效果： 当你成功的以擒抱抓住对手时，你可以立刻发动此招数来将敌人投掷出去。进行一次摔绊判定，你所胜出的每一点都能将对方投掷出一米的距离，并且倒在落点。对方被投掷的距离若超过自身体积，那么超过的每一米都会使其在落地时受到1点严重伤害。

连续技：如果在前一轮或本轮内使用过圣堂防身术-0或54，那么此招式造成的伤害中有最多 3点将被提升为恶性伤害。


<a id="L30"></a>
## 圣堂防身术-7 · D级〔候选15XP〕

前提：圣堂防身术 -0、力量5、感知3 、智力3

加成：无

招式效果：你在肉搏攻击时可以进行一次智力+肉搏判定，至多取得24点成功，每2个成功数允许你在攻击物体时无视1点硬度，若攻击的是无主物体，且前述成功数已经足以无视物体的全部硬度，你不需要进行攻击判定就能立刻摧毁那件物体；在攻击生物时每个成功数可以无视1点天生或盔甲防御。

连续技：如果在前一轮或本轮内使用过圣堂防身术-0、1或13，那么你可以对生物额外造成2点严重伤害。


<a id="L37"></a>
## 圣堂防身术-13 · C级〔候选25XP〕

前提：圣堂防身术-1 、意志5、肉搏5、感知 4

加成：闪避防御+6

招式效果：要使用此招式，你先在防御值上降低一定的数值，最多不能超过你的E(肉搏)的两倍。每因此而降低二点，你就能在防御上获得一个附加成功。接着，若任一对手对你发动近战攻击且并未获得任何成功，那么你可以支付迅捷动作立刻对其发动一次普通肉搏攻击。

连续技：如果在前一轮或本轮内使用过圣堂防身术 -0、1或54，那么你在使用此招式时，你发起的反击获得你因此能力在防御上获得的附加成功。


<a id="L44"></a>
## 圣堂防身术-25 · D级〔候选10XP〕

前提：圣堂防身术-5、圣堂防身术-7 、运动4

加成：跳跃判定+6DP

招式效果：你在肉搏攻击时可以支付迅捷动作与1精力进行一次跳跃判定，若你获得的成功数高于对方的基础防御，那么你可以在攻击时，额外获得等于胜出数的附加成功，最多不超过你的体积调整+5。若你拥有飞行能力，那么你可以在跳跃判定上根据机动性而获得一定加值（笨拙 +0、不良+1、普通 +3、良好+5、完美 +10）。若对方也具有飞行能力并且飞在空中，那么你的判定结果会减去等额的成功数。若你对飞在空中的敌人造成大于其体积的伤害，则他必须以敏捷+运动对抗你造成的伤害，每失败1点都会使其失速1点。

连续技：若你在前一轮或本轮内使用过圣堂防身术-0或5，那么你可以在跳跃判定上减少不超过E(运动)的 DP，并获得该数值一半的附加成功。

## 圣堂防身术-33 · C级〔候选35XP〕

前提：圣堂防身术-7

招式效果：你的天生武器攻击获得『眩晕』特性，并将攻击上的附加成功计入武器伤害中。若原本就已经拥有眩晕特性，则可以忽略击晕的体积/力量限制。

连续技：若你在前一轮或本轮内使用过圣堂防身术-0、 7或54，那么你在使用此招式时，可以忽略对方不超过你E(肉搏)的闪避防御。


<a id="L57"></a>
## 圣堂防身术-49 · D级〔候选15XP〕

前提：圣堂防身术-0、移动速度10+

加成：移动速度+20

招式效果：以标准动作，冷却1轮，你发动一次RE冲锋攻击，消耗1能量，冷却1轮但你只能移动不超过你移动速度一半的距离。你以俯低身体、连续纵跃的方式移动，因此你在这次RE冲锋中可以进行最多 90度的转向，并且可以在一般无法RE冲锋的地形RE冲锋，甚至可以在墙壁、天花板上移动。当你进行攻击时，你的敌人若用侦查对抗你的隐藏判定失败，则D级视为措手不及。

连续技：若你在前一轮或本轮内使用过圣堂防身术-0、5 或25，那么你在使用此招式时，可以在攻击上获得一个额外的附加成功。


<a id="L64"></a>
## 圣堂防身术-54 · C级〔候选35XP〕

前提：圣堂防身术-13

加成：无

招式效果：你在肉搏攻击时可进行一次感知+肉搏的判定，对抗对方的意志，你每胜出一点，那么在你下次行动前，目标的基础防御上就有-1罚值，如同他受到了多次攻击一般。此减值对他人攻击也有效。

连续技：若你在前一轮或本轮内使用过圣堂防身术-0、1、13或49，那么你的胜出数将优先抵消对方在防御上的附加成功。


<a id="L71"></a>
## 圣堂防身术-73 · D级〔候选15XP〕

前提：圣堂防身术-1、敏捷6、感知6、力量6

加成：天生武器伤害+1

招式效果：以标准动作，冷却1轮，你对触及范围内所有目标进行一次攻击，若至少受到一点伤害，则目标必须选择以力量+运动对抗你的力量+肉搏。你的每个胜出数可以将对方击退1米，若他被击退的距离大于自身体积，那么他还会被击倒。

连续技：若你在前一轮或本轮内使用过圣堂防身术-0或54，那么无论对方被击退多少距离都会被击倒。


<a id="L78"></a>
## 圣堂防身术-83 · C级〔候选35XP〕

前提：圣堂防身术-33，73、力量7、敏捷7、肉搏5

加成：基础防御+3

招式效果：以一个标准＋迅捷动作，冷却1轮，你对一个目标发动三次攻击。这三次攻击分别针对头部、咽喉和胸部发动，因此你会受到相应的罚值。三次攻击几乎在同时发动，因此在你攻击时不会获得特别的好处，但在攻击结束之后，对方视为被攻击了三次。若你三次攻击都击中了目标，则目标必须以力量+运动对抗你的力量+肉搏，若你胜出，则你可以将对方击退1米，每3个胜出数可以再将他击退1米。若他被击退的距离大于自身体积，那么他还会被击倒。使用这一招时，造成的伤害为三次攻击中取得的最高的成功数，并且将另外两次（如果命中）攻击的附加成功数加入伤害中。你只能将可以附带在每次攻击中的附加成功数以此方法叠加。你在使用这一招时视为使用RE全力攻击，获得相应加减值。

连续技：若你在前一轮或本轮内使用过圣堂防身术-0、49或73，那么你在使用此招式时，对方每被击退1米就会受到1点冲击伤害。
