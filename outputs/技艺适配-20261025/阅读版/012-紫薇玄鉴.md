# 紫薇玄鉴

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
紫微玄鉴（心法 星贤者武学）

需求：智力6 内力能量池 魔力能量池


<a id="L10"></a>
## D级

参数：价格：D级〔候选15XP〕

效果：

1.你获得一个特殊的能量池［化劲］。你可以将经过所有伤害减免之后，且你的［化劲］能量池为空时，即将对你造成非精神与毒素类型的冲击和严重伤害，按照1:1的比例转化到[化劲]槽中，成为其能量［劲］，并使这些伤害不对你的生命值造成影响。这种转化不占用动作，可以在他人的回合进行。该能量池目前上限为1点。如果已经拥有该能量池，则其总值+1。它在每个场景结束时都会被清空，并且无法被普通的的能量池强化提升上限。这无法转化已经造成的伤害。

2.你现在有两种办法来处理这些［劲］，这些法门被称为［散劲］。如无特殊说明，所有的［散劲］都属于迅捷动作。

－用一个自由动作让所有的［劲］完全消散，其表现形式与能量的来源有关，例如若转化的是火焰伤害，则效果就可能是你呼出一口灼热的空气。

除上述方法之外，一回合之内用其余的方法消散的［劲］不能超过当前紫薇玄鉴的等级*2。

－消耗任意数量的［劲］，将其作为无名加值的dp，加在你的一次肉搏或者白刃攻击上。

3.你所有具有【武学推演】关键字的判定，获得+2dp的加成。

4.你还可以将你的［魔力］用1：1的比例转化为［内力］，但不能转化回去，这不需要消耗动作。


<a id="L21"></a>
## C级

参数：价格：C级〔候选35XP〕

效果：

1.［化劲］池上限再+1（跟Ｄ级的叠加，以下类同）

2.你增加两种［散劲］的法门：

－消耗任意数量的［劲］，将其作为无名加值的dp，加在一次强韧或者反射豁免的判定上。这是一个反射动作。

－消耗任意数量的［劲］，以每点10米的比例，转化为你的步行速度，持续一轮，这是移动动作的一部分。

3.你所有具有【武学推演】关键字的判定，获得+4dp的加成。

4.所有攻击特定部位的减值最多减少1点。

5.所有带有【星贤者武学】关键字的能力，在计算等级时，可以用其自身等级或者紫微玄鉴的等级，取高。

6.在攻击之前，你可以对敌人进行一次观察，进行一个［智力+白刃／肉搏（取高）］的判定，观察其破绽；这是一个迅捷动作，但每回合只能进行一次。对同类敌人可以只进行一次判定（比如几十个同类型的克隆兵）这次判定具有【武学推演】关键字。之后对其进行肉搏／白刃攻击时，可以选择一种额外效果附加：

－增加等同于判定结果/3那么多点的破甲，至多16点。

－增加等同于判定结果/3那么多点的高速，至多16点。


<a id="L35"></a>
## B级

参数：价格：B级〔候选85XP〕

效果：

1.［化劲］池上限再+2

2.所有具有【武学推演】关键字的判定，获得+8dp的加成。

3.你获得一个新的主动能力：星移日换。用一个反射动作，跟一个正在对你进行攻击判定的目标进行以近战白刃或肉搏攻击进行一次对攻且对方无法拒绝并视为具有【武学推演】关键字。

这次攻击的覆盖区域或原本的目标，必须有一个在你的射程之内。如果你胜出，你可以使你的该次攻击不正常生效而是为对方的这次攻击选择一个新的目标（可以是对方自己），它必须在你的射程范围内；若对方这次攻击有多个目标，你只能偏转其中一个。

4.所有攻击特定部位的减值最多减少3点。


<a id="L44"></a>
## A级

参数：价格：A级〔候选215XP〕

效果：

1.［化劲］池上限再+4

2.所有具有【武学推演】关键字的判定，获得+16dp的加成。

3.增加一个新的主动能力：点穴截脉。对于你已经观察并推演过的对手，你可以进行一次特定部位的攻击（正常减值为5，但因为紫微玄鉴本身的加成效果，减值被抵消到0），这次攻击具有【穴道攻击】关键字，可以使用招式。一旦命中后不造成伤害，就可以——

－让对方所有依赖经脉运作的能量（只要能量池有基于生理系的属性就算）无豁免被封印一轮，视为能量池无法使用，正在以这些能量运作的持续性效果立即失效。这是个A级变形效果。

－造成等同于伤害的麻痹点数，强韧豁免抵消。

4.所有攻击特定部位的减值最多减少5点。

5.现在你可以用化劲转化恶性伤害了。

6.你可以将［劲］10:1转化为持续一个场景的临时内力或者临时剑气，这是一个标准动作，这个方法一回合转换的［劲］没有上限，但是内力能量池满了则强制停止转换。


<a id="L56"></a>
## S级

参数：价格：S级〔候选565XP〕

效果：

1.［化劲］池上限再+8

2.所有具有【武学推演】关键字的判定，获得+32dp的加成。

3.你的能力“星移日换”得到了提升。每场战斗一次，当你在将攻击转移向新目标时，还可以将自己在这次判定中所用的攻击累加其上，两者合并计算伤害，冲突的效果取高。

4.现在你可以立刻将你获得的任意一种不良状态点数1：1转化为［劲］，但一回合只能转化一种不良状态点数。

5.增加一个新的主动能力：六识轮转，天心顿开。用一个标准＋移动动作思考和蓄力之后，别人会看到氤氲白气从你头顶冒出，随后你可以用一个标准动作一掌打在一个自愿或无法反抗的目标的顶门，强行提升其武学智慧，让其生平种种如走马灯般一一重现，历历如在眼前，刹那间重复喜怒哀乐千百次，心灵剧震的同时，眼耳鼻舌身意，六种感知力均会不可思议地急速增长。这可以将对方的武学智慧推升至极高境界，不断推演和思考自己的武学，强行拥有小天位的天心意识（视为拥有天位训练 小天位，但无法结合天地元气，也用不了天源内力）。这个能力每部完整冒险只能使用一次。目标如果在3年内无法真正靠自己的力量提升到天位，则会爆头而死，无任何法子可救（如果对冒险者，则是必须下一部完整冒险开始之前，在特殊重塑服务处购买该训练，此时价格变为原本的2/3）。这个能力也可以对自己使用，是一个简化版本：消耗一个标准动作进行思考和推演，在这个场景中，你所有具有【武学推演】关键字的判定，再获得等同于智力或感知值较低者一半的加成。

6.你现在可以尝试用紫微玄鉴去改变和引导巨大的能量流，比如通天炮，死星的主炮或者宇宙大帝的能量，等等，只要你跟其主要能量管线有直接的接触。这是一个需要多个标准＋移动动作的剧情效果，主持有最终解释权。一般情况下，你会受到巨大的反震伤害，但也可以改变能量流的一些细微运作，这体现在主炮射击角度偏转了微小的角度等等方面。
