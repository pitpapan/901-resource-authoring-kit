# 六翼刀法

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
前提：拥有内力


<a id="L9"></a>
## D级：（D级〔候选10XP〕）

以一个自由动作，消耗1点内力启动，效果持续5轮

你在背后现出1对羽翼，你的移动速度提升20米，并且无视困难地形，能在液体表面正常行走。

你在近战攻击中获得1点招式加值，1点增强加值，高速优势2点，视目标处于D级措手不及之下，并在防御上获得1点闪避加值。


<a id="L13"></a>
## C级：（C级〔候选25XP〕）

在D级启动之中，以自由动作，消耗3点内力启动，效果持续5轮并重置D级持续时间

你在背后现出2对羽翼，你的移动速度再提升40米，并且获得等同移动速度的飞行速度，机动性完美

你在D级近战攻击中获得的招式加值，增强加值，以及防御上的闪避加值提升2点，高速优势提升至6点，措手不及提升至C级。


<a id="L17"></a>
## B级：（B级〔候选65XP〕）

在C级启动之中，以自由动作，消耗5点内力启动，效果持续5轮并重置DC级持续时间

你在背后现出3对羽翼，你的移动速度再提升80米，并且C级的飞行速度提升为3倍。

你在C级近战攻击中获得的招式加值，增强加值，以及防御上的闪避加值提升4点，高速优势提升至14点，措手不及提升至B级。


<a id="L21"></a>
## A级：（A级〔候选175XP〕）

在B级启动之中，以自由动作，消耗7点内力启动，效果持续5轮并重置DCB级持续时间

除了背后的3对羽翼外，在刀上会显现出有内劲形成的1个半透明羽翼，你的移动速度再提升120米，并且C级的飞行速度提升为7倍。同时你的移动视为传送。

你在B级近战攻击中获得的招式加值，增强加值，以及防御上的闪避加值提升8点，高速优势提升至30点，措手不及提升至A级。
