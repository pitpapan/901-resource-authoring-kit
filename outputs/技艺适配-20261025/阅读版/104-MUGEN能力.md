# MUGEN能力

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
MUGEN系统能力

特异本质

本页内容默认不能通过常规秘籍自学；须实际剧情或明确授予方式取得。

若主持已同意某一条的具体武学表现与传授来源，该条可按候选XP自学；本册纳入不自动视为这项同意。


<a id="L12"></a>
## 回血 D级〔候选10XP〕

你获得1点快速医疗。

每支付10点XP，你获得1点快速医疗，与前述并不叠加，但独立生效。

支付5点XP，你可以将两个来自本效果的快速医疗1变为一个快速医疗2

支付10点XP，你可以将来自本效果的快疗2和快疗1变为一个快速医疗3

支付20点XP，你可以将来自本效果的快疗3和快疗1变为一个快速医疗4


<a id="L20"></a>
## 回气 D级〔候选10XP〕/C级〔候选35XP〕/B级〔候选85XP〕

你在战斗场景中获得一个临时能量池，上限为5/10/20，初始为0，每轮你行动开始时恢复1/2/4点，在非战斗场景失去。

当你需要支付任何通用能量时，可以从临时能量中扣除，但必须一次结算，不能分开各自支付一部分。

本能力可以支付差价升级。


<a id="L26"></a>
## 受身 D级〔候选10XP〕

当你倒地或浮空时，你可以以冷却时间1轮的一个反射动作站起或结束浮空状态坠落。

当你受到物理伤害时，你可以立刻被击退至多1米，并减少1点伤害。


<a id="L30"></a>
## 偷跑 C级〔候选25XP〕

你在战斗开始前总是获得突袭轮。

你在先攻判定上获得8点修行加值。


<a id="L34"></a>
## 精防 B级〔候选65XP〕

当你进行格挡时，你不会获得格挡加值，而是获得格挡加值/4的全伤害吸收。


<a id="L37"></a>
## 霸体 B级〔候选65XP〕

你不会因A级以下来源的不良状态点数进入严重后果。

你的专注无法被打断。

你的移动速度不会因A级以下的任何原因减少。


<a id="L42"></a>
## 大伤害免疫 B级〔候选65XP〕

当你作为防御方进行伤害处理时，若一个伤害在“ 防御方伤害判定”流程处理完毕后，“伤害结算”流程处理前，伤害高于40点，该伤害不再进行伤害结算处理，你也不视为受到了伤害。这视为一个基于命运法则的A级效果。

——受此结算顺序影响，多个额外伤害会独立越过本能力效果。


<a id="L46"></a>
## 精防回复 A级〔候选175XP〕

前提：精防

若一个来自敌人的伤害未能突破你的全伤害吸收，你获得医疗点数等同你的全伤害吸收，每4点医疗点数可以治疗1点恶性伤害，1点治疗1点严重或冲击伤害。


<a id="L50"></a>
## 刚体 A级〔候选175XP〕

前提：霸体

你免疫来自A级或更低能力的不良状态点数。

你免疫来自A级或更低能力产生的不计状态点数的不良状态，例如震慑，浮空等。


<a id="L55"></a>
## 无限气 A级〔候选295XP〕

前提：B级回气

你回气中的能量槽每轮行动时会恢复到最大值。


<a id="L59"></a>
## 一败加强 S级〔候选485XP〕

一败加强：取得时登记一套原价合计不超过485XP的可自学能力配置，可含多个完整阶段。配置须逐项已有本册／正式资源的价格和完整规则，满足其知识、能量、树及使用前提；登记后只能在完整冒险之间重配。该485是临时配置额度，不是可支出的XP，不受学习减费折算，也不提高原角色实际学习记录。

每场景一次，受到致死伤害或效果时免疫该次伤害／效果，并结算下列只针对自身的恢复。不是重开战斗、倒退剧情或读取存档；场景编号及他人的状态均不变化，自己的本项及其他每场景／冒险限次、已支付代价、独立计数均不重置，除下一句明示恢复的资源与状态外不清除记录。

之后，你所有生命变为完好，意志，精力和通用能量恢复到最大，移除所有状态点数。

触发一败加强后，临时取得登记配置至本场景结束；配置内有持续时间的效果在失去配置时一并结束，已经实际完成的普通伤害或治疗不倒退。

因为是获得，所以这些效果若原本是需要冷却的效果，例如每场景一次的，在这里也需要重新经过冷却时间。
