# 险锋闪走

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
险锋闪走（身法）

沉重的盔甲会降低身法的灵动性，使闪避动作变形并且使人对护甲抱有期望，因此只有身穿轻甲或不穿甲时才能使用这套身法。在使用这套身法时，你所受到的每一点盔甲减值都会使你在攻击DP和防御上再额外受到1点减值。

启动险锋闪走是一个移动动作，但对于击剑高手来说哪怕是片刻的先机也值得争取，因此若人物愿意支付1点意志则可以改为以一个自由或反射动作启动。每次战斗你可以使用这套身法不超过[你的力量值+你在A(力量)]的轮数。


<a id="L10"></a>
## D级〔候选10XP〕

身法效果：

·仅在身穿轻甲或不穿甲，未使用盾牌并且使用近战武器的情况下，人物可以将智力值作为闪避加值，但不能超过身法等级。人物在运动技能上所拥有的每个附加成功可以使此上限增加1倍，至多运动15级时等同6倍身法等级。

·被近战攻击时，若对方未获得任何成功，则人物可以立刻移动不超过人物敏捷值+运动技能的距离。因此效果一轮触发的移动总距离不能超过你的移动速度。例如人物本身移动速度为30米，在轮到自己行动前因此效果而移动了15米，则在轮到自己时最多只能移动15米。

·若人物在运动技能上至少拥有一附加成功，每轮一次，人物可以在进行格挡的同时移动不超过人物敏捷值+运动技能的距离。


<a id="L15"></a>
## C级〔候选35XP〕

身法效果：

·仅在身穿轻甲或不穿甲，未使用盾牌并且使用近战武器的情况下，人物可以将A(智力)作为洞察加值加到防御值中。

·被攻击时，若对方使用了任何降低攻击DP增加攻击上的附加成功或相反的效果，那么对你来说，他失去那些奖励，但仍然要承受相应的减值。

·被攻击时，若对方使用了任何降低防御以增加攻击，或相反的规则、效果，那么对你来说，他失去那些奖励，但仍然要承受相应的减值。

## ·现在你可以以自由动作宣言格挡


<a id="L21"></a>
## B级〔候选65XP〕

身法效果：

·仅在身穿轻甲或不穿甲，未使用盾牌并且使用近战武器的情况下，人物可以在进行格挡时将E(运动)加到基础防御中，并将K(运动)加到防御上的附加成功中。

·现在人物可以用移动动作进行全力防御

·被攻击时，若对方未获得任何成功，则人物可以以一个反射动作立即对其进行一次不附带招式、能量和特殊能力的普通近战攻击。

·被攻击时，你可以以一个反射动作，冷却3轮，移动不超过自身敏捷值+运动技能的距离，这用于应对攻击或伤害时，总是视为已经脱离了范围。


<a id="L27"></a>
## A级〔候选215XP〕

身法效果：

轻甲／无甲、不用盾并持近战武器时，基础防御改用max(敏捷,感知)，另获得该较高属性的L值×2闪避防御。

·被攻击时，若对方使用了RE冲锋或RE全力攻击选项，其并不会因为该选项在对你的攻击中获得加值，而你在1轮内对其的攻击中可以获得其本应取得加值点增强加值，至多不超过L(敏捷)*2

·被近战攻击时，若对方未获得任何成功，并且在你的触及范围内有另一个敌人存在时，人物可以以一个反射动作将该次攻击偏转到另一个敌人身上。攻击者按正常攻击掷骰，而被他攻击的目标被视为措手不及。

·被攻击时，若你受到的伤害低于L(敏捷)*2，则你可以将此次攻击视为满足了“若对方未获得任何成功”的条件来使用某些能力，但仍然要照常受到伤害。

·在你的回合中，你每以移动动作之外的移动方式移动1米，在攻击和防御上获得+1DP加值，至多不超过你的E(运动)+K(运动)。
