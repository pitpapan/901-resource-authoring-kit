# 浑天宝鉴

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
本质：魔幻本质


<a id="L22"></a>
## 入门 D级〔候选10XP〕

罡气为东方通用能量池；容量与恢复使用本册依赖的内力公式，不附送内力基本用法。

基本用法：当你需要消耗内力，斗气，或气时，可以消耗罡气作为代替


<a id="L27"></a>
## 第一层：白云烟

参数：价格：D级〔候选10XP〕

白云烟：你的移动速度提升20米。

当你进行RE全力攻击时，你可以不在攻击上获得加值，而在防御上获得6点闪避加值，相应你会在攻击上获得6点完美减值

以一个标准动作，消耗1点罡气，你获得等同浑天宝鉴层数的白云烟罡气，每层罡气使你在防御上获得1点掩蔽加值，这些罡气至多存在一个场景。你拥有的白云烟罡气上限是你浑天宝鉴层数的两倍。

灵感视觉：你获得灵感视觉


<a id="L35"></a>
## 第二层：玫霞荡

参数：价格：D级〔候选15XP〕

玫霞荡：以一个标准动作，消耗1点罡气，你获得等同浑天宝鉴层数的玫霞荡罡气，每层罡气使你在防御上获得1点力场加值，这些罡气至多存在一个场景。

以一个反射动作，你可以将任意数量的白云烟罡气和玫霞荡罡气进行转换，你拥有的玫霞荡罡气上限是你浑天宝鉴层数的两倍。

你在进行近战攻击时，每层玫霞荡罡气使你获得1点增强加值，只要玫霞荡罡气不空，你可以选择将伤害类型转变为火焰伤害。


<a id="L42"></a>
## 第三层：土昆仑

参数：价格：C级〔候选25XP〕

土昆仑：以一个移动动作，消耗3点罡气，你获得等同浑天宝鉴层数的土昆仑罡气，每层罡气使你在攻击和防御上获得1点增强加值，这些罡气的效果与其他浑天宝鉴中罡气带来的增强加值叠加，至多存在一个场景。

以一个反射动作，你可以将任意数量的白云烟罡气，玫霞荡罡气和土昆仑罡气进行转换，你拥有的土昆仑罡气上限是你浑天宝鉴层数的两倍。

回气：你可以从地脉中汲取元气，恢复体内罡气，每天一次，只要你脚踏实地，可以以一个自由动作立刻回复一次罡气，视同你进行了一次15分钟的打坐调息。

固体制御：以一个标准动作，消耗3点罡气，你能风度感知米内的无主固体，其硬度不能超过你的土昆仑罡气数。

风度期间，你获得以下效果：

-你能在这些固体中游泳般前行，但你可能会因为没有视线而无法判断方向，也会因为没有空气而窒息，这个效果持续一个场景

-你可以扯起这些固体成为掩体，这样制造的掩体体积上限等同你的感知值，硬度与原本相同，这个效果可以以一个反射动作启动而非标准动作，以此应对攻击时，视为目标处于等同掩体硬度的墙壁保护之下，克服相应硬度的伤害才会伤害到被保护的目标。

-你可以直接摧毁范围内所有你能够控制的无主物体，例如无人驾驶的载具，无人机等（远程驾驶或者AI控制都不视为物品正被持有着）

-你也可以和主持协商其他用法，例如将范围内的地面推开来挖坑等


<a id="L55"></a>
## 第四层：碧雪冰

参数：价格：C级〔候选35XP〕

碧雪冰：以一个移动动作，消耗3点罡气，你获得等同浑天宝鉴层数的碧雪冰罡气，每层罡气使你在攻击中获得1点增强加值，这些罡气的效果与其他浑天宝鉴中罡气带来的增强加值叠加，并在攻击造成伤害时可以造成碧雪冰罡气/2点额外的寒冷严重伤害，并使目标受到等同实际所受额外寒冷伤害的冻结点数，可叠加，不可豁免。这些罡气至多存在一个场景。

以一个反射动作，你可以将任意数量的白云烟罡气，玫霞荡罡气，土昆仑罡气和碧雪冰罡气进行转换，你拥有的碧雪冰罡气上限是你浑天宝鉴层数的两倍。

雪冻极光：当你身具碧雪冰罡气时，以你为中心，感知米为半径内温度会下降罡气层数级，半径每增加一倍，温度下降的等级减少1级，你免疫寒冷温度带来的影响，并且当你处于寒冷温度时，你在所有判定中获得6点环境加值。


<a id="L62"></a>
## 第五层：紫星河

参数：价格：B级〔候选65XP〕

紫星河：以一个迅捷动作，消耗5点罡气你获得等同浑天宝鉴层数的紫星河罡气，每层罡气使你在攻击中无视1点任何来源的伤害减免，吸收，抵消，降级，以及硬度，这些罡气至多存在一个场景。

以一个反射动作，你可以将任意数量的白云烟罡气，玫霞荡罡气，土昆仑罡气，碧雪冰罡气和紫星河罡气进行转换，你拥有的紫星河罡气上限是你浑天宝鉴层数的两倍。

星河倒卷：“紫星河”能将物理或能量伤害转移，你可以将所受伤害转移到虚空中或者脚下的大地——甚至是敌人身上！。当你受到物理伤害或能量伤害时，可以消耗紫星河罡气来抵消伤害，将每点紫星河罡气视为2点临时生命值使用，被紫星河罡气吸收的伤害若是近战伤害，可以转移给与你相邻的单位，若是远程伤害，则可以转移给原本射程范围内的目标，反射的伤害类型，特性与攻击的类型相同，不再计算防御，但正常进行减伤处理。

超凡感知：你获得等同模糊感知范围的盲感和敏感视觉范围的盲视，并且模糊和敏感感知范围提升一倍。


<a id="L70"></a>
## 第六层：暗混沌

参数：价格：B级〔候选85XP〕

暗混沌：以一个迅捷动作，消耗5点罡气，你获得等同浑天宝鉴层数的暗混沌罡气，每层罡气使你获得1点全伤害吸收（向下取整），这些罡气至多存在一个场景。

以一个反射动作，你可以将任意数量的白云烟罡气，玫霞荡罡气，土昆仑罡气，碧雪冰罡气，紫星河罡气和暗混沌罡气进行转换，你拥有的暗混沌罡气上限是你浑天宝鉴层数的两倍。

吞噬同化：“暗混沌罡气”可以吞噬掉除了精神攻击外的一切能量，无论是阴损的剧毒、奇诡的劲力、抑或是恶毒的能量，接触“混沌”之后都只有被和光同尘，同化为一，你在受到任何非影响心灵的不良状态时减少等同你因暗混沌罡气获得的全伤害吸收点数，并且你可以以自由动作，主动消耗任意数量的暗混沌罡气层数来减少所有能受其影响的状态点数，每层罡气能移除1点所有受其影响的状态点数。


<a id="L76"></a>
## 第七层：靛沧海

参数：价格：A级〔候选175XP〕

靛沧海：以一个自由动作，消耗7点罡气，你获得等同浑天宝鉴层数的靛沧海罡气，每层罡气使你获得4点临时生命值，当临时生命值被消耗，罡气层数也自然消失，此外当你具有靛沧海罡气时，你在水下不会受到环境带来的负面效果影响，并且你能获得等同你移动速度三倍的游泳速度。这些罡气至多存在一个场景。

以一个反射动作，你可以将任意数量的白云烟罡气，玫霞荡罡气，土昆仑罡气，碧雪冰罡气，紫星河罡气，暗混沌罡气和靛沧海罡气进行转换，你拥有的靛沧海罡气上限是你浑天宝鉴层数的两倍。

滔天势：当你具有靛沧海罡气，进行近战攻击时，可以消耗3点靛沧海罡气，将这个近战攻击变为火力压制，你可以从攻击范围中忽略任意数量的目标使其不受影响。你可以消耗更多的靛沧海罡气来加强威力，每消耗1点，所有目标在反射豁免中失去1点成功数。

浪卷势：当你具有靛沧海罡气，进行近战攻击时，可以消耗3点靛沧海罡气，这次近战攻击对范围内所有你选择的目标进行，并且这些目标需要进行反射豁免，难度等同其所受的伤害数，若失败，其下轮无法进行正常移动，处于飞行的目标会立刻坠落，同时目标的基础，格挡，闪避防御收到等同失败数的环境减值，持续直到目标的回合结束。

“滔天势”与“浪卷势”中的范围有以下几种范围模式可以选择。

·攻击以你为中心，半径感知*50米的范围内选择的目标。

·攻击以你选择的方向，长感知*500米，宽5米内选择的目标。

·攻击某个方向上，长度感知*100米，锥体范围内选择的目标

## 第八层：金晨曦

参数：价格：A级〔候选215XP〕

金晨曦：以一个自由动作，消耗7点罡气，你获得等同浑天宝鉴层数的金晨曦罡气，每层罡气使你获得3点力场防御并在攻击与豁免中获得3点增强加值。这些罡气的效果与其他浑天宝鉴中罡气带来的增强加值叠加，这些罡气至多存在一个场景。

以一个反射动作，你可以将任意数量的白云烟罡气，玫霞荡罡气，土昆仑罡气，碧雪冰罡气，紫星河罡气，暗混沌罡气，靛沧海罡气和金晨曦罡气进行转换，你拥有的金晨曦罡气上限是你浑天宝鉴层数的两倍。

太阳真火：以一个标准动作，消耗7点罡气，冷却3轮，你可以以你为中心制造耀眼的强光，半径你的力量*100米范围内所有生物和物体会受到60点神圣能量严重伤害，强韧豁免，所有受到伤害的生物还会受到等同实际伤害的目眩点数，无法豁免。

## 第九层：天晶·血苍穹

参数：价格：S级〔候选485XP〕

血苍穹：修炼成功后，你逐渐朝着“超越者”靠近。你视同拥有神格等级0，但在神格0时不会受到针对神格等级的效果。

以通用XP提升基础属性时，若该次提升前基础值低于26，按901实际该级费用减半并向上取整；如普通一级6→3XP、突破级12→6XP。资源属性加值不影响此门槛，不额外发XP或重复取得节点收益。其他优惠只在明确相容时按其自身顺序结算。

元气转化：你可以将天地元气直接转化为生命力，以一个标准动作，消耗9点罡气，你能够获得96点医疗点数，每4点可以修复1点恶性伤害，2点可以修复1点严重伤害，1点可以修复1点冲击伤害，此外，当你受到致死伤害时，只要还有罡气剩余，可以立刻发动这一效果一次，先结算治疗效果，再结算伤害效果，若这个伤害效果依然能使你死亡，那么你正常死亡。
