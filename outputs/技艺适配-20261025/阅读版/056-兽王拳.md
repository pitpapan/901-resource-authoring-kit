# 兽王拳

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
兽王拳（招式·拳法）

前提：具有兽类血统的半兽人；其他角色须另有明确传授许可。

可以使用内力推动，但半兽人的窍穴与常人不同，必须经过锻炼，在肉搏技能上学习『兽王拳』专业之后，才能将内力转化为相应等级的拳劲

可选表现约定：若本团实际启用，每次出拳须说强者语或体现相应气魄，未做到时仅本拳法数值减3；默认不额外启用。


<a id="L10"></a>
## 可选规则：万能的特殊重塑服务当然可以让非半兽人也学习此能力


<a id="L11"></a>
## D级〔候选10XP〕

基本拳法：你的肉搏技能+1，最高5级。

力贯拳脚：以一个自由动作消耗1点内力，你拳劲沉重，虎虎生风，即使擦中也会头破血流。你的拳脚视为伤害4L，破甲3,9加骰的天生武器，在命中时可额外消耗1点内力催发内劲，本次攻击额外造成1点严重伤害，不计入伤害上限，效果持续一个场景。

身强体壮：在拳劲运转全身之后，身体本身的基础素质得到提高，力贯拳脚状态下，你获得dr1/-


<a id="L16"></a>
## C级〔候选25XP〕

拳法入门：你的肉搏技能+1，最高6级

力贯拳脚：现在你可以消耗额外3点内力进入该状态，若如此做，你力量获得+2增强加值，天生武器变为8加骰，催发内劲时可以再增加1点内力，严重伤害相应提升1点。

象肤：在拳劲运转全身时，你的皮肤如象般坚韧，力贯拳脚状态下，你在天生防御上获得+3加值，并获得1点全能量抗力。


<a id="L21"></a>
## B级〔候选65XP〕

拳法小成：你的肉搏技能+2，最高10级

力贯拳脚：现在你可以再消耗额外5点内力进入该状态，若如此做，你力量再获得+4增强加值，天生武器伤害提高3L，破甲+6，催发内劲时可以再增加2点内力提升2点伤害。

刚猛无俦：力贯拳脚状态下，你的天生防御加值提升到9，dr和全能量抗力提升到3。


<a id="L26"></a>
## A级〔候选175XP〕

拳法大成：将兽王拳融会贯通之后，你的肉搏技能+3

白金之拳：刚猛无匹的白金之拳，是兽人血性之中无尽战意的体现，此拳一出，当勇往直前，无坚不摧，你可以以一个标准动作消耗7点内力，冷却6轮，进行一次近战肉搏攻击，本次攻击获得+48DP招式加值并且破甲额外提升32点。

世界之拳：与白金之拳完全相反的拳法，在领悟了自然世界之后，兽人的武学也进入了崭新的世界。阴柔的世界之拳不再以力量强攻破敌，而是直接破坏对手内部。你可以以一个标准动作消耗7点内力进行一次近战肉搏攻击，冷却6轮，本次攻击视为A级接触攻击，且无视任何B级或更低来源的伤害吸收减免抵消转化。
