# 六脉神剑

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>

<a id="L6"></a>
## 乾天指 D级〔候选10XP〕

前提：拥有内力池

效果：你获得指法作为天生武器，具有伤害3L，具有2点破甲和2点高速，在攻击特定部位时受到的减值降低4点。

使用这种天生武器时，你能以敏捷取代力量进行攻击判定。


<a id="L11"></a>
## 一阳指 C级〔候选25XP〕

前提：乾天指

你的指法天生武器提升至8L，破甲和高速各提升4点，只要内力不空，指法触及范围提升10米。

以一个标准动作，消耗3点内力，你可以以这种指法武器做出如下选择，各用法都具有独立冷却时间。

-渡气治疗：你以指法近战接触一个目标，其获得8点医疗点数，每4点可以回复1点恶性伤害，2点回复1点严重伤害，1点回复1点冲击伤害

-神指点穴：冷却1轮，你以指法攻击目标特殊部位时，造成的状态点数或转化的伤害在计算豁免后加倍，但受影响的生物可以支付通用能量点数来1:1抵消这些额外的状态点数或转化的伤害

-阳关三叠：冷却2轮，你以指法对一个目标发动三次近战攻击，前两次攻击不会造成伤害，但是造成的伤害都会累计作为第三次攻击的dp加值。

-一指乾坤：冷却6轮，你以指法对一个目标发起一次强力的攻击，这次攻击视为RE全力攻击，以你的敏捷取代力量计算调整值，并且在破甲和高速优势上获得等同RE全力攻击调整值的提升。


<a id="L20"></a>
## 六脉神剑 B级〔候选65XP〕

前提：一阳指

你的指法天生武器提升至16L，破甲和高速再各提升8点

若你在以指法攻击时消耗5点内力，指法还获得射程等同你的感知*60米，并具有B级措手不及效果。
