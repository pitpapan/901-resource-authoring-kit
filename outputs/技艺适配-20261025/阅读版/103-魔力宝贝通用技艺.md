# 魔力宝贝通用技艺

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
魔力宝贝通用战斗技艺


<a id="L7"></a>
## 崩击 D级〔候选10XP〕/C级〔候选25XP〕/B级〔候选65XP〕/A级〔候选175XP〕

以一个标准动作，消耗1/3/5/7点魔力，冷却1轮，你向目标发动一次近战攻击，若被攻击的目标正处于肉搏/白刃格挡或全防御状态下，你这次攻击获得9/18/36/72点招式加值，并无视目标6/12/24/48点格挡防御，闪避防御或基础防御。

本技艺可差价升级


<a id="L10"></a>
## 战栗袭心 D级〔候选10XP〕/C级〔候选25XP〕/B级〔候选65XP〕/A级〔候选175XP〕

以一个标准动作，消耗1/3/5/7点魔力，冷却1轮，你向目标发动一次近战攻击，若这次攻击造成实际伤害，目标不会受到实际伤害，而是失去等同实际伤害的通用能量，意志或精力点数，意志豁免减少，从最高的开始扣除。

在C/B/A级，你的这次攻击判定中获得6/12/24个附加成功。

本技艺可差价升级。


<a id="L14"></a>
## 乾坤一掷/诸刃 D级〔候选10XP〕/C级〔候选25XP〕/B级〔候选65XP〕/A级〔候选175XP〕

以一个标准动作，消耗1/3/5/7点魔力，冷却1轮，你向目标发动一次攻击，这次攻击中获得9/18/36/72点招式加值，3/6/12/24个附加成功，你在下一轮行动开始之前，防御上受到6/12/24/48点减值。

本技艺可差价升级。


<a id="L17"></a>
## 连击/乱射 D级〔候选10XP〕/C级〔候选25XP〕/B级〔候选65XP〕/A级〔候选175XP〕

以一个标准＋迅捷动作，消耗1/3/5/7点魔力，冷却1轮，你可以进行二/三/五/九次攻击，这些攻击若针对了同一目标，你对该目标的攻击受到等同对该（目标攻击次数-1）*3点减值。

本技艺可差价升级。


<a id="L20"></a>
## 气功弹 D级〔候选15XP〕/C级〔候选35XP〕/B级〔候选85XP〕/A级〔候选215XP〕

本技艺相当于连击/乱射，但你并非用已有的武器发起这些攻击，而是打出这么多个能量弹来发起攻击。能量弹视为武器伤害4/8/16/32，造成纯能量严重伤害，使用敏捷+运动（能量射击）来进行攻击判定的武器，射程为你的力量*30/60/120/240米，能量弹具有魔法，正常攻击灵体特性。

本技艺同样可差价升级


<a id="L23"></a>
## 迅捷果敢 D级〔候选10XP〕/C级〔候选25XP〕/B级〔候选65XP〕/A级〔候选175XP〕

迅捷果敢：标准动作，预支下一次自己的移动动作，消耗D/C/B/A对应1/3/5/7魔力，冷却3轮，近战攻击取得12/24/48/96招式DP及4/8/16/32个RE附加成功。已预支或下一行动已全部占用时不能发动；不能重复预支。

本技艺可差价升级。


<a id="L26"></a>
## 戒骄戒躁 D级〔候选10XP〕/C级〔候选25XP〕/B级〔候选65XP〕/A级〔候选175XP〕

你在进行先攻判定时，可以选择承受8/16/32/64点减值，若你做出了对应选择，你在该战斗场景中将处于D/C/B/A级戒骄戒躁状态。

在D/C/B/A级戒骄戒躁状态中，你可以以一个标准动作，消耗1/3/5/7点魔力，冷却1轮，你向目标发动一次近战攻击，这次攻击中获得9/18/36/72点招式加值，3/6/12/24个附加成功。

本技艺可差价升级。


<a id="L30"></a>
## 阳炎 D级〔候选10XP〕/C级〔候选25XP〕/B级〔候选65XP〕/A级〔候选175XP〕

以一个标准动作，消耗1/3/5/7点魔力，冷却1轮，你向目标发动一次攻击，这次攻击中受到6/12/24/48点减值，你在下一轮行动开始之前，防御上获得9/18/36/72点招式加值，3/6/12/24个附加成功。

本技艺可差价升级。


<a id="L33"></a>
## 反击 D级〔候选10XP〕/C级〔候选25XP〕/B级〔候选65XP〕/A级〔候选175XP〕

当你受到攻击时，若攻击者在你的触及范围内，你可以立刻消耗1/3/5/7点魔力与3/3/2/迅捷动作额度，向攻击者发动一次近战攻击，你在这次攻击中只能获得一半成功数。

在C级时，你的攻击能获得完整成功数

在B级时，你的攻击能获得完整成功数

在A级时，你的攻击能获得完整成功数

本技艺的反击可以用于进行对攻。

本技艺可差价升级。


<a id="L40"></a>
## 护卫 D级〔候选10XP〕/C级〔候选25XP〕/B级〔候选65XP〕/A级〔候选175XP〕

以一个标准动作，消耗1/3/5/7点魔力，冷却3/2/1/0轮，你可以选择一个友方目标，在你下一个次行动开始之前，若该友方目标受到攻击或作为单个目标受到效果影响，你可以立刻移动到该友方身边，并将攻击和效果的目标变为你，该能力对影响所有目标的效果无效，你通过本能力移动的距离之和不能超过你的速度，若你的剩余移动距离无法让你移动到该友方身边，本效果将立即结束。

你在应对因此转移的攻击或效果影响时，若需要用到防御，在防御上获得4/8/16/32点招式加值，若需要用到豁免，在豁免上获得8/16/32/64点招式加值。

本技艺可差价升级。


<a id="L44"></a>
## 圣盾 D级〔候选10XP〕/C级〔候选25XP〕/B级〔候选65XP〕/A级〔候选175XP〕

你在进行白刃格挡时，可以立刻消耗1/3/5/7点魔力，使你在防御上获得9/18/36/72点神圣加值，并获得3/6/12/24点法术抗力，持续到你下一轮行动开始

本技艺可差价升级


<a id="L47"></a>
## 明镜止水 D级〔候选10XP〕/C级〔候选25XP〕/B级〔候选65XP〕/A级〔候选175XP〕

以一个标准动作，消耗1/3/5/7点魔力，冷却1轮，你可以获得8/16/32/64点医疗点数，每4点医疗点数可以恢复1点恶性伤害，每1点可以恢复1点严重或冲击伤害。

本技艺可差价升级
