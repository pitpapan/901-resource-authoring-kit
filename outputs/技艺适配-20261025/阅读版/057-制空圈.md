# 制空圈

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>

<a id="L6"></a>
## 制空圈D级〔候选10XP〕

以一个移动动作，消耗1点意志启动，你展开制空圈，此时你宣言肉搏格挡是一个自由动作，当你格挡时免疫C级或更低的措手不及效果，效果持续你的意志轮。


<a id="L10"></a>
## 流水制空圈 C级〔候选25XP〕

前提：制空圈

你在展开制空圈时，额外消耗3点意志，将制空圈转化为流水制空圈，除了制空圈效果外你还获得如下奖励：

-你获得等同你格挡加值基本值的闪避加值。

-你可以以肉搏攻击对进入你触及范围或在你触及范围内移动的目标以一个反射动作进行一次基本近战攻击，每次行动只会触发一次。

-免疫的措手不及等级提升到B级。
