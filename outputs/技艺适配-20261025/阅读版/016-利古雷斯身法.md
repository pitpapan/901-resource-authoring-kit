# 利古雷斯身法

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
利古雷斯用来推动这套身法的能量不明，特殊重塑服务处强化的这套身法可以应用任何基于感知的能量


<a id="L9"></a>
## 雾水翔D级〔候选10XP〕

·你的移动速度提高20米

·当你移动时，无论对手还是队友都不会阻挡你的步伐，你甚至可以与你的队友或敌人占据同一格，若你与他人占据同一格，该人对你的接触攻击自动成功，但如果该接触将造成伤害，那么仍正常进行掷骰。他人对你们两个中任一个进行攻击时，有25%几率击中另一人。

·你现在可以用迅捷动作进行准备动作来准备一次应对他人攻击的移动，借助他人攻击引起的气流卸力穿行，触发时，你可以按照自身的移动速度进行一次移动。若移动出攻击范围，如常获得双倍防御

·启动是一个自由动作，1点能量，持续5轮。


<a id="L15"></a>
## 流影打C级〔候选25XP〕

·你的移动速度再提高40米

·现在当你移动时，困难地形也不在成为你的阻碍，你不再因困难地形而在速度或其他判定上承受罚值，但这并不表示你忽略所有环境减值，当你进行RE冲锋时，移动速度增加一倍

·现在当你用迅捷动作进行准备一次应对他人攻击的移动时，触发你这次移动的攻击者如果在你的移动范围之内，你可以移动到其身边对他进行一次近战普通攻击，并且若你移动之后你的位置若离开目标的触及范围，则你可以获得雾水翔的好处，这次攻击你无法附带任何需要选择启动的效果，同时你必须用一把有刃挥砍兵器来进行这次攻击。本效果具有1轮冷却时间。

·启动流影打时，自动启动雾水翔，无需额外消耗。

·启动是自由动作，3点能量，持续5轮。


<a id="L22"></a>
## 闪光冲B级〔候选85XP〕

·你的移动速度再提高80米

·当你以移动动作进行移动时，如果你只进行直线移动，你可以移动四倍距离

·现在当你用迅捷动作进行准备一次应对他人攻击的移动时，若你发动流影打的效果，并且你选择直线移动到其身边，你除了获得雾水翔和流影打的效果外，你还能以你的普通近战攻击（包括武器伤害）进行一次判定，将判定结果作为对该直线上的范围伤害数，至多24点，对该直线上的所有目标造成伤害，反射豁免，这是一个严重物理伤害。并且现在你发动此技能，无论你在移动之后的位置是否离开目标的触及范围，皆视为离开。现在不仅攻击能触发你的准备，范围伤害也可以。本效果具有1轮冷却时间。

·你用流影打发动的攻击视为具有RE冲锋和RE全力攻击效果，并视为具有B级措手不及效果，并且你进行白刃攻击判定，结果作为范围内其他目标反射豁免的减值。

·启动闪光冲时，自动启动雾水翔和流影打，无需额外消耗。

·启动是一个迅捷动作或者一个反射动作，5点能量，持续5轮。


<a id="L30"></a>
## 弧月闪A级〔候选175XP〕

·你的移动速度再提高160米

·现在四倍距离移动取消了直线限制

·现在你可以不用迅捷动作来准备，直接用一个反射动作发动原本需要以迅捷动作准备的效果，需要照常遵守冷却时间。

·启动弧月闪时，自动启动闪光冲，雾水翔和流影打，无需额外消耗。

·启动是一个自由或者反射动作，7点能量，持续5轮。
