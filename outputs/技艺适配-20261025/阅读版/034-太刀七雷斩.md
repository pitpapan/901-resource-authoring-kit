# 太刀七雷斩

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
本能力下的招式必须依顺序学习

前提：拥有内力

特殊：本能力必须使用分类为弯刀，日本刀等武器发动


<a id="L11"></a>
## 敌欲驻我必袭 D级〔候选10XP〕

以一个标准动作，消耗1点能量，冷却1轮，你可以发起一次相应武器攻击。

若你攻击的目标在1轮内尚未进行过移动，你可以对其发动RE冲锋RE全力攻击，而不是攻击。


<a id="L14"></a>
## 敌既退我必追 D级〔候选15XP〕

当一个目标试图主动远离你时，你可以以一个反射动作，冷却时间1轮，消耗1点内力对其发动【敌欲驻我必袭】，视同目标未进行移动而进行RE冲锋RE全力攻击。你会在你选择的位置上截击他。

特殊的，若该目标为应对你通常发动的【敌欲驻我必袭】而进行移动的话，若其没有移动距离未超出你的移动速度，则视为他没有离开攻击范围，同时应对这次攻击时，目标都视为处于C级措手不及状态。


<a id="L17"></a>
## 敌已乱我再打 C级〔候选25XP〕

当你对一个对你视为措手不及的目标发起相应武器攻击时，你可以在该攻击处理后，再支付迅捷动作对其追加进行一次相应武器攻击，这次攻击视同目标处于和前述相同，至多达到B级的措手不及状态下。本能力具有1轮冷却时间

若目标因移动触发【敌既退我必追】的效果，你将这个效果中的C级措手不及提升至B级

现在若你正常使用【敌既退我必追】效果截击移动远离你的目标或使用【敌欲驻我必袭】RE冲锋未移动的目标时，目标视同处于C级措手不及效果影响之下。


<a id="L21"></a>
## 敌欲守我狂斩 C级〔候选35XP〕

当你对一个格挡中的目标发起相应武器攻击时，你可以在该攻击处理后，再支付迅捷动作对其进行一次相应武器攻击，本能力具有1轮冷却时间。

若你在这次攻击之前的本次攻击结算序列中发动过【敌既退我必追】，那么本次攻击也获得之前获得的RE冲锋和RE全力攻击加值。

若你在这次攻击之前的本次攻击结算序列中发动过【敌已乱我再打】，那么本次攻击也视目标处于同样的措手不及之下。

你在相应武器攻击中获得16点高速，破防优先级为上述倒序，这项效果是一个被动能力。


<a id="L26"></a>
## 敌已残我猛攻 B级〔候选65XP〕

当你对一个生命槽中最严重的伤害类型是严重伤害的生物发起相应武器攻击时，你可以在该攻击处理后，支付迅捷动作再对其进行一次相应武器攻击，本能力具有1轮冷却时间。

若你在这次攻击之前的本次攻击结算序列中发动过【敌既退我必追】，那么本次攻击也获得之前获得的RE冲锋和RE全力攻击加值。

若你在这次攻击之前的本次攻击结算序列中发动过【敌已乱我再打】，那么本次攻击也视目标处于同样的措手不及之下。

若你在这次攻击之前的本次攻击结算序列中发动过【敌欲守我狂斩】，那么本次攻击获得8点高速提升。

你在相应武器攻击中提升破甲，破魔各8点。


<a id="L32"></a>
## 敌已弱我更撼 B级〔候选85XP〕

当你对一个生命槽中最严重的伤害类型是恶性伤害的生物发起相应武器攻击时，你可以在该攻击处理后，再支付迅捷动作对其进行一次相应武器攻击，本能力具有1轮冷却时间。

若你在这次攻击之前的本次攻击结算序列中发动过【敌既退我必追】，那么本次攻击也获得之前获得的RE冲锋和RE全力攻击加值。

若你在这次攻击之前的本次攻击结算序列中发动过【敌已乱我再打】，那么本次攻击也视目标处于同样的措手不及之下。

若你在这次攻击之前的本次攻击结算序列中发动过【敌欲守我狂斩】，那么本次攻击获得8点高速提升。

若你在这次攻击之前的本次攻击结算序列中发动过【敌已残我猛攻】，那么本次攻击视为B级接触攻击。

你在相应武器攻击中无视目标10点任意来源的伤害减免，吸收或抵消。


<a id="L39"></a>
## 雷霆一击天下大定 A级〔候选175XP〕

当你发动过【敌已弱我更撼】后，你可以立刻消耗7点内力发动此能力，冷却6轮

本次攻击视同目标处于S级措手不及影响之下，并且是一个S级接触攻击，无视目标B级以下来源的伤害吸收，减免，抵消。

同时，本次攻击中你获得最大限度的RE冲锋和RE全力攻击好处，并且这两项的调整值不受基础防御限制，而且两者都加倍计算调整值。

此外，在攻击结束后，你可以移动至多等同你速度两倍的距离。

全七刀连续技：满足各刀触发且全部已学时，可在同一整轮按顺序完成七刀，分别支付各自能量及冷却，并预支自己下一次行动的移动动作。该移动不可再预支或使用；若下一次行动原已被占用则不能开始全七刀。没有满足触发条件的刀不会白送，已发生的攻击不退还。
