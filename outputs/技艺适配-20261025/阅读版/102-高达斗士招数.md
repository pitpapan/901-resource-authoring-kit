# 高达斗士招数

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>

<a id="L6"></a>
## 真·流星蝴蝶剑 C级〔候选25XP〕

真·流星蝴蝶剑：一次合法RE冲锋中付3气、自受X点不可避免L，冷却6轮，取得X招式DP且伤害上限＋X；X不高于自己的HP容量。本次可另付迅捷加力，额外取得7点完美DP，不重复加力。


<a id="L9"></a>
## 豪热机枪拳 C级〔候选25XP〕

效果：以一个标准＋迅捷动作，消耗3点气，冷却6轮，你可以以天生武器发起你的气能量池等级（D1-S5）次攻击，这些攻击具有L(敏捷)*3的高速优势

若你已经获得了中级气掌握，在使用“气劲外放”时，只需要一次消耗即可让所有本技艺发起的攻击都获得“气劲外放”的效果


<a id="L13"></a>
## 大地粉碎击 C级〔候选25XP〕

效果：以一个标准＋迅捷动作，消耗3点气，冷却6轮，你选择一个方向，该方向上长度等同你力量*30米，沿着你所在的固体表面蔓延的锥形区域内所有目标受到你天生武器的武器伤害/2的物理严重伤害和纠缠点数，反射同时豁免两者。

本技艺影响的区域成为困难地形，持续时间为立即

因本技艺产生的纠缠点数在离开本技艺影响的区域时清空。


<a id="L18"></a>
## 蔷薇飓风 C级〔候选25XP〕

效果：拥有此技艺的角色不需要精神力来让飞翼浮游炮认主和使用，而需要气，进行多个飞翼浮游炮编组时，支付的是气而不是精神力，用于减消耗的则是风度和力量而不是意志。

角色或角色驾驶的载具以多个飞翼浮游炮编组进行攻击时，若攻击同一目标的飞翼浮游炮达到3/5/10个，那么这些飞翼浮游炮发起的攻击都可以视为具有短点射/长点射/连射特性，并且除了第一次命中的飞翼浮游炮外，其他所有命中的飞翼浮游炮，在计算防御方伤害判定前的伤害都可以作为第一次命中的飞翼浮游炮造成的额外伤害。

认主角色的飞翼浮游炮生命值和硬度计算中的物品价格变为本技艺和角色拥有的最高级气能量池强化中的较高者。

以一个标准动作，消耗3点气，冷却6轮，你可以以至少10个认主你的飞翼浮游炮来发起一次火力压制，这次火力压制的范围等同武器极限射程（通常高能粒子脉冲步枪为*8）而非武器射程，造成的范围伤害提升等同参与的飞翼浮游炮数量+你的L(风度)+你的L(力量)，所有受影响的目标在反射豁免中受到同等数量减值，你可以选择任意数量目标不受火力压制影响。
