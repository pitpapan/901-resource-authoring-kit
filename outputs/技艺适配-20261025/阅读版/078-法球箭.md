# 法球箭

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
来自war3的一些弓箭技艺，在使用时消耗能量以在射出的箭中附加特殊效果


<a id="L8"></a>
## 根据原著效果，你同时只能使用一种法球箭

前提：拥有魔力


<a id="L10"></a>
## 灼热之箭 D级〔候选10XP〕

月之女祭司，DOTA中骷髅射手等英雄使用的弓箭技艺，能力启动后在每次以弓箭射击进行攻击时都会消耗魔力，使射出的弓箭造成额外的火焰伤害。

你在每次以弓箭射击进行攻击时，可以消耗1点魔力，这次弓箭射击若成功命中，额外造成4点火焰严重伤害。

本技能可差价升级至C级〔候选35XP〕/B级〔候选85XP〕/A级〔候选215XP〕，技能中每次支付的魔力提升至3/5/7点，造成的额外火焰伤害提升至8/16/32点。


<a id="L14"></a>
## 寒冷之箭 D级〔候选10XP〕

娜迦女妖，DOTA中黑暗游侠等英雄使用的弓箭技艺，能力启动后在每次以弓箭射击时都会消耗魔力，使射出的弓箭造成额外的寒冷伤害并冻结对手。

你在每次以弓箭射击进行攻击时，可以消耗1点魔力，这次弓箭射击若成功命中，额外造成2点寒冷严重伤害，并对目标造成4点冻结状态点数，该状态点数不可与任何其他冻结点数叠加，但可以和自身叠加，也不可豁免，但只持续3轮。

本技能可差价升级至C级〔候选35XP〕/B级〔候选85XP〕/A级〔候选215XP〕，技能中每次支付的魔力提升至3/5/7点，造成的额外寒冷伤害提升至4/8/16点，造成的冻结状态提升至8/16/32点。


<a id="L18"></a>
## 黑暗之箭 D级〔候选10XP〕

黑暗游侠使用的弓箭技艺，能力启动后在每次以弓箭射击时都会消耗魔力，使射出的弓箭造成额外的亵渎伤害并使对手承受诅咒，在诅咒缠身期间死亡将被唤起成为黑暗奴仆。

你在每次以弓箭射击进行攻击时，可以消耗1点魔力，这次弓箭射击若成功命中，这次弓箭射击若成功命中，额外造成2点亵渎严重伤害，并且目标受到D级诅咒效果缠绕，持续一轮。

被命中的生物若在诅咒生效期间死亡，其灵魂将沦为黑暗之箭的奴仆，被转化为听从使用黑暗之箭的攻击者号令的黑暗之奴，黑暗之奴不适用生物原本数据，其形象类似普通的骷髅战士，使用下列数据，黑暗之奴会存在一个场景，之后会自行碎裂随后风化消散在空气中。指挥黑暗之奴不消耗额外动作，它们可以使用自己的动作，完全服从召唤者的指挥，并视为与召唤者有心灵连接，并能共享其视觉。黑暗之奴和召唤者共享先攻顺位。

本技能可差价升级至C级〔候选35XP〕/B级〔候选85XP〕/A级〔候选215XP〕，技能中每次支付的魔力提升至3/5/7点，造成的额外亵渎伤害提升至4/8/16点，造成的诅咒等级提升至C/B/A级，产生的黑暗之奴在非空属性上每级获得2/3/4点提升，并且每级体积调整获得1/2/4的提升，所有技能等级1/2/4的提升，天生防御6/12/24的提升，同时，使用的武器伤害获得2/4/8点提升，盾牌的盾牌防御获得6/12/24的提升，所有提升都是叠加的。
