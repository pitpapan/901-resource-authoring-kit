# 九曜极速

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
九曜极速（身法 星贤者武学）

本身法具有【星贤者武学】关键字。

特殊：施展九曜极速时，不能穿重甲，且内力或者魔法力池不能为空（也即是说，你至少需要掌握这两个能量池中的一个才能修习此强化）。


<a id="L9"></a>
## D级

参数：价格：D级〔候选10XP〕

效果：

1.你的移动速度增加20米，且你的跳跃无需助跑。你可以凌波微步，履绝境如平地，你可以在水面、流沙、沼泽等液态表面正常移动；无视困难地形并获得蛛行术效果，但回合结束时该能力也失去。非战斗状态下，在旗杆、电线杆顶端和钢丝绳等狭小的地方站立行走时，无需进行运动判定。

2.你获得特殊能量池［化劲］，上限为1点。如果你已经获得，则其上限+1。该能量在每个场景结束时都会被清空。它无法被正常的能量池强化提升上限，该能量池详细见紫薇玄鉴。

3.你可以用高速的移动来化去敌人的攻势。你可以在受到一次攻击后，用一个反射动作移动10米（不限制方向），每移动10米，就可以把这次攻击中你受到的1点伤害转化成1点[化劲]槽中的能量［劲］。这种转化不消耗动作。这同类型的能力可以叠加，但不会重复作用。

4.你得到了一种［散劲］的能力

－用一个自由动作让所有的［劲］完全消散。其表现形式与能量的来源有关，例如若转化的是火焰伤害，则效果就可能是你呼出一口灼热的空气。


<a id="L18"></a>
## C级

参数：价格：C级〔候选25XP〕

1.你的移动速度再增加60米。

2.［化劲］池上限再+1（跟Ｄ级的叠加，以下类同）

3.你可以用移动来为自己“蓄力”。就像弹簧一样，在每次移动中叠加自己的劲力，直到出手致命一击。每移动5米，你可以让你的［化劲］池中，［劲］+1点。

4.你现在依靠移动化解攻势时可以用一个反射动作移动30米。

5.你的RE冲锋不再需要沿直线进行。


<a id="L26"></a>
## B级

参数：价格：B级〔候选65XP〕

1.你的移动速度再增加60米。在你移动时，视为拥有机动性为完美的飞行能力，速度等同你的移动速度。

2.［化劲］池上限再+2

3.你现在依靠移动化解攻势时可以用一个反射动作移动80米。提升之后的九曜极速能将敌人的劲力导入地下或者散发到四周，所以现在你可以不进行实际移动就化劲（至多相当于你的移动距离），但依然消耗反射动作。这可能表现为接下一击之后脚下砖石龟裂、背后轰然爆出白色的雾气，四周的空气发出剧烈的爆音等形象。

4.你的RE冲锋不再减少防御。

5.远遁：每个场景一次，你可以将速度提升至极限，瞬间飙出极远的距离。你可以在任何一次移动动作之前，宣告使用这个能力，这次移动将可以移动你通常移动速度的24倍（需要蓄力或者准备的不算在内，比如各种旅行速度），之后将强制定身一轮，并进入持续一个场景、不可避免和解除的20点疲乏状态点数。这次移动并不是空间传送，所以不会让你能通过原本无法通过的地方。


<a id="L34"></a>
## A级

参数：价格：A级〔候选175XP〕

1.你的移动速度再增加240米。

2.［化劲］池上限再+4

3.你你用反射动作进行移动以化解攻势时，至多移动150米，并且每场景至多L(敏捷)次，你可以在攻击结算前发动此能力，若成功移出范围，这次攻击会自动落空，而不是双倍防御。

A级：在自己的移动动作过程中受到攻击、范围效果、陷阱或准备动作时，每轮一次可立即沿本次尚余移动距离改向移动；若确实离开该效果射程／区域，该效果不影响你。它是本次移动的一部分，不额外增加移动距离，不允许在已经结算命中后追溯闪开。
