# 全真剑法／玉女剑法

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
全真剑法/玉女剑法


<a id="L7"></a>
## 全真剑法 D级〔候选10XP〕

以一个标准＋移动动作，消耗1点内力，你能以手持剑分类武器向触及范围内一个生物发起一次攻击，并进行一次白刃格挡

你在这次攻击中获得8点招式加值，并在防御上获得8点招式加值，持续到你下一轮开始。


<a id="L11"></a>
## 玉女剑法 D级〔候选10XP〕

以一个标准＋移动动作，消耗1点内力，你能以手持剑分类武器进行一次白刃格挡，并进行一次半速移动，在过程中任意一点向当时触及范围内一个生物发起一次攻击，之后继续进行剩余的移动。你在这次攻击中获得3点增强加值，并在防御上获得3点闪避加值，持续到你下一轮开始。

若被你的攻击的生物在使用全真剑法，其不会获得防御上的招式加值，在攻击你时也不会获得招式加值，持续1轮。
