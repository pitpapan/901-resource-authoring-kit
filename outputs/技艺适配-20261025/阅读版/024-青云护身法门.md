# 青云护身法门

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
本能力支持任何合适的修真能量如剑气，真元力，道力，灵力，佛力等

特殊：青云的护身法门虽各不相同，但循序渐进，启动高级护身法门的同时将带动低级护身法门，启动护身法门总是一个自由动作。


<a id="L9"></a>
## 齐物论D级〔候选10XP〕

消耗1点能量，持续5轮

你在防御上获得+3环境加值

你获得临时生命值等同你风度和L(感知)较高者，每次启动时重置。

补正·齐物论（3XP）：

齐物论中获得的临时生命值变为6点与你风度和L(感知)较高者取高。


<a id="L16"></a>
## 真元护体C级〔候选25XP〕

消耗3点能量，持续5轮

你获得dr2/-，全能量抗力2，全伤害吸收2

这些效果在你受到针对特定部位攻击时加倍生效。

你可以额外支付能量，每支付3点，受到部位攻击时这些效果都增加1点。


<a id="L22"></a>
## 天仙附体B级〔候选65XP〕

消耗5点能量，持续5轮

你获得12点属性加值，可自由分配，单项不超过4点，视为神圣加值。

你在攻击，防御，豁免判定上各获得+6神圣加值。


<a id="L27"></a>
## 天尊法身A级〔候选175XP〕

消耗7点能量，持续5轮

你额外获得24点属性加值，可自由分配，单项不超过8点，视为神圣加值，但和B级分配在同一属性的话可以叠加。

你可以将投入能量到任何判定中，每点能量+1DP，每5点能量获得1点附加成功，针对单次判定生效，上限是你支付的能量的关键属性中的较低者。
