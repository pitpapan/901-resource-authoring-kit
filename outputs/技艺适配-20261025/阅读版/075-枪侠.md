# 枪侠

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
同源：本兑换带来的修行加值可以与楷覆功页面带来的修行加值叠加。


<a id="L9"></a>
## D级〔候选10XP〕

要求：楷覆功二级或更高，敏捷4+，意志4+，意志3+

枪侠戒律：你需要修习楷覆功，否则无法获得和提升枪侠等级，此外，为了表示对每一颗子弹的珍惜，你无法使用连射攻击。

快速拔枪：腰间枪械以自由动作拔出，口袋或大衣内枪械以迅捷取出。为枪械装填可用比该枪械通常装填动作低一档的动作〔整轮→标准＋移动→标准＋迅捷→标准→移动→迅捷→自由〕，最低为每轮一次自由；手枪可单手装填。

紧绷神经&枪侠训练：你进行聆听，侦查，生存，动物沟通，学识相关判定，先攻判定以及在防御上修行加值提升枪侠训练等级点。

一枪一杀：你以意志取代敏捷进行枪械射击判定。

补正·枪侠&楷覆功（3XP）

在计算本页面与楷覆功页面中L(感知)/L(意志)/L(意志)造成的影响时，你可以将其视作6点与你自身的对应传奇属性取高。


<a id="L19"></a>
## C级〔候选25XP〕

要求：楷覆功三级或更高，枪侠训练第一阶

紧绷神经&枪侠训练：该特性给予的加值额外提升等同你的L(意志)点。

一枪一杀：你将L(感知)，楷覆功页面强化数量和L(意志)加入枪械射击判定中作为修行加值的提升。


<a id="L25"></a>
## B级〔候选85XP〕

要求：楷覆功四阶或更高，枪侠训练第二阶

紧绷神经&枪侠训练：该特性给予的加值额外提升等同L(感知)，楷覆功页面强化数量和枪侠等级*2的加值。

一枪一杀：你现在可以进行一种特殊的连射而不会受到惩罚，视同进行了连射一般获得加值，但每个目标只会吃到一发子弹也只消耗你射击的目标发弹药，并且多个目标不会承受减值，并且不会误伤不想攻击的目标，进行这种攻击时你获得单发射击相关好处，并如同已经瞄准了这些目标3次一般获得好处，若你消耗意志力进行这次攻击，你额外获得等同L(意志)的完美加值，你在使用枪械攻击特殊部位时不会受到减值，

你把楷覆功页面强化数量和枪侠等级加到枪械伤害上限和枪械破甲上。
