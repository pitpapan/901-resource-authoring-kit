# 艾因格朗特流剑技

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
以下剑技需要手持至少一把刀/剑分类的武器才能使用，下称相应武器，标注为双刀流剑技的则必须手持两把相应武器才能使用。


<a id="L10"></a>
## 夺命刺击 D级〔候选10XP〕

以一个标准＋移动动作，消耗1点精力，冷却3轮，你以相应武器向一个敌方目标发起RE全力攻击，这次RE全力攻击中获得12点破甲和高速优势。

进化：支付25XP进化本技艺，你这次攻击若命中，将击溃目标的格挡架势，这将使其不再处于肉搏或白刃格挡之下，持续到其下次行动开始。


<a id="L13"></a>
## 音速冲击 D级〔候选10XP〕

以一个标准＋移动动作，消耗1点精力，冷却3轮，你以相应武器向一个敌方目标发起RE冲锋，这次RE冲锋攻击中额外获得18点加值。


<a id="L15"></a>
## 旋舞终结斩 D级〔候选10XP〕

双刀流剑技，以一个标准＋迅捷动作，消耗3点精力，冷却1轮，你以两把相应武器对各自触及范围内所有敌方目标发起一次近战白刃攻击，这视为两次攻击，表现上你挥舞双剑原地旋转，斩杀所有临近之敌。


<a id="L17"></a>
## 蛇咬 D级〔候选10XP〕

以一个标准动作，消耗1点精力，冷却3轮，你以相应武器向一个敌方目标发起两次攻击。


<a id="L19"></a>
## 垂直连斩 C级〔候选25XP〕

以一个标准＋迅捷动作，消耗3点精力，冷却3轮，你以相应武器向一个敌方目标发起一次RE全力攻击举剑下劈，若这次攻击成功造成实际伤害，你对其发动第二次攻击反握上挑，这次攻击若成功造成实际伤害，目标将浮空，之后你起跳将其从浮空状态下击落，你可以移动至多等同你运动技能的距离并对该目标发动第三次攻击，这次攻击若成功造成实际伤害，目标需要进行力量判定，难度等同自身所受实际伤害，可以将体积调整作为附加成功计入，若其判定失败，每点失败数受到1点物理冲击伤害，并且移除浮空状态，但变为倒地。


<a id="L21"></a>
## 深度冲击 C级〔候选25XP〕

双刀流剑技，以一个整轮动作，消耗3点精力，冷却3轮，你以两把相应武器各自向触及范围内一个目标发起两次近战白刃攻击，这视为四次攻击，表现上这四次攻击将集中攻击同一位置。

若两把相应武器都至少成功命中目标且造成伤害一次，任何之后对目标发起的攻击破甲视为提升4点，持续一个场景

若四次攻击全部命中且造成伤害，对目标的破甲提升变为8点

上述效果在本技艺结算中不会计算。


<a id="L26"></a>
## 水平四方斩 B级〔候选65XP〕

以一个标准＋迅捷动作，消耗5点精力，冷却3轮，你可以移动至多等同你移动速度两倍的距离，你可以在移动过程中以相应武器发起至多四次近战白刃攻击，每次攻击都视为具有B级措手不及效果。


<a id="L28"></a>
## 猩红飞溅 B级〔候选65XP〕

双刀流剑技，以一个整轮动作，消耗5点精力，冷却6轮，你以两把相应武器各自向触及范围内一个目标发起四次近战白刃攻击，这视为八次攻击。表现上你放弃防御，用尽全力发起斩击。

这8次攻击中，每次攻击都视为RE全力攻击，以敏捷取代力量决定修正值，并且获得的加值上限不受基础防御限制，你在防御上受到等同你获取的加值的减值取代原本因RE全力攻击受到的防御上的减值。获取加值不受力量限制的能力对本能力没有作用，因为本能力以敏捷决定，在RE全力攻击中不受防御上减值的能力对本能力也没有作用，本能力产生的减值是能力效果并非RE全力攻击效果。


<a id="L31"></a>
## 剑技组合 A级〔候选175XP〕

剑技组合：每轮一次，一项本系列剑技完整结算后，可无动作追加另一项施展所需动作不多于前一项的剑技；其他代价、先修、冷却照付。不能是同一剑技，两项不能都是双刀流。

两项剑技不能都是双刀流剑技。且两项剑技不能是相同的剑技。

若前两项都非双刀流，可再追加第三项非双刀流剑技，所需动作同样不多于前一项；整个组合至多三项，不再递归触发剑技组合。


<a id="L35"></a>
## 星爆气流斩 A级〔候选175XP〕

双刀流剑技，以一个整轮动作，消耗7点精力，冷却6轮，你以两把相应武器各自向触及范围内一个目标发起八次近战白刃攻击，总共十六次攻击。表现上你挥舞双剑斩击的速度将逐渐加快。

本招式期间每次以相应武器攻击，你获得1点攻击上可与自身叠加的增强加值。


<a id="L38"></a>
## 日食 A级〔候选215XP〕

双刀流剑技，每轮以自由动作消耗1精力预热3轮，以一个整轮动作，消耗21点精力与意志，施放后冷却10轮，你可以以两把相应武器各自向触及范围内一个目标发起十三次近战白刃攻击，总共二十六次攻击，随后发起一次RE冲锋RE全力攻击达到二十七次攻击，本次攻击不会产生防御减值。表现上你的斩击均匀的连成一片，宛如一道光幕。

目标因此受到的攻击都视同处于A级措手不及影响之下。
