# 守护方阵

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
参数：价格：C级〔候选25XP〕

前提：拥有任意通用能量

以一个标准动作，消耗3点任意通用能量，你将手持插入地面，以你为中心，半径60米内展现白色的法阵，并向空中竖起圆柱体状影响区域，高度为30米。

法阵区域内，所有友方获得2点快速医疗，所有敌方在回合开始时受到12点纯能量严重伤害，强韧豁免。

本能力可以标准＋移动动作维持，维持时无需消耗能量，至多持续3轮。

进化：守护凤凰阵（40XP）

守护方阵技能消耗的能量提升至5点，半径变为120米，高度变为60米

区域内快疗提升至4，敌方所受的严重伤害提升至20。
