# 拔枪术

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
本技艺各级之间没有前置要求，但依然具有各自的前提。

本质：自然本质


<a id="L10"></a>
## 拔枪术 〔候选3XP〕

闪电拔枪：你可以以冷却时间1轮的自由动作取出在佩戴你伸手就能摸到的区域的（如枪套在腰间、大腿处、胸前的手枪），物品体积计算体积调整小于你至少3点的枪械。

先手必胜：你在先攻判定中获得+1专长加值

快速射击：你取出手枪后进行的第一次攻击将对手视为处于D级措手不及效果之下。


<a id="L15"></a>
## 拔枪术大成 D级〔候选10XP〕

前提：拔枪术

先手必胜：你在先攻判定进行前可以进行一个拔枪术判定，使用你的意志属性进行这个判定，这个成功数会作为先攻加值，并加在你对先攻低于你的目标进行的攻击判定上。


<a id="L19"></a>
## 午时已到 D级〔候选10XP〕

前提：拔枪术，敏捷4，意志4

你可以以一个至少标准动作，消耗1精力与1意志力宣言摆开拔枪架势，将手放在利于迅速拔枪的位置，同时摆好角度利于迅速射击，这种警戒的姿态通常不会被认为是展露敌意，因为连武器都没有拔出。这期间具有专注、姿势成分需要标准动作维持的同时你无法进行移动，除非你以完美机动性的飞行方式进行移动（若是你始终处于拔枪架势状态以这种形式进行移动会显得非常怪异—一个始终顶起前胯把手放在大腿枪套上的牛仔在天上飘浮？）。

在拔枪架势状态你可以如常进行瞄准。

拔枪射击：架势中用一个反射，以相应枪械进行一次枪械攻击。可在进入架势时同时支付自己的迅捷，令该次射击另攻击一个不同目标；再支付自己的移动则可再射击已经攻击的一个目标一次。至多三发，每发独立攻击，均可触发快速射击的措手不及。不使用点射、连射或火力压制；弹药、枪械循环、定位仍须满足。

每发之间原本不超过迅捷的扳机／撞针／枪栓循环作为本招射击一部分完成，不额外付动作；装填与故障仍另处理。

拔枪射击结束后架势结束。

攻击结束后你可以以自由动作将相应武器收回枪套。

先攻较低者的拔枪射击无法插入先攻较高者的拔枪射击流程。

上述追加攻击仅消费进入架势时实际付出的动作，不能支付尚未到来的动作，也不能保存到第二次架势；反射锁照常。

进化：火并射术（15XP）

火并射术〔15XP〕：相应枪械可放宽为体积调整小于你至少1。每次用移动动作发动，冷却3轮，并付精力1、意志点1；无需架势。

以自己行动中的移动动作支付首发；追加不同目标付迅捷，追加已攻击目标付标准，合计至多三发，不得重复换算。

火并射术不额外产生反射；若当前没有所需动作，不得发动。

该动作的攻击不再能触发拔枪术中快速射击特性的措手不及。

攻击结束后你无法以自由动作将相应武器收回枪套。

先攻较低者的拔枪射击可以照常插入这种拔枪射击流程。


<a id="L38"></a>
## 死神之眼 D级〔候选25XP〕

前提：午时已到，敏捷4，意志4，感知4

架势中以迅捷及1精力为一个已精确定位目标放1标记；或在自己行动中以自由动作付3精力放1标记，每轮一次。同目标可有多个标记，分别持续2轮。

消耗该目标一个死神之眼标记，可把对该已攻击目标追加一发的代价从移动改为迅捷；同一次拔枪射击最多消耗一个标记，并仍至多三发。

进入架势时，可另用一个标准专注加力，令这次拔枪射击的所有攻击获得3点完美DP；这一标准不能同时用于追加攻击，也不能反复加力。

进化（5XP）：你无需处于拔枪架势便可对目标进行标记。

进化（5XP）：被你标记的目标在受到你拔枪射击特性的攻击时额外受到2点同类伤害。

进化〔5XP〕：上一项加力可以在自己行动中的火并射术发动时支付标准，不必预先进入架势；轮外射击仍只能使用预先支付的加力。


<a id="L46"></a>
## 指哪打哪 D级〔候选10XP〕

前提：拔枪术大成

特殊：本技艺为特异本质

精准弹道：你无视5点来自部位射击的减值，你可以使用枪械造成伤害时变为冲击伤害，如此选择时，枪械获得眩晕特性。


<a id="L52"></a>
## 闪电射击 D级〔候选10XP〕

前提：拔枪术大成

以标准动作，冷却1轮，你在以相应武器攻击可以同时攻击至多等同你子弹容量的目标。

这次攻击视为具有【连射】带来的好处，而获得+3DP加值。


<a id="L57"></a>
## 警告威慑 D级〔候选10XP〕

你进行拔枪术判定时，可以选择一个目标，目标会受到等同拔枪术判定成功数的恐惧点数，意志豁免。

你对目标进行胁迫技能判定时，获得等同上述恐惧点数的加值。

你可以将一次攻击与胁迫（咆哮）结合，这次攻击不会造成伤害，造成的伤害变为胁迫判定中获得的加值。

为便于对照，这里提供战斗专长—快枪手/美式居合的内容。

快枪手/美式居合（1-5）

敏捷3，枪械2

不同专长的各级还会有额外的要求，但不会随着专长等级而提高。

本专长中的相应武器为物品计算体积调整小于你至少3点的枪械武器。

1级：拔枪术

你获得技艺—技巧—远程类型中拔枪术页面的拔枪术技艺


<a id="L71"></a>
## 2级：电光石火

前提：敏捷4

拔枪术中你获得的先攻加值变为本专长等级*2点专长加值。

拔枪术快速射击造成的措手不及变为C级措手不及。


<a id="L76"></a>
## 3级：午时已到

前提：意志4

你获得技艺—技巧—远程类型中拔枪术页面的午时已到技艺


<a id="L80"></a>
## 4级：空间感知

前提：感知4

你在进行枪械攻击时，视作已经进行了2次瞄准，你可以同时保持对多个目标的瞄准次数。

在对敏感感知范围内的目标进行攻击时，每次瞄准为你攻击带来的瞄准加值提升1点。

5级：死神之眼

你获得技艺—技巧—远程类型中拔枪术页面的死神之眼技艺
