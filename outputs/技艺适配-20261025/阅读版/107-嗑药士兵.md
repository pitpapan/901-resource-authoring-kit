# 嗑药士兵

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>
本质：特异本质


<a id="L9"></a>
## D级〔候选10XP〕

药物兴奋：每当你服用一份药剂，药水，魔法药水，丹药之类的消耗品（也包括常见杂物中的消耗品）时，你获得1点兴奋点（特殊的，可以运功化开药力的丹药在化开时视为服用），兴奋点可以累积，每点兴奋点让你在攻击判定和意志豁免中获得1点士气加值，兴奋点至多持续一个场景。

药物适应：你可以免除无资源级别药物带来的副作用，例如毒品的上瘾，沸腾之血的属性减值等。

过量药物：你比常人能吸收更多剂量的药物，你可以重复使用同种药剂，每份药剂给予的加值效果叠加，但至多叠加1次，因此你可以服用两份沸腾之血来让所有生理属性获得4点增强加值。服用动作变为一个标准＋迅捷动作，你必须事先将药剂准备在手中。


<a id="L14"></a>
## C级〔候选25XP〕

药物兴奋：现在因为价格高于构造值1的消耗品而获得的兴奋点变为3点

药物适应：现在免除的药物负特性提升至D级药物

过量药物：现在你可以一次服用3剂药物，来叠加三份药剂的效果，服用动作变为一个标准＋迅捷动作，你必须事先将药剂准备在手中。


<a id="L19"></a>
## B级〔候选65XP〕

药物兴奋：现在因为价格具有资源级别的消耗品而获得的兴奋点变为7点

药物适应：现在免除的药物负特性提升至C级药物

过量药物：现在你可以一次服用

4剂药物，来叠加四份药剂的效果，服用动作依旧为一个标准＋迅捷动作，你必须事先将药剂准备在手中。


<a id="L25"></a>
## A级〔候选175XP〕

药物兴奋：现在因为价格在C级以上资源级别的消耗品而获得的兴奋点变为15点

完美适应：现在当你服用药物时，药物给予的加值都视为完美加值。

完美体验：当你有兴奋点时，每轮可以获得等同兴奋点/2的临时意志以供使用，至多16点。
