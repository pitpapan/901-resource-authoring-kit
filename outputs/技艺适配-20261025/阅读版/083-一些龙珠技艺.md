# 一些龙珠技艺

本批候选；使用[共用技艺判定](../共用技艺判定.md)。各阶段及招式须分别满足前提、支付学习XP。

<a id="条目"></a>

<a id="L6"></a>
## 太阳拳 D级〔候选10XP〕/C级〔候选25XP〕/B级〔候选65XP〕/A级〔候选175XP〕

以一个迅捷动作，冷却1轮，消耗1/3/5/7点气，以你为中心，半径15/30/60/120米球形区域内所有除你之外的目标受到18/36/72/144点目眩点数，强韧豁免减少。

该效果不会与任何目眩点数叠加，包括自身造成的点数，且效果只持续1轮。

该效果对处于目盲的角色不会生效，拥有盲感或盲视的生物也免疫本技能效果。

本强化各级间可差价升级。


<a id="L12"></a>
## 残像拳 D级〔候选10XP〕

作为移动的一部分，你可以消耗1点气来创造一连串的视觉幻象，这些视觉幻象会持续1轮，你可以在连续的轮中连续移动来使用这一能力来维持视觉幻象的不间断存在。

当视觉幻象存在时，不能免疫D级视觉幻术的目标无法以视觉获得你的精准定位。

当视觉幻象存在时，你发起的第一次攻击对不能免疫D级视觉幻术的目标具有C级措手不及，但在攻击结束时，视觉幻象消失。


<a id="L17"></a>
## 万国惊天掌 D级〔候选10XP〕

以一个整轮动作进行蓄力后，消耗1点气，你对力量*30米内一个目标发起远程接触攻击，这次攻击的武器伤害视为5L，并具有能量武器，魔法，且视为适合擒抱的武器。若该攻击命中，不会造成通常伤害。

取而代之的，你对目标发起擒抱判定，目标进行擒抱对抗，你在判定中以力量取代原本的属性作为关键属性。

若你在擒抱对抗中胜出，你将成功远程擒抱住对方，同时目标将处于【浮空】状态，无法移动。该浮空状态在本能力持续期间始终维持。此外，目标受到5点力场严重伤害，且无法使用需要维持专注的技艺。

在之后的每一轮，你行动开始时，可以以整轮动作并消耗1点气来维持本技能，这使你能再次与目标进行擒抱对抗，若对抗时处于擒抱状态，成功后将额外获得压制效果并造成5点力场严重伤害；若对抗时已经处于压制状态，则成功后造成10点力场严重伤害。

目标若在第一次对抗中胜出，则不会被本能力擒抱。

目标若以自己的行动成功进行摆脱擒抱的对抗，则本能力效果结束，若是被压制的情况下摆脱压制，则依旧处于被擒抱的状态。

若目标以其他方式脱离擒抱，本能力效果同样结束。


<a id="L26"></a>
## 四妖拳 C级〔候选25XP〕

以一个标准动作，消耗3点气，你创造出两条额外的手臂，效果持续一个场景。

这两条手臂可以如正常的手臂般持有和使用物品。

四妖拳期间，每轮自己的行动中额外获得一个仅能用双臂操作物品、完成肉搏格挡或协助已付标准的肉搏攻击的移动动作；协助攻击仅给3DP，不产生独立攻击。不能施法、换成迅捷或用于再次启动四妖拳，不解除反射锁。


<a id="L31"></a>
## 魔封波 B级〔候选65XP〕

获得这项技巧的同时，你也学会了如何制作魔封波所必须的封印符，你可以花费1天时间并支付构造值0.01材料费来制作这种封印符。

此外，你必须有一个体积至多为1的容器，任何箱子锅子瓶子都行，理论上它甚至不值构造值0.01，通常具有2点硬度和2点生命值，你可以购买硬度和生命值更高的容器，每点生命值需要增加构造值1，每点硬度需要增加构造值2.5。

要使用这项技艺，你必须首先以一个移动动作将容器放置在与你相邻的地上，为了正确使用它，你不能仅仅用一个自由动作把它丢掉。

之后，你必须空出双手，以一个整轮动作，你消耗5点气，发出一道能量束进行一次远程接触攻击，射程至多等同你的力量*120米，以力量+运动进行这次判定，能量束伤害视为0L。若这次攻击命中，不会造成任何伤害。

此时，目标将被卷入能量束中，之后以同样的方式对容器发起一次攻击，这不会再消耗你的气，这次攻击只要获得1个成功数即可将目标封入容器中，若成功将目标封入容器，目标无论体积大小都会进入容器，并且昏迷1轮。本技艺是一个基于A级空间法则效果的效果，免疫的目标不会受本技艺影响。

但是，计算目标所有通用能量，意志和精力当前值之和，若该数值高于你的气，精力和意志当前值之和，目标可以扭曲魔封波的生效机制，使你成为被封入容器。若该数值不高于前述数值，但高于你气，精力当前值之和，每点差值会使你这次攻击中受到3点减值（如果该计数和你比对方低了100点，就会受300点减值），并且在攻击结束之后，你立刻不可避免的死亡。若等于或低于，则你失去等同该数值的气和精力当前值，优先扣除全部的气值。

当目标被封入容器后，任何能以天生武器触及容器，且拥有封印符的生物，都可以以一个移动动作来封闭容器。

一旦容器被封闭，容器内的目标将持续处于昏迷状态。

若目标在昏迷1轮结束后，容器仍未被封闭。或者容器被破坏，或者容器封闭后又被打开，被封印的生物将不再昏迷的出现在容器所在方格。封印有生物的容器视为一种空间存储物品，因此无法在其他储物空间中被打开，若它在储物空间中被破坏，则首先会破坏全部包含有它的其他储物空间，之后被封印的生物出现在最外层储物空间对应的锚点。

被封印的生物不会受到任何效果影响，破坏容器也不会影响到被封印的生物。

被封印的生物在任务世界传送时，不会随容器一起回到特殊恢复据点，若原本是其他小队成员，它会回到正确的空间而不是你的队伍所在的空间。
