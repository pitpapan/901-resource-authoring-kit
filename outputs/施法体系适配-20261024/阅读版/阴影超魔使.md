# 阴影超魔使

用途：额外超魔与专注支援；本体不提供施法职能。

**v0.1适配候选·阅读版；未接入。**

[共用判定](../共用901判定.md)｜[依赖](../依赖/引用定位.md)｜[来源/核算](../来源与核算.md)。各阶继承，替换值不叠加。

## 本体

前提：已有魔力池、任一超魔技巧、至少D施法职能及一道D法术。魔幻本质；本体不新开能量池、不授施法职能或施法等级，只依次开D/C/B本树。

| 阶 | 收益 |
| --- | --- |
| D | 内心之影：生命上限+3G、强韧+3G内在DP。阴影力量：所有法术P+1，但成为黑暗生物。 |
| C | 阴影集中：施法自动带超魔“升阶”，其额外魔力耗−2、可到0。阴影超魔：每次施法可临时选一项旧价≤D+500的超魔使用，即使未学；不选超魔则该术魔力耗−1、最低1。C临时选择不含超魔熟稔。 |
| B | 阴影超魔：临时选择数量改任意项，旧价仍各≤D+500，同技巧不能重复；继承C阶排除超魔熟稔。阴影疾驰：每天2G次，原q≤12的法术q−2后查动作表。 |

阴影力量的黑暗生物层级由该分类依赖给定，不能把G直接当黑暗层级。

### 阴影超魔使技能树

### D级

### 隐秘法术 D+1000
- 在施放时，若法术增加等于法术等级倍的基础魔力消耗，法术的效果本身会获得反侦测等级，等于其法术等级。
- 这意味着面对你使用的法术，若目标无法看到法术效果，就会处于等于法术等级的措手不及影响之下；也难以自知被什么法术影响了(例如你使用的火球没有外观，声音，风压，仅仅让所有被影响的生物受到灼伤，通常无法看出这是个火球术，但效果本身不会变化，一个受到不良状态点数的生物依然知道自己受到了不良状态，其他人也能发现，但通常不知道理由。)
- 但在施放时，依然须通常的法术成分，因此即使不知道受到的是什么法术影响，依然可能知道影响来自于你(特别是即使你去除了语言，姿势，材料，依然可能因他人能观察到能量流动而被识破)
- 你只能以该技艺对不高于S级的法术作调整。

### C级

### 阴影专注 C+2000
- 阴影专注：将至多3项须动作维持的效果交给影子。影子每轮能维持的原动作标值合计≤10，单项≤12；超过10但≤12的单项须占满前后两轮维持容量；若效果须每轮支付该维持动作，则不能连续交给影子。该容量仅检验同时维持负荷，不储存、不转给主人、不用于施法或攻击；能量仍由主人支付。原10恢复/12上限改为本项维持时序候选，见R-影子。
- 若一个效果原本可能打断自身专注或迫使你作专注判定，你依然须正常作该判定，若你判定失败，自身影子维持的专注会被正常打断。
- 进化：支付65XP强化此能力，可让影子所维持的专注无法被打断。

### B级

### 法术恒效 B+2000
- 阴影的力量永存不灭，自身魔法也一样。
- 但法术的持续不是永久而是24小时；在同时只能拥有一道搭配法术恒效的法术。

### 影子戏法 B+4000
- 借助阴影的力量，可向目标的投影，而非他本人施法。
- 可对间接观测的对象施法，但自身实际观测对象必须如常处于自身范围。
- 例如你向镜中，电视中，显示屏中，雷达中的对象施放时，这些事物必须处于自身范围；法术目标会如常获得你因间接观测而只能模糊定位的好处。
- 即使只有模糊定位，你也能以此能力施展能够以生物为目标，而非位置，区域或其他对象为目标的法术。
- 以此形式施放时，法术等级下降一级，影响所有相关法术参数；P最终值减半。
