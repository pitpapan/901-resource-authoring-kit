## 本体

能量：魔力；D阶从六属性任选K，选定不改。D/C/B/A/S依次开对应施法职能。

| 阶 | 新增/替换收益 |
| --- | --- |
| D | 火花：无需食水、呼吸、睡眠，寿命无限且不老。 |
| C | 火花：法术P+1，耗魔−1、最低1。时空感知：模糊视觉内时间/空间法则效果≤G+1时自动知道发生地点与用途，G阶探知；始终知自身绝对位置、方向、时间流逝及是否跨界，同界传送知距离/方向。每处经过位置都可作为仅自己可用/可发现的空间道标。 |
| B | 火花P再+1、减耗再+1（累计+2/−2）；诸界行者免疫环境影响；获得下述点燃。 |
| A | 火花P再+2、减耗再+2（累计+4/−4）；免疫≤A级时间/空间法则；为通用法术多职能学习减费视为额外有一套G阶职能。 |
| S | 火花P再+4、减耗再+4（累计+8/−8）；时间/空间免疫升S；获得下述时间线回溯。 |

**点燃（B）**：1分钟姿势＋语言仪式并维持专注，自身5魔力，每多一名接触范围自愿目标再5魔力。可每缩短1轮给所有被传送者10不可避免晕眩，最短1轮（此时共90晕眩）。选以下其一：

1. 传往已有道标；本条本身不另赠设标能力。
2. 传往已知存在的其他位面，随机未占据且可承载全队的固体平面；在出发点留1小时道标。明确知道目的地一处存在的位置时，可机运骰成功抵达该点。位面不存在则进入第3项。
3. 进入时空裂隙并在出发点留道标：裂隙内每轮每种通用能量−10，每失1点受1不可避免A。环境免疫只减半；同时免疫SSS时间与空间法则者无影响。无法可知的位面、无目的地条件不得由模型自行创建。

**S时间线回溯**：点燃消耗双倍魔力且仅自己，每完整冒险篇章一次，投射回本篇章自己经历过的任意时点，从该点重开时间线，后续事件重新游玩。自己及免疫S时间法则者保留被移除时间线的记忆。此次耗魔和晕眩保留；目标时点魔力不足则不能发动。此为阅读资源效果，不执行删除现有存档。
