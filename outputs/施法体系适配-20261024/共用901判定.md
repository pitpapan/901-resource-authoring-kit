# 共用901判定

本页只适用于本批32项候选及其必要依赖。901已采用口径优先于本批转换；本批转换不是全库村规。阅读版是本批唯一规则正文；来源/核算只解释变更，覆盖表只索引条款；本批没有执行版或JS接入。

## 检定与六属性

- 六属性为力量、敏捷、智力、感知、意志、风度。旧耐力/体质职责归力量，决心/沉着归意志，操控归风度。旧同源属性在同一公式只计一次；同源固定属性/同类加值取较高值，不能把两个旧属性都加到新属性。
- `E(领域/子项)=主技能＋一个匹配子技能`；主技能最多5，子技能无固定上限。旧专业资格要求匹配子技能≥1；双专业须同时有两个资格，但只加最贴切一个子技能。旧“无专业成功减半”取消，不能将资源消除该惩罚的文字误读成额外奖励。
- DP投D10，8—10算成功，10加投；DP≤0投机运骰，只有10成功并加投。固定DC达到即成功，普通主动对抗主动方达到被动方即成功。极大成功通常为5成功，但单项明确改阈值优先。
- 901自动成功：属性跨6/11/16…每次+1，主技能5给1，子技能每满5给1；合法判定即使骰子无成功仍计入。正文明确的RE“附加成功”仍要求有效骰子成功>0。`L(X)`/“传奇X点数”指已确认卡面的传奇属性点数；它不自动等于901自动成功数，不由属性值自由反推。来源没有给传奇点数时需角色数据，不能凭高属性补出。
- 普通意志判定/意志豁免DP＝意志＋风度；反射＝敏捷＋E(运动)，强韧＝力量＋E(求生)。正文明确的特殊骰池优先。意志点是可消费余额，上限＝意志＋风度；“临时意志”是临时点数，“意志属性加值”才改变属性。
- 固定召唤物九属性卡合并同源取高。原技能数值V且附“所有专业”的，本批建立主技能`min(5,V−1)`及对应子技能`V−主`，故E仍为V；所有专业指该模板能使用的相关子项，不赠其他生物资格。该分配是本批固定模板转换，901自动成功由分配后的主/子技能计算。

## 动作

每回合1标准、1移动、1迅捷；标准可换移动，移动可换迅捷，不能逆换。自由通常限自己行动时，讲话例外。反射动作可中断，但用后至下一次行动结束不得再反射或迅捷；明确授予的额外反射次数才例外。响应动作占反射，在他人两动作间作一个标准并跳过自己下一次行动。

`q`仅为某一行为的**固定原动作价格**，用于本批施法加减费和依赖条款的精确查表；不是角色拥有、恢复或存储的行动点。出现“动作标值6”等字样时，明确读为本表所列的901动作。先对单个行为计算条文明确的加减价，再查表，不能把自己的标准/移动/迅捷任意拆回q支付。

| 最终q | 901实际占用 | 身份 |
| --- | --- | --- |
| 0 | 自由动作 | 本批转换 |
| 1—2 | 迅捷 | 2已采用；1为本批向上落档 |
| 3—4 | 移动 | 4已采用；3为本批向上落档 |
| 5—6 | 标准 | 6已采用；5为本批向上落档 |
| 7—8 | 标准＋迅捷，同一回合同时支付 | 8已采用；7为本批向上落档 |
| 9—10 | 标准＋移动，同一回合同时支付 | 本批转换 |
| 11—12 | 整轮：标准＋移动＋迅捷均被占用 | 本批转换 |
| 大于12 | 每满12为一个完整回合，再下一回合支付余数对应动作，末次支付完成时生效；整除时在最后完整回合完成 | 本批跨轮转换 |

例如14＝本轮整轮＋下一轮迅捷，36＝连续3个整轮；不能一轮内连付三次整轮。按分钟/小时/天计时的仪式沿原持续时间，不能换成表中短动作；每轮持续参与时失去该轮全部动作，原文另明维持动作的除外。q加减费最低0，单项最低2等限制优先；分数q向上取整再查表。

反射用法单独转换：原q≤2反射为普通反射；q3—4反射另预支下一次行动的移动；q5—6另预支下一次行动的标准；q7—8另预支标准＋迅捷；q9—12另预支整轮。预支动作到下次行动确实扣除，反射锁仍成立。原文只写“反射”无数值，按普通反射，不补出能量。原写“自由/反射”是自己行动时自由、回合外反射二选一。反射改价不是无限次反射。

额外/恢复/上限/临时AP已经在剑魔、魔纹、机智爆发、阴影专注、后发制人、夜天自动书记及融合支援各条分别改为动作次数或专注时序；不得从其他原文AP字样再取得一套池。代价、冷却、每日次数及使用者限制照各条，额外动作不能支付其他行为所预支的动作债务。

## 法术共用操作

1. 先确认已学法术、职能阶位、技能树与专业资格。职能只开学习范围，不直接免费学全树；正文明确赠术/借术是例外。D/C/B/A/S/SSS/九S的序号为1/2/3/4/5/6/7。魔导书还要求相应书阶；阴影超魔使本体不提供职能。
2. 默认关键属性K＝智力，主技能神秘学。天生魔力默认K＝风度；本体指定理论智力、感知、意志或自选属性的按本体。**法术卡中作为施法参数的“智力”（判定、距离、范围、数量及其他效果参数）统一读取K**，能力组本体明确基于智力的属性收益/学习收益不改。默认施法DP＝K＋E(神秘学/该术专业)＋明确修正；法术写用白刃等替换时按其式。
3. 指定生物/物品须精确定位；指定区域只需有合法位置。默认须有视线和效果线；范围效果影响范围内所有对象（包括自己），明示选敌、排除或自身免疫优先。“模糊定位”本身不能满足指定个体，阴影戏法等明确例外优先。
4. 姿势须能正常行动、至少一只空手；措手不及、定身或擒抱等使其不能满足时不能施放。阴阳术明确要双手。语言须清晰咏唱；在效果线且能模糊感知施术者的生物自动获得对施术者的模糊定位，不能仅靠静音/高反侦测绕过。明示免成分例外优先。材料真消耗；法器须持有；不因免语言就免材料。
5. 施放/维持中受伤时，作专注：普通意志豁免结果＋强韧豁免结果，但两项均不计属性/技能自动或附加成功；DC＝本次伤害。已有异常时施法前DC＝所有未忽略异常点数之和，新增异常时立即再检定，计入新增点数。失败失去已付动作/能量，施放中断或维持结束。维持动作每支付一次才产生一次维持效果；只减施放动作的能力不减维持动作。
6. 法术表：D/C/B/A/S/SSS/九S基础P＝3/6/12/24/48/144/432，默认能耗＝1/3/5/7/9/11/13；条文另列P、能耗优先。普通威力上限`floor(基础P×4/3)`；无支线基础P1、上限2。通用及魔导书法术的上限可按每10XP+1提升，但不超过基础P×2，提升额度对所有法术共用；须实际支付/取得，不自动加P。非通用且非魔导书的适用施法规则资源，按原明文自动具有最高基础P×2的可提升上限；仍须有真实威力加值。明示突破上限的条款才突破。
7. 升阶须已会原术，且最高职能及所需树支持目标阶。基础P、默认能耗换目标阶；其他公式随之重算，特殊升阶条款叠加。低阶版本保留则各是独立法术；放弃低阶可付差价。原生C等不强加D前置。学习报价见核算。
8. 法术需攻击检定：正文给武器伤害W时，以施法DP＋W－适用目标防御（P仅在条文明确作为加值/W时加入），成功数造成所列伤型；法术上限默认`4P＋E(施法技能)`。接触攻击只忽略由接触语义排除的防御，不能无视一切防御。接触型对非自愿目标须力量＋E(对应施法专业)接触命中，远距化后改敏捷＋E；不中消耗仍损失。
9. “造成定值D，豁免减少”按对应豁免的成功数逐点减D，最低0；若写施法检定成功数作豁免减值，先减骰池再掷，不把施法成功同时加进伤害。明确对抗型则按净胜出数/成败照条文。一次豁免同时减伤害与状态时同一成功数各应用于列明的两项；分开豁免的分别投。定值豁免不再扣一次被动防御。
10. 同术重复施放默认同一类别加值取最高、各自记来源与到期；“可叠加/再/额外/累积”按明文。明确的职业替换和D/C继承不能双算。P与G不能混用，神恩/灵感/奥能/水银计数不套通用能量扩容。

灵力的“意志点能量”是回复灵力的数量＝意志属性，不是再回复可消费意志余额。“灵感疲劳”就是灵力消耗的旧名；**赠送池不赠基本用法**，因此阴阳师本体并不免费得到用精神束缚替代消耗的额外用法。若单独已取得灵力基本用法，才可在已有最高精神束缚≤3×意志时，以至少1点、等同能耗的不可避免精神束缚代付，叠在最高来源上、只靠长休全移除；灵视基本用法也须另有授予。

生命燃烧：每恢复1生命魔力，按本次长休后累计燃烧回复量c（计入这1点后）判断：c≤力量/2时自受1L；c≤(力量＋意志)/2时自受1L但恢复难度按A；c≤力量＋意志时自受1L且仅自然7天恢复1点；超过时自受1A且只能自然恢复。分段逐点计算，不用最后档反算整笔。伤害不可减免；动作并入使用该魔力的行为。累计区间为两次长休之间，依血族源第70行；长休完成即清零累计量，不清除已经造成的伤势。

魔力可有多个种类，但一次消耗须由一种完整支付，不能混付。池加值作用于本体指定种类；无指定时取得时选定一池。当前值不足不能发动；占上限不等于花当前值，解除占用不补满。临时增上限不送当前量，上限下降则截掉溢出，不事后返还。不同来源重复开启同种通用池额外+5上限，同一资源重复购买不获此收益；特殊池/计数器不享受。通用池强化D/C/B/A各新增上限10/20/40/80，每级依次取得，恢复改为每小时1/每30分钟1/每15分钟1/每15分钟2；更高阶仅源明授予。恢复各明确来源单独结算，上限不能超出。

魔力基本用法仅在明确授予时：在已有模糊视觉范围感知魔力波动并获得方位/模糊定位；使用中的能力波动＝能力阶，物品/生物波动＝物品阶/最高用魔力能力阶−1；波动0不可感知。探知等级＝魔力池等级、最多B；高反侦测可阻断。能量池等级取开启阶、池强化阶、上限20/40/80/160/480/1440对应C/B/A/S/SSS/九S中的最高。

神恩、水银、灵感、奥能、星极层数、神名等按各自来源与恢复时点；未写恢复就不补通用回满。原“影片”本批映射为主持预先划定的**一次完整冒险篇章**，不是每场景或每节点；同一事件不在多边界重复触发。原主神补给/兑换/跨影片运输须有901服务或场景来源，不因资源存在而出现。

## 伤害、防护、状态与感知

- 结算顺序：A有效性/DP/成功与上限→B免疫、忽略、硬度、吸收、DR/能抗、抵消→C临时生命、降级、实际生命损失。防御只在DP扣一次。无来源的硬度/吸收/抵消为0。物理DR抵物理，能量抗力抵对应能量；同类DR/能抗取最高，明确叠加才加。攻击命中、造成伤害和实际损伤分开触发。
- RE破甲X逐点削掩蔽→力场→器械→盾牌格挡→盔甲→天生防御，余量破硬度，**不穿DR**。破魔削幸运/士气/增强/神圣或亵渎/招式/表现/内在/无名防御，高速削基础/闪避/非盾牌格挡/洞察/修行类防御；每类同一次攻击只削实际存在值，不因名称作万能忽略。其完整类别交互见[防护关键字依赖](依赖/防护与状态.md)。伤害忽略额度若写“总计”，各类别共用一份额度。
- L/B/A逐点入槽，先用完好槽；无完好时B先把B→L再L→A，L/A先把B→A再L→A；全A死亡。A满前源明确“还须额外1伤才死”的永生酒为特例。临时生命优先承伤、不能治疗成真实生命。
- 治疗点/医疗点按各术明确比率转换，不能把四比一A套到明确三比一者。零碎治疗点不自动凑整或留存。本批RE快速医疗在每轮开始恢复，优先最重伤势：每1点治1B/L，单个快速医疗来源达到4才可每4点治1A。多个不同来源分别运作，不能把来源3与来源2拼成一项5去治A；原术明确取高/不叠加/四分之一速度等优先。
- 普通异常沿PHB：抵抗骰池＝所列六属性关键抵抗属性的较低值＋E(求生)；点数超过较高属性为重度，超过其两倍才检查该状态允许的毁灭后果。旧同源只算一次。相同状态并列取最高、记录来源，明示叠加与疲乏例外。15分钟短休可重抵一项，8小时长休可移除一项等于较低关键属性的点数；特殊不可恢复、疾病、毒素及持续来源优先。
- 异常的轻度、重度与毁灭后果不能只凭名称猜；本批所用状态、灵体/虚体及探知定义详见[防护与状态](依赖/防护与状态.md)。源仅列名而未给自定义状态的，阻止该后果并登记R-源缺，不发明新状态。
- 正常敏感视觉缺省`10×感知＋20×A(感知)`米；已有明确卡面优先。模糊视觉、特殊感知距离须有角色/来源输入，本批不凭敏感视觉自动推倍数。`盲感`给模糊定位，`盲视`给精确定位，仍受各自来源阻碍；灵视能看到灵体但不自动造成灵体伤害；正常攻击灵体不等于幽冥完整关键字。
- 比较物品阶级、硬度、生命、战力、法术位、其他角色模板时使用已确认目标数据，不用D/C标签反推。来源把对象称作“价格等同法术物品”但未给硬度/生命时，须用下列已整理构造依赖；仍缺输入只阻止相应动作，不阻止整个角色。

数字与术卡缩写：未另写时，分数数值在算完整效果后向下取整，XP费用向上取整；距离保留精确值。术卡未另列P/能耗时查上方法术阶位表；未另列持续时为立即。`言/姿/器/材/仪`分别为语言/姿势/法器/材料/仪式。`10KP米`等于`10×K×P米`。独特耗能/持续一律由卡面明列。已有帝国法术的反射用法按其现有条文，不追加本批反射预支；本批新卡才用本页转换。

## 多职能学习减费

只计无持续时间的永久职能；每个阶位先排除一套职能，不看取得顺序。额外D每满2套减1XP，额外C/B/A/S每套减1/2/4/8XP；SSS/九S在S项中分别视为2/4套。自高往低计算，每阶减费不能超过高一阶实际减费，但该阶第一次减费单位不受此上限：若原始减费r>0，实际为`min(r,max(本阶单位,高一阶实际减费))`，D/C/B/A单位为1/1/2/4，S项不封顶。各阶相加，只减通用法术自学/升阶XP，最低1；不修改其他学习资格，不用于明确不享职能减费的其他体系。例：两条DCBA树共减7，另多一D树变8。源：RE施法规则“多个施法者职能”。

通用池可用上限≤0时该池及明确以前提依赖它的效果暂时停用；回到正值后恢复原已学资格，不删除学习记录/XP、不自动新开另一池，也不补当前能量。本批将RE的“失去资源”表达为暂时失效；叠加/重开规则不能用同一资源反复停启刷+5。
