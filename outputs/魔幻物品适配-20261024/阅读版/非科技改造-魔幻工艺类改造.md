# 魔幻工艺类改造

**901候选阅读版 v0.1；未取得、未接JS。** [共用判定](../共用物品判定.md)｜[来源/核算](../来源与核算.md)

工艺通常制作/取得时选1项。以下基础工艺可与其他工艺共存，但三档只能选一档，升级替换而不叠加。

<a id="基础工艺"></a>
## 基础工艺
精制品旧D+500：使用相应物品的判定+3器械；大师旧C+1000改+12；传奇旧B+2000改+24。适用武器攻击/格挡，甲盾防御/反射掩蔽，载具驾驶或设备相关电脑等判定；格挡所得该加值无类型，不当器械同类扣除。具体用法须确实使用该物品，不能常驻给全判定。

<a id="复合魔导器改装"></a>
## 复合魔导器改装
旧DD+1000；魔幻工艺。前提已有米德式或贝尔卡式；可与该原工艺共存并获得另一种全部效果，即使原武器通常不适配另一种。原接触法术须命中时，可把武器伤害及特性计入该次攻击。魔力弹总容量/单次上限均变10；可另购微型智能AI芯片组件并视为魔幻，本改装不免费赠芯片。

<a id="贝尔卡式战斗魔导器"></a>
## 贝尔卡式战斗魔导器
旧D+1000；仅基础冷兵器模板武器。可登记一套含该武器的装备，平常缩成饰品收纳，首次登录1分钟，移动动作换装整套；仅这一套须含本武器，不占依赖插件10体积的普通物品空间，也不凭改造多送该10体积储物栏。空间限制见基础依赖。武器伤害+1、破甲+4、魔法；持用手完成姿势。容5魔力弹，每颗装填移动动作；每消耗1发任选本次武器伤害+1，或提供1点能量仅用于通过该器施展法术/能量射击的增幅。无额外启动动作、每次最多5发、只生效1次；弹价＝初级魔力容器一半。

<a id="米德式战斗魔导器"></a>
## 米德式战斗魔导器
旧D+1000；仅原本纯科技、未计附魔基础价<D+1000的武器。登记/收纳一套含绑定武器装备同贝尔卡。武器破魔+4、9加骰、魔法；持用手完成姿势，施法判定+3器械DP。改造本身不自动改变基底科技本质。

<a id="轻量化重量化"></a>
## 轻量化/重量化
旧价0，工艺仅甲：重甲→轻甲，甲防−3最低0；轻甲→重甲，甲减值+2。不自行加另一方向未给的防御或减值收益；制作时选择，不能把0价当战中免费变甲。
