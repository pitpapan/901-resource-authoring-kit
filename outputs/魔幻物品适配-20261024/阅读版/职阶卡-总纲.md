# 总纲

魔幻法器，须真实持有具体卡。限定展开与梦幻召唤都为标准动作，支付具体卡的魔力/意志，持续1场景；解除同样标准动作。

<a id="限定展开"></a>
## 限定展开
暂将卡化成对应宝具，取得该卡明列的一项技艺/物品；不连带得到完整英灵数据。明确消耗在每张卡支付，不因已经拥有同名人物能力免付。

<a id="梦幻召唤"></a>
## 梦幻召唤
把卡融入自身，以卡的六属性/技能/明确特性暂时替换自身数据，但不替换原物品。卡内旧九属性同源取高，技能转901主/子，派生和攻防按901重算；原示例旧AP、控制力/影响力和重复专业+1不直接带入，源冲突列核算。属性提升已计入卡面，不再次加一遍。

**进入：**保存本体当前伤势、各能量实际消耗、异常、永久代价与取得记录；把已有损伤/消耗转到英灵形态，不清洗。若原伤能使英灵死亡或消耗令其意志/精力为负，则启动失败、动作浪费（原未明是否退能量，见未决）。自己施加的有持续时间效果结束，原物品保留但仍核当前形态资格。

**形态内：**原异常点数不变，按新属性重新判断轻重；不能强化兑换/自学，永久代价真实保留。英灵承受致死伤害时立即结束形态，本体承接其全部伤势及最后超额伤害，可能同时死亡。

**离开：**英灵当前B/L/A伤势从最严重者先转写到本体生命槽，超容量逐点依PHB恶化，不能只按剩余生命百分比换算。形态内消耗全部转写本体同种池；消耗超过本体可承担上限时，记负余额并立即昏迷，只能自然恢复到1才醒。若本体根本没有该能量池，每消耗1点改受1不可减免L，治疗难度按A；因此升级出的A只能自然恢复或明确主神服务。形态自己施加的持续效果随替换结束，异常与永久代价照旧保留。

再次安装另一张卡或其他整卡置换，须先完整退出/转写第一张，再以本体进入第二张；不能直接卡间跳转抹消耗。上述是资源阅读规则，不授权覆盖现有T0/存档。
