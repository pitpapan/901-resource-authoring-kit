# 无支线武器

**901候选阅读版 v0.1；未取得、未接JS。** [共用判定](../共用物品判定.md)｜[来源/核算](../来源与核算.md)

本章均魔幻本质；基本冷兵器/枪械的完整底模见必要依赖，未列的基础属性只从指定底模继承。

<a id="念珠"></a>
## 念珠
旧价：同便携暗器；特殊武器·念珠，体积1。默认便携暗器底模但造成B；有佛力池时改L，对黑暗生物有魔法、对灵体可正常攻击。没有佛力不获后两项。

<a id="桃木剑"></a>
## 桃木剑
旧价250；长剑，体积2，伤害3B。固定木质，不能作材质改造，木质可突破对应DR。已有道力池时改L，对黑暗生物有魔法、对灵体正常攻击。持用时使用道术或耗道力技艺，神秘检定+1器械DP，也可加符咒之术的固定DP。

<a id="阿尔法法杖"></a>
## 阿尔法法杖
旧价200；短棍底模，体积3。需力量1、E(神秘)3。木质可突破对应DR；持用手可完成法器与姿势成分，持有施法判定+3器械DP。

<a id="十字军"></a>
## 十字军
旧价500；手枪，体积1，小型左轮底模；需智力3、E(神秘)3。用该枪攻击可将敏捷/枪械分别替换为智力/E(神秘)，只改本次枪攻击式。

<a id="秘银火铳"></a>
## 秘银火铳
旧价500；步枪，体积3，需力量1。伤害5L、射程单位150米、装弹1，步枪弹；双手、魔法、正常攻击灵体，硬度明确为4（不按普通秘银改造再升6）。

<a id="咒法战刃"></a>
## 咒法战刃
旧价500；长刀底模，魔法、正常攻击灵体。攻击可用智力代力量，源只指定攻击检定，伤害上限保原力量式；这是有限职责替换，不扩大为全属性替换。
