# 魔幻添加类改造

**901适配候选阅读版；未取得/未接JS。** [共用](../共用物品判定.md)｜[来源核算](../来源与核算.md)

<a id="转变本质"></a>
## 转变本质
主神本质添加，真实无持续时间实物才用（持续永久不算）；附魔本来不改物品本质，科技物在禁科技处仍停。付原完整价2/3，支线不能拆则D=500旧分，转非魔幻为魔幻，自身HP×2，载具也可。例D+100高斯步枪折600×2/3=400；A+8000分项2/3=BB+5333（分向整数保源报价）。

<a id="装备改造继承"></a>
## 装备改造继承
主神服务将一个已付改造从原装备移到同装备位另一件，须适用新件且该改造在两件价格相同，付原改造价1/3；不复制改造，原件失该项。不同位/新件不适用/定价不同不可用，明确规则已排漏洞无需笼统裁定。

<a id="附魔等级"></a>
## 附魔等级
武器/防具1—10级，每级500，第一级另250、第十级另D+1000；累计+1=750，+2=1250，+10=D+6250。每级硬度+1/HP+2；武器W+1L（天生提升也同），防具选甲防或盾防+1并抵破甲2；同一物兼武器防具须选一支，不一价双领。第1得魔法，第10神兵。

附魔武器与弹药明确可叠；每发弹药价为同级完整武器附魔价折D=500后÷9向上取整，+1/+2/+10＝84/139/750。无尽正义算基底价时弹药附魔部分先×9，不把单发小价直接作基底。

<a id="灵力浸润"></a>
## 灵力浸润
500，武器只250。有灵力生物使用：武器正常攻击灵体，另有灵力攻击技艺才幽冥；非武器正常影响灵体，不赠池/技艺。

<a id="无尽正义"></a>
## 无尽正义
可加投掷/便携暗器/科技消耗弹/基础箭矢。攻击后即返手/发射器，无特别射击间隔/装填规则则已装好、最佳修复可下一攻；同一攻击连射仍需实际多发，不让一弹完成连射。

非消耗投物基底完整价/3，其余基底×3，最低250。基底含已有收费改造；附后再受任何其他改造/强化术/升级即本附魔失效，须重算重做，不自动跟随提高价。附魔弹的附魔价按前述×9计。

<a id="武器链"></a>
## 武器链
250，针对一武器。移动连接/解除自身/甲/衣，连接不能离>1米；物品是否可储及储存与连接对象共同判，连人不能进仅物储物，连甲要连同甲存。被击落移动拉回。击落时链可见可定点击，硬度2/HP5；夺取胜数伤链，断则正常拿走，不断虽夺成但不能离1米。已被夺链不算自己携带而无主；任一方被击退先以距离伤链并减同距离击退，最多7米扯断（源H2+HP5例），独立伤型/硬度输入不得无故再减第二遍。

<a id="战灰"></a>
## 战灰
每武器只一项；无视技艺前提取得附着，原通用能量改等量意志力。无前提且无通用耗＝原技艺价；有前提的无支线/D/C/B/A/S分别再80/250/D+500/C+1000/B+2000/A+4000；有通用耗再250。旧价不把技艺XP乘旧分，须已知技艺原完整报价，否则列输入合同。

短/长休可换/加/移，卸下战灰无物质但保已取得可再装；手持该武器才视有技艺，离手后衍生效果至多场景，其原更短照短。技艺具体版/前提跳过的永久代价是否免须单项核，不把“无视前提”扩到免代价。
