<a id="荣誉的光辉"></a>
## 荣誉的光辉
B+4000，概念武装，只能附着重甲，须骄傲地将甲及装饰展露外面。使甲变魔幻/认主；转赠须至少1小时仪式，或临死交付传承意志，再对新主认主。

甲防×2；忽略≤C破甲；面对≥B破甲抵破甲+12并与同类叠加。封闭+2、法术抗力+4；原有每项DR/能抗分别+2；自身硬度/生命×2；防御等级升一级，最高S。负面影响心灵的抵抗+6士气。

<a id="天踏绚"></a>
## 天踏绚
C+1000，概念披风。敏捷/感知/风度各+2增强，移动+40米。自由激活承受3灵感疲劳＝真实耗3灵力，获完美飞行＝移动，10轮；已实际获得灵力基本用法才可按依赖把耗替为3不可避免精神束缚。物品本身不赠池/基本用法，不能改扣精神魔力。

<a id="magdalen圣骸布"></a>
## Magdalen圣骸布
C+2000，概念披风。力量/感知/风度各+2增强，力场防御6。自由对感知数值米内一个生物擒抱：武装力量＝max(风度,感知)，肉搏E＝自身；成功同轮立即压制，再胜定身。任何针对受缚者的攻击或敌意行动立即解缚，下一轮才能再次对其擒抱；最多缚一目标。对手擒抱胜出≥5，武装暂毁，24小时全效果失效。源描述“异性”未在操作条款限定：本批按具体“生物”可选全性别，记录解释。可选限制须取得时明确选用：仅女性、失贞后全收益失效；默认不启用该可选。

<a id="圣葬天衣"></a>
## 圣葬天衣
C+2000，概念轻甲，防御8，无甲关键字。迅捷构筑/解除；已有轻甲不能构筑，其他甲按多甲。防御/豁免+6神圣。自身被生命恢复效果影响时，可令15米内一友方同时受该效果，数值减半并按可实现治疗单位向下取整；自己使用超自然治疗他人，需检定时+自身风度附加成功数DP。每天一次衣角浸水，制造一剂圣水或天使之泪；若浸已有一剂则效果数值×2，不能同时造新并加倍。黑暗生物层数−2，至0暂失分类；不永久清层。

<a id="lo-aias熾天覆七重圓環"></a>
## Lo Aias熾天覆七重圓環
C+2000，概念重盾，体积3，盾防8/防弹/防能量武器/神兵。格挡状态受远程攻击或从远处发起的范围攻击时，可付3意志力，仅本次攻击有30临时生命；从远处发起的近战攻击不合格。该临时生命不留给下一攻击。
