# 智能武器

**901适配候选阅读版；未取得/未接JS。** [共用](../共用物品判定.md)｜[来源核算](../来源与核算.md)

<a id="智能物品共用"></a>
## 智能物品共用
全为认主，主人及物品自身能用；拥有智能物品占原造人名额，不限物品件数，901须先有对应名额记录，目录不默认授名额。是独立意识，可受心灵效果。可独立按实际奖励取得XP/兑换，但无模板位不能购模板；不自动生成每场景XP。

<a id="同调与意识同步"></a>
### 同调与意识同步
初同调q=0；实际完成该物赞赏/厌恶行为分别+1/−1，可负，由明确行为记录决定，不用玩家一句评价刷。器魂可应用属性y=clamp(⌊原属性/2⌋＋q,0,原属性)；映射六属性时同源合并取高，不把决心/沉着双加。

持用时攻击洞察+y智力、防御洞察+y感知、意志检定内在+y意志；对应传奇点数另作附加成功，须有效骰成功>0。本批固定器魂的传奇点数明确按y跨6/11/16…得0/1/2/3…，只给本模板，不赋任意角色传奇。原意识同步直接把物品的影响力/控制力作为内在贡献：本批转为防御及所有对抗/竞争/豁免+⌊y风度/2⌋内在，同源同次只计一次；对应传奇附加成功也只一次，不把旧风度/操控双加，不另建影响/控制池。技能可用器魂较高E，不与自己E相加；它有专业可借资格。

无独立肉身的器魂不构造力量/敏捷/HP。固定模板E保原数字，按职阶共享的固定E分配：有专业且E≥2取主min(5,E−1)＋该子余量，无专业取主min(5,E)；E1的“全专业”只给资格、不额外+1DP；相关属性及技能901自动成功独立计算，不沿旧总攻击DP。独立显现的物品标准切物/生物形态，既物又生物取有利，位置实际随形态移动；武器显现天武等同本武器整套效果。自身动作/能量不凭主人库存无限复制。

<a id="完全同步"></a>
### 完全同步
q高到所有适用属性达到原值（下列最大原值16需q8；12需q6；11需q6；10需q5）才完全同步。主人任何心灵效果可转物，直到物失意识；主人因非伤势/非心灵原因失意识，器魂可接管身体，用主人力量/敏捷及器魂其他属性，伤/能量/持续效果记录不清。显现未给体积者需输入基础模板，不能自行猜HP。

<a id="兽矛"></a>
## 兽矛
A+8000长矛W24L/甲24/魔24/8加骰/魔法/神兵。仅正义善良且强烈除妖意志者获认；逃作恶妖魔或屈服即普通矛，直到有足洗耻的实际勇敢行为。

器魂：无生理，智7/感7/意16/风7；E白刃10(长矛)/运动10(自保)/调查8(侦查)。赞灭强妖，厌撤退或与妖订约停战。攻有妖力池或黑暗者破全部DR，至多W伤改A；器魂/主人可感模糊范围已观测生物是否妖力/黑暗层，不给未观测目标定位。
- 同调≥0精神净化：双方都不愿伤的人类可让矛穿身无伤，只伤附身妖或驱附体/控制；≤B自动驱，BB以上主人意志对施技关键判定（没有用施者意志）胜才驱。中间“双B”保原等级而非擅写A级。
- 同调≥0御气飞行：由矛控制良好飞行1000米/轮；投掷有贯穿。源无启动动作，见缺参。
- 完全同步人矛合一：对妖魔克星有效目标，所有对抗+亲和值（原未定义，推荐用当前同调q见未决）；迅捷变身，本次战斗力量/意志各+12增强，旧力耐合并一次。

<a id="共用电磁操纵"></a>
### 共用电磁操纵
同调≥0：物与持有者免电。标准由主人（显现时由它）操纵至器魂模糊视觉：自选范围目标风度＋感知电范围伤、B侦测、B EMP、联网或黑客；须技能时直接成功＝器魂风度＋感知，持续效果1场景。电伤默认L；器魂模糊视觉范围按其感知及明确感官式算，EMP有限规则见依赖；不由联网能力自动跨网取情报。

<a id="妖刃貂瞳"></a>
### 妖刃“貂瞳”
W24L/甲16/魔32。每本武器攻击额外W音波L，强韧减（缺严重度按原FAQ）。黑独角兽，赞杀强龙，厌本战没有杀死自己用它攻击过的目标。
- 同调≥0电气缝合：主人或显现器魂标准作特殊白刃攻击，另5其意志力；命中给W医疗，4治A/2治L/1治B，或1:1清肢体妨碍，不同时普通伤（源特殊攻击医疗意图解释）。
- 完全同步漆黑之后：命中再W的A阶毒伤，强韧减；可改接触攻击只毒不普通伤，毒伤默认L，A仅其毒效果等级。显现力量/敏捷基础×2（合并耐力不再×一次），HP按力量12/敏捷12/体积8重算36，移动32再飞×10。

<a id="凶剑邦杰明"></a>
### 凶剑“邦杰明”
W30L/甲32/魔16。白独角兽，赞杀强龙/挑战霸权，厌顺从威权。攻击增强＝4×器魂L风度及附加成功＝器魂L风度，满值为+8DP/+2附加成功（不是主人风度）。

- 完全同步纯白之王：本武器命中可不伤改治疗，付发动者5意志力，W医疗4治A/2治L/1治B，并立即驱≤A病/毒/诅咒。

## 几乎从来没有人见过的“雨纹匕”
A+8000匕首W25L/甲32/魔16/8加骰/魔法/神兵。器魂无生理，智16/感16/意7/风7；E白刃10(匕首)/肉搏10/感受8。无对话/显现。每完整冒险同调+1，不下降，完全同步q8。

贴身自由藏体/取，藏时不占位且金属科技探测无效。藏时物质崩溃力场：肉搏天武用本匕首基本数值；免弹药体积≤1且发射器无体调的直接远程单体物理伤，炮弹虽分解仍爆、不免范围；天武力场伤，首次受攻者S措手不及；肉搏射程器魂原智×10＝160米。此固定武器射程用器魂原智，不同调半值无文改。

完全同步雨纹飞燕：自主飞移不耗主人动作，速度主人最高移动（含飞）/完美；攻击仍耗操作者动作。跨位面始终知匕位置，须以其他来源知目标位置才可不限距离操纵攻击；匕本身获上述力场及其实际160米攻击射程，不把无限遥控当无限瞬间飞达。

## 最著名的妖刀之一“不知火”
A+8000弯刀W30L/8加骰/魔法/黑暗/神兵。器魂无生理，智/感/意/风各10；E白刃10(弯刀)/求生7(自保)/感受10(察言观色)。赞一天≥10魂（重量不重质），厌战斗未得魂；完全同步q5。

杀有魂智慧生物得1魂，攻击中每现魂可使1伤改A且物理/火/精神三混，须能抗全三型才减。每天无新魂便主人受现魂数精神束缚，可叠不可豁免且不可移，之后魂−1最低0；再增魂清本项全部束缚。达精神束缚严重后果不昏迷，改狂攻周围全部生物、S免心灵，直到得1魂或魂归0。S诅咒，解诅咒整刀永久普通。
- 同调≥0业火之盾：即将伤死时魂作临时生命扣；即死扣最大HP魂，魂不足清空却不挡即死。
- 同调≥0不死焰魂：标准耗X魂，自身X×20米球X火精神混A，DR取低；目标强韧/意志取较低成功减，不分敌我。X≤实际该半径中可供魂生物数，不从自造短暂召唤物补数。
- 完全同步业火化身：每场景一次自由/10魂，攻防+48亵渎，攻击额外10火精神混A取低抗；身边开始回合或近战攻自己者同10A无豁免，1场景。源“身边”半径未给，须输入，不能用魂爆X半径代。

## 金羽寄魂箭
A+4000一组12支可适各弓；须实际命神仪式人箭合魂，誓守一群体并实际奋不顾身。赞为群体承担巨大风险/牺牲，厌能护而不护或伤群体；器魂无生理，智12/感12/意12/风6，E运动15(弓或投掷)/感受10(察言观色)，全同步q6。

射击：弓W+8L/高速+16/甲魔各+8/8加骰；近战/投掷本箭W25L/高速32/甲16/魔16/8加骰/轻投。主人或守群遭伤后，用箭攻加害者+24DP（源未写类型，保未分类）。同调≥0战斗用箭场景末归囊；主人未死时箭不可毁，超过自身HP的受伤转主人；主人死且箭未毁/未夺走，源主神1000旧分可复活。

完全同步：模糊视觉范围内攻击A免措手不及；若能触破敌，敌移动导致攻击失效/防御增加（含超射程弹道速度），箭自动改路续同一次正常攻击，能循空间道标跨位面至真身。不额外产生第二次攻击，不绕过原定位要求。

### 全身着装
移动下令覆盖全身，原未给时长见缺参：
1. 上述五E不足10视10/全专业，不给XP奖励，也不能满足其他兑换门槛。
2. 力量/敏捷/感知/意志各+6增强，旧力耐/决沉各合一次。
3. 免环境；攻防全豁免+12增强。
4. 移动+80，全吸收4/抵破甲24。
5. 标准拟化符合时代的非消耗/非弹药科技武器，视无限弹，可自带特殊弹；在基底上提升女巫之刃对应武器增量。须所选基底实际表，不能任意“时代神器”。

显现为女性金属盔甲人，可自行全身着装，甲防48；源未给体积，以实际显现模板输入后算HP/移动，不能默认为5。战场传送同调≥0：标准＋移动至本冒险剧情范围随机战场空地，战场须人数>一万或至少一≥A生物，先能感知该场大战。完全同步女武神只显现时：全部属性增加三倍＝原×4，已有技能E改15，速度与主人取高；自身着装2/3/4数值×2（不把自己原属性增三倍误作×3，字面/源运算记录）。
