# 魔幻材质类改造

**901候选阅读版 v0.1；未取得、未接JS。** [共用判定](../共用物品判定.md)｜[来源/核算](../来源与核算.md)

材质通常须制作/取得时选择，只有1种；不单凭材质是魔幻就改变物品本质，另有转变本质改造才变化。旧价是额外实物/材料价。

| 材质 | 旧增价与适用 | 完整收益 |
| --- | --- | --- |
| <a id=精金改造></a>精金 | 基底+1000；金属物品 | 硬度至少16。近战/投掷武器破甲+2、忽略4硬度；甲/盾对应防御+2、已有DR+1或新得DR1/-。弹药每发+80获武器收益；发射器只得硬度，不能再与弹药双叠武器收益。 |
| <a id=天空圣宝石></a>天空圣宝石 | 武器基底+1000；弹药每发+80 | 硬度至少4。武器破魔+2、魔法，可用武器命中传递接触法术（含远程）；弹药攻击破魔+2、魔法。发射器仅硬度，不能另得前两项。 |
| <a id=玄铁></a>玄铁 | 金属物品+750 | 硬度至少8；武器伤害+1，近战另获威猛。 |
| <a id=秘银></a>秘银 | 金属物品+500；弹药每发+1 | 硬度至少6。武器力量需−2，投掷射程单位×2；甲/盾力量需−2、甲减值−2、法术抗力1；载具机动+1。弹药获银；发射器只得硬度与武器收益。 |
| <a id=耀钢></a>耀钢 | 无支线/D/C/B/A/S基底增80/250/D+500/C+1000/B+2000/A+4000 | 任意物品，被敌方效果毁坏后，前使用者可标准＋移动动作使残骸接合、生命回满、恢复可用；不是任意自毁重置。升级补材质差价；载具材质价×6，多支线再乘相应倍数（两倍率相乘）。源C+2000载具示例旧增价合计为BD+5500，公式冲突见核算。 |
| <a id=瑟伦木></a>瑟伦木 | 基底+500；箭/弹材质增价为1/9 | 武器获幽冥，木质可突破对应DR。算无尽正义改造时，此材质部分按基底武器价格×9。 |
| <a id=金晶></a>金晶 | 基底+500；箭/弹材质增价为1/9 | 武器获神圣。算无尽正义时，此材质部分按基底武器价格×9。 |
| <a id=日炎真铁></a>日炎真铁 | 基底+500 | 武器加骰提升1级，最多9加骰；未取得加骰时如何起算源未写，不能从10加骰直接跳8。 |
