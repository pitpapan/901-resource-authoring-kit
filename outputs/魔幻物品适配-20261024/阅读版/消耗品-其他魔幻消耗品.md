<a id="寄生草"></a>
## 寄生草
B+7000，种子/新草HP1，受攻击死。携带种子者死亡吸魂，前三轮在种子200＋死者感知/20米范围内找完整躯体：不允许源主神兑换物或有持续生物，自己原身体例外且源可1000旧分购。完整尸无对抗；活体双方意志，死者败则占失败，种子不接触目标则对方成功数×2。

复活后保本人心智/社交属性，身体属性取躯体；901力量/敏捷取身体，智力/感知/意志/风度取本人；模板失自己得躯体。源先说技能/专长本人、后又说全取身体，真实冲突未定，不自行选择。消耗/伤势/躯体模板记录另输入，不借换体抹永久代价。

前三轮没找到可继续留魂24小时，只能完整尸复活且进新恐状态；901“新恐”接口未定义见依赖输入。24小时未复则种子就土5分钟长新草，活7天；七天内完整带回源主神服务可按修体价复活，否则能采新种子。复活者/种子不可重复复制旧魂。

<a id="魔法卷轴"></a>
## 魔法卷轴
D/C/B/A/S法术卷轴旧价500/D+500/C+1000/B+2000/A+4000；材料价另加，法术XP代价按每点100旧分加在卷轴物资价，**不是用卷轴价反领角色XP**。制造者除常规制作资格，必须会对应术。

只有满足该术学习/使用条件（职能、能量池、专业及特殊资格等）者可用，按该术动作/基础参数，免基本能量耗；使用者如施术者决定效果，但不享自己P加值/动作减免等特性，不额外耗能增幅、不用进化/超魔，只基础术。已封材料/XP按卷轴价处理，原法术其他永久代价未明是否免，须单术核，不全免。

<a id="尘晶"></a>
## 尘晶
单色100旧分/份，体积不计、携带作手枪弹。红/白/黄/紫/蓝/绿六色；混色双色200，之后每再一色价×2，m≥2价=200×2^(m−2)，可混绿黄。四用法分开，不一份既射又植：
- 填专用物品（如柳叶白菀），按该物耗。
- 投掷：破片手雷底模，范围伤每色4L（绿/黄都物理，红火/白寒/紫电/蓝纯能），魔法；反射减m−1成功。真实反射伤害分型逐份，不把“每色”改一次4m混伤。
- 标准＋1元气引爆远程：DP=敏捷＋E运动(能量射击)＋W−防御，W4mL/破魔4m/高速4m/魔法、上限2W；所有颜色混型，能抗其中任一的防护都能生效且相加（本项特例），消耗尘晶。射程原未给，列缺参。
- 植体/刻装备，以下。

<a id="植体尘晶"></a>
### 植体尘晶
同色每5份一基础效果：红/白/紫能抗3，天生攻击额外1相应L及1燃烧/冻结/麻痹；蓝改全能抗1/额外1纯能L/攻击破魔2；黄天防3/力量+2增强；绿速度+20米/敏捷+2增强。每生效基础份使非元气通用能量耗+1。

增量按已植份数n：每15份提供2倍基值，余数5—14另1倍，故倍率b=2⌊n/15⌋＋min(2,⌊(n%15)/5⌋)；例5/10/15/20/25为1/2/2/3/4，原要求每增加两倍后先再植5空档。全色实际植入总份≤力量无害，超出每份HP上限−1。每份植/取1小时并受1不可避免A，源主神服务可免时间/伤。尘晶占用不消耗，取出解收益；不把零散不足5份也加完整效果。

<a id="装备尘晶改造"></a>
### 装备尘晶改造
刻武器/防具，视添加改造，效果同植体以持有人取代植者、不加非元气能耗；一物仅一份生效尘晶效果，基值/倍率及究竟是“同色组”或混色份原未明，见未决。制作者须元气池及魔法造物，一造物周期内DC5未成则耗材料；源主神每份再100旧分可代。成功立即成改造，不再当可消耗弹；实际移除返料规则未给不能白拆。

## 贝黑莱特
C+2000/消耗/认主；每人仅能取得并用一次，不能常规制造/复制/其他效果取得。可基因锁机会点放弃该检定激活，或确认超越一切强欲激活。实际献祭二选：失去仍具有基因锁，或最珍视人/物（应至少2B负面特性实质代价，不能以无损造人替）。拒献也消耗；成功残壳价500/硬度8，不完整不可再用。

<a id="使徒"></a>
### 使徒
献成即因果律一环，对神格者的影响自己全部法则免疫失效；丑陋使徒形态使有正常认知智慧生物初始态度−2。得内部60XP抵扣，只购属性/技能/体调/技艺，可分次但每笔先用尽抵扣，超额自己XP补；跳技艺前提另D/C/B/A/S加5/10/20/40/80XP。所有用抵扣所得仅使徒态生效，移动切使徒/常态，共享10轮冷却。切形保伤/能耗及永久代价往返，不能洗数据。

献物被取走，献人烙S永久印死复不解除；同位面因果律使徒/神之手总能感其大致方位但无定位，A探知可阻，并会实际追杀不死不休。印者/使徒/献成神之手在本献祭世界死，魂入幽界，须夺回魂、≥SSS复活或源主神才能复活；不把专名因果律与其他同名法则自动联动。

<a id="霸王之卵可选变体"></a>
### 霸王之卵（可选变体）
取得时可选1D100≥99（99/100两点）或主持明确替换，规格S+8000；不是每场景再抽。取得定野心，确认其彻底不可实现则蚀到（原216年周期为背景，不能盖过具体触发）。无论卵在哪/毁过，S命运令其返主；有深羁绊且有可能到场者S命运聚来献祭，免疫者可阻部分/全部，神之手临降包括源主神购版跨冒险。

选择奉献：献血肉及全部同伴成神之手，卵残壳C+1000/硬度16不可再用；拒献若导致源主神任务失败即抹杀，901没有该实际任务/抹杀条件不自动创建。神之手得“魔”计数，上限min(160,蚀刻已死祭品战力总和/2)，沿传奇风度1—3用法以魔替影响力池；需具体专长依赖，不因一句名称由模型编造。神格0，3整轮(q36)可进出同世界幽界位面并原地留空间道标。神之手通常神格/战力>81怪物，源可替相应神祇/神侍，属于世界输入不是901既定存在。
