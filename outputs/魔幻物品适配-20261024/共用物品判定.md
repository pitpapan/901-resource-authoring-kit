# 共用物品判定

本页只用于本批魔幻物品适配候选；901已采用规则优先，具体物品明示例外再优先于本批默认。目录纳入不代表世界存在、人物持有、库存增加、制作资格或已接入JS。所有“旧价”均保留原支线＋分数，不转换成角色学习XP。

## 取得、装备、携带与消耗

分别核验物品实例、认主者、实际持握/穿戴/直接携带/储存、装备位及启用状态，不能只核所有权。持有多个也不突破装备位。物品装入纳戒/异次元空间后，通常的携带收益失效；明文允许储存生效才例外。消耗品须有实物且实际扣除，使用失败仍消耗的照原文；不能因条目在目录就补库存。

使用武器先核原文具体前提：旧数字技能门槛用`E＝主＋一个匹配子技能`；旧专业资格须对应子技能≥1。主技能最多5，子技能无固定上限；多个所需资格不等于同时加多个子技能。资源明确使用神秘代枪械、智力代力量时，只替指定式，不能把整个角色转成该属性。

### 装备位（未替代PHB优先）

| 位置 | 生效限制 |
| --- | --- |
| 头盔、护符、手套、鞋袜 | 各一件/一副。面具、眼镜等若未另占位，仍受同一感官只享一件好处及物理佩戴限制。 |
| 戒指 | 基础1枚；最高技能领域上已有的技能自动/附加成功每点另允许1枚。901双层技能取同一领域主＋匹配子所提供的技能自动成功，不计属性成功；本批不采用RE“每手一枚”替换。明文额外戒指位优先。 |
| 衣物（披风/斗篷/法衣等） | 同位只最外层生效，不改用RE最内层。 |
| 盔甲 | 轻甲通常占上装，重甲占上下装；可合理重甲内穿轻甲或轻甲配下装。多甲防御只取最高，其他效果仅最内层。破甲逐层消耗，各甲原减值相加，基础防御及对范围攻击的抵抗再−2×甲件数。液态金属甲不计多甲件数但仍占轻甲位。 |
| 手持 | PHB不将其计为槽位，但须有合适肢体且以适当方式使用；放在行囊不等于手持。 |
| 概念武装 | 须条目明示；只占概念武装位，不因外观再占同形普通位。无明文不自动增加可同时装备数。 |
| 无装备位 | 合理直接佩带/携带可多件，同名效果取最好一件；储物空间内无效。 |

同一普通槽多件时，在合法数量内按原等级最高者生效；源明确套装/双持/穿戴组合照其条款。不是所有魔幻物品都强制占位。护符/项链/披风类未另定时须与佩戴者相处超过1场景才正常生效，这是本批随物品采用的RE具体准备条件。普通穿脱标准动作；轻甲战斗中整轮、非战斗1分钟；重甲战斗1分钟、非战斗5分钟；具体瞬穿例外优先。

## 六属性、检定与加值

力量承担旧力量/耐力/体质的身体职责，意志承担旧决心/沉着，风度承担旧风度/操控；智力、感知、敏捷不变。同一旧公式含已合并属性时只计一次；同源固定模板或同源属性加值取较高，不把旧两项叠加。标题、物名、动词“操控”与描述“魔力体质”原样保留，不全局换字。全生理属性＝力量/敏捷；全心智＝智力/感知/意志；全社交＝风度/意志；同时覆盖同源旧类别仍只计一次。

合法检定D10，8—10为成功、10加投；DP≤0用机运骰，仅10成功。901属性跨6/11/16…各给1自动成功，主技能5给1、子技能每满5给1；即使骰子0成功仍适用。明确RE附加成功仍要求有效骰子成功>0。传奇点数`L(X)`从已确认资源/卡面读取，不凭901自动成功数字相同就替代；固定模板明确提供的传奇来源另保留。

普通意志检定/豁免＝意志＋风度，反射＝敏捷＋E(运动)，强韧＝力量＋E(求生)。缺省减费最低1，明确可0者例外（原FAQ第1问）。普通主动对抗主动方达到被动方即成功；明示严格胜出/差值照条目。加值类型与来源分开：本批同类增强/器械/修行等取最高，明确增加/再/额外/可叠加才累加；同物多件取高和装备位限制仍要过，不凭“可叠加”绕过使用资格。能力组每阶≤2属性特性上限不适用于本批装备属性。

数值取整：明确原文取整/例值优先；本批候选把DP/伤害/加值/次数/距离的正分数向下、实际消耗向上，时间保分数不擅归零。次数/新生物等离散量不取小数；未经本批采用的取整口径先作为结算输入。新增HP给完好槽而不清旧伤，缩容按PHB溢出；只增能量上限不填当前值。

## 动作与次数

每回合1标准、1移动、1迅捷；标准可换移动、移动可换迅捷。反射可中断，但使用后至下一次行动结束不能再反射或迅捷，明示额外次数才例外。响应占反射，在他人两动作间作1标准并跳过自己下一次行动。自由通常限自己行动时，讲话例外；物品写自由/反射时分别用于自己行动/回合外。

| 原固定动作价 | 901实际动作 |
| --- | --- |
| 2/4/6/8AP | 迅捷/移动/标准/标准＋迅捷（已采用） |
| 0AP | 自由（仅本批对应条款） |
| 1/3/5/7AP | 向上落到迅捷/移动/标准/标准＋迅捷（本批候选） |
| 9—10AP | 标准＋移动，本回合一起付（本批候选） |
| 11—12AP | 整轮，占本回合标准/移动/迅捷（本批候选） |
| >12AP | 每12为连续一个整轮，余数在下一次自己行动按表支付，末次完成才生效；如36＝3整轮。原明示多轮/仪式优先。 |

阅读条款中的`q`是某一次行为的原动作标价，仅用于指定加减费后查表，不是可存储AP。先算该行为最终q再选档，不把剩余差额变成另一次行动。以反射形式施用时只支付一次反射锁，不因原2/4/6等数值再生成AP池；本批反射原价>2的补偿/预支在对应条目单列，没有单项说明就不凭原AP降低反射成本。

额外AP、恢复/上限、连锁1AP追击不得套固定价自动创造行动池；已在维克那法袍、洛鸣等各自写本项次数/动作方案，仍候选。以分钟/小时/天计的行为保留实际时间，不压成一个战斗动作。普通饮用药剂及少量丹药移动动作，涂油标准，原另列吃用/注射/泼洒动作优先。

## 武器、伤害与防护

普通近战DP＝力量＋E(白刃/肉搏)＋武器伤害−目标防御，上限＝力量＋E＋武器伤害。弓/投掷/枪等沿PHB相应类型公式；具体异式、武器伤害、射程单位、射击模式及耗弹在基础模板依赖列明。一次攻击只扣一次防御；不把高成功数直接当“实际伤害”。伤害顺序：攻击有效性/骰池与上限→免疫、忽略、硬度、吸收、DR/能抗、抵消→临时生命/降级→B/L/A逐点入槽。无来源防护为0。

多个适用同类DR/能抗通常取最高，明写增加/额外/可叠加才相加；不把这个规则推广到所有吸收。忽略额度写“总计”时是一份共同额度，不能对DR、吸收、硬度各拿全额；明确分别忽略者分别用。多种伤害写混合取低/取优按原文，不拆为多次命中；明确两次/分段则各自结算。

本批RE破甲逐点削掩蔽→力场→器械→盾牌格挡→盔甲→天生防御，余量破硬度，不穿DR；破魔削幸运/士气/增强/神圣或亵渎/招式/表现/内在/无名防御；高速削基础/闪避/非盾牌格挡/洞察/修行防御，范围效果改减反射DP。类别只减实际存在值，不直接加伤害上限。旧PHB装备没有明确RE来源的破甲仍依PHB装甲语义。

神兵含魔法、正常影响灵体/虚体并穿透除DR/-及能抗以外的伤害减免；神器还须有器魂，不从名字“神器”补智能/属性。魔法对虚体可伤但减半，不自动能伤灵体；正常影响灵体不自动带幽冥。幽冥、能量武器、加骰、贯穿等具体交互沿[已有状态与关键字](../../resources/imperial-magic/07-状态与特殊机制.md)，本批条目明确例外优先。

普通状态沿PHB门槛/恢复，欲眠/晶化等RE独有按必要依赖单项；不能整体换RE的无碍/三倍/四倍门槛。治疗点按具体物品比率，不能通用混算；快速医疗每轮开始优先最重，1点治1B/L、单来源≥4才可4点治1A，不同来源不能拼等级门槛，明确取高优先。生命全A死亡；复活、护命等例外只按具体触发。

## 物体硬度、生命与毁坏

已明确硬度/生命的物品先用明值。未明值的本批RE实物：原支线折D个数w（D1/C3/B9/A27/S81，双同阶加倍），原分数p；价格硬度`H价=ceil(w+p/1000)`，与已知材料硬度取高。价格生命`HP价=max(1,5×(H价+max(0,体积调整)))`；材料独立计算则`HP材=max(1,5×(H材+体积调整))`，生命取两者较高。无材质数据不猜材料硬度。条文直接给硬度不自动丢掉原价生命算法；按原物品具体式核。

原总则D+500例说硬度1/生命5与公式冲突，本批用公式硬度2/生命10；S+8000、体调15应为(89+15)×5＝520，纠正原中间算式，不改结果。按901 XP报的新物品没有旧价映射，须自己有硬度/生命，不能拿XP换旧分。物体单轨生命，B/L/A都扣同数；破坏到0后变残骸，所有效果立即失效。复原/重铸只在原文授予时生效，不默认物品不可损坏。

没有自身防御的非载具物体具有floor(1.5×硬度)抵抗破甲，只用于防止破硬度或超级贯穿击破，不当普通防御再扣一次。装备遭定点攻击/范围损坏的901适配边界见未决；未明确启用RE整套范围装备分摊，不把其规则无提示套到现有人物。

## 升级、合成、改造与价格

升级差价与累计实物价分开。判断等级/硬度/生命用累计取得价；原写保留的效果继承，提升至/改为替换旧值，写再/额外才相加。相关改造若按基底价计则升级补差，固定价改造保留。不要把素材抵扣价用于制造高级物品的完整造价。

添加类可后装且多项共存；材质通常制作/取得时选1项，工艺通常制作/取得时选1项；原基础工艺/复合魔导器等明示共存例外优先。只有真实、无持续时间的永久实物能改造；“持续永久”仍是有效果期限的造物，不合此条件。精金/圣宝石对发射器和弹药的收益分别列出，不两头全额重复计算。

实物取得依剧情、交易、制作或明确授予；旧分数只保留物资规格/相对报价，不默认901商店。角色学习、物品制造XP、物品内部记录/充能、XP奖励和材料价各记各账。消耗物明确产生XP可保留，不等同训练天数产XP；须真实持有、实际消耗、范围和每篇章次数核验。限定属性XP/通用XP与悟法XP分别记，不能互换。原影片映一次完整冒险篇章，不等于节点或场景；复活/回归奖励冲销须有既有分支记录，不能借物品改真实存档。
