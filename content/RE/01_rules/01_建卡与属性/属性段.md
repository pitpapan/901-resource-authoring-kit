**属性段**

人物的属性定义了人物先天所具备的最为基本的能力。不同于无限恐怖原著的“智力，精神力，细胞活力，神经反应速度，肌肉组织强度，免疫力强度”这六项属性，在无限TRPG的规则里，人物属性分为九项，它们分别是对应三大类属性（生理属性，心智属性，互动属性）的三个分支（力量，技巧，耐性）。

|  |  |  |  |
| --- | --- | --- | --- |
|  | 力量 | 技巧 | 耐性 |
| 生理属性 | 力量 | 敏捷 | 耐力 |
| 心智属性 | 智力 | 感知 | 决心 |
| 互动属性 | 风度 | 操控 | 沉着 |

建立一张新人卡

首先，将人物的所有属性基本值设置为1。  
然后对于每一项属性，你可以投入当前值*1点XP将属性提升1点，小数记录不舍去，上限为5点，此时共计需要1+2+3+4=10点XP

作为通用建卡规则，你获得70点总XP，你必须在属性上至少投入9点XP，至多投入30点XP。

 

朱成认为自己十分聪明，有体格带来的力量和体质，其他属性在平均值的程度，因此他将智力提升至4点，花费6点XP，将力量提升至4点，花费6XP

其他7项属性提升至2，花费7*1=7点XP

总计在属性上投入为6+6+7=19XP，符合9-30区间。

 

朱成属性：

力量/敏捷/耐力：4/2/2

智力/感知/决心：4/2/2

风度/操控/沉着：2/2/2
