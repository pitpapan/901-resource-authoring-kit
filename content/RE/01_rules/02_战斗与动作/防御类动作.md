全力防御：

这是一个消耗6通用AP的标准动作。

由于你尽全力躲闪你的敌人，直到你下一次做出其他标准动作为止，但每轮开始需要你支付3通用AP动作维持，你的闪避防御获得相当于你的基本防御的闪避加值。同时你对抗范围伤害的豁免检定上获得相当于你的基本防御的DP闪避加值。

此外，如果你能够看到以枪械攻击的敌人，则他在攻击你时枪械的【高速】降低5点。

维持本效果需要专注。

某些能力或专长或许可以提升或改变全力防御的效果。

肉搏格挡：

这是一个消耗4通用AP的标准动作。

直到你的下次行动开始前，你在防御上获得相当于你的肉搏技能等级的格挡加值。  
若你的天生武器具有【格挡】特性，你可以额外获得4点盾牌防御，这部分数值会随体积调整变化，见天生武器词条。  
你的格挡加值基本值=上述两项之和，若肉搏技能有格挡专业则再+1。  
若有其他资源允许你获得格挡加值或在格挡加值上获得加值，取高与格挡加值基本值叠加计算决定你的格挡加值。  
若有其他资源允许你提升格挡加值，可与前述项叠加计算决定你的格挡加值。  
该动作不能和白刃格挡同时进行，你只能选择两者中一个进行。

白刃格挡：

这是一个消耗4通用AP的标准动作。

直到你的下次行动开始前，你在防御上获得相当于你的白刃技能等级的格挡加值。你必须持有一件白刃武器才能格挡。  
若你的白刃武器具有【格挡】特性，你可以将白刃武器的体积加在格挡加值中，这部分的防御称为盾牌防御。  
你的格挡加值基本值=上述两项之和，若白刃技能有格挡专业则再+1。  
若有其他资源允许你获得格挡加值或在格挡加值上获得加值，取高与格挡加值基本值叠加计算决定你的格挡加值。  
若有其他资源允许你提升格挡加值，可与前述项叠加计算决定你的格挡加值。  
该动作不能和肉搏格挡同时进行，你只能选择两者中一个进行。

掩蔽与隐蔽：

寻求掩蔽是一种有效的防御行为。寻求掩蔽是一个消耗4通用AP的标准动作，在战斗中，人物可以利用自己可以搬动或移动的物品架在身前，或者躲在树木，墙壁的后面。一方面可以用来躲藏，一方面可以有效避免遭受攻击，躲避远程攻击尤其有效。

当目标受到攻击时，先判断目标是否具备掩蔽。从攻击方的位置任何一点开始与防御方位置的任意一点进行一条连线，是否有掩蔽物，如果有则目标视为掩蔽。所以一般情况下，掩蔽都具备方向性，也就是只针对某一方向具备掩蔽。

获得掩蔽后，人物会获得掩蔽防御，掩蔽防御视人物的体型和掩蔽物的大小而定，数值见下，当用来掩护的物品达到你体积的两倍时，视为完全掩蔽，ST可以判定角色所在方格的相邻方格内是否存在能进行提供掩蔽防御的物体，以及这些掩蔽的效果。

同时，其在对抗范围伤害的豁免检定若为反射检定，则该反射检定也获得等额的掩蔽加值。

当然人物也可以自己搬动或拾取物品架在身前，形成掩蔽（拾取物品是一个移动动作）。若人物可以拿动掩蔽物，且他在这一轮中还可以进行移动（例如某种使用迅捷动作移动的能力，或利用标准动作移动），他可以在掩蔽的情况下带着物品移动。

另外，使用不同的物品进行掩蔽，获得的掩蔽值也可能不同。一般来说，能为你提供掩蔽的物品至少要能（在现实意义上的）挡住人物。某些物品，比如说一把体积4的长矛，可能用作掩蔽时的效率较其他物品更差，或根本无法用它进行掩蔽；同样，当人物无法被物品完全挡住时，获得的掩蔽也可能不同。这些情况由ST判定。  
范例：

|  |  |  |
| --- | --- | --- |
| 少许掩蔽 | 获得2点掩蔽防御 | 比如躲在椅子后面 |
| 部分掩蔽 | 获得4点掩蔽防御 | 比如在车门后露出半截身子 |
| 大量掩蔽 | 获得8点掩蔽防御 | 比如蹲在汽车后面 |
| 完全掩蔽 | 你完全被掩蔽物掩蔽起来，敌人无法定位你，攻击全部打到掩蔽物上 | |

完全掩蔽的效果会同时切断效果线和视线，但掩蔽物的体积小于你十倍的话，就不足以用于混淆对手的视线来重新进行躲藏。

特殊：你使用带有【格挡】的物品进行的并非掩蔽而是格挡，此时获得的是格挡加值和盾牌防御，而非掩蔽防御。

特殊：当目标拥有绕过完全掩蔽定位你和攻击你的能力，则不视为你全掩蔽。如一些雾气类效果（大多数范围攻击是不能绕过的），或者雷达定位配合【贯穿】攻击，在击破你的掩蔽物后会对你造成伤害。

特殊：云雾，烟雾等可以穿过的掩蔽物视为提供隐蔽，隐蔽只切断视线，不切断效果线，因此范围伤害可以正常击中你，雷达定位配合普通攻击也可以。同样，掩蔽物的体积小于你十倍的话，就不足以用于混淆对手的视线来重新进行躲藏。

若是通过云层，烟雾等可以穿过的效果造成的视觉的全掩蔽效果。若目标具备某些看穿云雾的效果（如盲视）则可以正常攻击和定位。或者目标可以进行尝试攻击其自认为你所在的区域，如果正好你在，那么其视为在模糊定位下对你造成影响。

掩护物后射击 (Fire from Concealment)
：在掩护物后伸出来，作出远程攻击，再缩回掩护物后面的远程攻击行动。DP所受到的影响如下：

|  |  |
| --- | --- |
| 少许掩蔽 | 承受1点环境减值 |
| 部分掩蔽 | 承受2点环境减值 |
| 大量掩蔽 | 承受4点环境减值 |
| 完全掩蔽 | 这种状态下不能做出攻击 |

攻击全掩蔽的目标：针对全掩蔽的目标，若有你有能力获取其定位，或使用范围攻击，甚至最不济的情况下你可以揣测其位置

若你揣测其位置或获得其定位后对其发动攻击，那么攻击首先需要击破掩蔽物，适用掩蔽物的防御，硬度和生命值，若掩蔽物是无法行动的物体，那么不适用防御。当掩蔽物被完全摧毁后，立刻以同样的攻击数值对掩蔽物之后的生物发动攻击，但是伤害和伤害上限会减少等同掩蔽物硬度+克服剩余HP的数字，举例而言，硬度3，HP5的墙壁后躲着的生物，在受到子弹7点伤害时是不会受到伤害的，此时掩蔽物剩余硬度3，HP1，再次受到7点伤害时会被击穿，同时对墙后的生物正常发动攻击，若造成5点伤害，会减少4点，生物只受1点伤害，即使是原本不被硬度阻挡的伤害也同样处理。同时，你可能因为对墙后目标仅有模糊定位而减半成功数。

若你以范围攻击包含掩蔽物和目标，并且范围攻击不具备可以有路径可达即可绕过障碍物的描述（如果可以就不用计算全掩蔽），那么同样先伤害掩蔽物，掩蔽物被完全摧毁后，会影响掩蔽物后的生物，此时影响该生物的范围伤害减少等同掩蔽物硬度和克服剩余HP的数字，依然以硬度3，HP5的墙壁为例，受到7点范围伤害后不会伤害墙壁后躲着的生物，此时墙壁硬度3，HP1，再次受到7点范围伤害后，墙壁的后生物会受到3点范围伤害，再进行反射。若一次范围攻击中不同生物躲于不同掩蔽物后，对每个生物只计算伤害中心与其连线上的掩蔽物影响。

单位体积掩蔽物：面积100米的水泥墙用于在单次攻击中掩护一个生物和面积2米的水泥墙并不会有什么区别，因此在上述两种攻击中都视同只需击破单位体积掩蔽物即可影响到其后的生物，将单位体积掩蔽物的生命值视为其硬度+5，当生物改变位置时，相应需要重算，击破单位体积掩蔽物意味着出现缺口或洞等，但不意味着毁坏了掩蔽物整体（将掩蔽物整体的生命值如常计算，也会因这个伤害扣除），也不会对掩蔽物的使用造成影响（如果掩蔽物可以使用的话），注意，载具和驾驶员使用其自身的规则，不适用此处的攻击全掩蔽目标的规则中的伤害扣除，因为其可能正常具备防御等，见相关描述。
