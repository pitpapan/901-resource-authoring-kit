# 901 Core Rules v0.1：按需决策清单

本清单整理至 2026-10-17。普通检定、对抗、PHB 行动、单段普通攻击、三阶段伤害、B/L/A 入槽、常见异常、基础恢复及普通成长的通用兼容规则已经采用；见同目录[核心规则](901-core-rules-v0.1.md)。本文只保留接入单项资源时必须补齐的事项。此处的“按需”不授予任何资源的取得资格。

## 已冻结，不再重问

- 901 使用六属性、主技能上限 5／子技能无固定上限、有效技能＝主＋一个匹配子、两层 3/9XP 与每五级自动成功；旧角色当期已确认卡面值优先。依据：901 村规 H01/H02 与本快照已采用的后续决定；原文见 [村规 H01/H02](evidence/90_用户村规原文.txt)。
- PHB 的 D10 和动作次数是基础；RE 动作价格已定为 2AP→迅捷、4AP→移动、6AP→标准、8AP→标准＋迅捷，不运行 AP 池。RE 三阶段顺序与 PHB B/L/A 伤势升级合用。无完好槽时按最重 B／L／A 分别处理，仍有非 A 槽的 A 伤才逐轮恶化；全 A 死亡，PHB 急救与明确能力可阻止恶化。来源：[PHB 基本规则](../content/PHB/01_rules/基本规则.md)、[行动](../content/PHB/01_rules/非战斗行动与战斗行动.md)、[生存状态](../content/PHB/01_rules/生存状态.md)；[RE 伤害处理流程](../content/RE/01_rules/02_战斗与动作/伤害处理流程.md)；2026-10-15 已采用的动作价格决定。
- 六属性派生值、普通意志检定、DR／同类抗力默认取最高、裸 PHB 破甲只按装甲范围、正常视觉敏感距离、普通状态映射与剧痛／疲乏属性伤害分配已确认；具体式及适用边界见核心规则。剧痛毁灭性属性伤害总点数不变，在力量／意志间分配；疲乏在力量／敏捷间分配，承受者先选，主持可按来源限定。来源：PHB《第三章 生存状态》§3；2026-10-13 的整体采用与单项确认。
- PHB 长休与 901 节点／章节按实际发生的事件分别恢复意志点，不超过上限；普通场景结束不自动恢复。特殊能量池仍依来源。来源：PHB《第三章 生存状态》§1；901 村规 H01《节点》。
- 节点 XP 由主持逐项裁量，可为 0；传奇智力在明确的节点清算按 PHB 1／2／4／6／8XP 发一次。训练天数不自动产 XP；自学能力逐项确认可学范围、XP 价、训练条件后才可支付。奖励点／支线兑换已取消。来源：PHB《属性概述》、RE《自学规则》及原整理时用户确认。
- 普通专长沿 PHB 每级本级×3XP，旧数字技能前提按相应领域有效技能值、旧专业资格按对应子技能至少 1 级；具体条目异式仍优先。负面特性无默认 XP 奖励或赎买价格。来源：PHB《专长概述》、RE《专长概述》《特殊兑换》及原整理时用户整体采用。

## 接入单项能力时必须确定

| 事项 | 已有通用规则 | 单项接入时才需确定 |
| --- | --- | --- |
| RE AP 能力 | 2／4／6／8AP 分别占迅捷／移动／标准／标准＋迅捷；普通攻击→标准，冲锋→移动＋标准；仍须满足 PHB 动作次数及原能力条件。 | 其他 AP 价格，以及 AP 减费、恢复、额外／临时／预支 AP、心智／躯体 AP 的实际次数、动作节省、冷却及代价；不建立 AP 池。来源：RE《场景与动作》、PHB《第四章》及用户 2026-10-15 决定。 |
| 特殊防护与突破 | 同类 DR／能量抗力默认取最高；无来源的硬度、吸收、抵消为 0；裸 PHB 破甲只影响装甲。 | 具体能力的防御类别、破甲／破魔／高速目标、能量对物体的硬度特例及明确叠加文字。来源：PHB《生存状态》《装备与装备位》；RE《防御类型》《伤害类型》《物品关键字》。 |
| 混合／额外／定值伤害 | RE 三阶段顺序和 PHB B/L/A 入槽已定；无攻击检定的定值伤害不产生“命中”。 | 原能力究竟是一段多类型或多段、各段防护适用次数、额外伤害是否触发其他效果、状态触发点。来源：RE《伤害处理流程》“特殊／混合伤害与同类伤害”。 |
| 特殊状态与感官 | 常见状态用 PHB 点数／休息骨架及已确认六属性映射；正常视觉距离已定。 | 单项能力另写的抵抗骰池、免疫、不可休息恢复、特别感官与定位资格；旧角色已确认异式优先。来源：PHB《生存状态》《非战斗行动与战斗行动》。 |
| 自学、专长、补正、负面特性 | 普通成长费用与逐项核价程序已定；没有默认负特性 XP 收益。 | 每项能力的剧情来源、学习资格、XP 报价、训练要求、旧属性／专业前提、折扣和补正。原书 D/C/B/A/S 标签只是估价证据，不是通用价格或同战力保证。来源：PHB《自创能力规则》、RE《自学规则》《可选规则列表2》。 |
| 特殊资源／能量池 | 血统、改造等须符合剧情取得条件；无通用能量上限或回满。 | 具体上限、消耗、恢复及等级收益；涉及概念、时空、因果的高阶效果可保留有限主持叙事裁定。来源：RE《能量池》及 901 已确认资源边界。 |

上述事项只有在该能力实际进入 901 时才成为决定点。本清单只记录单项资源接入时的决定点，不代表批量采用 RE 资源。
