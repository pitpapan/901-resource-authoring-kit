C级非枪炮

爆弹冲击锤
本质：科技本质
价格：C+2000
分类：巨锤
体积：6
前提：力量需求7
描述：这柄战锤的锤头仿佛是一个特大号的转轮枪弹仓，当将它砸到敌人身上时，可以同时击发填装在弹仓内的子弹，制造出剧烈的爆炸，给予敌人猛烈的打击。
武器基本属性：武器伤害13L，破甲6
武器特殊属性：【威猛】【眩晕】【击飞】
重武器：使用者在使用本武器进行攻击时，会在攻击检定上获得6DP器械减值，获得2点武器伤害提升，已计入。
爆弹：这把战锤可以填装六发专用的特殊子弹，装填子弹每发需要一个4AP动作，在使用它攻击的同时，可以选择以一个2AP动作击发一发子弹，增加攻击的威力。爆弹冲击锤可以填装两种不同的子弹：
爆裂弹：通过火药爆炸产生的推进力来增加攻击力。攻击检定获得2点附加成功，破甲提升4点。价格：1发/10分
魔力弹：将纯净的宝石磨成粉末，掺入火药之中，并在弹头上刻上符文，有两种型号。
A型：攻击获得【魔法】【正常攻击灵体】特性，本武器攻击可以造成火焰/寒冷/电击伤害，购买子弹时选择，1发/10分
B型：攻击获得【魔法】【正常攻击灵体】特性，本武器攻击可以造成火焰/寒冷/电击伤害，购买子弹时选择，同时额外获得【神圣】或【亵渎】，【幽冥】，【能量武器】特性，1发/450分

海蛇
本质：科技本质
价格：C+2000
分类：鞭
体积：2
描述：能放射高压电流的长鞭，以液态金属制作的鞭身具有优越的可塑性，不但提升了长鞭的触及范围，也增加了挣脱束缚的难度，据说是狱卒，奴隶主的最爱。
武器基本属性：武器伤害8L，触及变为30米。
武器特殊属性：【软兵器】
供能：需要装载1枚3级能量容器（电力，D1000分版），以自由动作启动后可作为武器使用，同样的动作可以关闭，关闭时不视为武器，只能作为普通长鞭使用，开启效果耗电忽略不计。
电击：持有者使用海蛇进行攻击时，攻击检定获得12点增强加值。若成功命中，则额外造成2点雷电严重伤害，同时受到2点不可避免的麻痹点数，可累计。
九头蛇之吻：使用海蛇进行攻击时，若成功造成了伤害，并且目标体积小于10，则你可以让这条鞭子形成金属电网纠缠住对手，这视为你立刻发起了一次擒抱。
任何被你擒抱的目标在其每回合结束时若未能挣脱擒抱，会受到2点电击严重伤害和2点不可避免的麻痹点数，可累计。

光剑
本质：科技本质
价格：C+1000
分类：长剑
武器基本属性：武器伤害8L，破甲16，【8加骰】
武器特殊属性：【能量武器】
熔断：光剑在攻击物体时武器伤害和破甲加倍计算，无视天生武器带来的格挡加值，除非天生武器具有能量武器或神兵特性，面对白刃格挡时，在结算防御之前视为对用于格挡的武器或盾牌进行了击破武器。拥有能量武器特性或神兵特性的武器不会在格挡中受到光剑伤害。
耗能：一枚2级能量容器（电力）可为其供能20轮。

粒子聚合棍
当银河文明遇见了高能星球的武器纳入体内的方法的时候，科学家们对此进行了深度的研究，得出了武器转化成微观粒子分散在细胞之内，使用时粒子迅速在指定点聚合，从而完成出现，科学家们通过这种研究制造了粒子聚现手套和粒子聚合棍，黑色纳米高能金属丝制成的聚能手套和分解高能矿石加入各种合金制成的漆黑无比的金属战棍。
本质：科技本质
价格：C+1000
分类：长棍
体积：4
武器基本属性：武器伤害8L，破甲16
武器特殊属性：【能量武器】【8加骰】
粒子聚现：这把武器平时以一个手套的形式佩戴，你可以以一个自由动作聚合本武器，也可以花费一个自由动作解离本武器变回手套。
高能聚爆：以一个标准动作，选择一个触及范围内的目标，你可以以此武器对其发起一次接触攻击，在接触攻击命中时，武器将化为粒子流冲入敌人体内，这次攻击不会造成通常伤害，而是造成等同武器伤害+2的严重伤害，该伤害来源于物体自身的崩溃，伤害不属于任何特性类型，因此这个伤害不受任何伤害减免，能量抗力，伤害吸收，和硬度影响，不造成通常伤害的效果也不会触发这个严重伤害。

伍基人弩枪
本质：科技本质
价格：C+1000
分类：弩
体积：2
前提：需求力量6
描述：壮观的体型和巨大的力量让伍基人在赤手空拳时也令人害怕。但要打击他们完全够不着的目标时，他们的首选武器是土制的弩枪，这种融合了各种技术的弩枪有多功能的膛室，既支持能量箭，也支持实体弹，比如头部有炸药的箭。除了伍基人，只有少数种族能精确控制弩枪，因为这种武器需要很大的力气才能扳击锤和开火，其后坐力足以撂倒弱小的人。
武器基本属性：武器伤害6L，破甲6，高速6，装弹数6，基础射程单位50米
武器特殊属性：【多功能弹药】【蓄力】【散射】【可装卸】
【多功能弹药】：伍基人弩枪能使用爆矢弹和普通箭矢，没有箭矢时也能发射能量弹，使用不同弹药时，射程，基本特性会有所变化，但无论如何，弩枪使用箭匣，并不需要逐支装填，装填动作与步枪等同，装填的箭匣同时只能适用下述一个种类，否则无法发射。
-普通箭矢：破甲+2，基础射程变为200米
-爆矢弹：伤害+2，基础射程变为100米
-能量弹：获得【能量武器】，造成纯能量严重伤害，并且无限弹药
【蓄力】：伍基人弩枪可以对包括能量弹在内的弹药以绞弦的方式蓄力，许多耐心的伍基人能以蓄力后的弩枪进行狙击。以一个2AP动作，你可以对弩枪进行一次【上弦】，至多叠加5次，射击时，上弦每有一次，武器力量需求+1，伤害+1L，破甲+1，基础射程加倍，上弦达到5次时额外获得【贯穿】特性，一次射击后清空所有上弦次数。
【散射】：伍基人弩枪可以散射至多所有弹药，由于射击角度限制，散射箭并不能瞄准多个目标，其生效机制视同点射/长点射/连射，消耗至少2/4/6发弹药时，相应获得点射/长点射/连射效果。
【可装卸】：伍基人弩枪在有专业（伍基人弩枪）的使用者手中可以在一分钟内被拆解成一堆零件（视为体积0来携带，且没有同一专业无法识别其是武器零件），同样在一分钟内被组装起来。

灰烬天堂
灰烬天堂（Ember Celica）是Yang的武器，一对双重远程猎枪臂铠（Dual Ranged Shot Gauntlets，DRSG），平时以护腕形态收在Yang手腕上。在需要时，臂铠可在短时间内完成变形并覆盖Yang的左右前臂。
本质:科技本质
价格:C+1000
种类:臂铠
体积:2
武器基本属性：武器伤害8L，破甲8
武器特殊属性：【格挡】
肉搏武器：本武器使用肉搏而非白刃来进行攻击判定，也视为天生武器/肉搏来发动相应技能而非白刃武器。
手持武器：臂铠占用的是手持武器位，因此手套，护腕可正常生效。即使它也处于护腕形态（见变形）
变形：本武器可以以2AP动作展开或回收成为体积1的一对护腕，作为护腕时不能作为武器使用，但也不会被发现是武器，除非目标可以获得武器内部结构（如透视），并能够制造本武器。
成对：本武器同时获得两份。
枪击：本武器在臂铠形态下，也可以作为来福枪/狙击步枪使用，但装弹量为12，武器伤害与特性等同本武器。
传动：本武器每次以来福枪射击后，能让你在下一轮结束之前的下一次以臂铠进行的攻击中获得6点增强加值，此外，你也可以消耗1发来福枪弹药，让你在一次臂铠进行的攻击中获得6点增强加值。这两者效果叠加。
双击：本武器在臂铠形态下，若成功命中触及范围内的目标并造成伤害，可以立刻以自由动作使用来福枪形态追加一次攻击。
特种弹药：本武器可以使用两种特殊弹药，一种是红色弹药，一种是黄色弹药，价格等同通常弹药，但不能再与其他特种武器混用。
红色弹药：红色弹药射程远，威力大，其射程加倍，破甲增加4点，并附加击飞特性，同时以目标为中心，产生半径5米的爆炸，范围伤害等同本武器伤害，目标不会受到二次伤害，其他目标反射豁免，被击飞至少1米的目标将同时倒地。
黄色弹药：黄色弹药射速快，可以进行连射，其获得连射，火力压制特性，并且高速优势增加8点。

Crescent Rose新月玫瑰 C+1000
新月玫瑰是一把大口径高速狙击步枪镰刀，颜色为玫瑰红色与黑色，也是Ruby所选择的武器。新月玫瑰平时通过折叠的方式收纳在Ruby的腰带背后，隐藏在斗篷里；在战斗时可以变化成狙击步枪、半长柄镰刀、长柄镰刀三种形态。在狙击步枪形态中，Ruby使用常规狙击弹，并可以通过操作在很短时间内切换到镰刀形态，其子弹威力之强，甚至能够用于加速挥砍镰刀与担当快速移动时的推进力。
本质：科技本质
种类：巨镰
体积：4
武器基本属性：武器伤害8L，破甲8,8加骰
变形：本武器可以以2AP动作转换成四种形态之一，分别是体积1的收纳形态，看起来像个方盒，无法使用除变形外的其他功能，也无法作为武器使用；体积3的狙击步枪，同同名无支线科技武器，但以本武器的基本属性替换同类属性；体积4的巨镰形态（本武器数据的基本形态），以及体积3的混合形态，混合形态下可以同时作为巨镰和狙击步枪使用，但必须具有在白刃和枪械上具有专业（新月玫瑰），否则视同没有专业般受到惩罚。
爆裂推进：以一个自由动作，消耗1发狙击步枪中的子弹，可以令本轮中以本武器作为巨镰发起的攻击中获得12点增强加值。
反冲制动：以一个2AP反射动作，消耗1发狙击步枪中的子弹，你可以移动至多等同你运动技能米距离。
一石二鸟：本武器在混合形态下作为巨镰攻击时，可以选择一个该目标之外的目标发起一次以本武器进行的狙击步枪攻击。

Gambol Shroud跃影飞绫 C+1000
跃影飞绫是Blake的武器，外形看似连鞘的阔刃短刀，抽出后内部是一把复合武器，该复合武器主体部分为一把附黑色长绫带的打刀，刀柄的扳机和刀镡上的枪口令本武器也可以作为冲锋枪使用。
本质：科技本质
种类：特殊
体积：2
武器基本属性：武器伤害8L，破甲4
武器特殊属性：8加骰，投掷时基本射程30米
复合武器：本武器可以视为弯刀（日本刀）使用，也可以视为冲锋枪使用，见基本冷兵器和同名无支线科技武器，但以本武器的基本属性替换同类属性。
回旋枪刃：本武器可以以投掷武器来投掷弯刀的方式使用，此时可以通过操纵缎带来控制投掷武器的飞行轨迹，并在投掷攻击结束后，可以以自由动作将武器收回手中。
飞绫：本武器以投掷武器方式命中时，做出下列选择之一
-立即进行一次摔拌尝试，本武器视为适合摔拌武器，且以敏捷取代力量，白刃取代肉搏发起。
-立即进行一次擒抱尝试，本武器视为适合擒抱武器，且以敏捷取代力量，白刃取代肉搏发起。
-立即进行一次移动，这次移动中你获得完美飞行速度等同你的移动速度，但移动结束后会失去而可能正常坠落，并且移动结束后，你不能比移动开始时更远离你的投掷攻击目标。

磁极双镰 C+1000
磁极双镰是rwby中戮兽猎手使用的武器，其外观是两把拥有不同极性的单镰，通过磁力，它可以将投掷出的单镰召唤回手中，也可以让自己飞向目标所在的位置，将两把单镰组合，它还将成为一把双头巨镰。
本质:科技本质
价格:C+1000
种类:巨镰
体积:4
武器基本属性：武器伤害12L，破甲12
武器特殊属性：8加骰
双头巨镰：双头巨镰也视为巨镰，若角色在白刃专业上具有双头巨镰专业，他可以以一把双头巨镰来发动原本需要手持两把武器才能发动的技艺和专长效果，此时将其视为两把相同的武器。
拆分：以一个自由动作，角色可以在手持双头巨镰时，将其拆分成两把单镰，或者在手持两把单镰时，将其组合成一把双头巨镰，拆分后的两把单镰都继承武器的数据，包括对其进行的改造，但不具有独立价格。
单镰：磁极双镰中的单镰的体积为2，失去巨镰基本模板中的双手，长柄武器特性，分类不变，武器伤害下降4L，破甲降低4点，变为9加骰。利用磁极双镰的磁性连接，单镰也可以适用本来只能以巨镰使用的效果。
灵活投掷武器：单镰能够以灵活的方式进行投掷，它既可以作为轻投掷武器使用，也可以作为重投掷武器使用，其基本射程为50米。
磁引：当你以磁极双镰中的单镰进行投掷武器攻击时，你可以在你和被攻击的目标连线的反向延长线上，与你总距离不超出你单镰最大投掷射程的范围内选择一个有固体表面存在的方格，你投掷的武器将插在那个方格上，若你这次攻击命中了目标，单镰也可以直接插在目标身上。若你手持另一把磁极双镰中的单镰且与插在方格/目标上的单镰距离不超过你单镰的最大投掷射程，你可以以一个4AP或反射动作，使用如下两种效果之一：
-你可以将那把单镰召回手中，它将同时攻击与你之间的直线上，它在飞行轨迹上遇上的第一个目标，这如同你以单镰作为投掷武器攻击了它一般，一个场景中第一次受到这种攻击的目标对这次攻击处于C级措手不及影响之下，武器在攻击完后将飞回你手中，回到手持状态。若单镰是插在目标上的，它总是会攻击它插着的目标而不是途经的第一个目标。若你和单镰之间有物体阻挡单镰移动，单镰也会攻击该物体，如同你以单镰对其发起投掷攻击一般，若攻击能成功摧毁阻挡物体，单镰能继续飞回你手中，否则它将插在该物体上。
-你可以让自己冲向单镰所在方格，若移动未被敌方生物或物体阻挡，你会直接移动到单镰所在方格，并捡起单镰，回到手持状态，若移动被生物或物体阻挡，你会停在对应的阻挡物前。

名刀电光丸
本质：科技本质
价格：C+1000
分类：短棍
描述：多啦A梦世界中的玩具武器，中有雷达可以侦测敌人的动向并自动加以攻击和防御，平时刀刃为银色，通电使用后会变成金黄色，可以引导使用者进行战斗，在对生物攻击时会自动抑制杀伤，虽然叫这个名字，但实际上确实是根棍子。
武器基本属性：等同短棍
耗能：没有通电时，电光丸就是一根武士刀造型的短棍，以一个自由动作你可以启动电光丸的所有下述效果，一枚1级能量容器可以将其视为无限能量。
电光武器：该武器启动耗能后变为金黄色，具有能量武器特性
杀伤抑制：该武器对生物造成伤害时，总是造成冲击伤害，也不会因为能量武器特性而改变伤害类型和严重程度。
自动防御：持有该武器的生物总是处于以该武器进行白刃格挡。
大师武术：以该武器进行攻击或格挡时，角色视为有15级白刃技能等级，并具有对应专业。
